## 構成と更新

- `index.html`: 本文、章の目次、講演テキストと図版。
- `style.css`: 記事・プレゼンのレイアウトとスマートフォン対応。
- `presentation.js`: 本文からのスライド構成、キーボード・全画面・ページ選択。
- `assets/`: 図版、登壇者写真、OGP画像、favicon。

外部JavaScript・外部フォントに依存しない静的サイトです。文章や図版を変更する場合は該当HTMLを編集します。サイト名・説明・入口URLを変更する場合は、同じコミットで `/catalog/` とルートREADMEを更新してください。

## プレゼンモード

記事上部の「プレゼンモード」または「プレゼンで見る」から開始します。記事本文を見出し・図版・事例ごとに区切り、1画面ずつ表示します。元資料52枚のテキスト・図版は、従来どおり記事の各章末から参照できます。

- `P`: 記事からプレゼンを開始。
- `←` / `→`、`↑` / `↓`、`PageUp` / `PageDown`: 前後へ移動。
- `Space` / `Shift+Space`: 次／前へ移動。
- `Home` / `End`: 最初／最後へ移動。
- `F` または「全画面」: 対応ブラウザで全画面表示を切り替え。
- `Esc` または「終了」: 記事表示へ戻る。全画面中のEscはブラウザによって先に全画面のみ解除されます。
- ページ選択メニュー: 任意のスライドへ移動。
- スマートフォン: ボタン・ページ選択・左右スワイプで移動。長い内容はスライド内を縦スクロールできます。

`#present=1` のようなURLで特定のスライドを直接開けます。ページを更新しても位置を復元します。プレゼンは記事の本文から生成するため、記事修正を両方へ反映できます。画面幅900px以下では通常の文字サイズを優先した縦表示、それより広い画面では16:9のキャンバスを画面に収めます。

JavaScriptやdialogが利用できない場合も記事は通常どおり読めます。プレゼン未対応環境では開始ボタンを表示しません。
