全動画はH.264（yuv420p）・30fps・AAC 96kbpsのMP4。冒頭のメタデータを先頭へ移動する `faststart` を適用しています。PC視聴を想定し、UNITEは720p、StoryMakerの画面デモは1080p、タイトルは元と同じ720pです。カット・尺変更・音声削除は行っていません。各ファイルを49MB未満に抑え、Git LFSなしで配信できる構成です。

## 構成と更新

- `index.html`: 紹介文、各動画のプレーヤー、関連リンク。
- `style.css`: トーンとレスポンシブ表示。
- `script.js`: 別の動画を再生したら、再生中の動画を一時停止。
- `media/`: 圧縮MP4と各動画から切り出したポスター画像。
- `assets/`: OGP画像とfavicon。

`preload="none"` と静止画ポスターを使用し、ページ表示だけでは動画本編をダウンロードしません。標準プレーヤーでシーク・音量・全画面表示に対応し、MP4を直接開くリンクも用意しています。元動画には字幕ファイルが含まれていないため、字幕トラックは追加していません。

動画の差し替え時は、名前・長さ・説明・ポスターも合わせて更新してください。入口やURLを変更する場合は、同じコミットで `/catalog/` とルートREADMEを更新します。ルート `AGENTS.md` のルールに従ってください。
