## 元の20案との重複整理

元の20案には、現行機構に置き換えた結果として近い攻略が残っていた。反射01・06・18、橋03・12・19、磁場04・09・14、外周移動11・16が特に近い。**[更新した20案の企画書](https://github.com/bittrove88/bittrove88.github.io/blob/review/arcline-map-redesign-handoff-20261105/ARCLINE/design/map_brainstorm/20261106_20_concepts/README.md)で、比較表と全案の空中障害の構想を確認できる。** 画像版06は「上下の射点で使い分ける反射庇」、15は「氷斜面と頭上の射撃窓」へ改題した。旧ファイル名とアイデア番号は対応を保つため維持している。

初期文章案の橋・浮島・斜坑等にも重複があるため、発展案として関係を残す。「過去にないコンセプト20件」とは扱わず、具体設計で判断が同じになる案は統合候補とする。これらは企画比較であり、実プレイでの独自性や経路成立の確認は今後行う。

## 空中障害を含めた企画更新

空中は通過するだけの空白にせず、**浮岩、短い庇、空中隔壁、反射下面、破壊可能片**で射線・転移先・遮蔽を分ける。雲C・風F・磁場M・上昇気流Uは効果領域であり、実体のある障害物の代用にはしない。

現行版の固定障害と、v2で初めて動かす障害を区別する。以下はv2を検討する際の空間構想であり、現行版へ新しい挙動を加える指示ではない。

| ID | 空中障害の構想 | 障害が加える意思決定 |
|---|---|---|
| V2-01 | 局所重力域の上と下にずらした固定浮岩 | 重力を切り替えてどちら側へ弾を通すか。全域を塞ぐ天井にはしない |
| V2-02 | 上昇経路の途中に短い庇と別高度の着地棚 | 庇の下で止まるか、端から上へ抜けるか。キャラを運ぶ効果はv2で検討 |
| V2-03 | 上空の固定庇の下で横移動する遮蔽 | 移動遮蔽の脇へ射点を移すか、開く帯を待つか |
| V2-04 | ゲート出口の先に空中隔壁と固定退避棚 | 出口直後の遮蔽と次の行動を見て、接続先を選ぶ |
| V2-05 | 固定庇と磁場で動かす金属片を別々に配置 | 金属片を射線から退けるか、自分の遮蔽として残すか |
| V2-06 | 二つの磁場の間に固定浮岩を置く | 各磁場の状態を選び、浮岩の上側と下側を使い分ける |
| V2-07 | 固定退避棚の上方に支持された破壊片 | 崩すと開く射線と落下範囲を比較する。落下予告と退避空間が必要 |
| V2-08 | 雲の中と外に短い空中隔壁を配置 | 視界の変化と実体障害を分けて読み、見通せる窓へ移る |
| V2-09 | 境界の内側に浮岩、再入場側に広い開口 | 境界を使う経路か、障害の内側を通る経路かを選ぶ |
| V2-10 | 端子で開閉する空中門と常時使える退避棚 | どの端子を操作してどの射線を開くかを選ぶ |
| V2-11 | 氷斜面の上空に高さの違う短い庇 | 滑走の停止位置と庇下の射撃角を合わせる。現行版では通常歩行 |
| V2-12 | 中央砲塔の上に庇、周囲の島間に浮岩 | 砲塔の攻撃を遮る島を維持するか、別の射角を得るため移るか |
| V2-13 | 搬送経路の上に短い梁、分岐先に別の空中窓 | 搬送される前にどちらの出口へ向かうかを選ぶ |
| V2-14 | 固定浮岩の脇に可動鏡を配置 | 鏡の状態を変えて浮岩を迂回するか、別射点から鏡を使わず狙うか |
| V2-15 | 上下の固定庇の間に高度を変える浮遊門 | 門が開ける高さと次の着地先を見て通過帯を選ぶ |
| V2-16 | 固定内殻の短い庇と動的な外側バリア | 外殻の状態に合わせて内側へ入るか、外の射点を維持するか |
| V2-17 | 横風域の先に浮岩と風下の退避庇 | 流される距離と浮岩の遮蔽を見て、風に乗るか手前に残るか |

障害の密度を一律に増やさず、それぞれが変える判断を優先する。全体を一枚の屋根で塞がず、上・下・脇に幅のある開口を残す。車体・砲口・転移着地・可動範囲の余白と、全状態での退避場所を確認する。障害を外しても攻略が変わらないなら再配置し、固定障害だけで狙いが成立するなら現行版の企画へ戻す。今回、座標データ・ラフ画像・実ゲームは変更しない。

## 初級 中級 上級への適性評価との関係

**[現行版40案の難度別精査と改善候補への適性](https://github.com/bittrove88/bittrove88.github.io/blob/review/arcline-map-redesign-handoff-20261105/ARCLINE/design/map_brainstorm/MAP_IDEA_DIFFICULTY_REVIEW_JA.md)**を参照。改善候補11面には既存ストックから有力案があり、新しい20案やv2機構の追加より、主な学びを一つに絞る簡素化・重複整理を優先する。

初級は短い移動や一回反射、中級は既知の仕組みの比較、上級は準備手数と反撃を含む位置・操作順の選択で評価する。これはEasy／Normal／Hard設定ではない。固定障害で成立する企画へ新しい物理を加えて難しくする必要はない。

本書の17候補は将来機構の保管資料であり、現行版の初級・中級へ導入を確定した教材ではない。新機構を採用する場合も、単独の作用を理解できる導入形から段階的に評価し、既存機構との複合や敵の高い攻撃圧を同時に必須化しない。G09の複数MやG19の状態別転移は、現行版での利用条件と安全な固定着地先が未整理のため保留する。

## 採用までの判断基準

1. **なぜ既存の仕組みでは実現できないのか**を説明できること。現在の地形と既存ギミックだけで攻略の核が実現できる場合は、ver2で新たな仕組みを作るより現行版での採用を優先する。
2. **プレイヤーの新しい意思決定**を具体化すること。見た目の違いだけでは採用しない。移動、射点、反撃、対象部位、手数に実質的な差が必要。
3. **実装コストと互換性を別途評価する。** 衝突・転移・弾道・破壊単位・敵AI・難易度・保存とステージ設計への影響を検討し、必要に応じて限定したステージング環境で試す。
4. **既存ステージへの無断追加禁止。** ver2機構の実装・使用許可はユーザーの個別承認が必要で、今回の資料保存自体は承認ではない。
5. **本番・既存ゲーム不変更。** v2のステージング分離方針を維持し、現在のゲーム実装やPR #65の環境PoCには影響を与えない。

**ver2向けの将来提案をここに集約し、現行マップ用企画書では可能な限り実装済みの仕組みを利用する。**
