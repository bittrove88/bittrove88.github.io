- 参照時のmainコミット：`1c38c9adc5542d37537a9072849184c80fa5f578`
- 状態：既存の難易度倍率・ダメージ倍率はゲーム本体へ実装済み。以下の追加学習AIは診断用シミュレーションまでで、ゲーム本体へは未実装。今回の更新は指示書のみ。
- 方針：本書は敵AI・照準調整の正本。追加仕様は既存の実装と分けて記述し、最小変更・最小検証を優先する。

## 1. 目的と成功率の取り扱い

ステージ後半で敵の攻撃が外れやすく、プレイヤーがほとんど敗北しない状態を改善する。一方、プレイヤー自身も敵に弾を当てにくいため、敵HPや攻撃回数を増やさず、クリア可能性と緊張感を両立する。

難易度別の**設計目標**は、ステージ81〜100における**1ステージの初回挑戦**のクリア成功率を次のとおりとする。

| 難易度 | 設計目標 |
| --- | ---: |
| Easy | 90% |
| Normal | 80% |
| Hard | 70% |

これらは机上の目標値である。今回の完了条件に統計的な実証を含めない。実測していない数字を達成済みの勝率として報告しない。100ステージ連続無敗の確率とも混同しない。

## 2. 追加変更の範囲と不変条件

### 現行実装として維持するもの

1. **ステージ別照準誤差倍率**：角度と出力の既存誤差を段階的に縮小（第3節）。
2. **難易度別照準誤差倍率**：Easy / Normal / Hardの差は敵の照準誤差のみ（第4節）。
3. **ステージ別敵ダメージ倍率**：後半のみ最大+10%。同一ステージの敵ダメージ倍率は全難易度で共通（第6節）。

### 今回新しく実装するもの

4. **近接着弾からの照準学習**：Easyには導入しない。Normalは**41〜60で弱い学習を開始**し、61以降は学習完了時に角度誤差をゼロにする。Hardは21以降で既定の学習案を維持する。実効出力誤差は学習前後で変えない（第5節）。

学習の導入を理由に敵のダメージ倍率・HP・武器・射撃回数・移動性能・プレイヤー側のHPや射撃性能を変更しない。Normal 41〜60の与ダメージ倍率増加（+15% / +25%など）は今回**採用しない**。Hardの21〜40に追加の角度誤差を残す案（50% / 75%など）も今回**採用しない**。

### 変更しないもの

プレイヤーのHP・射撃性能・弾道物理、通常敵とボスのHP、敵の攻撃回数・攻撃パターン・移動AI、地形、武器、スキル、回復・アイテム、ステージの行動回数制限、ボス部位破壊後のダメージ半減、既存セーブ・難易度別進行管理を維持する。100面の10機連戦、機体交代、現行HP70・各機の必要与ダメージ100、行動上限80を維持する。

## 3. ステージ別の既存パラメータ（変更なし）

| ステージ | 既存の照準誤差倍率 | 敵→プレイヤーダメージ倍率 |
| --- | ---: | ---: |
| 1〜40 | 1.00 | 1.00 |
| 41〜60 | 0.90 | 1.00 |
| 61〜80 | 0.75 | 1.05 |
| 81〜99 | 0.65 | 1.10 |
| 100 | 0.70 | 1.10 |

通常敵は既存の `errorAngle` / `errorPower`、ボス・中ボスは `enemyProfile` の計算を維持し、既存の最適角度・出力探索を変更しない。この表は**学習前の誤差幅**を定義する。学習後は第5節の「角度誤差の残存率」を重ねる。

## 4. 難易度別の既存パラメータ（変更なし）

| 難易度 | 照準誤差倍率 |
| --- | ---: |
| Easy | 1.40 |
| Normal | 1.00 |
| Hard | 0.65 |

学習前の実効角度誤差幅 = 既存角度誤差幅 × ステージ倍率 × 難易度倍率

実効出力誤差幅 = 既存出力誤差幅 × ステージ倍率 × 難易度倍率

**学習後の実効角度誤差幅 = 学習前の実効角度誤差幅 × 第5節の残存率**。

乱数の消費回数・順番、同一シード再現性、通常CPU / Web Workerの処理一致を維持する。角度誤差をゼロにする場合も乱数値そのものの消費を省略しない。誤差値の丸めを追加しない。

100面の学習前参考値（現行基準：角度±6°、出力±12）：

| 難易度 | 角度誤差幅 | 出力誤差幅 |
| --- | ---: | ---: |
| Easy | ±5.88° | ±11.76 |
| Normal | ±4.20° | ±8.40 |
| Hard | ±2.73° | ±5.46 |

100面で学習が成立したNormal / Hardは、通常照準の**角度誤差のみ0**となる。出力誤差は上表を維持する。特定座標で発生するボス特殊攻撃（`DROP` / `MARK` / `TRIPLE` / `PREPARE` 等）の照準・生成方法は変更しない。

## 5. 新規：敵の近接弾道学習（今回の確定変更指示）

### 5-1. 発動ステージ・学習後の角度誤差

| 難易度 | ステージ | 学習の有無 | 学習後の角度誤差残存率 |
| --- | --- | --- | ---: |
| Easy | 全ステージ | なし | 該当なし |
| Normal | 1〜40 | なし | 該当なし |
| **Normal** | **41〜60** | **あり（弱い学習）** | **25%** |
| Normal | 61〜100 | あり | 0% |
| Hard | 1〜20 | なし | 該当なし |
| Hard | 21〜100 | あり | 0% |

残存率25%とは、**従来の角度誤差幅の25%を残す**意味であり、照準角そのものを25%変化させる意味ではない。例えば学習前の角度誤差が±8°なら学習後は±2°。Normal 41〜60では学習で誤差を75%縮小する。出力誤差は一切縮小しない。

Hardの発動開始21、Normalの61以降の角度誤差ゼロは従来の検証案を維持する。Normal 21〜40への前倒しは行わない。

### 5-2. 学習成立条件

- 敵の通常攻撃の**実際の弾道軌跡**が、プレイヤーの現行の実際の当たり判定形状（楕円等）から**30ワールド座標以内**に近づくと、その敵の学習状態を成立させる。
- ダメージを与えた命中だけでなく、**ダメージゼロの近接ミス**も学習対象とする。照準計算上の推定到達点だけで判定しない。
- 複数弾ならいずれかの軌跡が条件を満たせば成立する。弾道と当たり判定の距離はゲーム内の実座標で求め、楕円の単純な中心距離を30以内とする代用判定は禁止する。
- 学習を成立させた**当該射撃は従来どおり**。学習後の精度は**次回の敵の通常攻撃から**反映する。
- `DROP` / `MARK` / `TRIPLE` / `PREPARE` のような既存のボス特殊攻撃は、学習トリガーと通常照準補正の双方から除外し、元の攻撃仕様を保つ。

### 5-3. 学習解除と再学習

- **Normal：学習後にプレイヤーの累積自力歩行距離が50座標以上**になった時点で解除。
- **Hard：学習後にプレイヤーの累積自力歩行距離が70座標以上**になった時点で解除。
- 累積距離は移動方向に関係なく各回の**実移動量の絶対値**を加算する。左右往復でも積み上がり、座標差の相殺は行わない。壁などで実際には動けなかった量は加算しない。
- 敵の自力移動では学習を解除しない。敵の新しい位置に合わせて既存の最適角度・出力探索を毎回実行する。
- 解除後は学習前の誤差へ戻り、近接条件を再び満たせば再学習できる。新しいステージ・戦闘開始時に状態を初期化する。100面の機体交代時も状態を初期化する。
- 学習状態・歩行累積値を難易度別の恒久セーブへ保存する必要はない（戦闘内の一時状態）。

### 5-4. 目安としての命中率と、行動予算の位置付け

次の命中率は**静止した相手に対する設計上の感覚値**であり、マップ・武器・機体HPが異なるため各ステージへの固定ノルマとしない。

| ステージ | Normal目安 | Hard目安 |
| --- | ---: | ---: |
| 1〜20 | 未設定 | 未設定 |
| 21〜40 | 25% | 40% |
| 41〜60 | 30% | 50% |
| 61〜80 | 35% | 60% |
| 81〜99 | 40% | 65% |

勝敗の評価では命中率だけを見ず、**プレイヤーの推奨機体HP・各ステージの行動回数上限・敵の最大反撃回数・累積被ダメージ**を併記する。通常の攻撃と反撃の交互進行なら、最大反撃回数は原則「行動上限−1」。ダメージによる敗北と行動回数切れを混同しない。

**診断結果（実装前の検証用シミュレーション）**：Normal 41〜60の代表5面×2シードでは、従来「行動上限よりHP切れが先」が0/10件。41面からの弱い学習（残存率25%）では2/10件で、累積被ダメージは増加した。全ステージでHP切れを先にすることが目的ではなく、静止・連続ミスの危険度を中盤から段階的に高めることが目的。この値を本番実測結果やクリア率と記載しない。

## 6. 敵ダメージ倍率の適用（既存仕様を維持）

敵からプレイヤーへのダメージのみに第3節のステージ別倍率を**一度だけ**適用する。敵自身への自傷ダメージ、部位ダメージ、プレイヤー攻撃、弾道・衝突判定は変更しない。難易度による別個のダメージ倍率は導入しない。

ボス部位破壊後の既存のダメージ半減（×0.5）は維持し、倍率の二重適用を防ぐ。攻撃予測と実際のダメージを一致させる。

## 7. 予測射線・難易度UI（最新の有効仕様を維持）

**最新の明示訂正を優先し、射線表示は Easy＝全軌道、Normal＝累積距離半分、Hard＝発射方向のみを維持する。** 本書旧版の「3モードとも全軌道」の記述は撤回済みとする。今回の学習AI変更では予測射線・難易度選択UI・既存のモード別保存・初回案内を変更しない。

## 8. 実装箇所と責務

- `ARCLINE/game/dist/engine.js`：`cpuPlan()` で学習状態に応じた**角度誤差残存率だけ**を反映。既存の `enemyParameters()` による角度・出力誤差、ダメージ倍率を保持。近接軌跡判定、状態の初期化、解除を必要最小限で追加する。
- `ARCLINE/game/dist/geometry.js` と既存の弾道・当たり判定処理：現行のプレイヤー当たり判定を再利用し、30座標の距離判定を整合させる。物理エンジンそのものは変更しない。
- `ARCLINE/game/dist/game.js` / `ARCLINE/game/dist/cpu-worker.js`：通常CPUとWorkerで同じ学習状態と射撃結果になるように必要箇所のみ連携する。
- 戦闘状態とキャラクター交代の処理：歩行累積距離、ステージ開始・100面交代時のリセットを整合させる。恒久セーブ形式を変えない。

生成対象ファイルがある場合は正式な編集元と `game/runtime.json` / `game/README.md` を確認し、生成先だけを手編集しない。独立した共通AIフレームワークや新たなデータ保存項目は追加しない。

## 9. 最小検証（同じ試験を大量に繰り返さない）

1. **境界値・数値：** Normal 40→41、60→61、Hard 20→21、Easyの全範囲、100面の機体交代を確認。学習後角度残存率がNormal 41〜60で0.25、Normal 61以降で0、Hard 21以降で0、未学習時は1であること。出力誤差と敵ダメージ倍率が不変であること。
2. **トリガー・解除：** 命中でない近接ミス（30座標以内）と30超の非成立を確認。学習成立射撃は従来の誤差のまま、次の攻撃から新精度になること。Normalの累積歩行49→50、Hardの69→70、往復歩行、敵の移動ではリセットしないこと、同一シード・Worker一致を確認。
3. **代表ステージ：** Normal 42・46・54・56・59のうち地形・武器が異なる**2〜3面**を優先し、各1〜2シード・20射程度の既存診断方式で変更前後を比較。追加の異常がなければ全100面は再試行しない。Hard 32の既知の早期撃破とNormal 61以降の維持を小さく回帰確認。
4. **行動予算：** 同じ代表面で推奨機体HPと実際の行動上限を設定し、「HP切れが先」対「行動切れが先」、撃破に至った反撃回数・残HPを計測。静止・反撃なしの脅威評価と、プレイヤーが攻撃して勝てるかという攻略可能性の評価を区別する。HP切れが常に先であることを合格条件にしない。
5. **ボス特殊処理：** 特殊攻撃の挙動、100面の10機交代、既存の部位破壊半減、旧セーブからの開始が破損していないかを、関連する最小ケースだけ確認する。

既に完了した25ステージ×全難易度の診断を機械的に再実行しない。大規模な総当たり・新しいテスト基盤・人間プレイヤー勝率の擬似推定は不要。試験不能な項目は未確認として明記する。

## 10. 完了条件

- Normal 41〜60で近接学習が成立し、**角度誤差が従来の25%に縮小**する。Normal 61以降とHard 21以降では学習後角度誤差がゼロ。EasyとNormal 1〜40には学習がない。
- 30座標の近接ミス、学習成立の翌射反映、累積歩行50/70による解除、敵移動後の再照準、100面交代リセットが動く。
- 既存の出力誤差、難易度別照準倍率、ステージ別ダメージ倍率、プレイヤーHP、行動上限、射線表示、難易度別セーブ、特殊ボス攻撃が保持される。
- 変更前後の代表面で、中盤Normalの被ダメージ圧力が増す傾向と、早期撃破などの過大な副作用がないかを**実測ベース**で報告する。全代表面の行動上限前撃破や、目安命中率への完全一致を必須としない。
- 既存の目標クリア率（81〜100の初回挑戦 Easy90% / Normal80% / Hard70%）は**未検証の目標値**として維持し、達成を主張しない。
