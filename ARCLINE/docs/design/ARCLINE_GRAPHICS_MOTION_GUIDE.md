# ARCLINE グラフィックとモーションのデザインガイド

ARCLINEの簡潔な画面で、技の個性、重さ、勢い、命中の気持ちよさを伝えるための判断基準。新しい技の制作、既存演出の改修、仕上がりのレビューで使う。2026年11月8日の攻撃演出改訂と、ユーザーの追加指示を基にまとめる。

**全ての技を個別に設計する。静止・スロー・加速は必要な瞬間にだけ使う。作った後は通常速度で心地よさを評価し、見直して改善する。**

## 1 形と時間で技を伝える

粒子や爆発の量を増やす前に、弾の輪郭、軌跡、変化する順番、間、速度、消え方で特徴を伝える。豪華さは要素数で決めず、技の意味が明瞭に伝わるかで判断する。

最初に「この技で最も見せたい変化」を言葉にする。重い接触、三発の連なる打撃、頂点での分裂、一点への収束、吸引から圧縮への移行など、見せ場に合わせて形と時間を組み立てる。

共通にするのは画面の読みやすさ、記述の粒度、機能を示す色、品質の基準。シルエット、動き、リズム、着弾の形まで一律に揃えない。**同じ情報量と、同じ演出は別のこととして扱う。**

## 2 各技を同じ項目で設計する

必ず「弾道」「着弾」「敵効果」を書き、時間の設計と理由を添える。前の案にあった「重い」「華やか」「煌びやか」「激しい」といった形容詞は残し、どの形・動き・間で表現するかまで具体化する。

| 項目 | 設計すること |
|---|---|
| 弾道 | 発射口、弾の数、色と輪郭、光跡、回転や分裂などの実際の移動 |
| 着弾 | 最初に見える変化、広がる方向、段階、最後の消え方 |
| 敵効果 | いつ何に当たるか、ダメージ、押し引き、遮蔽や反射との関係 |
| 時間 | 等速を保つか、どの瞬間を減速・静止・加速するか、その理由 |
| 見せ場と終了 | 一番見せたい変化と、余韻が退いて次の操作へ戻る流れ |

見た目だけでは判断できない数や範囲を、曖昧な言葉で埋めない。「三段階の爆発」と「三発の弾が飛ぶ」、「広がる絵」と「到達時に命中する波」は区別する。

## 3 静止 スロー 加速を選ぶ

三つを全技の必須セットにしない。自然な弾道や連射間隔だけで心地よく伝わる技には、追加の時間変化を入れない。等速を選ぶことも個別設計に含める。

| 手段 | 使う理由 | 外す判断 |
|---|---|---|
| 静止 | 接触や形の切り替わりを一瞬だけ読ませ、重さや変化を強調する | 毎回引っかかる、待たされる、同じ見せ場を重ねている |
| スロー | 収束・分裂・吸引など、読み取る必要のある変化に時間を与える | 全体がだれる、方向や命中の意味を変えずに尺だけ延ばしている |
| 加速 | 束になった一撃、流星の落下、圧縮後の消失などの勢いを伝える | 変化を読む前に終わる、弾や判定が飛んで見える |
| 自然な時間 | 斉射、連射、跳ね返りなど、本来の動き自体がリズムを持つ | 必要な転換点が読めない場合だけ局所的な強調を検討する |

時間変化を入れる前に「何を読ませたいか」「どこからどこまで必要か」を説明する。説明できない停止や減速は足さない。変化の前後も確認し、減速から加速へ唐突に切り替わって見えないようにする。

静止時間や倍率は技ごとに調整する。今回の数値を次の技へそのまま移植しない。停止の数を増やすより、既存の発射間隔や接触の順序を整えて解決できないかを先に試す。

## 4 色 輪郭 光跡を設計する

通常弾は機体のメインカラーを基本にする。色だけに頼らず、弾の輪郭、明るい芯、周囲との対比で、移動方向と現在位置が分かるようにする。細かな模様が読めない画面幅でも主弾を見失わせない。

複数色には役割を持たせる。ハナのパステルと金、リンの白と紫、リコの段階ごとの色と最終の虹など、配色と技の構造を結び付ける。金・白・虹を全技へ均等に配り、強調の意味を薄めない。

光跡は速度と経路を伝え、主弾より先に視線を奪わないようにする。古い軌跡を残し続けて戦場を覆わず、見せ場が終われば退かせる。高速弾は描画点の補間などで滑らかに見せ、見た目の滑らかさのために物理の判定を変えない。

## 5 着弾を技の意味に合わせる

共通の丸い爆発を全技の完成形にしない。花は開く、車輪は回転しながら成長する、リボンはしなる、流星は煌めいて落ちる、収束は一点へ集まる、重力は内側へ潰れる、といった固有の形と方向を使う。

主役の変化を補助するために閃光、煙、破片、火花を使う。接触の爆発が前方の衝撃波を隠すなら、接触側を小さくする。大きな光で対象や地形が読めなくなるなら、先に光量・広がり・残る時間を減らす。

複数段は始まり・展開・終わりが分かるようにする。三発の爆発は大きさと間で成長を見せ、最後の爆弾を強調するなら、実際の爆風の大きさと描画を揃える。余韻は次の操作や敵の予告を邪魔する前に消えるようにする。

## 6 演出の格を揃える

| 対象 | 表現の基本 |
|---|---|
| 自機の通常弾 | 機体のメインカラーと明快な輪郭。繰り返し見ても疲れない |
| 取得する補助武器 | 色と固有の挙動が分かる演出。必殺技の見せ場を奪わない |
| 自機の必殺技 | 機体固有の弾道・着弾・時間設計で個性を出す |
| 通常敵 | 弾を識別できる程度の色の違い。既存の形や挙動を不用意に変えない |
| 中ボス | 機構や材質に結び付いた専用の線・光・着弾モチーフ |
| 大ボス | 固有技と、避け方が分かる予告・弾道・着弾 |
| ラスボス | 特別な弾道変化や場の作用を明確に見せる。回避や地形の読みを残す |

格が上がるほど全画面を覆う必要はない。何が危険で、どこへ進み、いつ作用するかを読めることを保つ。複数の技を並べ、全てが同じ形・同じ間・同じ強さに見えないか確認する。

## 7 見た目と実際の作用を同期させる

波や光輪は到達時に命中し、押し引きは表示した方向へ動き、反射・分裂・収束は実際の接触や軌道変化と対応させる。これから発生するダメージを先に命中表示へ出さない。

静止・スロー・加速を使うときも、弾道、衝突、ダメージ、機体の移動、効果音の発生タイミングを揃える。描画の回数やフレームレートによって命中回数・合計ダメージ・消費数が増えないようにする。

装飾の粒子と実弾を区別する。装飾だけの火花や反射時の光輪に、説明していない命中判定を持たせない。演出の改修だけを理由に地形、保存、機体性能、敵の攻撃回数を変えない。

## 8 心地よさを評価する

**最初と最後は通常速度で見る。** 半速・停止・コマ送りは原因を調べるために使い、完成判定の代わりにしない。「狙う→発射→飛翔→命中→次の操作」の流れとして見る。

| 観点 | 確認する問い |
|---|---|
| 特徴が伝わる | 技名を読まなくても、形と動きから違いが分かるか |
| 操作に応える | 発射から作用まで自然につながり、不要に待たされないか |
| 命中が気持ちいい | 接触の瞬間が読め、音・反応・ダメージと一致しているか |
| 続けて心地よい | 繰り返し使っても停止や閃光がくどくならないか |
| 戦場が読める | 敵、自機、足場、次の予告を見失わないか |

各観点を「良い」「要調整」で判断し、そう感じた箇所と理由を短く記録する。見た目の良さで、待ち時間や判定の違和感を相殺しない。自動テストの合格を「気持ちいい」の証明に置き換えない。

演出を入れた版と時間変化なしの版を、同じ弾道・同じ画角・同じ再生速度で比較する。外れた時、壁に止まる時、反射した時、予告から移動した時も見る。小さい画面、背景の明暗差、他の技との連続使用でも確認する。

## 9 一技ずつ作り 改善する

1. 弾道・着弾・敵効果と、一番見せたい変化を定義する。
2. 実際の弾と判定を使い、一つの技として動かす。
3. 追加の時間変化なしを基準に、通常速度で見る・操作する。
4. 読ませたい瞬間に必要な形・色・時間変化だけを加える。
5. 心地よさと分かりやすさを評価し、不要な停止・光・粒子・残像を引く。
6. 判定や音との同期、外れ・遮蔽・反射、消費と結果の再現性を検証する。
7. 他の技と並べて演出の格と個性を確認し、通常速度で最終判断する。
8. 判断理由、調整値、比較方法、評価、残る課題を記録する。

一度に全技を同じプリセットへ置き換えない。問題が出た時は、まず一つの要素を変えて比較する。見せ場そのものが伝わっていない場合は、粒子を足す前に弾道・形・順序へ戻る。

## 10 今回の改訂から残す判断例

以下は0.29.0での選択例。今後の全技へ適用する数値や共通テンプレートではない。

| 技 | 残した見せ場 | 削減または描き分けの判断 |
|---|---|---|
| 破砕砲 | 重い接触から外周爆発へ解放する | 発射直後の余分な停止を削る |
| 連華砲 | 三斉射と小さな花が開く動き | 追加停止を外し、本来の斉射間隔を使う |
| 爆走砲 | 接地から車輪が走り出す勢い | 最後の余分な停止を削り、走行を途切れさせない |
| 衝撃砲 | 絡む三弾から前へ進む三波 | 丸い接触爆発を小さくし、波を主役にする |
| 流星砲 | 頂点での分裂と加速する落下 | 飛翔全体を遅くせず、分裂点だけを強調する |
| 跳弾砲 | 最終反射で虹色へ成長する瞬間 | 毎回の反射停止を外す |
| 光輪砲 | リボンのしなやかな二回転 | 着弾停止を外し、帯の展開に必要な時間を残す |
| 掘削砲 | 三実弾と成長する三爆発 | 各爆発の追加停止を外し、実際の発射間隔を使う |
| 収束砲 | 三分岐が束になる瞬間とその後の速さ | 汎用爆発を細い白紫の閃光と中心命中の光柱へ変える |
| 重力砲 | 吸引から圧縮、内向きの消失 | 外向きの大爆発を使わない |
| 終極砲 | 主弾から三つの白金の輪へ展開する | ヒバリのリボン状の回転を使い回さない |

## 11 今後の設計とレビューに使う記録欄

- 技名と、この技で伝えたい感覚
- 弾道
- 着弾
- 敵効果
- 主役の色・輪郭・方向と、補助する要素
- 時間の設計と、追加しない演出の理由
- 見せ場と次の操作へ戻る流れ
- 通常速度での比較条件と、各観点の評価理由
- 引いたもの・変えたもの・改善後の結果
- 判定・音・消費・地形との同期確認
- 未確認の条件と次に確かめること

現在の個別値は技の定義と実装記録で管理し、このガイドには判断の理由を残す。新しい知見が出たら、特定の技の数値を全体の原則へ昇格させず、再利用できる判断だけを追記する。
