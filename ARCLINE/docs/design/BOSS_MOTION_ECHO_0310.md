# ボスの移動・転移・残像：0.31.0 詳細設計

状態：制作中の矛盾補完を含め、2026-11-09のユーザー指示「検証してマージして」で最終合意済み。本検証・CI成功後にマージし配信を確認する。工程ごとの結果は [PR142](https://github.com/bittrove88/bittrove88.github.io/pull/142) とリンク先の記録を参照。基準mainは `a2234ed88c665f0d3d96201304921541787a4c48`。本仕様は今回の中ボス・大ボス・ラスボスに限って、旧PR76の「固有敵は新移動から除外」を更新する。

## 対象と定数

正本は手書き `game/dist/boss-actions.js` の `rules` と `rule()`。地形、HP、既存技の威力、照準誤差、保存世代は変更しない。

| 条件 | 中ボス | 大ボス | ラスボス100面 |
|---|---|---|---|
| 歩行開始 | 30面以降 | 30面以降 | 有効 |
| 転移開始 | 50面以降 | 50面以降 | 有効 |
| 転移上限 | 1戦闘1回 | 1戦闘2回 | 各戦場2回。最大4戦場 |
| 待ち時間 | 成功後の敵2手番 | 同左 | 同左。機体交代・戦場移行で短縮しない |
| 残像 | 生成しない | 最大1体 | 最大1体 |
| 残像弾数 | ― | 1発 | 第1/2戦場1発、第3/4戦場2発 |

徒歩は1敵手番の確定移動の絶対値合計140px。左右往復・分割・Worker経路も同じ予算。歩行速度160px/秒。浮遊型30/90面は同じ水平予算で高度を維持し、地上型へ落下させない。地続きの経路・本体・生存部位・装甲が通れる範囲だけ移動する。

## 行動の決定

1. 敵手番開始時に判定。プレイヤーの歩行中や弾の飛翔中へ割り込まない。
2. 本体と生存部位の輪郭から自機の当たり判定までの最短距離が150px以内なら接近退避。転移回数と待ち時間を満たし、双方が攻撃できる合法な退避先があれば、射線の改善量や追加抽選に依存せず転移する。
3. 接近条件がない場合は71面以降の通常敵と同じ比較・確率で、現在地/徒歩後より有利な射点への転移を選ぶ。固定ターン・HP節目で強制しない。機会を繰り返し見送った場合などの既存優先発動も利用する。
4. 転移しない場合は、その場で攻撃/徒歩して攻撃を比較する。

接近退避と射線改善は同じ回数・待ち時間を共有。コア露出、予告済み大技、残像の存在は転移を抑制する条件にしない。

転移先は現地形の上面から生成。通常敵と共通の中心間離隔（水平250px以上・実距離300px以上）、ワールド境界、支持面、衝突を守る。接近退避はさらに外縁間150pxの範囲外かつ今より離れる位置。外縁間300pxを新たな必須条件にはしない。本体・生存部位・装甲の寸法に合う場所を探索し、次の地形境界でも有効であることを評価する。浮遊型は現在高度で障害物を避ける。適切な場所がなければ通常行動。

反撃可能性は、本体HPだけでなく生存部位への有効打も含む。自機が自由歩行で向き直れることを評価し、転移前の砲口方向だけで背後への転移を除外しない。通常敵側の判断は変更しない。

## 転移の確定

- 転移弾の表示用軌道が目的地へ到達した時点で、移動・回数・待ち時間を一度だけ確定する。出発時の仮確認ではライブ状態を更新しない。
- 同一手番で歩行・本体射撃を追加せず、自機へ手番を渡す。失敗時は回数を消費せず再計画する。固定先への無限再試行はしない。
- HP、生存/破壊部位、露出期間、弱体化を引き継ぐ。装甲・部位の実体形状と向きも移動先へ更新する。
- 転移で予定の攻撃順を進めない。予告済み攻撃は標的とともに保持する。
- 30/90面の旧固定横揺れは新しい判断移動に置換し、転移直後に旧座標へ戻ったり、140pxに上乗せされたりしないようにする。部位破壊・フェーズ・雲などの既存変化は残す。

## 残像の状態と命中

大ボス/ラスボスの転移成功時、旧位置とその時点の部位・向きを記録した残像を1体生成。ゲーム内の別ユニット、HP、部位HP、遮蔽物、接地面にはしない。

残像は次のプレイヤー手番中に攻撃を1回受けると消える。直撃・爆風・光輪/衝撃波・地面を伝う攻撃を、実際の軌道/作用範囲と遮蔽で判定する。非攻撃の転移弾では消えない。命中イベントは残像IDと時刻を持ち、HP・数字・音と同じイベント適用経路で消去する。

残像への接触は弾道、弾の残威力、本体へのダメージ上限を消費せず、その先の弾は進む。残像への命中では本体HP・部位・最終戦担当量・報酬を増減しない。世代の異なる残像へ古い弾のイベントを適用しない。

## 残像の砲撃と手番

1. 生成直後の敵手番には撃たない。
2. 次のプレイヤー手番で歩行→攻撃/転移/修復等が完了するまで残る。歩行だけ、照準時間、ポーズの時間では発砲しない。
3. 本体撃破・担当量達成による機体交代・戦場移行・敵手番スキップは砲撃より優先し、残像を消去する。
4. 生存した残像は次の敵手番の冒頭に、残像位置から、その時点の自機を狙って通常砲撃を行う。本体の通常弾と同じ照準計算・難易度/ステージ誤差・防御/遮蔽を使い、固有大技と生成時の固定標的は使わない。
5. 火力は本体通常弾の25%/発、爆風半径80px。威力と防御効果を計算した後に残HP上限を適用し、低HP時の過小ダメージや表示の過大ダメージを防ぐ。後半2連射は開始時に1回だけ照準し、同じ角度/威力で0.2秒間隔。発射後は追尾しない。Guardは残像・本体の双方に有効で、本体の攻撃完了まで消費しない。
6. 残像は発砲して消滅し、発射済みの弾は着弾まで処理する。その後に同じ敵手番で本体を計画・行動させる。残像が地形を変えた場合は更新後の世界で本体を再計画する。
7. 残像は本体の攻撃順、再転移待ち時間、徒歩予算、自機の行動数・在庫を消費しない。本体の1行動だけで敵手番を終了し、待ち時間を1進める。
8. 残像発砲時に本体の予定が固有大技なら通常弾へ置換し、大技を次の攻撃手番へ持ち越す。予定が通常の攻撃ならその予定を実行し、通常どおり攻撃順を進める。残像を壊した場合は、この持ち越し制限は発生しない。

## 100面の進行と再試行

戦場はリレー番号から0〜3を求め、HP由来の3段階フェーズと混同しない。転移上限は戦場ごとに2回。3機ずつ交代する同じ戦場では回復せず、次の戦場で使用回数のみを再設定する。待ち時間は引き継ぐ。

既存の機体交代時再配置は転移に数えず残像も作らない。交代時に残像と古い予告位置を消去し、同じ戦場の攻撃順を保持して新しい機体へ標的を設定する。新戦場では既存どおりその戦場の攻撃順を開始する。

出撃時スナップショットへ残像、転移使用数、待ち時間、保留中の攻撃を含め、再試行時に同じ状態へ戻す。永続保存schema8/reset2は変更しない。現行mainの自機HP100、担当Normal/Hard150・Easy80、各20行動を維持し、以前の会話/資料のHP70等を復活させない。

## 演出

- 転移・残像砲撃の標的線、着弾範囲、カウント、溜め予告は追加しない。既存の本体大技の予告は維持する。
- 元のボス描画をマスク化した青系の半透明シルエットを旧位置へ残す。待機中の不透明度は一定。弱い二重輪郭と少量の光片のみで、HP/部位マーカー/接地影は付けない。
- ラスボスの第1戦場は青＋細い金輪、第2は青紫、第3は暗い核、第4は金白。残像の塗りは46%、補助輪郭は22%から調整する。
- 発砲時だけ砲口を光らせ、短い発射音を鳴らす。本体の砲口を誤って光らせない。
- 破壊時は電子音と約0.2秒の光片。発砲時は亀裂から崩れ、後半2発目の発砲まで姿を残す。新しい全画面閃光、停止、スロー、操作待ちは追加しない。
- 残像も自動カメラの撮影対象とし、特に小画面で旧位置が横へ切れないようにする。地形の大きな高低差は既存のマップ確認も利用する。reduced motionでは漂う光片を停止する。

## 制作中に見つけた矛盾への補完

| 観察 | 改善 | 採用仕様との関係 |
|---|---|---|
| 残像を普通の敵攻撃として解決すると攻撃順/手番/CDが二重に進む | 補助攻撃フラグと同じ敵手番への継続経路 | ターン不要を成立させるための実装補完 |
| 通常敵の反撃評価は本体HPだけを見る | 部位ダメージと向き直りもボスの反撃評価へ含める | 発動機会を不必要に減らさない |
| 大型本体と装甲を一般機の小さい接地判定だけで移すと埋まる | 実寸判定、向き連動、現地形から細かく候補探索 | 不正配置を防ぎ、正当な候補を拾う |
| 60面の装甲下部は既存の支持斜面と接している | 支持地形との下部26pxの接触は維持し、装甲上部と他の壁・天井への侵入を拒否 | 既存姿勢を不正として移動候補を消さない |

| カメラは本体と自機だけを追うため残像が横へ切れる | 残像の輪郭もフレーミングへ追加 | 攻撃対象を実際に見えるようにする |
