# ARCLINE｜ステージ1〜50 マップ変更指示書

**2026年11月4日確定／設計承認済み・ゲーム未実装**

## 1. 最上位決定と対象範囲

**ステージ1〜50のマップ設計を承認済みとして確定する。ステージ51〜100の再設計案は全件不採用・破棄し、新しい設計は別案件で行う。**

ここで破棄するのは、これまで作成した51〜100面の**未実装の新マップ案・全100面の配分案**のみ。実ゲームに既にある51〜100面、現行の4戦場・10機リレー最終戦、ゲーム進行・セーブデータは絶対に削除・巻き戻ししない。

この指示書を作ることと、設計を承認することは、実ゲームを変更・公開する権限を与えるものではない。実装着手・本番デプロイは別途明示指示を受ける。

## 2. 最終採用の座標データ

同梱の **`ARCLINE_STAGES_001-050_APPROVED_FINAL.json`** を、今回の50面に関する採用地形の一体型データとする。これは最新ローカル比較HTML（`ARCLINE_map_review_001-060_v4_fixed.html`）内の**1〜50面だけの改訂後データ**を抽出し、ステータスを設計承認済みに確定したもの。51〜60面は取り込んでいない。

JSONには面番号、名称、マップ幅、床区間・分断、屋根・壁・浮島、個別破壊フラグ、ギミック、開始位置、試用アイテムを収録。旧設計書の途中案と矛盾する場合、本採用JSONを優先する。元データに存在しない物理仕様を推測で補わない。

ステージごとの敵性能、ボス部位・HP、武器・スキル、行動制限、報酬は現行ゲームの正本から継承し、地形改訂のために変更しない。

## 4. エンジンへの必要変更

1. **床・浮島の反射板W**は、実際の床・支持面と一体になるよう衝突材を設定。狙える長さ・位置と反射後の敵への経路を確認。
2. **天井下面の反射**は現行Wでは作動しない。8・35・40面の下向き反射用に、法線と反射材の指定・当たり判定・見た目を実装する。
3. **大型結晶K**は現行の約110pxに対する設計上の1.8倍（約198px）。描画だけではなく物理判定も拡張し、岩・屋根と重ならないようにする。
4. **開閉橋B**には40面用の下へ開く動作が必要。閉状態／開状態の物理衝突、通行、射撃を一致させる。
5. **破壊可能な壁と屋根**は、連結一体の見た目と約100pxごとの実際の個別破壊単位を混同しない。破壊後の空間と射線・移動を実測。
6. **分断した床と独立支持面の出撃**は、浮島・洞窟上からの安全な出現、BLINKの着地、足場の維持を実装・検証。
7. ステージ幅を変更した場合も、カメラ、マップ端、行動数、徒歩移動上限140px/ターンと整合を取る。

## 5. 絶対に変更しない仕様

* **ステージ51〜100の現行ゲーム地形・部品・ギミック・敵・武器・報酬・行動制限は差分ゼロ。** これらの新設計JSONは取り込まない。
* 100面の4戦場・10機固定リレー・各機HP70・各機の本体100表示ダメージ・80行動・距離800px以上、難易度別保存と章進行を保持。
* 1〜50面でも敵AI・攻撃精度・HP、ボス部位・攻撃、キャラクター・武器・スキル・報酬は既存実装を保持。
* 本番向け生成元は `ARCLINE/design/expedition_013/stage_blueprints.json`。`game/dist/` のみの直修正は禁止。

## 6. 実装指示（実装を別途許可されたときに実行）

1. `main`にある現行100面のゲーム地形・敵・セーブ形式のスナップショットを作成し、専用実装ブランチを切る。
2. 本採用JSONから**1〜50面だけ**をゲームの地形正本へ変換し、ジェネレーターから配布資産を生成。
3. 下面反射・大型結晶・下降橋・浮島出撃・破壊単位の必要機能を整備する。未実装機能を見た目だけで擬似的に「実装完了」としてはいけない。
4. 1〜50面の初期位置と射線、各破壊ブロック、ギミック反射・風・雲、移動とクリア可能性を検証。
5. ゲームの**51〜100面は現行と実際の地形・部品・ギミックが一致**することをデータ比較と実プレイで検証。
6. `npm ci`、`npm test`、`npm run check:generated`、`npm run test:browser`、`npm run build`を実施し、未実施・失敗・成功の区別を記録。
7. 変更差分とテスト証跡をPRに記し、別途公開指示がある場合のみマージ・デプロイする。

* 実ゲームの51〜100面は撤去も巻き戻しも行わない。
