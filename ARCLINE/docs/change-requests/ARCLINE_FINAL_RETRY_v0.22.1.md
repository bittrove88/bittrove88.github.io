# ARCLINE 最終戦のキャラ別再挑戦（0.22.1）

2026-11-04の追加依頼。対象はステージ100のみ。従来の各機必殺1発・全体80行動を今回の範囲で更新する。

1. 固定順10機は全員、出撃時に必殺技3チャージ。HP70・各機の本体への必要ダメージ100・4戦場・交代演出・最後ガンを維持。
2. 各機の行動上限は90面と同じ28回。キャラID別の設定を持ち、交代時に使用数を0へ戻す。28回目の達成でも敗北させず交代し、未達成なら行動切れ。
3. 敗北画面に「このキャラから再挑戦」を追加。出撃時のHP70・必殺3・28行動を復元し、そのキャラの担当ダメージを0へ。それまでの達成済みキャラは保持。
4. 持ち物・敵のHPと装甲・戦場の破壊状態も当該キャラの出撃時点へ戻す。遅延CPU応答と入力を破棄する。
5. 先頭からの再挑戦も残す。キャラ別再挑戦は同じ戦闘内の敗北画面から行い、永続セーブ形式・難易度別進行・タイトル帰還／リロード時の面開始チェックポイントは変更しない。
6. 他99面・地形・物理・敵AI・ダメージ係数・音源・エンディングは維持。STG・学習AI・新しいマップ案は含めない。

検証：全10機の3チャージ・28行動、最終行動での交代、各戦場のキャラ別再挑戦、既存セーブ不変、日英・小画面の実操作。実機と公開状態は別に報告する。
