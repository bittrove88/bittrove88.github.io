# ARCLINE サイト・ゲーム演出への反映 v0.21.0

2026-11-03の「全て反映」という明示依頼を、直前の8項目の提案に対応づける。共通コンセプトは「日常が壊れる。仲間と出会い、一射ずつ道をつなぎ直す」。既存ストーリー本文・承認素材・結末を再定義しない。

| ID | 反映対象 | 受け入れ条件 |
|---|---|---|
| PX-01 | サイト冒頭 | 承認済みの日常→暗転→分断の画像→ロゴ。プレイを待たせず、1回の短い導入後は静止 |
| PX-02 | ムービー導線 | ヒーローに既存promoへのリンク。クリックで視聴し、音声の自動再生はしない |
| PX-03 | 攻略デモ | 既存の実エンジン軌跡・着弾を強調。反射・破壊・転移の結果を捏造しない |
| PX-04 | 仲間・風景 | 仲間選択の飛行トランジション、海辺→火山→要塞の実画面切り替え。結末を追加開示しない |
| PX-05 | 開始・プロローグ | 既存ロゴと光の線を開始画面へ。分断の場面で短い暗転。本文・既読・時計・終了条件は維持 |
| PX-06 | 加入 | 承認済み透過切り抜きが斜め進入し、減速・停止。名前と紹介を順に表示。スキップ・失敗時Canvas・保存を維持 |
| PX-07 | ボス登場 | 戦場全体→ボスへ寄る→名前→通常カメラ。最大3.2秒、スキップ可能。操作許可前に戻し、低モーションではカメラ移動と待ち時間なし |
| PX-08 | 章クリア | 結果に次章の実際の地形と章名、光の経路を表示。次章の加入や映像は既存の順序。最終面に次章は出さない |

勝利曲についての追加確認と新たな音源配置を受け、[勝利BGM正本](ARCLINE_VICTORY_BGM_CHANGE_REQUEST_v1.0.md)のVB-01〜07も実装する。採用②のSHA256一致を必須とし、9大ボス勝利・加入・30/60幕間・全曲ループ・次戦切替・100面除外を検証する。0.19.3以降は選択済み面も通常キャンペーンであり、廃止した練習分離を復活させない。

保存schema8/reset2、物理・弾道・ダメージ・AI・100面の地形・加入順・既存URLは維持。iPhone OSの向きや未反映の0.20.1試行は変更しない。動きを減らす設定、日英、画面寸法、入力とフォーカス、配布ZIP、生成一致を検証し、実機未確認は明記する。
