## 0. 意図と確定／検討中の区別

目標は、通常弾無制限の100面砲撃ゲームにおいて、有限の武器とスキルを「取得・使用・温存」できる長期的な選択肢へ変えること。単なる自機近くの補給ではなく、弾で狙い取る小さな攻略目標にする。一方、ロジックの複雑化や新しい位置選択操作を避ける。

**確定済み**
1. スキルの種類はレア3＋通常12＝15種類。名前と基本効果は本書第1章。
2. 補助武器の最終構成はレアなし12種類。標準弾（W01）・機体固有必殺技・転移弾は別枠。
3. 武器とスキルの未使用残数は大ボス撃破後もリセットしない。章を越えて蓄積・利用できるようにする。
4. カプセルの区別は武器＝オレンジの横長弾薬型、通常スキル＝シアンのひし形、レア＝金色の紋章型。色だけでなく形を変える。**各アイコンの下にその武器／スキルの名称を表示する**。
5. 位置固定・自機近傍への一律配置を避け、地形に応じた取りやすい位置を選ぶ。マップ内の位置指定操作をスキル使用に追加しない。
6. スキル効果の特別な回数制限は設けない。特にレア3種類は所持残数があれば同一戦闘中も再利用できる。

**検討中の設計値（採用前に最終判断を要する）**
1. 取得1回の補充量：武器・通常スキル・レアスキル共通で**2回分**。以前の「スキル3回分」と「武器1回分」を比較した結果の推奨案であり、現時点でユーザーの最終承認待ち。
2. 100面の取得量：武器40か所、通常スキル30か所、レア6か所。通常スキルは当初24か所から6か所追加した推奨案。合計76回の取得機会（武器40＋通常30＋レア6）。最大供給量は武器80発、通常スキル60回、レア12回。何も拾わない面も残す。
3. 同種の所持上限6回分、種類による所持枠制限なし（武器12種・スキル15種すべて保管可能）。UI上の表示枠数は実所持制限にしない。
4. ユーザーが挙げた武器12種類（既存9、新規3）を有力候補として整理。二波雨弾のみソラ必殺派生として残し、誘導雨弾・絨毯雨弾は不採用。転がる弾は継続、反射・跳弾系は候補外。第5章を参照。
5. マップ内の個別座標、弾道到達性、スキルの一部の行動消費、全体攻撃の基礎ダメージ値。

### 配置位置の考え方

現在の武器は x=24付近、既存スキルは x=20 に偏っている。全マップで自機近傍へ固定しない。

- 近距離25%：チュートリアル・補給向け
- 中距離55%：基本弾で少し調整して狙える主流配置
- 遠距離20%：地形を読む意義があるが、極端な高所や敵の背面は避ける

位置はマップごとに固定し、ランダム出現させない。基本弾で取得可能な軌道が存在すること、地形・ギミック・キャラクターと重ならないこと、複数アイコン同士が重複しないこと、Hardで理不尽な精密操作にならないことを必須受け入れ条件とする。

**計画座標をコピーするだけでは不可。** 30面の地形改訂、動的ギミック、敵配置、移動後の位置変化を反映し、各面の現行弾道シミュレーションによって到達性・見やすさ・取得のしやすさを実測してから確定する。武器・スキル同時配置面の位置は十分に離す。

### 5.2 ソラ派生の整理

- 継続：**二波雨弾だけ**。現行のソラ必殺技「Meteor Rain」は8個の子弾が降る。派生版では**3＋3の2波を位置・時間でずらす**。単なる8個の小型コピーにしない。
- **誘導雨弾・絨毯雨弾は類似しすぎるため不採用**。候補12種類に加えない。
- 弾幕による高命中期待は狙い付近の範囲カバーによる。完全必中にはせず、射角・出力・障害物の制約を残す。全体必中スキル「全体攻撃」と明確に区別。
- 6子弾の威力・間隔・ダメージ上限・ボス部位と最終100面への適用は実射シミュレーションを経て確定。子弾を個別にボスに重ねて制限値を突破しない。

### 5.3 似た武器をどう区別するか

| 似て見える組 | 差別化の仕様案 |
|---|---|
| **空中広範囲爆発** / **空中炸裂弾** | 前者は**弾道頂点付近で自動爆発**し、非常に広い爆風・低〜中威力。後者は**敵の近くで接近信管が作動**し、中範囲爆発・比較的高威力。爆発位置の決定条件を変える。名称「空中広範囲爆発」は説明的な仮称で、短いUI名への変更余地あり |
| **重榴弾** / **空中広範囲爆発** | 重榴弾は**着弾点**を中心とした大きなダメージと地形破壊。空中広域版は**空中**で広がり、複数地点の範囲を覆うが最大単体ダメージは控えめ |
| **転がる弾** / **地走り弾** | 前者は**物理的な弾本体が接地後に転がる**。後者は**地表を伝播する波状攻撃**。斜面・障害物・隙間・床上ギミックへの判定を別定義 |
| **扇状弾** / **分裂弾** | 扇状弾は**砲口から即3方向**。分裂弾は**飛行中に分かれ、渦状／螺旋状に広がる**。見た目だけでなく実際の衝突軌道も変える。処理負荷・予測可能性に注意 |
| **分裂弾** / **二波雨弾** | 分裂弾は横に旋回・拡散、二波雨弾は上空から時間差の落下。分裂タイミング・方向・届く場所を別にする |
| **吸収弾** / **応急処理・完全修復** | 吸収弾は敵への実ダメージがあって初めて回復する攻撃。地形破壊や空振りでは回復しない。回復割合・上限は別途調整し、回復スキルの希少性を損なわない |

### 5.4 命中率と遊びやすさ

- 命中しやすい主力候補：二波雨弾、空中広範囲爆発、扇状弾、空中炸裂弾、地走り弾。**高確率の数値保証ではなく設計意図**であり、マップや照準誤差に応じて実測する。
- ピンポイント系：レール弾、吸収弾、打ち上げ弾。全弾が高命中ではなく、用途の幅を優先する。
- 連射弾は発射時の時間差、分裂弾は飛翔中の螺旋、二波雨弾は上空での時間差。三者が同じ見え方にならないようにする。
- 武器の操作は既存の射角・チャージ・射撃のみ。手動の照準先選択、追加ボタン、弾頭操作などを増やさない。
- すべて1回発射すると武器残数1を消費。複数発・多段攻撃も**補助武器の1発分**として扱う。
- 現行の各武器ごとの爆風・クリティカル・地形破壊・ボス最大ダメージのバランスに対し、過剰な多段ヒットを防ぐ。

### 5.5 今回の候補から外す武器

優先的に外す：W05 ホッパー、W06 跳弾、W08 低空跳弾、W20 ピンボール。転がる弾W07は残す。

その他の新アイデア（二段爆破弾、連鎖火炎弾、くさび弾、フリーズ弾）も**今回の有力12種には不採用**。別途の明示採用まで復活させない。
