## 0. 意図と確定／検討中の区別

目標は、通常弾無制限の100面砲撃ゲームにおいて、有限の武器とスキルを「取得・使用・温存」できる長期的な選択肢へ変えること。単なる自機近くの補給ではなく、弾で狙い取る小さな攻略目標にする。一方、ロジックの複雑化や新しい位置選択操作を避ける。

**確定済み**
1. スキルの種類はレア3＋通常12＝15種類。名前と基本効果は本書第1章。
2. 補助武器の最終構成はレアなし12種類。標準弾（W01）・機体固有必殺技・転移弾は別枠。
3. 武器とスキルの未使用残数は大ボス撃破後もリセットしない。章を越えて蓄積・利用できるようにする。
4. カプセルの区別は武器＝オレンジの横長弾薬型、通常スキル＝シアンのひし形、レア＝金色の紋章型。色だけでなく形を変える。**各アイコンの下にその武器／スキルの名称を表示する**。
5. 位置固定・自機近傍への一律配置を避け、地形に応じた取りやすい位置を選ぶ。マップ内の位置指定操作をスキル使用に追加しない。
6. スキル効果の特別な回数制限は設けない。特にレア3種類は所持残数があれば同一戦闘中も再利用できる。

**検討中の設計値（採用前に最終判断を要する）**
1. 取得1回の補充量：武器・通常スキル・レアスキル共通で**2回分**。以前の「スキル3回分」と「武器1回分」を比較した結果の推奨案であり、現時点でユーザーの最終承認待ち。
2. 100面の取得量：武器40か所、通常スキル30か所、レア6か所。通常スキルは当初24か所から6か所追加した推奨案。合計76回の取得機会（武器40＋通常30＋レア6）。最大供給量は武器80発、通常スキル60回、レア12回。何も拾わない面も残す。
3. 同種の所持上限6回分、種類による所持枠制限なし（武器12種・スキル15種すべて保管可能）。UI上の表示枠数は実所持制限にしない。
4. 既存の補助武器13種から2種を外し、未配置の分裂弾を採用する仮12種。新案も含めて精査し、最終武器リストは後日確定。
5. マップ内の個別座標、弾道到達性、スキルの一部の行動消費、全体攻撃の基礎ダメージ値。

細部：防壁ではなく**バリア**、砕路は廃止。バリア（自機）と敵火力低下（敵）を別効果とし、同時使用時はそれぞれ乗算で軽減する。例：元100→敵火力低下で60→バリアで30。無敵なら0。低重力と高重力は後使用を優先して上書き。ⅠとⅡは別スキル／別残数。攻撃前に1タップで発動し、位置・ターゲット選択は増やさない。持続中の効果はステージを越えて残さず、未使用回数のみ持ち越す。

全体攻撃のダメージ値、ボス各フェーズの弱点・部位・最大ダメージへの具体的な配分、回復系の行動消費／エフェクト時間、他スキルの行動消費、既存の必殺チャージと必殺補充の相互作用は**実装前の詳細仕様確定・テスト対象**。全体攻撃を無条件にボス本体へ通してパズルや100面の進行を壊さない。

削除・不採用：未来予測、照準ジャマー、弱点露出、出力妨害、反動増幅、偽装標的、砕路、移動封鎖、一斉破砕、地盤修復、自動防壁、全面反射、仮設足場、風向操作、磁場生成。旧「砲撃遅延」は敵スキップへ置換。旧「弾薬複製」は必殺補充へ置換。

## 4. 途中出現・取得位置

### 途中出現（推奨）

カプセル計66個のうち、**20個だけプレイヤー2ターン目開始時に出現**させる。残り46個は開始時から見える。中ボス撃破報酬10回は独立。

- 武器10面：9,19,29,39,49,59,69,79,89,99
- 通常スキル4面：9,48,58,98
- レア6面：18,28,38,68,78,88
- その他のカプセル：ステージ開始時から配置。新規追加の通常スキル6カプセルは開始時表示。

開始時は出現予告、プレイヤー2ターン目開始時に色別の短い落下・発光演出、着地後はステージ終了まで残る。出現前に撃破した場合は、未出現カプセルをクリア時に補償取得できる仕様案（特にレアを取り損ねさせない）。再プレイや途中中断で無限に複製しないよう、一度だけの取得台帳と進行保存に連動する。

### 配置位置の考え方

現在の武器は x=24付近、既存スキルは x=20 に偏っている。全マップで自機近傍へ固定しない。

- 近距離25%：チュートリアル・補給向け
- 中距離55%：基本弾で少し調整して狙える主流配置
- 遠距離20%：地形を読む意義があるが、極端な高所や敵の背面は避ける

位置はマップごとに固定し、ランダム出現させない。基本弾で取得可能な軌道が存在すること、地形・ギミック・キャラクターと重ならないこと、複数アイコン同士が重複しないこと、Hardで理不尽な精密操作にならないことを必須受け入れ条件とする。

**計画座標をコピーするだけでは不可。** 30面の地形改訂、動的ギミック、敵配置、移動後の位置変化を反映し、各面の現行弾道シミュレーションによって到達性・見やすさ・取得のしやすさを実測してから確定する。武器・スキル同時配置面の位置は十分に離す。

## 6. 実装前に詰める項目と互換性

1. 武器の12種正式選定。新案を入れるか、W15急降下等を試すか。採用名称・効果・各面に登場する順序・弱点を一覧で確定。
2. 1取得2回の共通化、所持上限6、所持種類制限撤廃を最終承認。武器は「2発追加」であって「残弾を2に上書き」としない。上限時は無駄になったことが明確に分かるUIにする。
3. 既存保存の武器・スキル・取得台帳、章ボス後のリセット、難易度別進行、クリア済み面選択時の在庫、100面の機体リレー、リトライを調査。残数を無断初期化しない移行方法を示す。旧保存を新上限へ移す際の挙動を検証。
4. 100面の途中出現と、物資未出現のままクリアした場合の補償。消費した弾でカプセルを射抜いたときに取得可能になる順序と、ステージを戻した際の台帳重複を検証。
5. 新15スキルの攻撃・HP・重力・行動スキップの例外を既存の敵AI、地形、必殺、ボス各段階に対応。Easy/Normal/Hardの射線表示は現行のEasy全軌道、Normal半分、Hard方向表示を変更しない。
6. カプセルラベルの視認性、3種の外形差、レアの過度な発光、プレイ中のヒット判定をPCとスマホ横画面で確認する。
7. 実装時は生成元を更新し、game/runtime.json に従って生成物を再生成。npm test、npm run check:generated、必要なブラウザー・シミュレーション検証を実行。実機・公開・アップロードと区別して結果を報告。
