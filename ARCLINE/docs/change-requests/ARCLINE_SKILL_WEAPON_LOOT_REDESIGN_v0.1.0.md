## 0. 意図と確定／検討中の区別

目標は、通常弾無制限の100面砲撃ゲームにおいて、有限の武器とスキルを「取得・使用・温存」できる長期的な選択肢へ変えること。単なる自機近くの補給ではなく、弾で狙い取る小さな攻略目標にする。一方、ロジックの複雑化や新しい位置選択操作を避ける。

**確定済み**

**今回の追加決定：** マップ配置は武器20・通常スキル20・レア3種×2＝46個。出現は開始時またはプレイヤー5ターン目、3種の形状区別と常時表示名を必須とする。取得座標は候補で、P3の承認済み1〜50面を参照し弾道確認後に確定する。具体的には第3・4・8〜11章が旧提案に優先する。
1. スキルの種類はレア3＋通常12＝15種類。名前と基本効果は本書第1章。
2. 補助武器の最終構成はレアなし12種類。標準弾（W01）・機体固有必殺技・転移弾は別枠。
3. 武器とスキルの未使用残数は大ボス撃破後もリセットしない。章を越えて蓄積・利用できるようにする。
4. カプセルの区別は武器＝オレンジの横長弾薬型、通常スキル＝シアンのひし形、レア＝金色の紋章型。色だけでなく形を変える。**各アイコンの下にその武器／スキルの名称を表示する**。
5. 位置固定・自機近傍への一律配置を避け、地形に応じた取りやすい位置を選ぶ。マップ内の位置指定操作をスキル使用に追加しない。
6. スキル効果の特別な回数制限は設けない。特にレア3種類は所持残数があれば同一戦闘中も再利用できる。

**検討中の設計値（採用前に最終判断を要する）**
1. 取得1回の補充量：武器・通常スキル・レアスキル共通で**2回分**。以前の「スキル3回分」と「武器1回分」を比較した結果の推奨案であり、現時点でユーザーの最終承認待ち。
2. （旧配分は失効）武器40・通常30・レア6の推奨案は、今回指定の**武器20・マップ通常20・レア6**へ更新済み（第3章）。中ボスクリア報酬10回は地図配置の数に含めない。
3. 同種の所持上限6回分、種類による所持枠制限なし（武器12種・スキル15種すべて保管可能）。UI上の表示枠数は実所持制限にしない。
4. ユーザーが挙げた武器12種類（既存9、新規3）を有力候補として整理。二波雨弾のみソラ必殺派生として残し、誘導雨弾・絨毯雨弾は不採用。転がる弾は継続、反射・跳弾系は候補外。第5章を参照。
5. マップ内の個別座標は46候補を第3章で記録し、弾道到達性は未実測。スキルの行動消費・全体攻撃の基礎ダメージは第9章に今回の設計案を記録。

全体攻撃のダメージ値、ボス各フェーズの弱点・部位・最大ダメージへの具体的な配分、回復系の行動消費／エフェクト時間、他スキルの行動消費、既存の必殺チャージと必殺補充の相互作用は**実装前の詳細仕様確定・テスト対象**。全体攻撃を無条件にボス本体へ通してパズルや100面の進行を壊さない。

削除・不採用：未来予測、照準ジャマー、弱点露出、出力妨害、反動増幅、偽装標的、砕路、移動封鎖、一斉破砕、地盤修復、自動防壁、全面反射、仮設足場、風向操作、磁場生成。旧「砲撃遅延」は敵スキップへ置換。旧「弾薬複製」は必殺補充へ置換。

## 4. 出現タイミング・取りやすさ・取り逃し

1. 出現パターンは **(A) ステージ開始時** と **(B) プレイヤー5ターン目開始時** の2種類だけ。敵ターンやショット数を「5ターン」と数えない。Aは34個、Bは12個（武器6、通常6）。レア6個はすべてAとし、貴重な報酬の取り逃しを防ぐ。旧「2ターン目に20個出現」という案は失効。
2. Bは5ターン目の照準操作開始前に予告→出現→当たり判定を有効化し、位置は固定。出現後は戦闘終了まで残る。5ターンに満たず勝った場合は、Bに該当するその面のアイテムを**クリア確定時に1回だけ補償付与**する。5ターン目以降に取得できた／取得済みの場合は二重付与しない。敗北・途中離脱では無償付与しない。所持上限で入らない分は既存の選択・保留UIの導線へ送り、取得台帳は確実に重複防止する。
3. 武器・通常スキルは**自機横へ固定しない**。基準は自機から敵までの進行方向の中盤（目安：距離の25〜65%）。自機側への偏りより、初手〜数ターンの**通常弾が敵へ向かう主な射線／自然な移動ルート**との近さを優先する。無理な逆向き射撃・敵背後への長距離移動・極小の高所を要求しない。今回の46候補の数値と地形は静的な案であり、未検証項目は受け入れ前に修正する。
4. レアは普通の主射線から少し外した**追加の攻略目標**とする。ただし取れない場所、不可視の足場、完全に遮蔽された部屋は不可。通常弾またはBLINK等の現行合法手段で到達可能な具体的ルートを残し、敵を倒す前に現実的に回収できるようにする。
5. アイコンの実取得判定は種類共通で半径**22px**を維持する。図柄のサイズ・輝度・ラベル高さを当たり判定の拡大として扱わない。敵機体、HP、照準UI、地形、他のカプセルの名称、ギミック表示を重ねない。マップカメラ移動中もラベルと図柄が同じ座標に追従する。
6. 1〜50面では承認マップの壁・浮島・天井下面の反射・大型K結晶・可動橋の**実物理が導入された後**に座標を検証する。51〜99面の現行地形を新案へ差し替えない。各候補について、標準弾の初期位置からの射路／必要なら最大1回の現行合法移動後の射路、景観と文字の重複、5ターン目時点の戦闘状態を確認。未計測の「自然に取れる」は合格としない。
7. 3種の図柄は**武器＝オレンジの横長弾薬、通常＝シアンのひし形、レア＝金色の二重枠紋章**。アイコン中央は武器／スキルごとの固有シンボル。**全アイコンの直下に日本語名を常時描画**し、英語環境では英語名に切替。背景に強い縁取りと必要に応じて不透明ラベル地を付け、最小横画面で原則2行以内。単なる色違いは不可。発生時は図柄と名前を同時表示し、視認可能な短い演出後も取得できる。

### 5.2 ソラ派生の整理

- 継続：**二波雨弾だけ**。現行のソラ必殺技「Meteor Rain」は8個の子弾が降る。派生版では**3＋3の2波を位置・時間でずらす**。単なる8個の小型コピーにしない。
- **誘導雨弾・絨毯雨弾は類似しすぎるため不採用**。候補12種類に加えない。
- 弾幕による高命中期待は狙い付近の範囲カバーによる。完全必中にはせず、射角・出力・障害物の制約を残す。全体必中スキル「全体攻撃」と明確に区別。
- 6子弾の威力・間隔・ダメージ上限・ボス部位と最終100面への適用は実射シミュレーションを経て確定。子弾を個別にボスに重ねて制限値を突破しない。

### 5.3 似た武器をどう区別するか

| 似て見える組 | 差別化の仕様案 |
|---|---|
| **空中広範囲爆発** / **空中炸裂弾** | 前者は**弾道頂点付近で自動爆発**し、非常に広い爆風・低〜中威力。後者は**敵の近くで接近信管が作動**し、中範囲爆発・比較的高威力。爆発位置の決定条件を変える。名称「空中広範囲爆発」は説明的な仮称で、短いUI名への変更余地あり |
| **重榴弾** / **空中広範囲爆発** | 重榴弾は**着弾点**を中心とした大きなダメージと地形破壊。空中広域版は**空中**で広がり、複数地点の範囲を覆うが最大単体ダメージは控えめ |
| **転がる弾** / **地走り弾** | 前者は**物理的な弾本体が接地後に転がる**。後者は**地表を伝播する波状攻撃**。斜面・障害物・隙間・床上ギミックへの判定を別定義 |
| **扇状弾** / **分裂弾** | 扇状弾は**砲口から即3方向**。分裂弾は**飛行中に分かれ、渦状／螺旋状に広がる**。見た目だけでなく実際の衝突軌道も変える。処理負荷・予測可能性に注意 |
| **分裂弾** / **二波雨弾** | 分裂弾は横に旋回・拡散、二波雨弾は上空から時間差の落下。分裂タイミング・方向・届く場所を別にする |
| **吸収弾** / **応急処理・完全修復** | 吸収弾は敵への実ダメージがあって初めて回復する攻撃。地形破壊や空振りでは回復しない。回復割合・上限は別途調整し、回復スキルの希少性を損なわない |

### 5.4 命中率と遊びやすさ

- 命中しやすい主力候補：二波雨弾、空中広範囲爆発、扇状弾、空中炸裂弾、地走り弾。**高確率の数値保証ではなく設計意図**であり、マップや照準誤差に応じて実測する。
- ピンポイント系：レール弾、吸収弾、打ち上げ弾。全弾が高命中ではなく、用途の幅を優先する。
- 連射弾は発射時の時間差、分裂弾は飛翔中の螺旋、二波雨弾は上空での時間差。三者が同じ見え方にならないようにする。
- 武器の操作は既存の射角・チャージ・射撃のみ。手動の照準先選択、追加ボタン、弾頭操作などを増やさない。
- すべて1回発射すると武器残数1を消費。複数発・多段攻撃も**補助武器の1発分**として扱う。
- 現行の各武器ごとの爆風・クリティカル・地形破壊・ボス最大ダメージのバランスに対し、過剰な多段ヒットを防ぐ。

## 8. 武器12種の直撃ダメージ・複数弾仕様（追加の実装設計値）

**小弾の最低有効直撃値**：子弾を持つ二波雨弾は**1子弾直撃18**、扇状・分裂は**1子弾直撃16**、連射は**1発直撃18**を基準とする。第一波が空振りでも第二波の子弾が1個だけ直撃すれば18を与える。子弾3個の合計を先に固定し均等割りする旧方式を新設計では用いない。爆風だけが触れた場合は減衰後の値とし、**全弾外れへの自動命中・無条件ダメージ保証は設けない**。

**上限・重複禁止**：上表は単一標的への1射内の合算上限。直撃・爆風・多段・重複当たりは1つの射撃記録で集計して一度だけ適用する。敵弱点の既存倍率と、ボスの部位破壊前の本体保護、フェーズ遷移、最終100面の機体別必要与ダメージ・上限は優先する。各ボス部位の個別HPに対して弾数を水増しして突破しない。火力アップⅠ・Ⅱは個別ヒット計算の前に掛けるが1射上限を突破させない。相手の敵HPを超える回復は吸収弾に計上しない。

**二波雨弾の着弾設計**：第1波3発を主な照準点中心・左右差で、短い遅延後の第2波3発をその着弾域の隙間を補う位置へ落下させる。これは時間差と散布を利用した**命中しやすさ**の設計であり追尾・自動必中ではない。子弾は6つとも衝突判定を持ち、1発当たり18表示。既存のソラ必殺8発・最大45表示を無断で強化・上書きしない。両波の実射で「最初の3発全外れ、後半1発だけ直撃」の回帰テストを必須とする。

**攻撃スキルの例外**：全体攻撃は画面上に敵が1体でもいるなら使用できるが、ボス部位を飛び越えて本体へ通さない。ボス部位への表示20は「部位HP」を削るもので、本体HPへの別加算はしない。残HPより大きなダメージは実HP減少量として数え直す。複数敵の追加が将来あっても敵ごとの上限を共有しない。

**持続と行動消費の採用案**：持続バフは各自／敵ターンの開始・終了で一度だけカウントし、未使用回数は章を跨いでも在庫に保持するが効果そのものは戦闘終了で消去する。スキルは自ターンに1回まで。既存の応急処理の1行動消費を維持し、完全修復・全体攻撃は各1行動消費案、その他は0行動（射撃前に使用可能）案とする。実装では敵反撃の発生条件と行動上限の扱いを確認する。追加の敵攻撃を無断で発生させない。
