# ラスボス固有技の変更案 — 2026-11-09

基準はmain `a2234ed`、0.30.4。PR140の攻撃、PR138の移動表示、PR141の在庫・クリア継承を保持する。次版の番号・キャッシュ更新は最終合意と先行マージを確認してから確定する。

## 依頼と具体案

- 星環砲は「1発当たりのダメージを2倍にするとどう？」への比較案。本弾20→40、衛星4→8を3発、合計上限32→64。弾道と弾数は維持する。
- 重界砲は「少し余裕のある軌道」。高い放物線を優先し、屋根で通らない配置では低い放物線を選ぶ。速度係数1.1・重力係数0.65、上向き55〜74度／低い側-8〜54度から実地形を使って選ぶ。予告時点の位置・姿勢を固定し、発射の照準ぶれを加えない。発射前後に移動した自機を追い直さず、地形衝突と着弾36、重力領域の双方への作用を維持する。
- 終極砲は追加依頼により、旧主弾と光輪を廃止し、地形を無視する太いレーザーへ変更する。前の自機ターンに固定したX座標へ、次の敵手番で上から縦に照射する案。幅320px、38ダメージを一度だけ適用。0.18秒後に照射し0.62秒で消える。通常歩行の1ターン上限140pxでは逃げ切れず、テレポートで帯の外へ離脱する。遮蔽では防げない。照射時の追尾と継続ダメージは加えない。防御・無敵・残りHPへの制限は適用する。

HP100・担当150（Easy80）・20行動・必殺3・6手の順番・機体交代と出撃時点の再挑戦を維持する。他99面・地形・取得物・保存・自機攻撃・転軌砲は対象外。

## 実装と表示

正本は `design/attacks/definitions.json`。`enemy-attacks.js` と `engine.js` が重界砲の予告固定の照準を選び、`physics.js` が終極砲の一度だけの接触を作る。`render.js` の予告帯と `effects.js` の実ビームは同じ幅320を使う。照射の演出時計は等速にし、旧主弾の静止と三波の演出を外す。既存SFXを照射時に同期し、音源は追加しない。本編・CPU Worker・攻撃確認モデルと単体HTML・マップ総覧の共有コードへ反映する。

## 限定的な事前確認

制作中の比較であり、本検証や人の勝率の証拠ではない。

- 星環砲：Normal/Hard×3seedの第1戦場だけを実入力で比較。6条件とも第2戦場へ到達。固有技18回の外れ込み平均は9.9→19.8、実測最大56。設定上限64は100HPに対して重いので、最終採否の対象とする。
- 重界砲：現行版の実到着状態を元に3機の射線を確認。その場に残ると36、予告後の合法な歩行で0。移動先の傾斜も照準へ読み直さない。
- 終極砲：追加の「ほぼ移動ではなくテレポートが求められる」を受け、初案の幅100→320へ変更。現行地形のガン到着状態から、その場・左右の上限140px歩行は38、左右約230pxへの合法な転移弾は着地に成功して0。予告は歩行や転移後の位置へ追従しない。画面の案内も「テレポートで離脱」へ更新。初案の幅100で歩けた旧記録は履歴として区別する。本編Controllerと実CPU WorkerでもPC/小画面の6場面で居座り38・歩行38・転移0と次入力を確認。[今回の事前確認](../../evidence/final-teleport-preview-20261109/PLAN_AND_RESULT.json)。
