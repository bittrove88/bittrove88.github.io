## 最新の合意と依頼

- 星環砲は「上限は固定、単発は増加」。本弾20→40、衛星4→8を3発、合計上限は32のまま。上限64の試作は採用しない。
- 重界砲は地形を越える高い放物線を優先し、屋根で通らない配置では低い放物線を選ぶ。粗い探索が命中候補を見落とした場合だけ近傍を細かく再探索する。速度係数1.1・重力係数0.65、上向き55〜74度／低い側-8〜54度から実地形を使って選ぶ。予告時点の位置・姿勢を固定し、照準ぶれを加えない。移動後の自機を追い直さず、地形衝突・着弾36・重力領域の双方への作用を維持する。
- 終極砲はアークハートの砲口から伸びる直線レーザー。本体の描画高に近い太さ110pxの射線全体に命中判定を持ち、手前・奥を問わず重なれば38ダメージを一度だけ適用。予告地点だけの点攻撃にしない。予告時の足元側（自機中心から下へ52px）を狙う直線を固定し、地形を貫く。射撃開始から砲口で0.5秒ため、予告地点まで0.3秒で届く等速で伸ばす。到達時にダメージを与え、予告対象または命中位置への到達から0.62秒保持し、0.18秒で減衰する。転移先を追い直さず、防御・無敵・残りHPへの制限は適用する。
- 終極砲の流れはユーザーの「それで良い」を受領。レーザー直前の通常砲撃ターンにアークハートがチャージを始め、固定した点線を出す。文字と塗り帯は表示しない。プレイヤーのチャージ開始には連動しない。転移先を狙う通常砲撃がそのターンにあり、次の敵手番で古い線へレーザーを照射する。
- 発射時の「ド派手な演出」と、参考画像のような螺旋・根元の直角解消の追加依頼により、細い砲口から滑らかに広がる輪郭、白金の鋭い芯、その前後を巻くオレンジの螺旋を実装する。砲口へ集光してから先端が急伸し、光の衝撃波・光片と発射直後0.14秒の短い揺れを添える。判定幅と38ダメージを演出で増やさず、停止・スローは入れない。動きを減らす設定でも先端とダメージの到達時刻を揃え、螺旋の回転・揺れ・光片・衝撃波を省く。既存の重い発射音とビーム音を照射に同期し、音源は追加しない。

[詳細設計・変更前後の比較・同期の改善判断](ARCLINE_FINAL_PROJECTILES_DETAIL_20261109.md)を参照。演出の形は維持し、最新依頼により「砲口で0.5秒ため、予告地点へ0.3秒で到達」へ変更する。

HP100・担当150（Easy80）・20行動・必殺3・機体交代・再挑戦を維持する。他99面・地形・取得物・保存・自機攻撃・転軌砲は対象外。

## 攻撃順

通常4手・固有2手の6手ループは維持する。第4戦場のみ、直前のDROPをARCへ変更する。

| 戦場 | 6手 |
|---|---|
| 1 | LOW → ARC → 星環砲 → DROP → TWIN → 星環砲 |
| 2 | REFLECT → ARC → 転軌砲 → TWIN → DROP → 転軌砲 |
| 3 | CURVE → MARK → 重界砲 → ARC → TWIN → 重界砲 |
| 4 | TRIPLE → ARC＋レーザーチャージ → 終極砲 → TWIN → ARC＋レーザーチャージ → 終極砲 |

通常砲撃に固定命中率の抽選はなく、現在位置を狙う照準の角度・威力にぶれを加える。したがって転移先にも当たり得る。レーザーだけが前のターンに固定した線を使う。

## 正本と共有実装

`design/attacks/definitions.json` が威力・攻撃順の正本。`enemy-attacks.js` がチャージ開始時の線を `finalBeamCharge` へ保持し、直前の通常砲撃と次のレーザーへ引き継ぐ。実際のレーザー解決でチャージを消す。機体交代・戦場移行・出撃時点への再挑戦は既存の戦闘状態に従う。

`physics.js` の共通の線分形状を予告と実ビームで共有する。`render.js` の点線は文字なし・塗りなしで、通常の射線表示より控えめに描く。`effects.js` が発射時だけ砲口から広がる輪郭・白金の芯・前後を巻く螺旋・先端の急伸・発光と衝撃波を描く。`render.js` が発射直後の短い揺れを加える。`attack-motion.js` は等速。既存SFXを照射時に同期する。本編・CPU Worker・攻撃確認モデル・単体HTML・マップ総覧を同期する。
