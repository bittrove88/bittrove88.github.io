# ARCLINE 追加変更指示 v0.17.0

2026-11-02（日本時間）の追加依頼。既存のv2.2.0実装に対する変更です。以下の範囲では最新のユーザー指示を優先し、それ以外のセーブ・公開URL・承認素材・エンディングの自動進行などの制約を維持します。

## ユーザーの追加指示原文

> ボス戦はボスごと必ず曲を最初からかけること。大ボスクリア後の次の面でも曲を最初からかけること。
>
> 初回スタート時一番最初にホーム画面への追加方法を案内。 その後、開始画面ではじめる。のみ表示し開始したのちにプロローグとする
> 機体変更がわからないためメニューのわかりやすいところに移動。
> ノーマル、ハードモード等の選択時 照準、威力は固定でゲージ表示なし 再試行もなし試撃のみ また横向きにすると画面が潰れる対策して
> ストーリーモードは1章単位で選択可能にし1面ごとの選択機能はなくす1章単位でプロローグから10面クリアまで 次11-20までみたいにして章単位で自動再生されるようにしてプロローグ、ストーリー表示、仲間追加全て全画面に切り替えること
>
> ヒバリとリコの加入タイミングを逆にする。
>
> また最序盤以外にも平地が多すぎるため、完全な平地は最序盤のみとし、バリエーションを作る。平地だけど一部崖で途切れてるとかほんの少しの段差とか障害の山があるとか

添付のSafari横画面では、難易度画面の試撃操作部が下へ切れ、描画も縦に圧縮されていました。

## 確認済みの範囲

章単位の自動再生について、ユーザーは「ストーリーの連続再生のみ（推奨）」を選択しました。戦闘の開始・面選択の仕組みはこの追加要求の対象に含めません。

## 要求と受け入れ条件

| ID | 変更 | 確認条件 |
|---|---|---|
| AD-01 | ボスごとにBGMを先頭から | 中ボス・大ボス・100面の開始、同じBOSS曲の別ボス／再戦で0秒開始。大ボス後の11/21…91面も通常曲を0秒開始。音源・選曲そのものは維持 |
| AD-02 | 初回導線 | 追加案内→単一の「はじめる。」→クリック後のプロローグ。既存・途中保存を消さず、不必要に初期化しない |
| AD-03 | 機体変更メニュー | HPカードの隠れた操作をポーズメニューの明示項目へ移動。操作可能な手番だけ変更し、HP割合・弾数・行動・在庫を維持 |
| AD-04 | 固定試撃と横向き表示 | 同じ照準・威力で3難易度を比較。調整ゲージ・再試行を除去。実試撃後にのみ既読を保存。6画面サイズ・回転で操作が届き、描画の縦横比が等しい |
| AD-05 | 章の連続再生・全画面表示 | 各章のクリア済み台詞・加入・既存映像を順に自動再生。個別の面の再生選択を除去。第1章はプロローグから10面、第2章は11〜20面。全100台詞・9加入・4映像を保持。回想で保存・編成・進行を変更しない。エンディングの手動禁止は維持 |
| AD-06 | 加入順 | リコ25面、ヒバリ30面。過去に得たヒバリ、装備、加入途中の旧25面ヒバリ／30面リコの記録も維持。推薦機体に未加入のヒバリを使わない |
| AD-07 | 地形の変化 | 最序盤以降は完全に平らで連続した床を残さず、起伏・小段差・切れ目を増やす。既存の敵HP・AI・物理・装置・持ち物・100面を維持し、実戦と安全配置を再検証。古い地形の攻略証拠を新しい合格と扱わない |

実装・検証結果は [0.17.0記録](../releases/0.17.0.md) に分離します。実機、公開URL、CI、Pages、ローカル検査は区別して報告します。
