# 大ボス固有技の弾道と既存照準誤差の調整案

基準は main `a2234ed88c665f0d3d96201304921541787a4c48`、ゲーム0.30.4。2026年11月9日の依頼「当てにくい場所など動いていない状態なら命中率50%くらい」「弾道仕様の調整でもともとの命中補正のなかで」に対応する制作中の候補。その後のユーザーの「プレイヤーが移動した後とかも考慮しシミュレーションし考慮もれないかチェック」という指示に基づき、移動後を含む限定本検証まで実施。CI、版数更新、PR、マージ、公開は未実施。

## 目標と採用している方法

Normalで射線が通る静止位置を狙った場合、当てにくい位置でも約半数が命中することを目安にする。見通しのよい位置ではそれ以上になる。Easy1.40／Normal1.00／Hard0.65の既存誤差倍率を保持する。命中率を直接抽選する処理、命中・失敗の弾道プール、移動後の自機を追う処理、壁を無視する命中処理は追加しない。

通常の射角・威力誤差に掛ける `aimErrorScale` を技の正本に置き、既存の `cpuPlan` で使用する。通常敵、中ボス、大ボスの基本技、ラスボスはこの調整の対象にしない。AIの乱数消費は従来の3回。

雲裂砲は初速・重力・爆風範囲を調整し、高い頂点での三分裂を維持して遠い予告地点へ届くようにする。挟撃砲は上下22pxからの2発を正本のvolleyへ移し、独自の再照準を外す。照準探索と発射が同じ2発、同じ風・重力・衝突を使う。発射間隔0.18秒、1発の威力0.55、1敵行動の上限は保持する。

## 編集元と連動先

- `design/attacks/definitions.json`：7技の既存照準誤差係数、雲裂砲の弾道、挟撃砲の2砲口の位置と間隔。
- `game/dist/engine.js`：通常大ボス固有技だけ既存誤差へ係数を適用。
- `game/dist/physics.js`：volleyの省略可能な砲口Y差分。未指定の武器は従来どおり。
- `game/dist/enemy-attacks.js`：挟撃砲だけの発射直前の再照準を廃止。
- 生成先：`attack-catalog.js`、攻撃確認の単体HTML、全100面総覧の埋め込み。同じ物理・照準を本編、Worker、確認画面で使う。

地形、HP、行動上限、技の発動周期、ダメージ上限、部位破壊の半減、保存・取得物・最終リレーは保持する。灼熱砲と空襲砲は今回の精度調整を行わない。

## 制作中の事前確認

最初の2ラウンドを同じ実入力相当の射撃と実際の敵反撃で進め、3ラウンド目の固有技を確認する。通常の開始位置に加え、左右の歩行上限まで移動できる足場を予告開始位置として使う。調整に使っていない128seedの射角・威力誤差で確認する。Normalのガン、同じ開始手順での標本であり、全連続座標・全機体・全地形状態の証明ではない。

再現ツール：`node game/tools/probe_boss_ballistics.cjs 10 20 30 40 50 60 80`。必要なら `ARCLINE_EVIDENCE_DIR` へ入力ソースのSHA256と観察結果を保存する。このツールは制作中の観察用で、本検証の合格判定を出さない。

候補の[観察結果](../../evidence/boss-ballistics-candidate/OBSERVATIONS.json)。開始位置・左右の3位置のうち、命中数が最も少なかった位置を示す。分母は各128seed。

| 固有技 | 最も当てにくかった標本位置の命中数 |
| --- | ---: |
| 潮撃砲 | 61/128（48%） |
| 挟撃砲 | 56/128（44%） |
| 雲裂砲 | 67/128（52%） |
| 分光砲 | 61/128（48%） |
| 穿岩砲 | 58/128（45%） |
| 氷嵐砲 | 76/128（59%） |
| 極性砲 | 62/128（48%） |

この標本での最も難しい位置は概ね半数。比較的容易な位置では高くなる。別の開始手順・完全な遮蔽・異なる地形状態まで一律の確率にはしない。

実画面の限定確認：`node game/tests/boss-ballistics-browser.test.cjs --preview`。20・30・60・80面の難しい足場で、静止時の実命中、予告後の実歩行、Workerとメインの計画、HP減少、次の操作への復帰を60fpsで確認する。追加検証指示に基づき、PC/小画面・30/120fpsの本検証も実施した。

[限定ブラウザ確認の記録](../../evidence/boss-ballistics-candidate/BROWSER_PREVIEW.json)は4位置×静止／歩行の8ケース。実命中時にHPが減り、予告後に退避方向へ140px歩いたケースはダメージ0、Workerとメインの計画が一致し、次の自機手番へ復帰した。雲裂砲・極性砲は別方向へ歩くと被弾が残ったため、退避方向も確認して記録した。全方向への歩行で必ず回避できるという意味ではない。

## 本検証の候補と完了条件

`verification-plan.json` に候補を登録する。新しい `boss-ballistics` は実マップの到達性、静止位置での命中頻度、予告後の回避、砲口、遮蔽、乱数3回、部位破壊と実HPを扱う。`enemy-evolution` は既存の通常敵・中ボス・基本技、技の上限と予告を確認する。`final-attacks` は対象外の最終戦を保護する。ブラウザは `boss-ballistics-browser` に絞る。

追加された検証指示の範囲で必要な検査と生成物一致を実施した。完了条件は、選んだ難しい静止足場で命中が概ね半数、予告後に移動すれば回避できること、実命中とHP、次の自機手番、Workerの一致を満たす。全100面の再攻略、音声、保存移行、エンディングを一律に再検査しない。

今回のレビュー対象はローカルの調整案。リリースする場合は最終合意した内容で版数・キャッシュ・更新案内を揃える。マージと公開には今回有効なユーザー指示が必要。


## 移動後の追加検証と修正

全9体の[284条件・1,542射](../../evidence/boss-ballistics-candidate/PLAYER_MOVEMENT.json)を30/120fpsで確認した。歩行の大小・上限・往復、移動無制限、機体変更、実転移の遠距離／高所／急斜面／ボスの反対側／失敗、歩行後の転移、遮蔽破壊、部位破壊、防御、低重力・高重力、残HP1/5、敵スキップ、勝敗による反撃停止、6・9ラウンドの環境変化を含む。5つの実在する破壊可能な足場では、自機が落下した状態まで確認した。単なる任意座標への移動だけで転移成功を代用しない。

発見して修正した内容：

1. ボスの反対側へ転移すると、砲口が移動後の自機へ向き直っていた。通常大ボスの固有技だけ、予告地点から発射方向を決める。
2. 急斜面への転移後の傾きが照準探索へ入っていた。予告時の位置・傾きを保存し、当たり判定と同じ中心を使う。照準探索も保存した姿勢へ戻して計算する。
3. 足場破壊後、予告帯だけが落下後の高さへ移っていた。描画も予告時の世界座標へ固定する。5つの足場の落下前後を実Canvasで確認した。
4. 残HP1でも20などの被ダメージを表示していた。通常大ボス固有技も残HPで計上量を切り、HPとイベント・数字を一致させる。
5. 潮撃砲の波150では開始位置からの徒歩範囲に完全回避点がなかった。波を90へ短くし、静止時の最難標本48%を保持して歩行での退避を可能にした。波以外の火力・上限は保持する。

[実転移と残HPのブラウザ確認](../../evidence/boss-ballistics-candidate/MOVEMENT_BROWSER.json)は37ケース。[足場落下時の予告帯](../../evidence/boss-ballistics-candidate/WARNING_BROWSER.json)は10ケース。既存の28ケースと合わせてブラウザ75ケースを扱い、潮撃砲の変更に関係する4ケースだけ追加で再確認した。[検証の集計](../../evidence/boss-ballistics-candidate/VALIDATION.json)。生成155件は2回の隔離再生成と一致した。

[歩行距離の追加走査](../../evidence/boss-ballistics-candidate/WALK_GRID_BEFORE_TIDE.json)は各技の最初の固有技で、照準誤差0・10px刻み。潮撃砲だけは変更前150の記録であり、[90との比較](../../evidence/boss-ballistics-candidate/TIDAL_WAVE_COMPARISON.json)と[実ブラウザ再確認](../../evidence/boss-ballistics-candidate/TIDAL_BROWSER.json)を併記する。空襲砲は[1px刻みの確認](../../evidence/boss-ballistics-candidate/SKY_WALK_FINE.json)で左71〜87pxに安全位置があった。最大距離まで歩くと隣の爆弾へ入る場合がある。移動方向・距離・遮蔽によって、回避、被害の軽減、別の弾への被弾が変わることを区別する。

連続する全座標・全操作列を網羅した証明ではない。記録した条件では、予告の追尾、HPの重複適用、30/120fpsの結果差、Workerの差、次手番へ戻らない問題は残っていない。ラスボスと既存の敵攻撃の保護検査も成功した。今回の指示は検証までであり、マージ・公開は行っていない。
