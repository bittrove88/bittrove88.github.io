# ARCLINE 追加指示 v0.17.1

## ユーザーの依頼原文

> 開始画面にセーブを削除機能をつける
> プロローグ、エンディング横向き表示時のみ再生可能とする

## 対象と受け入れ条件

| ID | 対象 | 条件 |
|---|---|---|
| SL-01 | セーブ削除 | 初回開始画面と既存のタイトル画面から削除確認を開く。取り消した場合は記録を変更しない。明示的に確定したときだけ攻略記録を初期状態へ戻す。保存失敗は元の記録を保持して再試行可能。未読のクラウド保存は消さない。過去の書き込み・二重操作で古い記録を復活させない。言語・操作配置・インストール案内と他アプリの保存を保持 |
| SL-02 | 横向き再生 | プロローグとエンディングの初回／章の回想で、横向きのときだけ再生。縦向きでは回転案内を表示し、映像・文字・音楽を停止、操作を無効にする。横向きへ戻ると同じ位置・セッションから再開。SDK・バックグラウンド等の別の一時停止を解除しない。PCの縦長ウィンドウにも適用。30面・60面の幕間や加入・章台詞は対象外 |

最新の明示依頼として、以前の「はじめる。」だけの開始画面に削除操作を加え、以前は再生できた縦画面のプロローグ／エンディングを停止します。それ以外の保存形式、進行、100面、機体性能、承認素材、公開URL、エンディングの手動送り禁止は維持します。

実装と検証は [0.17.1記録](../releases/0.17.1.md) に分離します。自動テスト、CI、Pages、公開画面、実機確認を区別して報告します。
