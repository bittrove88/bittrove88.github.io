# ARCLINE 任意マップカメラ v0.20.0

## 依頼

サイトとゲーム演出の提案は保留。先に、プレイ中にマップ全体を見渡して任意にカメラを動かす機能を追加する。射角・操作性に不具合を生じさせない。

## 実装範囲

- プレイヤーの照準中に、画面上部の「マップ」から見渡しモードへ入る。チャージ中、弾の飛行中、敵の手番、教材、結果、別画面では開始しない。
- 入ると全地形・領域・設置物・アイテム・自機・敵を含む全体表示。ドラッグで移動し、＋／−で拡大縮小。「全体」で表示を戻す。「戦闘に戻る」またはEscapeで終了する。
- PCは矢印キーでカメラ移動、＋／−で拡大縮小、0で全体表示。マウスホイールはカーソル付近を基準に拡大縮小する。タッチはドラッグと画面ボタンを使用し、複数指でブラウザ拡大や発射を起こさない。
- 見渡し中は戦闘進行と戦闘入力を停止し、照準角、威力、選択中の転移・武器・スキル、機体の位置・傾斜、HP、所持数、ターン、弾数を変更しない。BGMは継続する。
- 通常画面のドラッグ照準と見渡しのドラッグを分離。戻る際は入力を解放して通常カメラを即時復帰し、手動のズームをチャージ用カメラへ持ち込まない。
- 画面回転・サイズ変更で全体へ再フィットする。縦向き制限とSDK等のホスト停止を尊重し、復帰しても射角を変えない。タッチキャンセル、フォーカス喪失、画面変更でドラッグを解放する。
- 日本語・英語、キーボードフォーカス、44px以上の操作ボタン、モバイルのセーフエリアを扱う。

## 維持すること

物理・弾道・全機体共通の基本重量・明示された武器効果・敵AI・100面の内容・セーブschema8/resetVersion2/保存キー・進行・解放・BGMの選曲規則・公開URLは維持する。カメラ状態を攻略セーブへ保存しない。保留したサイト・映像演出を同時実装しない。

## 検証と完了条件

- 全100面、大小の表示領域で全体フィット・パン制限・ズーム復帰を検証する。
- 実Chromiumのマウス／タッチ、日英、568×240を含む横画面、回転、ページの表示倍率に対して検証する。
- 斜面上でカメラ操作前後の通常弾・転移弾の軌道、射角、状態・保存が一致することを確認する。
- 見渡し中の複数指・矢印・Spaceで戦闘が動かず、終了後に照準と一度のチャージ／発射が正常なことを確認する。
- `npm test`、`npm run check:generated`、関連ブラウザ・正式配布の検証を行う。実施した結果と未確認事項を実装記録へ残し、PR、CI、Pagesの状態を区別して報告する。

## 最新追加依頼：常に横向き、スマホの右側が上

- 任意の固定モードではなく、ゲーム画面は常に横長の配置で表示する。オン／オフや方向反転の選択は設けない。
- スマホの物理的な右側が画面上部になる向きに統一する。端末が縦長なら90度、端末が逆向きならネイティブ回転角も考慮して補正する。
- 縦向き判定でもゲーム・プロローグ・エンディングを同じ横長の論理画面で継続し、回転案内のために停止させない。OSの画面回転ロックAPIに依存しない。
- 元の横向きレイアウト・表示倍率・セーフエリア・動きを減らす設定を扱う。回転後のポインター座標と要素の範囲を論理画面へ逆変換し、射角と物理は変更しない。
- 回転切替では入力をキャンセルし、勝手に発射しない。SDK・バックグラウンドなどの独立した停止は解除しない。
- 向きは保存設定へ依存せず、新規起動でも常に横向き。攻略記録や端末内の好みへ新しい保存を追加しない。
- 縦長3サイズの実Chromiumタッチで90／逆90／180度、照準・カメラ・発射、メニュー、回転、再読み込みを検証する。ネイティブ向きの試験用値と物理iPhone Safariの確認は区別する。

## 縦向き用の残存処理の整理

最新の常時横向き要求に伴い、使わなくなる縦向き専用CSS、回転案内画面、関連翻訳、向きによる停止理由、画面監視を削除する。端末の実際の向きを検出する処理と、SDK・バックグラウンド停止は必要なので維持する。セーブや原素材・サイトのレスポンシブ表示は変更しない。

## 追加変更指示（2026-11-04）：iPhoneの時刻・バッテリー表示と横向き固定の干渉

実機スクリーンショットで、横向きに回転したARCLINEの背後にiOSの縦向きステータスバー（時刻・Dynamic Island・バッテリー等）が残る問題を報告。OS側のバーはCSS回転で隠せないため、起動形態・実際のOS表示方向を判定し、ネイティブ方向が利用可能なら優先、利用できなければセーフエリア内で横長画面をフィットさせて重なりを防止する。WebのみでOSステータスバー完全非表示を保証しない。詳細な実装箇所・禁止事項・iPhone実機検収は [ARCLINE iOSステータスバー追加変更指示書 v1.0](ARCLINE_IOS_STATUS_BAR_LANDSCAPE_ADDENDUM_v1.0.md) を正本とする。**指示書の登録のみでゲーム実装は行わない**。
