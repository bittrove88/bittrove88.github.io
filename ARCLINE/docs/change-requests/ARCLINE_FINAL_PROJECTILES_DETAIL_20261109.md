## 2 終極砲の予告と確定範囲

**命中範囲は、砲口から発射方向へ伸びる太い射線全体。** 予告地点だけの点攻撃や円形爆風にしない。予告地点は向きと伸長速度の基準であり、命中位置をそこだけに限定しない。手前でも奥でも自機が射線に重なれば命中し、射線から外れれば回避する。地形は遮蔽に使えない。

1. 直前のARCが予告されるプレイヤー手番で、アークハートがチャージを始める。ここで自機中心から下へ52pxの位置を狙う軸を、砲口から確定する。
2. 軸の両側55pxに、文字なし・塗り帯なしの控えめな点線を表示する。自機のチャージ操作には連動させない。
3. プレイヤーが移動・転移・攻撃する。ARCはその結果の自機位置を狙い、既存の照準ぶれを適用する。固定確率の命中抽選は加えない。
4. 次のプレイヤー手番でも同じレーザー予告線を維持する。次の敵手番では、その線に照射する。移動・転移後の位置へ軸を引き直さない。
5. 照射後にチャージ情報を消し、TWINまたは次周期のTRIPLEへ進む。

`enemy-attacks.js` が線・対象位置・発射予定の周期を `finalBeamCharge` に保持し、`physics.js` の `beamGeometry` を予告と実ビームで共有する。射撃中はプレイヤー操作を受け付けない。今回の減速は発射を見せるための調整で、発射後の反射的な回避を追加しない。

## 3 終極砲の時間設計

時刻は敵の射撃開始を0秒とする。螺旋の形・色・回転、砲口の絞り、衝撃波は維持する。

| 項目 | 直前の試作 | 今回 |
|---|---|---|
| 砲口の集光 | 約0.04秒から | 射撃開始から0.5秒間。光が根元へ集まり、強くなる |
| 先端の出射 | 約0.08秒 | 0.5秒 |
| 先端の速度 | 命中イベントまたは予告位置まで約0.1秒で届く描画側の計算 | 予告地点まで0.3秒で届く等速。距離から発射計画で算出し、命中・外れ・画面サイズで変えない |
| 代表配置での飛翔 | 約0.1秒 | 0.3秒 |
| 代表配置でのHP減少 | 一律0.18秒 | 0.8秒、光が機体位置へ届く時刻 |
| 照射の保持 | 0.62秒 | 予告対象または実際の命中位置の遠い方へ到達してから0.62秒 |
| 消失 | 0.18秒の減衰が射撃時間の外側にも続く | 0.18秒の減衰を射撃計画に含める |
| 発射音・衝撃波・短い揺れ | 判定時刻基準の要素が混在 | 出射0.5秒へ同期。追加ビーム音は0.525秒 |
| 命中音・HP・数字 | 0.18秒 | 到達時刻へ同期 |
| 代表配置の射撃計画長 | 0.80秒 | 1.6秒。既存の射撃後の待機は追加しない |

単なる全体スローや停止は使わない。砲口での集光0.5秒を明示し、螺旋・衝撃波の動きは従来のまま、先端が伸びる時間を0.3秒にする。カメラの揺れは出射から0.14秒だけ。

### 共通の計算

- `u = normalize(to - from)`：予告で固定した軸。
- `a = dot(playerCenter - from, u)`：射撃計画時の自機の軸方向距離。
- `b = abs(cross(playerCenter - from, u))`：軸からの垂直距離。
- 命中条件：`-31 <= a <= beamLength + 31` かつ `b <= 110 / 2 + 31`。31は既存の自機接触半径。
- 出射時刻 `f = 0.5`、予告対象の軸方向距離 `a0 = max(0, dot(warningTarget - from, u))`、先端速度 `v = max(1, a0) / 0.3`。
- 命中時刻 `h = f + max(0, a) / v`。
- 描画先端 `front(t) = clamp((t - f) * v, 0, beamLength)`。
- 保持終了は `f + max(a0, hit ? max(0,a) : 0) / v + 0.62`。その後0.18秒で消える。

予告地点に居座る場合は0.8秒に命中する。同じ軸に沿って近づいた／離れた場合は、追尾せず、共通の先端がその実位置へ到達する時刻に命中する。

接触範囲や最終ダメージは発射計画で決め、HPは命中イベントの時刻まで減らさない。先端の装飾、螺旋、光片、衝撃波に追加のダメージ判定は置かない。

防御は既存と同じ。通常38、ガード19、半減バリア19、25％弱体28.5、無敵0、残りHP5なら5。命中音は実ダメージがある時だけ。30/120fpsでも同じ一回のイベントを適用する。

動きを減らす設定でも先端とダメージの到達時刻を共通にする。螺旋の回転、光片、衝撃波、揺れを省き、砲口の発光を弱める。

## 4 設計の矛盾と改善判断

| 発見 | そのまま減速した場合の問題 | 改善・扱い |
|---|---|---|
| 表示の伸長だけ遅くすると、固定0.18秒のダメージが先行する | 光が届く前に被弾する | 必要な隣接修正として実装。到達距離と速度からダメージ時刻を作る |
| 命中イベントの有無で表示速度の計算元が変わる | 同じ予告でも命中・外れで速度が変わり得る | 予告地点までの飛翔時間を定義へ移し、凍結した距離から求めた速度を描画と物理で共有する |
| 出射より後のダメージ時刻を、発射音・揺れにも使う | 砲口から出てから反動が発生する | 出射イベントと命中イベントを分離する。既存SFXはイベント時刻をそのまま使う |
| 減衰の終了が射撃計画長の外にある | 再生・確認画面ごとの末尾処理に依存する | 減衰まで計画長へ含める。旧本編で必ず途切れていたという意味ではない |
| 動きを減らす設定だけ全長を瞬間表示する | 表示上の到達とダメージ時刻が一致しない | 先端の速度を共通にし、装飾の動きだけ抑える |
| 星環砲の本弾40に対して合計上限32 | 「本弾が実際に40減らす」と読むと矛盾する | ユーザーの上限固定を優先。40は上限適用前の基礎値、実際の本弾単独は最大32と明記する。上限の再増加は行わない |

追加のルール変更は提案しない。今回の減速で必要な同期修正を同じ範囲に含める。歩行で常に避けられる幅への縮小や、ARCの命中率を固定抽選に変える変更は、現在の対処設計を変えるため含めない。

### 本検証で確定した隣接修正

- 屋根が残るリンの静的配置では、旧探索が45度・出力65で外れる一方、50度・出力57なら通って36ダメージになった。命中候補がない時だけ低い側の最良候補から角度±6度・出力±10を1刻みで再探索し、全探索や地形貫通は追加しない。
- 重界砲・終極砲の砲口の向きも予告位置に固定する。転移等で自機がボスの反対側へ行っても、発射方向を追い直さない。
- 同じ戦闘オブジェクトへの再挑戦で、出撃時の記録にない古いレーザーチャージが残るケースを再現し、記録にない場合は消す。保存形式は変更しない。

| `game/dist/render.js` | 控えめな点線、チャージ発光、出射時の揺れ、既存の累積ダメージ数字 | 本編、共有描画器 |

## 6 事前確認と本検証の計画

今回の事前確認は、射線の手前・予告付近・奥と幅内外を比較する27条件の幾何確認、実際のガン到達状態を使う小さなタイミング比較と、PC1200×720日本語／小画面844×390英語の実Controller・CPU Workerでの居座り／合法転移。居座り38・転移0、到達前HP維持、到達時HP減少、発射音・命中音の時刻、次の入力を対象とする。動きを減らす設定＋Workerなしの小画面1条件でも38ダメージ・到達時刻・入力復帰を確認した。幾何確認用の仮座標は合法な移動の証拠ではなく、物理端末や音声の実再生の確認でもない。

本検証では、最終合意した内容に対して次の範囲を選ぶ。同じソース・条件の事前確認は再利用する。

1. 星環砲：部分命中の基礎値増加と合計32、既存の弾道・数・間隔。
2. 重界砲：モグ・リン・ユイの実配置で高軌道／屋根の低軌道、予告の位置・姿勢固定、地形衝突、重力領域の双方への作用。
3. 終極砲：両方のARC前置き、予告開始・線の持越し、最大歩行・左右合法転移、地形無視、幅境界、防御・残りHP、30/120fpsと重複適用防止、出射・到達・減衰の同期。
4. 接続：本編Controller・Workerと非Worker、ポーズ、次の入力、周期の交代／戦場リセット、出撃時点の再挑戦。PR141の在庫復元を保持。
5. 共有物：必要な生成物、攻撃確認と総覧。先行変更を保護する既存のバイト固定検査は、今回許可された差分だけを説明できる形で更新する。
