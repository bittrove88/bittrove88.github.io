# ARCLINE 追加修正依頼（ゲーム0.19.0）

2026-11-02のユーザーによる明示的な5項目の実装依頼を記録する。過去の依頼をこの範囲で更新する。

1. ストーリーのテキスト表示位置の不具合を修正する。提供画像は37面クリア時の画面。
2. キャラごとに異なる弾の重さを、通常技・必殺技・転移・武器・スキルで共通化する。同じ操作・攻撃を別キャラで使っても同じ弾道にする。効果自体が重さ・弾道を変える攻撃は例外。
3. エンディングの10個のライトの光る丸を小さくし、画像の各枠内へ収める。
4. 中ボスではBGMをリセットしない。大ボス開始・大ボス後の次の面のリセットは維持する。
5. 添付の[戦闘効果音変更指示書v1.1](ARCLINE_SFX_CHANGE_REQUEST_v1.1.md)を読み、効果音を更新する。

## 効果音資料の扱い

添付v1.1は改変せず保存する。そこに記載された当初の「候補保管／再制作後の本実装」という段階と、今回の実装依頼・現時点の最終素材を区別する。

リポジトリにユーザーが追加した `design/audio/sfx/ARCLINE_SFX_FINAL.zip`（復旧元コミット `10a3a9127921b0d382c97ba830e23e3943ce31c9`）のREADME・台帳は、再制作7本のr1採用を記録している。今回の更新依頼とこの最終採用記録に従い、アプリへ反映する。旧P0/P1をそのまま本採用したとは扱わない。

原本ZIP、旧版、試聴資料、既存の承認素材を保持する。配布には最終版の37本のみを使用する。v1.1で本実装対象外とされた跳弾試作3本、archive、プレビュー、制作スクリプト、macOSメタデータ、加入音J-01を配布へ入れない。BGM音量の個別補正提案と勝利曲の追加は、今回の戦闘効果音に混ぜない。

保存キー・schema8・resetVersion2、所有・加入・進行、100面、HP・威力・AI・効果の条件、原画、既存公開URLを保持する。弾道の初速／重力の共通化は今回明示された変更であり、従前のキャラ別重量の維持条件だけを更新する。
