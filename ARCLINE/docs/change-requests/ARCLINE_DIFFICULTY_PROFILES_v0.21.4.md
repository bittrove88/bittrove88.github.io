# ARCLINE 0.21.4 — 難易度別保存の追加要求

2026-11-04の最新ユーザー指示を、独立した難易度変更指示書への追加要求として記録。

- Easy／Normal／Hardごとにクリア記録・保有機体を保持する。章内の持ち物、機体装備、加入待ち、補充状態、ストーリー記録も混在させない。
- 現在のセーブは現在選択中の難易度へ保持する。他2モードは最初から。言語と操作配置、初回操作案内は共通。公開URL・保存キー・schema8/reset2を維持する。
- 保存が成功してからモードを切り替える。失敗時は元の記録を維持する。マスターモードは現在の難易度だけを編集する。明示的な全セーブ削除は全モードに適用する。
- **最新の訂正「再プレイはカウントに含めない」を優先。** 既クリア面の勝利では連続使用回数と補充残りの両方を更新しない。未クリア面の初クリア時だけ更新する。敗北・重複結果・100面も対象外。
- 1〜99面は同一機で新規5面連続クリア後に機体変更を求め、別機体で新規5面をクリアすると補充完了。従来の単一機体保護は維持。
- 敵の調整と射線は[正式指示書](../change_requests/2026-11-04-difficulty-adjustment-minimal-verification.md)を唯一の正本とする。地形など別件は追加実装しない。
