## 主な正本と修正した問題

`game/ui/audio-manager.js`、`ending-credits.js`、`special-ui.js`、`game/styles/media-ending.css`、`design/ending_media.json`、`game/tools/build_media.py` が新しい正本です。ゲーム接続は手書きの `game/dist/game.js`、`story-view.js`、`save.js` に限定します。`game/runtime.json` が生成・読込順を所有します。

調査で見つかった結果画面の戻り経路の保存待ち漏れを修正しました。エンディングの画像読み込み待ちが時計を止める既存方式を避け、欠損時も進行します。実装検証で見つかった長いポーズ後の誤ったstall判定と、古いplay Promiseによる再開競合、初回からSDK音声オフのときのタイトル再生前ミュート適用を修正し、専用テストを追加しました。濃紺上で暗かった既存ロゴは原形を維持してゲームの明るいインク色で表示します。

保存キー `arcline-campaign-v1`、schema8、resetVersion2、PWAのid・scope、両公開URLを維持します。戦闘エンジン、機体プロフィール、物理・弾道、全100面、在庫、解放、AI、必殺技性能のソースは復旧基点とバイト一致を検証します。原画10枚、採用音源7曲、映像23枚、指定シート原本を破壊しません。過去の履歴と検証記録も維持します。
