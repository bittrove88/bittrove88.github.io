## 結果と変更範囲

通常20テーマ・大ボス9景・アークハート4戦場、計33景を実行時に使用します。6〜10面「鏡の岸壁」は1〜5面の暖かな配色を引き継がず、青い岩壁と銀紫の海を描いた再制作版です。各テーマは配色・物・構図を個別に設定し、マットな面の重ね方を共通の描画方針にしています。

10〜90面の大ボスでは、その直前のテーマの素材と色を受け継ぎ、閉鎖門、炉の足元、試験室、嵐の上甲板などの専用構図へ変更。100面は既存の固定リレーに合わせ、外壁／空中搬送層／岩盤整備層／帰還確認室の4景へ移ります。レンズは装飾として未点灯で描き、進行カウント・敵本体・早過ぎる勝利演出を背景へ混ぜません。

`game/tools/build_backgrounds.py` が、美術正本の `manifest.json`・`data/*.json`・`renderer.js` と `game/ui/backgrounds.js` から `game/dist/backgrounds.js` を生成します。背景はこの1ファイルに内包され、画像やJSONの追加通信を必要としません。正式ビルドと生成一致検査へ登録済みです。

`render.js` の共通グラデーション、山並み、汎用ランドマーク、旧洞窟背景を置換しました。既存の最終移動フレームで表示状態を決めた後、画面座標に中央coverで背景を描き、従来の地形・機体・敵・射線・エフェクト・HUDを重ねます。見渡し・ズーム・飛翔・画面揺れで背景は動きません。最終移動は既存の55%境界で旧／新景を切り替え、崩壊・移動時間・入力待機を維持します。

戦闘、物理、全100面の地形・配置、AI、HP、武器・スキル、100面の10機・各HP70・各100ダメージ・必殺3・28行動・敗北機からの再挑戦、保存schema8／reset2／キーは変更しません。実装前main `3ebb4c9` に対する主要13モジュールのバイト一致を検証。バージョンとキャッシュは0.23.2へ更新し、既存の公開入口を維持します。描画を共有する既存の美術比較ページには、新しい依存スクリプトを追加します。

## 再実行

`ARCLINE/` で `npm ci`、`npm run build`、`npm test`、`npm run check:generated`、`npm run test:browser`。背景専用は `node game/tests/backgrounds-browser.test.cjs`。証拠の出力先は `ARCLINE_EVIDENCE_DIR` で指定できます。`python3 game/tools/build_playables.py --output /tmp/arcline-package` で背景を含む静的配布ZIPを生成します。
