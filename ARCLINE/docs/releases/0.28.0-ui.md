## 実装

- 上部3ボタン・HPとターン、下部の移動・斜角・発射・数値・メニューを、承認された配置へ変更。チャージゲージと操作は維持。
- マップ横のキャラチェンジと一時停止を同じ実際の選択画面へ接続。全10機保有時は5×2で名前・HPを読みやすくする。
- 武器は自身武器／取得武器、スキルはレア／通常の3列と指定順。未保有・残数0は区分内で前に詰め、空見出しを出さない。
- スキルはカード閲覧と明示的な使用・セット確定を分離。効果・行動消費を説明し、回復の既存確認画面と一行動消費を維持。
- 色・選択状態・アイコンを統一。スキル図形は共有カタログをArcSkillsの描画APIで使い、本編・持ち物・全100面総覧で共通化。性能・互換ID・既存のカタログデータは維持する。
- カード上からのスクロール、左4/5の斜角と右1/5のマップ移動、戦場と全体マップの二本指ピンチ、一本指への復帰時の誤操作防止。ズームは戦場だけに適用。
- 2面の既存案内後に操作ガイド、9面の空き枠にキャラチェンジ。追加既読キーは `v7:touch-controls` と `v7:character-change` の2件だけ。
- 不要な足元リング・画面外のキャラ／射線矢印・敵HPの方向矢印を削除。チャージ演出のリングや射線そのものは維持。
- テレポート、爆風弾、チャージ速度70％／40％へ日英の表示名を統一。保存IDや内部の識別名は変更せず、取得通知や読み上げの複合文も翻訳層で整える。
- 武器カード説明はスキルの要約と同じ12px/17px、小画面11px/16px。武器下部の案内はスキル詳細と同じ11px/16px、小画面10px/14px。
- 紹介サイトの同じ4場面を再収録し、図形・UIと画像の指紋を同期。画像切替・総覧・生成JSのキャッシュURLをゲーム版数に揃え、サイトの構成とギャラリーは維持。

## 正本・依存

`game/ui/battle-ui.js`・`battle-catalog.js`・`battle-aim.js` と `game/styles/battle-ui.css` をruntime.jsonへ登録し、正式ビルドからdistへ生成する。game.jsは生きた状態の参照と既存コマンドを渡す明示的な橋渡しだけを追加し、画面・入力の既存入口を装飾する。ArcBattleInputの変更通知は現在のHUDへ転送する。

共有カタログはskills.jsより先に本編・Worker・サービスサイト・単体総覧へ読み込む。ArcSkillsの変更は描画補助3関数とその依存だけで、カタログ本体・互換判定・スキル効果は変更しない。save.jsの変更も許可される既読IDの追加のみ。既存のキー・schema8・resetVersion2・contentRevision5.0を維持する。

確認環境の全保有・各6個・自動開始・メモリ保存・比較メニュー・アイコン比較・ホストへのメッセージ送信は組み込まない。
