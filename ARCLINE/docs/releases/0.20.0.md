# ARCLINE 0.20.0 — マップカメラと寝転び用の横向き固定

## 変更

[依頼と実装条件](../change-requests/ARCLINE_MAP_CAMERA_v0.20.0.md)。サイト・映像演出の提案は保留し、ゲームの表示と操作を更新します。

自分の手番の照準中、上部の「マップ」から全体表示へ切り替えられます。ドラッグで移動、＋／−で拡大縮小、「全体」で再フィット。「戦闘に戻る」またはEscapeで通常カメラへ即時復帰。PCは矢印・＋／−・0・ホイールも使用できます。チャージ中・敵の手番・教材・別画面では開始しません。

見渡し中は戦闘と操作を停止し、射角・威力・斜面上の機体・転移選択・所持品を変更しません。BGMは継続します。ドラッグ中の拡大やキー操作では旧ジェスチャーを解放し、古いカメラへ戻ることを防止します。回転・SDK停止・キャンセル後も入力を保持しません。

寝転び中にiPhoneが縦向き判定になる問題へ、最新指示どおり常時横向きの画面を適用。スマホの右側が上部になる方向へ統一し、オン／オフや反転の選択は設けません。縦向き判定でもプレイ・プロローグ・エンディングを継続します。OSの回転ロックAPIや保存済みの好みへ依存しません。

横長の論理画面をネイティブ回転角に応じて90／逆90／180度で補正し、タッチ座標と要素の範囲を逆変換します。元CSSの順序を保ち、寸法メディアクエリ・viewport単位・セーフエリアを論理画面へ対応。動きを減らす設定と機器の入力条件を維持し、SDK・バックグラウンドの停止は解除しません。回転中のチャージはキャンセルして誤発射を防ぎます。

## 主要ファイルと互換性

- `game/ui/map-camera.js`、`game/styles/map-camera.css`：カメラの範囲・入力・専用画面。
- `game/dist/viewport.js`：常時横向き・ネイティブ回転の補正・論理寸法・逆変換。
- `game/dist/game.js`、`render.js`、`index.html`、`ui/screens.js`：ゲーム進行との接続、通常カメラ復帰、フォーカスと操作の分離。
- `game/runtime.json`：0.20.0・キャッシュと正規生成。ゲーム入口・サイトの版数参照・配布にも反映。
- `game/tests/map-camera*.test.cjs`、`landscape-view-browser.test.cjs`：全体表示、回転、操作・状態維持の検証。

保存キー・schema8/reset2・100面の内容・機体の解放と加入・弾道・物理・AI・在庫・BGM選曲・原素材・公開URLは変更しません。`render.js` の既存保護テストは明示的なカメラ表示変換と復帰の2箇所だけを除外し、その他の全バイトを従来どおり照合します。カタログは既存ARCLINEの1件を維持します。

## 検証

最終整理後、JavaScript構文とカメラ単体2101項目（全100面・4表示領域・パン制限・ズーム・状態不変）を確認。縦向きメディアクエリ11ブロック、停止画面の5スタイル、DOM・翻訳・監視・停止理由を除去し、能動コードに参照が残っていないことを検索しました。

整理前の開発検証では、見渡し115項目、横向き80項目、チャージ245項目、機体・初回導線101項目、保存削除・横向き映像49項目、音楽・ネイティブエンディング94項目が通過しました。見渡し終了後のフォーカス復帰に不安定なケースを発見し、タッチ押下時のネイティブフォーカス移動と終了時のクリック貫通へ対策を追加しています。これらの過去結果を最終修正後の通過とは扱いません。

最終修正後のローカル配布・ブラウザ再検証は、自動承認審査の利用上限により実行できませんでした。通常サンドボックスでの単体スイートも子プロセスのEPERMで失敗したため、全体成功とは記録しません。`evidence/map-camera-0200/STATUS.json` に区別を保存しています。正式CIへ単体・生成・カメラ・横向きの検査を登録し、対象コミットのCI結果を公開前に確認します。

Gitコミット・CI・Pages反映の結果は対応PRへ記録します。物理iPhone Safari／Android、ホーム画面アプリでの実機確認は未実施。公開画面の直接表示は管理環境の通信制限により未確認で、Pages処理の成功とは区別します。
