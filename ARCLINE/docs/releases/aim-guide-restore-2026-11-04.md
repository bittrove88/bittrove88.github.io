# 2026-11-04：難易度別の射線表示を旧仕様に復元

対象：v0.22.0のコード（PR #58「0.21.4 難易度別保存・敵照準調整」由来の表示変更）。

## 現行仕様

| 難易度 | プレイヤーの予測射線 | 敵の照準誤差倍率 |
| --- | --- | --- |
| Easy | 弾道の全軌道 | 1.40 |
| Normal | 実シミュレーションの軌道距離の半分 | 1.00 |
| Hard | 着弾予測なし。砲身の発射方向のみ | 0.65 |

射線の割合は**表示だけ**に適用。弾道の物理・実発射・威力・敵CPUの行動・乱数順序に変更を加えない。
Normal の分裂弾は親子の連続した軌道に対して半分の表示予算を計算し、Hard は通常の落下位置を公開しない。Soraの特殊射線については以前から存在する分裂点マーカーとその親の射線表示を残す。

## 変更箇所

- `game/dist/aim-guide.js`：PR #58直前の難易度別距離計算を復元。
- `game/dist/render.js`：Hard の方向線と飛行中ガイドの非表示を復元。
- `game/ui/difficulty-ui.js` → `game/dist/difficulty-ui.js`：任意の初回試撃にも3難易度の射線の違いを適用し、日英説明を更新。3回試撃の必須条件は復活させない。
- `game/dist/index.html`／`i18n.js`：設定画面の日英表示・アクセシビリティ名称を整合。
- `game/tests/aim-guide.test.cjs`／`difficulty-browser.test.cjs`：従来の全モード同一表示の期待値を、全軌道・半分・方向のみの契約へ変更。
- `game/runtime.json`：コード更新後の旧キャッシュ回避のため `cacheVersion` のみ0.22.1へ。ゲームの `version`、保存スキーマ、ゲームのURLは維持。該当する配布HTML／オフラインプレビューの生成物を更新。

## 維持する仕様

0.21.4で導入した難易度ごとの攻略・保有機体・装備・補充・ストーリー保存と、敵照準誤差倍率、後半の敵ダメージ調整、再プレイの連続使用・補充カウント除外を維持。さらに0.22.0の地形・100面リレー・HP・保存形式も変更しない。

## 検証項目

単体テストは軌道距離の50%・分裂・跳弾・連射・Hard方向ガイド・非破壊性を確認する内容へ変更。ブラウザテストは実Workerとの整合、3モードの保存・再読込、設定の日英表示、試撃を要求しない初回操作を引き続き確認する設計。**この接続環境ではリポジトリをローカルに展開してNode・Chromiumを起動できないため、`npm test`、`npm run check:generated`、ブラウザ・実機テストの実行結果は未確認**。PRのCI結果と実環境で最終判定する。
