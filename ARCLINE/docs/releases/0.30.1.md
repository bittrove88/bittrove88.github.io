# ARCLINE 0.30.1 メニューと装備確認の整理

仲間・武器確認・スキル確認・武器図鑑・スキル図鑑を1つの画面へ統合。上部の「仲間／武器／スキル」と「保有分／図鑑」で切り替える。ホームの「持ち物・図鑑」は保有武器、「仲間」は現在の仲間へ直行。選択中の項目・各一覧位置・仲間の説明位置と能力欄の開閉を保ち、図鑑への移動でホームを挟まない。「ホームへ」とEscapeは元の入口へ戻す。仲間のカードは閲覧のみ、「この仲間を選ぶ」で明示的に変更してホームへ戻る。未解放・補充待ちを維持し、Tabキーは選択中のタブだけを通る。[最終の導線と5画面](../../evidence/menu-inventory-0297/collection-flow/README.md)。

武器確認・スキル確認・武器／スキル図鑑を共通の64pxカードと詳細へ統一。一覧にはアイコン・名称・保有数・選択チェックを残し、効果と種類は詳細に集約する。詳細の保有数とアイコンを削除し、名称だけを対象の見出しとして残す。PCは3列、通常の横向きと縦端末の回転表示は2列。文字とコントラストを維持し、未所持も0を明示する。英語の効果欄が武器名だけになる取り込みも修正。確認画面は閲覧専用、図鑑の切り替えは保有分と並べて常設する。

章一覧は番号・章名・面範囲・進行状況を分けたコンパクトな2列表示。設定はカテゴリナビ＋内容ペイン、ストーリーは入口→一覧→詳細。戻ると閉じる、一覧の位置と再生後の戻り先を整理し、セーブ削除は設定へ移す。[UIの実装・検証記録](0.29.7.md)／[最新のコンパクト表示](../../evidence/menu-inventory-0297/compact-equipment/README.md)。

## 並行更新との統合

未公開0.29.7として準備していたUI作業中に、PR136の[0.30.0 HP・行動上限](0.30.0.md)がmainへ入った。main `1904d3e` を作業ブランチへ統合し、次の版数0.30.1としてキャッシュと正式生成物を同期する。既存のHP／行動上限変更、原画、攻撃判定・光輪、物理、敵AI、地形、取得、保存を保持する。

`engine.js`・`levels.js`・`encounters.js`・`combat_balance.json`・地形設計・在庫／保存など12ファイルがmainとバイト一致することを確認。`game.js` と `difficulty-ui.js` のmain側更新も保持し、UI差分だけを併存させる。設定の難易度説明もEasyで敵HPが下がる現行仕様へ合わせる。従来の「難易度の差は射線と狙いのみ」という説明へ戻さない。
