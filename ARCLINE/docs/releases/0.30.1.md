# ARCLINE 0.30.1 ラスボスの攻撃

2026-11-09。PR136のmain1904d3eを基準に実装。ユーザー確認により、自機HP100・担当150（Easy80）・各20行動を維持する。今回の作業はローカル実装と検証まで。未マージ・未公開。

## 威力と攻撃順

| 攻撃 | 最大ダメージ | 命中の内訳 |
|---|---:|---|
| 通常技 | 25 | 部位破壊中は18.75 |
| 星環砲 | 32 | 本弾20＋衛星弾4×3 |
| 転軌砲 | 34 | 10＋14＋10 |
| 重界砲 | 36 | 着弾36。重力場の追加ダメージなし |
| 終極砲 | 38 | 本弾14＋光輪8×3 |

防御・無敵は適用し、残りHPを超えた数字は表示しない。部位破壊の軽減は通常技だけに適用する。固有技に従来の面数倍率や半減を重ねない。

| 戦場 | 繰り返す6手 |
|---|---|
| 1 | LOW → ARC → 星環砲 → DROP → TWIN → 星環砲 |
| 2 | REFLECT → ARC → 転軌砲 → TWIN → DROP → 転軌砲 |
| 3 | CURVE → MARK → 重界砲 → ARC → TWIN → 重界砲 |
| 4 | TRIPLE → ARC → 終極砲 → TWIN → DROP → 終極砲 |

敵の攻撃を実際に解決したときだけ順番を進める。同一戦場の機体交代では順番を引き継ぎ、戦場変更では先頭へ戻る。交代後は新しい自機位置を予告し、再挑戦は出撃時点の順番と予告を復元する。

## 転軌砲

以前は低い位置で曲がり、高所のソラ・リコ・ヒバリの初期配置に3件とも0ダメージだった。砲口と予告地点の高い方から約360px上まで上昇し、頂点で固定した予告地点へ一度だけ向きを変える。以後は直進し、地形との衝突を維持する。予告後に移動した自機を追い直さない。

正本は `design/attacks/definitions.json`。手書きの `enemy-attacks.js`・`physics.js`・`engine.js` に最終戦専用の処理を追加し、限定差分を `final-attacks-0301-scope.json` で固定する。他の敵、自機攻撃、地形・配置・取得物、0.30.0のHP設定、保存の変更は対象外。
