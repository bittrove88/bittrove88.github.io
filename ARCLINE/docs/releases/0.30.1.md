# ARCLINE 0.30.1 メニューと装備確認の整理

武器確認・スキル確認・武器／スキル図鑑を共通カードと共通詳細へ統一する。アイコン・名称・保有数バッジ・効果・種類・「✓確認中」を同じ配置とし、説明を読みやすい大きさとコントラストへ調整。未所持も0を明示し、説明の濃度を落とさない。確認画面は閲覧専用、装備操作は追加しない。図鑑の入口は保有タブの横へ常設し、各図鑑へ直行する。

章一覧は番号・章名・面範囲・進行状況を分けたコンパクトな2列表示。設定はカテゴリナビ＋内容ペイン、ストーリーは入口→一覧→詳細。戻ると閉じる、一覧の位置と再生後の戻り先を整理し、セーブ削除は設定へ移す。[UIの実装・検証記録](0.29.7.md)／[統一デザインの画面](../../evidence/menu-inventory-0297/equipment-design/README.md)。

## 並行更新との統合

未公開0.29.7として準備していたUI作業中に、PR136の[0.30.0 HP・行動上限](0.30.0.md)がmainへ入った。main `1904d3e` を作業ブランチへ統合し、次の版数0.30.1としてキャッシュと正式生成物を同期する。既存のHP／行動上限変更、原画、攻撃判定・光輪、物理、敵AI、地形、取得、保存を保持する。

`engine.js`・`levels.js`・`encounters.js`・`combat_balance.json`・地形設計・在庫／保存など12ファイルがmainとバイト一致することを確認。`game.js` と `difficulty-ui.js` のmain側更新も保持し、UI差分だけを併存させる。設定の難易度説明もEasyで敵HPが下がる現行仕様へ合わせる。従来の「難易度の差は射線と狙いのみ」という説明へ戻さない。

## 検証範囲

統合後に装備デザインの4画面サイズ×日英・348項目と、戦闘UIの15シナリオが再成功。正式ビルドと隔離した155生成物の二重再生成も一致した。mainのバランス・物理・地形・保存は変更せず、バイト比較で維持を確認するため、HP調整の大量対戦や音声を慣例で再実行しない。PR全体のCIは既存の設定・階層・図鑑・削除保護を含め、[検証計画](../../verification-plan.json)の6スイートと生成物整合を確認する。

ローカル修正・検証と本番マージ・配信・物理端末確認は別工程。mainマージ・本番配信は未実施。
