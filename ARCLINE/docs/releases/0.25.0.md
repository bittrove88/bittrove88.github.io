## 変更内容

- 通常改修：3・4・7・8・9・12・14・16・18・19・20・23・26・27・28・29面。歩く／渡る／壊す／返す行動の結果と、射点を選ぶ理由を分けた。一面ずつ実ゲームで描画し、形状と主要な入力を改善してから次の面へ進めた。
- 承認済みの58・64・92面：固定された提案JSONから正本へ反映。入口と水平な着地・射点の小変更を保持。承認時の元JSONと画像は書き換えず、今回の比較画像のみ現行美術で再描画した。
- 7・16面：最後の経路確認で破壊を省く転移直通が見つかり、敵側の岩体を地面へつないで再制作。16面では隣の安全な列を探す転移の挙動も確認し、上面を水平にした。自機の開始頭上、破壊後の入口・射線・支持を残す。
- 8面：日英の案内と実弾道デモを「庇の下面で一回返す」に統一。床反射・入口の破壊片を外し、6面との反射方向の違いを見せる。
- 取得物：0.24.3の新配置を優先。新しい梁と干渉する12面をx34/h15へ、石畳との余裕が減った14面をh21へ調整した。他の現行座標は維持し、変更面の取得入力を再計算。全46個の種類・数量・取得ID・出現ターン・クリア補償を保持した。
- 関連する紹介サイトの4・7面デモを新しい地形へ同期。歩行を省き、7面では同じ位置から破壊の前後を見せる。4面は対岸の裏から横へ狙うネイティブ操作・敵の手番を再生成した。

0.24.3の勝利曲・難易度試撃・マスター・取得物のカメラ補正を保持し、STG基盤は変更していない。天井全体を常に画角へ入れる修正は、今回の実体コンポーネントの庇にも適用した。

地形の生成元は引き続きstage_blueprints、取得物はpickup_placements。案内・目的・経路文と検証記録も同期した。ゲーム版数・キャッシュは0.25.0、保存はschema8/reset2を維持。

31面はKを洞窟入口へ露出する候補を試作したが、初出としての反射の許容が不足したため今回は不採用。現行地形を保持する。その他の改善案と100面の専用検討は制作前の案として残す。通常16面は作業の実行を許可された変更後レビュー対象であり、設計承認済みとは記録しない。
