# 0.29.4：マスターモードの武器・スキル所持

基準mainは `5129717a09dc868ce6b632bbac75add19f512632`。武器とスキルをそれぞれ「なし／すべて保有」にできる依頼。

- 隠し入口とパスワード、クリア済み面数の設定に、武器・スキル各1つの選択欄を追加。初期表示は無変更のためのプレースホルダーで、選択肢は「なし／すべて保有」。選んだカテゴリだけ変更する。
- 「すべて」は現行武器12種・スキル15種を各6回分。既存の旧武器・旧スキルは勝手に消さない。「なし」は対象の所持数を空にする。通常弾・固有必殺技と獲得済み図鑑の記録は維持する。
- キャンペーンの在庫と次の出撃チェックポイントを揃えて保存し、リロード後や実際の戦闘へ反映する。100面クリア状態では在庫だけ保持し、不正なチェックポイントは作らない。
- 未選択時は従来の進行設定を維持。保存が失敗した場合は元データを保持し、選択を残したまま再試行できる。現在の難易度だけを変更する。

正本は `game/dist/master-progress.js`、`game/ui/master-mode.js`、`game/styles/master-mode.css` とHTML本文。保存schema8/reset2は変更せず、配信とキャッシュは0.29.4。戦闘・物理・AI・地形・音源は維持。

検証は変更に対応する既存 `master-move` 単体、`master-move-browser` の日英・小型横画面／縦画面、正式生成物の一致に限定する。保存失敗、再試行、再読み込み、カテゴリの独立変更、実戦への在庫受渡しと既存進行設定を確認する。全マップ・全音源・全ブラウザ・配布物全体は対象外。公開URL直接表示と実機は未確認。
