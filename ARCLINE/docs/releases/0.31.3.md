# 0.31.3 — 残像の発砲とボス転移の視認性

ボスの残像が弾を撃つ際にカメラを寄せ、転移直後に旧位置へ残像が残ったことを伝える。転移弾を追いにくいという追加指摘を受け、ボスの転移だけ少し遅くする。

## 表示と時間設計

- ボスの転移弾は距離÷500px/秒、最短0.7秒・最長1.6秒。通常敵の71面以降の転移は従来の650px/秒・0.45〜1.2秒、自機の転移も従来どおり。転移先を含む画角で弾の到着を待ち、その後に本体を移す。
- 大ボス・ラスボスが残す残像は、生成時に青白い輪郭と「残像」／「ECHO」を表示する。1.2秒で追加の強調を消し、残像そのものは従来の寿命まで残す。攻撃先・範囲・弾数の予告は加えない。
- 発砲前0.18秒で、旧位置に記録された残像の発射位置へカメラを寄せる。倍率は通常画角の最大1.35倍、画面の利用可能な高さ・幅でも抑える。本体が転移した先へは寄せない。
- 発射の光を0.16秒見せ、0.24秒で通常画角へ戻す。ラスボス後半の2連射は2発目の発射まで保持する。残像弾の速度や威力は変えない。
- 動きを減らす設定ではカメラ移動と発砲前の待ち時間を省き、残像の識別表示は残す。一時停止中は発砲前の進行も停止する。

中ボスは残像を残さない。歩行・転移の開始面、近接を含む転移条件、回数・クールダウン、手番、狙い、威力、地形、HP、保存schema8/reset2を変更しない。PR142以降にmainへ入ったラスボスの螺旋レーザーと通常大ボスの予告固定も保持する。

main `c56a4aa680dd942e027b9ed218a5ea8cee1eb0a0` を基点にする。時間・画角の計算は `game/ui/charge-camera.js`、発砲前の表示段階と転移時間は `game/dist/game.js`、輪郭・表示と画角の適用は `game/dist/render.js`。カメラ用に取得した発射計画を保持し、実発射前に戦闘を解決しない。表示用の画角を次回の通常画角へ混入させない。
