## 最終素材と再生

既存FINAL ZIP（13,049,413 bytes、SHA256 `b46fcb8519db762a8224cd814677b4b91d6e30ca00f45b4df6af074a852a1d94`）を保持。CRCとMANIFEST全72件を検査し、最終採用WAV37本を無変換で抽出する。強発射・I-04・S-05・ガン／バン／モグ／コロ発射の7本はr1。ファイルごとの再生補正値を採用し、試聴記録の中間設定 `0.65 × 10^(-4/20)` を独立SFXバスへ適用する。BGMの曲別補正提案は採用せず、既存BGM音量を維持する。

初回タイトルではWAVを読まない。戦闘開始・機体切替で共通音と選択中の必殺音を準備し、それ以外は必要時に読む。既存AudioContextを共有し、AudioBufferを最大24件キャッシュ。声数8・主着弾3の上限、優先度、近接イベント統合、SFX側リミッターで多重再生を制御する。

ハナは0／0.18／0.36秒の発射、モグは初弾＋0.22秒間隔の追加爆発、リコは実跳弾1〜4段階。ソラの分裂子弾とモグのパルス、ユイの圧縮に発射音を追加しない。バンの衝撃波とユイの圧縮では主衝撃音を重複させない。リンの精密アクセントは必殺の中心命中時だけ。コロの転走ループは実際の開始・落下・再転走・終了に追従し、復帰時のオフセットも実時間から算出する。

物理側の`appliedEvents`とは独立した音声カーソルを使う。ポーズ・非表示・SDK消音・タイトル・トークン変更で停止／解放し、未再生の過去音をまとめて鳴らさない。読み込み失敗は1音1警告で無音継続し、旧toneへのフォールバックをしない。自動試撃ループは無音を維持する。

共通弾道化でリコのデモ選択が先に2回跳弾の解を拾うことを発見。デモの探索条件を4回跳弾・上限到達へ合わせ、既存の実戦物理処理は維持した。
