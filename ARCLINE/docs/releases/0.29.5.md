# 0.29.5 攻撃判定とダメージ表示の同期

各着弾の演出に対してHP減少が遅れたり、部位と本体が重複して減ったりする問題を修正する。確定した威力・上限は[変更仕様](../change-requests/ARCLINE_ATTACK_DAMAGE_SYNC_v0.29.3.md)を参照。

正本は `design/attacks/definitions.json`、手書きの `game/dist/physics.js`・`engine.js`・`render.js`・`effects.js`・`preview.js`、UIの `game/ui/battle-catalog.js`・`sfx-manager.js`。版数・キャッシュは `game/runtime.json`。正式ビルドで攻撃カタログ、UI、Worker、単体HTML総覧、マップ総覧を同期する。

## 検証

- `damage-sync`：全32自機攻撃の命中時HP・数字の合計、命中順の上限、ヒバリ2光輪、モグの前進、移動できない敵への引き込み、遮蔽、攻撃中の部位破壊、通常弾の二重計上防止、大ボスの各上限、最終リレーの残り必要ダメージ、微小HP残量。
- `damage-sync-browser`：PC／スマホの64ケースで実際のCanvasに描く数字を照合。30／120fpsでHPと部位の結果を比較する。
- 既存の全攻撃総覧117項目と、本編の発射→敵AI Worker→敵手番→次の操作を検証する。
- 旧固定ハッシュ検査は `damage-sync-0293-scope.json` の限定差分を逆適用して、無関係なソースの保護を継続する。生の現行動作は新規の同期検査と現在の攻略記録で確認する。
