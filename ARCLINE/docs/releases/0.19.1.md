# ARCLINE 0.19.1 — 選んだステージを1つのボタンで開始

## 不具合と変更

攻略中の面がある状態で別の面を選ぶと、「この面を練習」と「再開」の両方が表示されていました。「再開」は戦闘を始めず、選択だけを攻略中の面へ戻していました。修正前の実画面で「3面を選択 → 再開 → 7面へ戻り、戦闘未開始」を再現しています。

選択を戻す `resumeRun` ボタン・イベント・スタイルを削除し、開始操作を日英の「ステージNを開始 / Start stage N」に統一しました。面を選んでこのボタンを1回押すと、表示された面を開始します。戦闘の一時停止中に同じ戦闘へ戻る操作は維持します。

既クリア面の再プレイは従来の独立した持ち物を使い、攻略中の章のチェックポイント・武器・スキル・進行を変更しません。保存キー、schema8、resetVersion2、100面、戦闘、原画、音源、公開URLは維持します。版数とリソースキャッシュを0.19.1へ更新し、正式ビルドで配布ファイルを生成します。
