# 最終戦の通し検査を現行AIへ合わせる（2026年11月10日）

## 問題と変更

基準はPR156を含むmain `a795468756ced3bb75619562fc7598d805e67fe6`、ゲーム0.33.1。旧通し検査は0.31.1の操作記録と毎射のダメージを期待していた。現行AIは2手目で間合いを保つ歩行を選び、旧記録の3射目が外れるため、`Recorded damage mismatch` で停止した。旧0.31.2では同じ47入力が完走したことも比較している。これは現行ゲームの進行不能を示す失敗ではない。

ユーザーの「はい進めてください」により、この検証更新を実施・再検証する。ゲーム本体、AI、HP・威力・物理・地形、保存形式、版数、サイトは変更しない。PR150の未マージ資料には依存しない。

- 現行エンジンで合法な歩行・射撃・転移と自律した敵行動を使い、勝利した38入力をfixtureへ保存。通常の必殺技残数を使用し、通常弾のみの攻略とは扱わない。
- 本編の`launch`・`update`・`draw`・CPU Workerに入力を渡す。敵の選択・移動先・射撃計画・ダメージを上書きせず、旧敵位置や毎射の固定ダメージは期待しない。
- 接触前後の各フレームのHPと、実際の射撃計画・命中イベントを照合。10機がそれぞれ担当150を達成し、4戦場・3回の移動・最後のガン・勝利・エンディングへ進むことを確認する。
- 自律歩行・転移・残像射撃、本体と残像の発射カメラ、戦場切替中の入力停止・地形とHPの不変を確認する。
- 敵の自傷で表示HPが尽きても担当未達なら戦闘を継続する既存の最終戦規則を確認する。勝利判定をHPだけへ置き換えない。
- 別ページで実際の保存を読み直し、100面クリアとチェックポイント終了を確認してから、元のページでエンディングへ進む。テストの入口fixtureは空の保存領域にだけ設定する。
- 旧検査にあった568×240・844×390・393×852、日英、軽減表示、4戦場の見渡しと遷移確認を保持する。

## 入力の再作成

[fixture](../../game/tests/fixtures/final-relay-0331.json)に基準コミット・生成元ハッシュ・38入力を記録する。既存の探索を再実行する場合：

```sh
ARCLINE_EVIDENCE_DIR=/tmp/final-relay node ARCLINE/game/tools/approved-map-qa.cjs 100 100 recommended normal
```

候補探索は隔離した状態で行い、採用した入力は変更していない実戦で実行する。fixtureはプレイヤー入力だけを渡す。ゲーム仕様を変更した場合、入力を再作成しても、実際の敵行動・全担当達成・勝利・保存・エンディングの成功を別途確認する。失敗を消すために敵AIを止めたり、HP・ダメージ・担当量を変えたりしない。

## 検証範囲と完了条件

[今回の計画](../../verification-plan.json)で`final-battle-browser`だけを選択。検査・fixtureのみの変更なので生成物一式の再生成と無関係な成功済み検査は追加しない。前段の単体5・ブラウザ8・通常速度の画面操作18手は、ゲームソース不変を確認して再利用する。

不正な出力101と、命中時刻より前にHPを更新する異常を、隔離したテストページだけに注入した。新しい検査がそれぞれ`Illegal replay aim/power`と`Contact-time HP mismatch`で失敗することを確認する。

最終結果は[検証記録](../../evidence/final-relay-verification-20261110/VERIFY.json)を参照。完了条件は、合成した命中・勝利を使わず、本編制御・実Workerで10機と4戦場を通過し、保存の再読込とエンディングが成功すること。物理端末・全100面攻略・人の理解度・勝率・音声全件は対象外。

マージ・配信の状態は対象PRのChecksと本文を参照する。この変更は検証を復旧するもので、ゲームの新機能やサイト更新を公開するものではない。
