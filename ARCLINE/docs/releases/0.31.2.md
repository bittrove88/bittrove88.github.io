# 0.31.2 — 大ボス固有技の命中と予告固定

ラスボス以外の大ボス9体を整理し、7技の既存の照準誤差と必要な弾道を調整する。Normalの難しい静止足場で概ね半数の命中を目安とし、命中を直接抽選せず、実弾の衝突で決める。予告後の歩行・転移・斜面・足場の崩落で狙いと警告帯が追尾しないよう固定する。

## 範囲

- 正本 `design/attacks/definitions.json` の7技へ `aimErrorScale` を設定。Easy/Normal/Hardの誤差倍率と3回の乱数消費を保持する。
- 雲裂砲は速度・重力・爆風を調整し遠距離へ到達。挟撃砲は上下2砲口のvolleyを照準探索と実弾で共用する。
- 潮撃砲の波を150から90へ短縮し、静止時の命中と徒歩による回避を両立する。灼熱砲・空襲砲は精度を変更しない。
- 予告時の衝突中心と姿勢を保存し、照準探索と描画で共用。残HPを超えるダメージ表示を抑える。
- main `1219d6ca9c5b71a37f7d4348c51da2b04eaecad3`（0.31.1）を統合。ボス移動・転移・残像と、ラスボスの星環砲・重界砲・終極砲を保持する。通常大ボス固有技の手番だけ、移動候補の判定・装甲・砲口を同じ予告方向へ向ける。残像による通常攻撃への延期は元の規則を使う。
- runtime/cacheと生成物・更新案内を0.31.2へ揃える。HP、行動上限、保存schema8/reset2、在庫と地形を保持する。

## 検証

[検証計画](../../verification-plan.json)と[統合後の記録](../../evidence/boss-ballistics-0312/VALIDATION.json)を参照。

旧mainでの[284条件・1,542射](../../evidence/boss-ballistics-candidate/PLAYER_MOVEMENT.json)と、各技の難しい足場の[命中数](../change-requests/ARCLINE_BOSS_BALLISTICS_ADJUSTMENT.md)は制作・移動検証の履歴。最新main統合後に直接影響する検査を選び直す。

- 弾道・プレイヤー移動・既存敵・ボス移動・ラスボス技と新弾道を単体検査する。
- 全9体×3位置で実際の敵行動を選択・適用し、歩行と転移、分身の砲撃と固有技延期、予告の保持を確認。結果の発射位置で各128seedの静止命中を観察する。最初の2手は共通の射撃手順であり、全操作列の再現ではない。
- ブラウザでは、プレイヤーの歩行／実転移・残HP1の表示・足場落下を計75条件で確認する。この75条件はボスの移動・転移予算を消費済みにして、同じ射点に対するプレイヤー回避を比較する。ボス自身の移動・分身・次手番は別の既存 `boss-motion-browser` と新しい行動シミュレーションで確認する。
- Workerと協調実行、実着弾とHP、30/120fps、PCと小画面を確認する。ラスボス専用の既存ブラウザ検査も行う。
- 正式生成155ファイルを2回の隔離再生成と比較する。

全座標・全操作列の網羅、全100面の再攻略、実機iOS/Android、音声全件、公開URLの動作確認は対象外。ボスが撃ちやすい場所へ移れば命中は増え、完全な遮蔽では当たらない。一律50%を保証する仕様ではない。
