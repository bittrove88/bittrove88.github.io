# ARCLINE 0.19.2 — 機体選択のスワイプ修正

## 原因と変更

仲間一覧はスクロール可能でしたが、カードは全ボタン共通の `touch-action: none` を引き継いでいました。指をカード上から動かすとスクロールが始まらず、844×390の横向きでは最初の4体以外へ移動できませんでした。高さの低い画面では、戦闘中メニューの機体変更にも同じ問題がありました。

`styles/gameplay.css` の `.machine-buttons button` と、`styles/player-flow.css` の `#battleMachineChoices button` に `touch-action: pan-y` を指定しました。カード上から縦方向にスクロールし、タップで機体を選べます。戦闘の移動・照準・発射ボタンに対するタッチ規則は変更しません。

版数・リソースキャッシュを0.19.2へ更新し、正式ビルドで配布CSSと参照先を再生成します。保存形式、解放状態、進行、章の持ち物、HP割合と必殺弾の引き継ぎは維持します。

前回0.19.1の全体CIで、版数に対応する `updates/0.19.1/index.html` の不足が判明しました。0.19.1と0.19.2の更新案内を用意し、公開リリースのリンク・表示検証を実行します。
