# 0.29.6 ダメージ表示の簡略化とヒバリの光輪

戦闘中の表示を1か所の累積数字へ絞る。HIT／CORE／CRITICAL／PART、MAX、命中数、部位への数字を表示しない。連続命中は同じ位置で数字を更新し、ヒバリは11→23→35。弱点・中心命中は色で示す。技説明は特徴と通常敵への最大値に整理し、倍率やダメージの計算式を省く。内部のダメージと上限は維持する。

ヒバリは描画される明るい円周と、前へ進む当たり判定を一致させる。中心方向の一点が遮られていても、見えている敵の輪郭へ光輪が到達すれば命中する。完全な固定壁は通さない。輪が通過済みの内側へ、後から命中しない。通常敵は中心11＋光輪12×2、上限35。大ボス弱点上限45。部位を破壊した光輪は、部位の残HPだけを消費して残りの威力を先へ運ぶ。同じ12ダメージの予算を部位と本体で共有し、二重計上しない。半径170・拡大0.75秒・発生間隔0.2秒は維持する。

正本は手書きの `game/dist/render.js`・`physics.js`・`effects.js`、説明文は `design/attacks/definitions.json`、版数は `game/runtime.json`。攻撃カタログ・単体HTML・マップ総覧・キャッシュは正式ビルドで同期する。過去の固定ソース検査は今回の限定差分を逆適用して保護を継続する。
