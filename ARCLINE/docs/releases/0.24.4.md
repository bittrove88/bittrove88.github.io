# 0.24.4 地面・地形の輪郭の見分けやすさ

「地面、地形等のオブジェクトの線をもう少し見分けやすく」という依頼を反映。輪郭の太さと同色相での濃さ、接地辺の幅だけを調整する。

| 対象 | 変更前 | 変更後 |
| --- | --- | --- |
| 地面・固定壁・天井・足場の外周 | 0.8px、面色のRGB97％ | 1.25px、80％ |
| 破壊材・橋・反射材の外周 | 0.9px、面色のRGB92％ | 1.25px、78％ |
| 接地できる上辺 | 1.8px | 2.6px |
| 橋の接触辺 | 2px | 2.6px |
| 反射辺 | 3px | 3.4px |

画面上で一定の線幅を使い、縮小カメラやスマホでも細く消えにくくする。共通の黒線には戻さず、素材の色相と各テーマの面色を保つ。

調整の正本は `design/components/runtime-approval.json` の `runtimeOutlineRevision` と `runtimeStyleOverrides`。旧承認の33景・共有材・描画設定のハッシュは保持し、`build_components.py` は検証後に今回の5項目だけを上書きする。制作時のギャラリーや承認記録を上書きせず、本番の明示的な追加修正として区別する。

既存の独立したPython描画器で、旧比較例198件を再生成できることを先に照合し、同じ入力へ今回の線設定だけを適用してブラウザの比較例を更新。面色・形状・103世界の衝突ポリゴン・機体・背景・ギミック領域・表示状態・保存は変更しない。

軽微な描画調整のため、STGの外部配信は行わず、ローカルのPC／スマホ相当と全33景の描画検証を使う。版数・キャッシュは0.24.4、セーブschema8/reset2を保持。実機と公開画面の直接確認は未実施。コミット・CI・Pages公開は別途確認する。
