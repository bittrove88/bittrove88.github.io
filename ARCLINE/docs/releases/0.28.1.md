# 0.28.1 — iPhone下部UI・雲・加入演出・8／12面

状態：作業ブランチで修正・検証。本番への追加マージ・配信は未実施。基準はmain `a45f6031b5e2f6b2eff74b0356554713bea631a0`（PR125／0.28.0）。[今回の直接依頼](../change-requests/ARCLINE_REPORTED_FIXES_v0.28.1.md)。

## 下部UI

- `100% - 24px` と画面中央基準の指定が、固定横向きのiPhoneで左右の安全領域を無視していた。440×956相当では武器単独656px、移動ボタン左端18pxが安全領域59pxへ侵入することを再現。
- 左右の安全領域を別々に差し引いて中央寄せし、下部全体を最大820px、武器・スキルを各212pxまでに制限。不在のメニューの幅へ引き伸ばさない。
- 横持ちではボタン下の数値もホームインジケーターから避ける。操作68×68px・アイコン40px・メニュー高さ36px、チャージの色・目盛り・数値・高さ26px・操作を維持。画面全体や戦場は安全領域で縮めない。

## 雲

従来は描画が時間・カメラ・倍率に依存して雲を並べ直す一方、減速判定が四角い領域全体に存在していた。

`geometry.js` が初期の世界座標に固定した輪郭を生成し、`component-art.js` の共有描画と `physics.js` の領域判定が同じ頂点を使う。カメラは切り抜きだけを行い、雲を再配置しない。雲の間の透明な部分、OFF・強度0の雲には判定を置かない。30面の旧オフセットも雲へ適用しない。減速倍率・1領域あたり1回の作用、90面の弱化、他の力場・敵行動・基本弾道は維持する。

## 仲間加入

加入／出会いの再生の「演出をスキップ」ボタンとハンドラを削除。原画を使う飛行演出では読み込み待ちのCanvasを隠し、原画のデコード後に演出を開始する。最終的な画像読み込み失敗時の代替表示、他の画面の代替描画、映画のスキップと保存処理は維持する。

## 8／12面

- **8面**：庇を水平な下面40・上面46へ整理し、40〜84の下面を鏡面にする。地上の頂点を31から24へ下げる。初期位置の実際の天井反射が敵へ届くことを確認。出現位置・敵HP・行動数は維持。
- **12面**：梁の上側と取得物の位置を保ち、下面だけを3（世界座標30px）上げる。床・左右幅・出現位置・敵HP・行動数は維持。

正本と変更前後の固定データは [明示依頼の記録](../../design/stage_reviews/STAGES_REPORTED_FIXES_20261108.json)。他98面の地形は変更しない。全46取得物の座標・種類・数量・ID・出現ターンは保持。雲の判定変更に伴い24・27・29・94面の検証用射角・威力・近傍成功数だけを更新する。

## 検証と保護

- iPhoneは4サイズ・縦横正逆・左右配置・メニュー4状態の128条件、773項目。修正前CSSの344件の失敗と修正後の成功を記録。[比較画面](../../evidence/iphone-dock-0281/README.md)。
- 雲のラスタ画像を時間経過・切り抜き変更で比較し、透明部分の物理接触が0であることを確認。原画を800ms遅らせた加入演出の51フレームで代替Canvasが出ないことも確認。[雲・演出・マップの画面と記録](../../evidence/reported-fixes-0281/README.md)。
- 更新した物理で通常31入力ケース・最終戦Normal／Hard2ケースを新たに記録。旧報告を変更せず、影響する入力だけを新しい証拠へ差し替えて、全161ケースを実際の敵反撃込みで再生する。自動入力は人間の難易度や勝率の測定ではない。
- 歴史的な地形・バイト保護検査は今回の固定差分だけを正規化し、他のコード・98面・保存を保護。新しい検査で変更後の地形・共有輪郭・実弾・原画表示も直接検証する。保護検査を丸ごと外さない。
- 単体・生成一致・iPhone回転・日英UI・チャージ・部品描画・加入フローを確認し、全CIで再検査する。最終結果はPRのChecksを参照。

iPhone安全領域はChromiumで制御した値。実機Safari／Android・WebKitは未確認。公開URLの直接表示も現環境のネットワーク制限で未確認。
