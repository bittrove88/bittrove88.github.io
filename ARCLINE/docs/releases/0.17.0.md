## 発見して修正した問題

試撃を縦横別倍率で描く処理に加え、画面回転時にviewport補正より前の古い寸法でCanvasを描いていたことを確認しました。固定比率のカメラ、独立したCanvasコンテナ、ResizeObserverと次フレームの再測定で修正し、描画用バッファとCSS寸法の一致を回転後も検査します。試撃の調整操作を除去したため、比較する入力も変化しません。固定試撃だけでは移動・照準・FIRE長押しを学べないため、その試撃だけでcontrolsを既読にせず、未読なら元の操作デモを戦闘で表示します。既存の既読キーは消しません。

加入順だけを入れ替えると旧25面ヒバリの加入途中記録が無効になる問題を防ぎ、既存の所有・実加入・装備と旧イベントを保持します。旧所有者はヒバリを失わず、新しい25面のリコも利用可能になります。新規進行は新しい順序で加入します。26〜30面のヒバリ推奨は未加入になるため、既に加入済みのソラへ変更して実戦確認します。
