# ARCLINE 0.21.3 — 各機HP70・本体へ100ダメージの最終戦

[最新の変更要求](../change-requests/ARCLINE_FINAL_100_v0.21.3.md)を反映。固定順の10機は全員HP70、各機が本体へ100ダメージを与えて交代します。全体HP1,000、余剰繰り越しなし。達成した攻撃後は次機へ移り、未達成なら敵の手番。最後はガンが決着をつけます。

| 戦場 | 構成 |
|---|---|
|1・外殻|従来の地形を維持。出現位置を遠方へ変更|
|2・浮遊回廊|14の浮遊構造物、空隙、風・反射。3機とも足場に乗って出現|
|3・地下迷宮|長い天井、上下の棚、壁と破壊する窓が入り組む洞窟。背景も洞窟へ|
|4・最終決戦|崖・浮遊棚・多段構造と全9種の環境装置を組み合わせる|

全戦場幅3,000px。出現時はボスから水平800px以上を確保。マップ2〜4は反射床、結晶、開閉橋、上昇気流、風、減速雲、噴気孔、磁場、極性端子を実際の物理へ配置しました。1ターン140pxの歩行、必殺1発と共通在庫は維持。行動上限80。

3・6・9機達成時は、地形の破片落下→画面切替→次の戦場への到着を2.2秒で表示。移行中は入力を止め、切替後にカメラと操作状態を復帰。軽減モーションでは落下なしの0.7秒表示。旧世界の描画用コピーだけを分割し、実際の地形・HP・ダメージ・行動数は演出で変更しません。FINAL_BOSS曲は継続します。

正本は `design/expedition_013/stage_blueprints.json` の100面、`game/dist/final-team.js` の条件、`game/ui/final-travel.js`／`final-team-ui.js` と `game/styles/final-team.css` の演出。表示HPは内部値の20倍。既存の3段階装甲は残りHP割合で移行します。`build_campaign.py` と正式ビルドでランタイム・攻略図・キャラ確認ページを同期。

## 追加：5面連続使用と5面分の補充

1〜99面では、勝利時の機体で5面連続クリアすると補充待ち。別機体で5面クリアするまで、出撃時に変更を求め、その機体の発射・戦闘中の変更も不可にします。残り面数を表示し、別機体を選択して保存が成功してから出撃。100面はユーザー指定により制限・補充カウントとも除外。敗北・再試行では減算しません。旧セーブへ使用履歴は捏造せず、schema8/reset2のまま任意のmachineUsageを追加保存します。仲間がまだ1機の間はクリア済み面の再プレイで詰まらないよう保護します。

正本は `game/dist/crew-usage.js`、R.finishの成功時記録、save.decodeの任意履歴。UIは `game/ui/crew-supply.js`・`game/styles/crew-supply.css`。初期5面→ハナ加入、5面での補充完了、重複クリアと敗北、リロード、マスターモードの履歴保持、100面除外を専用単体50項目とブラウザ17項目で検証しました。
