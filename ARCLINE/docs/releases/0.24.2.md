# 0.24.2 — 承認済みコンポーネント美術のゲーム統合

背景に対して地形の情報量が強く、風や噴気は発生位置・作用範囲を読み取りにくかったため、承認済みの地形・共通ギミック美術を正式なゲーム描画へ接続した。通常20・大ボス9・最終4の全33景に適用する。背景の表示と、最新0.24.1の100面・地形・当たり判定・AI・ダメージ・保存は維持する。

## 採用した表示

- 制作PR [#110](https://github.com/bittrove88/bittrove88.github.io/pull/110)、承認コミット `79d9521ddd2c8a783da2a698df1357efe4f25bb7`。地盤と支持材66材質、共通機能色、作用範囲改訂1.7、控えめなT端子を採用。
- 通常地形は素材の色相と単色色面を保ち、内部の明暗差・彩度・分割数を抑える。外周は素材と同色相0.8px、接地辺1.8px。破壊材の紫、反射面の青緑と明るい反射辺はテーマ間で共通。
- 風・気流・噴気は実際の領域と一致する7％の帯、真の発生端と終端までの流線、2.4px・95％の動く線を表示。源が画面外に隠れる場合は向き付きの短い案内を表示し、画面端へ源を移さない。
- 弱い風は形・数・濃さが同じで速度だけが変わる。OFFは帯・流線・記号・案内を全て非表示。磁場は薄い円弧と極性を残し、弱化で弧の数と速度を変更。雲は通常68％／薄化55％を維持。
- T端子は灰緑の操作面と抑えた外装。実際の `pendingPolarity` がある間だけ次の手番の符号を表示し、反転が適用された後は消す。重力スキルの倍率表示とHUD回避は既存の仕組みを維持。
- 画面外の源と切替予約は日英に対応。日本語の承認された見た目を保ち、英語では短い `SOURCE`／`VENT`／`NEXT TURN` を使う。狭い領域では方向記号へ省略。

## 実装と生成元

`game/ui/component-art.js` が、現在描画されているポリゴン・接地辺・領域・端子から美術のノードを作る。図版の古いマップをゲームへ読み戻さない。`game/tools/build_components.py` は編集JSON・共通ベクトル描画器・実装アダプターを `game/dist/component-art.js` へ生成する。外部通信や制作ギャラリーの読み込みは不要。

承認した35個の素材・表示JSONのハッシュは [runtime-approval.json](../../design/components/runtime-approval.json) で検査。ベクトル描画器に追加した言語引数は省略時に従来の日本語表示を維持する。制作ギャラリーとゲームで動く線の実装を分けない。

テーマ選択は既存の `ArcBackgrounds.sceneFor(state)` と共有し、最終リレーも既存の `ArcFinalTravel.frame` が返す旧／新状態を使う。崩壊中の断片や橋・反射板の途中のポリゴンは実際の形へ描く。最終戦の55％境界、移動時間、カメラ・チャージ90％表示は変更しない。

通常の安定したワールドでは実体ノードをキャッシュし、世界やポリゴンが入れ替わる破壊・開閉・崩壊では再生成する。外周の床と下方向の描画継続は維持し、内側の島の隙間を塗りつぶさない。機体・弾・取得物・弱点・射線・操作UIは既存描画を使用する。

バージョンと全リソースのキャッシュキーは0.24.2。campaignVersion5.0・schema8・reset2・保存キーを維持。CPU Workerのキャッシュ参照だけを同じ版へ更新し、計算コードは変更しない。正式な `npm run build`／`check:generated`／配布ZIPの対象へ登録する。

## 制作資料と公開状態

制作資料の `worlds.json` は0.23.1時点の固定した美術比較用データ。ゲーム側の最新マップの正本ではない。制作側の元コード検証は記録されたコミットと照合し、最新ゲームの不変は上記の実装用検査が担う。

この実装ブランチでは正式ゲームへの接続を完了。mainへのマージ・公開配信・物理端末の確認は別工程であり、完了と扱わない。
