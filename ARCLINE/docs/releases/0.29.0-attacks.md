# 0.29.0 攻撃演出・挙動の改訂（実装・検証済み、未公開）

PR125の0.28.0（a45f603）を基準に、[変更指示書](../change-requests/ARCLINE_CHANGE_REQUEST_v1.1.0.md)と追加の個別モーション指示を実装する。本番へのマージ・公開は別工程。

## 実装

- 通常弾は全10機のメインカラー。基本弾道・威力・チャージは保持。
- 補助武器12種：転走弾・炸裂弾・五月雨・散弾の改名、散弾10発、連射弾6発、分裂後の持続回転、地走り弾の実際の左右126伝播、紫の吸収弾と実ダメージ100%回復。爆風弾はPR125の名称を維持。
- 全10必殺技：破砕砲、連華砲、爆走砲、衝撃砲、流星砲、跳弾砲、光輪砲、掘削砲、収束砲、重力砲。三段爆発の描画だけで済ませず、3実弾・9実弾・12子弾・波の到達・実際の収束と貫通・吸引を判定へ反映。総ダメージ上限と一回の消費を管理する。
- 通常敵12種は色、中ボス10体は機構ごとの線と着弾モチーフ。既存の弾道、照準誤差、三回の乱数消費、部位破壊後の半減を保持。
- 大ボス9固有技、アークハート4戦場の固有技。三手番ごとに既存攻撃の一枠を使用し、一手番の攻撃数を増やさない。予告は自機移動前に固定。合計ダメージは基礎20、後半補正を含め最大22。重界砲は着弾点の半径200に一時領域を作り、両軍の次の一射を同じ法則で曲げて消える。リレー移動と再試行で解除。

## モーションの判断と見直し

時間変化を全技共通の型にしない。必要な技だけ局所的に静止・減速・加速を使い、物理判定と音は同じ表示時計へ同期する。軽減設定では追加の時間変化を省く。

|技|見せる瞬間|見直した内容|
|---|---|---|
|破砕砲|重い接触から外周爆発への解放|発射直後の余分な停止を削除。接触40msに限定|
|連華砲|三斉射と花の開き|追加の18ms停止を撤去。実際の連射間隔を使う|
|爆走砲|接地から走行へ|最後の余分な停止を削除し、走行の流れを優先|
|衝撃砲|絡む三弾から前方三波へ|最初の接触だけ45ms静止。波の到達と描画を同期|
|流星砲|頂点の分裂から流星落下へ|頂点75ms静止、落下加速。最低射角40°|
|跳弾砲|虹色へ成長する最終反射|毎反射の停止を撤去。三反射目だけ20ms|
|光輪砲|しなやかな二回転|着弾停止を撤去。帯の展開だけ0.85倍|
|掘削砲|三実弾と成長する三爆発|各爆発への追加停止を撤去。0.22秒の発射間隔を使用|
|収束砲|三分岐が一点へ束になる瞬間|発射停止を撤去。収束点25msから加速|
|重力砲|吸引、圧縮、内向きの消失|吸引を0.68倍、圧縮55ms。外向きの大爆発を除去|

敵も同様に、雲裂・分光・転軌・終極の意味のある切り替わりだけを強調。挟撃、氷嵐、灼熱、極性、空襲などは実際の弾道と発射間隔を優先し、追加停止を入れない。等速を選ぶことも個別設計に含む。

古い軌跡が残り続けると着弾の焦点を邪魔するため、残像を0.45秒、流星だけ0.65秒へ制限。高速弾の描画位置は物理点間で補間し、表示フレームの段差を抑える。通常速度での連続再生、変化なしとの比較、接触の前後を確認して改善する。心地よさは数値テストだけで証明できないため、ユーザーの鑑賞・実操作での評価も受けられる確認画面を用意する。

## 保護と検証

[動作確認画面](../../game/attack-review/)は本編と同じ物理・描画を使い、攻略保存を読み書きしない。117の選択肢は重複を除いた全攻撃パターンを含む。変更が原因で古い入力が成立しなくなった実戦は新しい入力記録を追加し、旧マップ承認資料は書き換えない。

100面の地形、全46取得物、HPと歩行・チャージ、保存schema8/reset2、最終固定順・HP70・各100ダメージ・28行動・3必殺・800以上の出現距離を保護する。旧版のバイト固定検査は変更を許可された攻撃ファイルだけ新しい機構テストへ移し、それ以外は固定比較を維持する。

## 再現性の修正

照準候補のキャッシュが機体位置を整数へ丸めていたため、近い別位置での探索結果を再使用すると、探索順序によって実戦の弾道や敵の移動判断が変わるケースを確認。座標と斜面角を正確にキーへ含め、同じ入力記録の再現性を保つ。攻撃の抽選回数や難易度の照準誤差は変更しない。

## 配布用レビュー

`game/attack-review/standalone.html` は全モジュールとCSSを内包した生成物。追加通信なしで117項目を描画することをブラウザで確認する。実行環境のChrome管理ポリシーで `file://` の直接起動は拒否されるため、この環境での単独ファイル確認はHTTPで配信し、文書以外の通信を遮断して実施する。公開・セーブの接続を必要としない。

敵側の比較でも、終極砲の輪はリボン状の回転を使わず、白金の円と四方の光点へ変更した。灼熱砲は縦の火柱と低く広がる根元の爆発を分け、星環砲の衛星は主弾より小さく、空襲砲の最後の爆風は実際の半径を描画にも渡す。共通描画器を使っても、同じ形・動きへ揃えない。
