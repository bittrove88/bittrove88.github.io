# ARCLINE 0.21.1 — 100面の最終戦を複雑化

[100面だけを難しくする明示依頼](../change-requests/ARCLINE_FINAL_BATTLE_v0.21.1.md)を反映。

- 地形を1枚の連続床・障害物2個から、3区間の床・2空隙・障害物8個へ変更。4個は破壊可能な壁／屋根。高さの異なる中継棚と、残る天井で射線を選ぶ。
- 外殻／内殻／核の3段階で、反射・結晶→雲・結晶→反射・磁場の配置を切り替える。
- 100面のenemyProfileだけ4→6。既存AIの狙い誤差を角度±8°→±6°、出力±14→±12へ縮小する。共通AIコードは変更しない。
- 敵HP・ダメージ・全機体共通の基本弾道、武器・スキル、行動上限28、最終BGMとエンディング、保存schema8/reset2、公開URLは維持。現在の攻略記録を引き継ぎます。

正本は `design/expedition_013/stage_blueprints.json` の100面。`build_campaign.py` が100面の指定フェーズと精度を取り込み、正式ビルドでlevels・ガイドへ出力する。追加済みのコンパクトなマップ総覧も `build_map_atlas.py` で100面／20テーマ目の集計だけを同期し、画面構成と他99面は維持する。

通常弾のみ・必殺なしの実戦3乱数条件は7／7／8手で勝利（従前の記録は5手）。推奨ガンの必殺を使う実戦も7手で勝利。これは自動探索の成立例で、人の勝率や狙いやすさの測定ではない。`record_final_stage.py` は今回の4戦だけを更新し、他99面の検証履歴を保持する。

検証：専用単体185項目（99面データと共通戦闘コードの一致、全10機体×3段階の配置、旧セーブ、実戦4戦）。専用ブラウザ24項目（568×240／844×390／393×852、日英、再試行、全段階の見渡しと照準・在庫保持、実戦クリアと保存後のENDING、マップ総覧の同期）。最終CI・ビルド・Pagesの結果はPRに追記する。
