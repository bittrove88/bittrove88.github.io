# ARCLINE 0.23.1：70度の接地・ギミック足場・切り替え表示

ユーザーの今回の明示依頼を反映する。0.23.0のマップ・在庫・学習AIは維持し、接地・ギミック状態表示に加え、追加依頼のカプセル表示と保有画面を更新する。作業開始時の復旧元は `5f81de5a159a132fd84be7200fe7611945230718`。

## 動作

- 水平から**70度以下（70度を含む）**の上面は接地・左右歩行・転移着地の対象。平地とのつなぎ目でも機体の姿勢を連続して変える。
- 70度を超える上面は立ち止まる足場にせず、斜面の下端を経由して下の安全な接地面へ滑り落ちる。転移着弾・接地の再評価・歩行中の急斜面接触で共通の処理を使い、描画も斜面を通る経路へ合わせる。
- 弾を遮る実体のあるギミックは、描画・弾の衝突に使っているポリゴンの上面から接地面を得る。通常の壁・天井・橋・反射床・破壊可能な足場に加え、従来不足していた反射結晶・ボスの地形判定付き装甲にも登録する。下面への張り付きは行わない。風・霧・磁場などの効果範囲は引き続き領域であり、透明な床にはしない。
- 足場を壊したらその接地面も除去し、乗っていた機体を下の足場へ落とす。ターン境界で橋が開く・結晶が回転する場合も接地を再評価する。
- 急斜面では機体の傾きに合わせて頭上・横の空間と実弾の機体中心を判定する。自力歩行は既存の左右累計140pxを維持し、滑落の強制変位を歩行消費へ足さない。

## 切り替えの表示

|対象|現在の状態を示す表示|
|---|---|
|風|左右の大きな矢印、方向別の色、`風 → / ← · ON`|
|上昇気流・噴気|上矢印、稼働色、`ON`。停止時は灰色の破線枠と `× · OFF`、流れの矢印を消す|
|磁場|時計／反時計方向の矢印、方向別の色、中央の極性、`磁場 ↻ / ↺ · ON`。無効化後は `OFF`|
|霧|雲形と減速ラベル|
|切り替え端末|操作が予約されている間は「次のターンで切替」|
|重力スキル|`重力 ×0.5 ↑` または `重力 ×2 ↓` と残りターン数|

日本語・英語を用意。矢印と文字はアニメーション軽減設定でも残す。フィールドラベルと重力ラベルは、ヘッダーと操作パネルを除いた範囲へ収め、必殺HUDと他のラベルも避ける。端末の本体より手前にラベルを描く。風の方向、磁場の回転方向、噴気のON/OFF、強度0の無効化を、物理が読む値から表示する。切り替え時期や風・磁場の力は変更しない。
