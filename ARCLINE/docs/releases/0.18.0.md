## 保持・修正

保存キー `arcline-campaign-v1`、schema8、resetVersion2、公開URL、100面の戦闘・進行データは変更していません。承認音源のENDING SHAは `73ee43cec9655eaae0290124b8bdce8df3577d523b5de32864d39d52620f6363`、166.250667秒。独立した勝利BGMの実装は対象外です。旧カード・風景・切り抜き・設計下書きは履歴として残し、新ロールでは使用しません。

透過化で背景が残った輪郭や細いアンテナ・リングを、原画のアルファだけで補正。隠れた部位を生成せず、元の向きを維持します。自機は明色・暗色・市松、敵は大きい設定画・ID・白装甲と鏡面を再照合。ホワイトハウルの雪、ブルーム・テンダーの放水は原画の表現を保持します。小画面の集合では足元と名前をそろえ、原寸超過を防ぎます。

## 検証と限界

[evidence/ending-300](../../evidence/ending-300/) に単体17・ブラウザ11スイート、生成90出力の2回一致、表示回帰、147エントリZIPと4倍CPU配信検査を収録。新規単体2318チェック、新規ブラウザ171チェック、原画RGB42体・マスク10体の完全一致を確認しました。native音源のシークなし通しは171333msで、11場面・42体・全区間・メニュー復帰を通過。更新案内ページ不足で一度失敗した参照検査は、ページを追加して全体を再実行し144チェックPASS。初回失敗の記録も保持します。シーク検査とnative音源の実時間通しは別に記録し、素材準備時の旧結果を流用しません。

物理iPhone Safari／Android、PWA実機、YouTube本番SDK、人による音楽の聴感・拍位置の評価は未確認です。公開ドメインはこの環境のネットワーク許可に含まれずCONNECT403で遮断されます。Pagesの対象SHAのデプロイと公開画面の直接確認を区別し、未確認を合格として報告しません。
