# 0.29.1 必殺技・射撃後のフリーズ修正

ソラの流星砲を本編で発射し、着弾後に敵AIへ処理を渡すと `DataCloneError` が発生することを、0.29.0（PR127のmain）で再現した。例外でアニメーションループの次フレームが予約されず、画面と操作が止まる。

原因は `game/dist/game.js` が、関数を含む演出時計を物理計画の `shot.motion` に保存したこと。解決済みの計画も `s.last[0]` に残るため、敵AIのWorkerへ状態を送る `postMessage` が失敗する。通常弾・補助武器・ほかの必殺技にも共通する経路で、攻撃総覧とエンジン単体の再現だけでは検出できなかった。

演出時計は本編コントローラーの `shotMotion` として所有する。Workerへ渡す射撃計画に関数を入れず、開始・着弾・ターン交代・再挑戦・タイトル復帰で時計の参照を解除する。個別の静止・スロー・加速、弾道・ダメージ・音・消費・保存・地形は変更しない。配信版とキャッシュ識別を0.29.1に揃える。

## 再発防止

`game/tests/battle-turn-continuity-browser.test.cjs` を正式なブラウザスイートへ登録する。確認用のHPを増やした9面で、本編の `launch/update/draw` と実際の非同期Workerを使い、全10必殺技・通常弾・全12補助武器について、自機の着弾→敵の発射→次の自機操作を検査する。Workerを使わない代替経路も確認する。

さらにソラは通常速度の `requestAnimationFrame` とFIREボタンで必殺技を発射し、ホスト停止・再開を挟んで次のターンへ進み、続けて通常弾を撃つ。描画・入力が継続し、敵AIの実処理、消費、2ターン目の必殺補充が成立することを確認する。端末実機や公開URLでの確認とは区別する。

検証結果と公開状態は修正PR・CIおよび添付の検証記録から参照する。ゲームの正本は `game/dist/game.js`（手書き）、版数と生成物の正本は `game/runtime.json`。

- 修正後：24ケースのターン交代と、通常速度のソラ必殺技→敵→通常弾→敵→次ターン、ホスト停止・再開が成功。
- `npm test`：43スイートPASS。生成物153ファイルの再生成一致。
- エンジン・物理・技別モーション・演出・全マップ・取得物正本はPR127のmainと一致。保存識別も維持。
