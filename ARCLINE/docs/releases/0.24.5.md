## 旧版CIで見つかった検証漏れ

0.24.4の[CI実行42357463433](https://github.com/bittrove88/bittrove88.github.io/actions/runs/42357463433)は失敗していた。専用のGitHubログ取得で確認すると、`chapter-flow-0170-browser` が試撃の旧威力70を期待していたため。0.24.3の明示依頼は威力30で、実装と新しい試撃検査は30を使っていたが、過去版の検査2か所の期待値更新が漏れていた。この2か所を30へ変更し、画角・固定射角・保存不変など他の判定は維持する。さらに先へ進めると、カードで覆われた内部ラジオボタンを直接クリックする旧検査も停止した。現在の表示カードをクリックして選択済み状態を確認する方法へ直し、同シナリオの46検査が最後まで通過した。ゲームを70へ戻さず、現行仕様を検証する。

[当時の失敗箇所と修正理由](evidence/0.24.5/CI_0244_FAILURE.json)。

## 再現できた不具合と修正

1. **表示が端へ寄る・余白が残る。** iOS相当のstandaloneで、実際のinnerHeightが852pxのままvisualViewport.heightだけ798pxを返すと、旧3版ともアプリが798pxに縮む。通常倍率・入力欄非編集中のstandaloneではアプリのウィンドウ寸法を使う。ノッチとホームインジケーターはネイティブのsafe-area-insetで外枠から一度だけ避ける。ブラウザータブ、ズーム、キーボード編集中は可視範囲を追従する。
2. **敵の見た目の位置が往復する。** 11面・コロ、同じ敵の世界座標x820/y370を固定し、852／798pxの高さ通知を繰り返すと、旧3版は表示Yが約50.57px往復した。修正後は同じ通知で0px。敵AI・当たり判定・移動座標には変更を加えない。この条件以外の実機での揺れまでは原因確定していない。
3. **回転したステージ選択で横スワイプが動かない。** 従来の回転スクロール補正は縦軸だけを扱い、touch-action:noneでネイティブ横スクロールも止まっていた。旧3版は同じ実タッチでscrollLeftが0pxのまま、修正後は215px移動。論理座標の横／縦を判別し、ドラッグ中のscroll-snapを一時解除、終了時に復帰する。マルチタッチ・キャンセル・ドラッグ後の誤タップも処理する。
4. **選択タブの中央寄せ。** scrollIntoViewによるページ全体のスクロールを避け、横ストリップだけのscrollLeftで中央寄せする。ネイティブ横画面ではパネルの横タッチ操作を許可する。

これらの再現は0.24.2にも存在するため、0.24.3や0.24.4で新たに導入された不具合とは判定しない。ユーザーの実端末の全症状と同一だと断定はしない。

## 検証と範囲

- `npm test`：35検査群通過。
- `npm run check:generated`：146生成物の一致・再生成の安定性を確認。
- `iphone-viewport-browser`：79検査通過。393×852／390×844／375×812の日英、両方向のCSS回転、ノッチ／ホームインジケーター、逆方向のスワイプ、誤選択防止、ルート位置固定、全46取得物の実中心、古い高さ通知への耐性、チャージ保持と1回だけの発射、セーブ不変、Safariタブ相当・ネイティブ横画面を確認。テスト配信のmetaだけを緩和して残留ズーム1.5／2／1倍も実際に注入し、セーフエリアが一度だけ適用されることと2倍時の実タップを確認。
- 全ブラウザー回帰検査：35検査群の最終結果が通過。初回の全実行は34/35通過し、旧UIの内部ラジオボタンを直接クリックする検査だけが停止した。表示カードをクリックする検査へ修正して、その46検査を再実行し通過。初回失敗の集計も保存する。全100面×PC／回転スマホ、難易度・Workerとの一致、武器／スキル、チャージ・中断、機体切替・スワイプ、マップカメラ、回転、ボス勝利曲、章再生・映像、公開ページ参照を含む。ゲーム本体は全実行の開始後に変更していない。

Chromiumの実タッチ入力と制御したiOS相当の画面情報を使った検証。実機iPhone、実際のSafari/WebKit、インストールしたPWAの実機確認は未実施。WebKitの追加取得は配信先の403制限で実行できなかった。公開URLの直接画面確認も実行環境の403制限があり、Pagesの配信成功と分けて扱う。

今回は表示・入力の限定修正と旧版比較のため、外部STGへの事前配信は行わず、ローカルで再現条件・全100面・既存回帰を検証する。保存schema8/reset2・進行・在庫・AI・物理・100面のデータを維持する。版数とキャッシュは0.24.5。コミット、CI、Pages公開、実機確認はそれぞれ別に報告する。
