# ARCLINE 0.30.4 再挑戦の在庫復元と難易度クリア連動

2026-11-09。ユーザーが2点の方針を合意し、実装・検証・PR作成をマージ直前まで指示。main `f3bce10`（0.30.3、PR138/140を含む）が基準。マージ・公開は行わない。

## 合意した挙動

- 1〜99面では武器・スキルを戦闘中に通常どおり消費し、勝利した時点で残数を確定する。失敗・引き分け・再挑戦・途中離脱・再読み込みでは、その挑戦で使用した分が戻る。
- 取得した持ち物と取得台帳は一緒に保持する。拾って使った分も復元し、同じカプセルは再出現させない。各6回の所持上限は維持する。通常弾や転移に架空の消費を加えず、必殺技の戦闘内チャージも従来どおり。
- Hardでクリアした面はNormal/Easy、Normalでクリアした面はEasyでもクリア済みになる。逆方向には反映せず、下位で既に先まで進んでいる記録も減らさない。
- 旧セーブのクリア記録も初回読み込みで下位へ補完する。クリア数に応じた既存の標準解放は反映するが、上位で拾った在庫・取得台帳・補充・装備選択・既読・途中チェックポイントはコピーしない。下位の途中プレイ位置は維持する。
- マスターによる明示的な進行編集は従来どおり選択モードに限定する。自然勝利時に下位反映を行い、移行済みセーブを読み込むたびにマスター編集を打ち消さない。
- 100面の「このキャラから再挑戦」は既存の出撃時スナップショットを維持。100面を実際にクリアした場合の下位反映は共通。

## 正本と保存互換性

手書きの `game/dist/campaign-run.js` が戦闘内の残数と使用分をライブcontextで追跡し、保存する在庫は再挑戦用の復元可能量とする。実戦の残数は増やさず、勝利時だけ実残数を保存する。追跡データをWorkerや永続セーブへ追加しない。

`game/dist/save.js` の `inheritClears` を旧セーブ初回読み込みと自然勝利から共有。追加の `clearInheritanceVersion: 1` は移行済み印であり、schema8/reset2・保存キーは維持。既存セーブのリセットはしない。新仕様以前に失われた消費履歴の遡及返却はできない。

本編 `game.js`・`i18n.js` の再挑戦文言、`menus.js`・`ui/difficulty-ui.js`・入口HTMLの難易度/保存/道具ガイドを日英で同期する。版数・キャッシュは `game/runtime.json` と正式生成で0.30.4へ更新する。先行の敵移動・ラスボス・リコ・自傷・メニュー・HP設定を保持する。
