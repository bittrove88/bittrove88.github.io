# ARCLINE 0.21.2 — マスターモードとターン移動上限

最新の明示依頼により、開始画面・ホームのロゴを短い間隔で5回タップするとパスワード入力を開く。初期パスワードは `ARCLINE-MASTER`。認証後にクリア済み面数0〜100を指定し、保存する。0は1面、99は100面、100は全クリア状態。ダイアログを閉じると認証状態を破棄する。これは端末内の操作入口であり、サーバー認証ではない。

保存成功後だけライブの進行を置き換える。読み込み不能時には変更不可。書き込み失敗は元データを保持し再試行可能。古い自動保存が後から上書きしないよう保存キューと排他を共有する。獲得済みの機体・武器、装備、難易度、言語・操作配置は維持し、増やした進行に応じた仲間と基幹武器を解放する。古い加入待ちと映像待ちは解除。同章なら章の持ち物を保持、別章なら従来の章開始規則。ストーリーの利用可能範囲は設定した進行へ正規化する。

プレイヤーの自力歩行を、全機体共通で1ターンの左右累計140px（基本機体約2体分）に制限する。往復・チャージ取消・機体変更・ポーズ・マップ確認で回復しない。次の自分のターン、面の開始・再試行で回復する。壁に阻まれた未移動分は消費しない。移動速度・坂の補正は維持する。敵の移動、転移弾・転移スキル、攻撃効果による変位は歩行制限の対象外。操作欄に移動残量％を表示する。

主な変更は手書き正本 `game/dist/master-progress.js`、`save.js` の原子的なreplace、`engine.js` の移動残量、`game.js` の接続。UI正本 `game/ui/master-mode.js` と `game/styles/master-mode.css` をruntime.jsonへ登録し正式生成する。保存schema8/reset2・公開URL・100面のリレー・全弾道・画像音源は維持。キャッシュ版は0.21.2。

専用単体で進行範囲・解放・章在庫・保存失敗／順序、全10機の上限・往復・交代・次ターン回復を検査。専用ブラウザで小型横画面と縦持ちソフト回転の日英、初回ロゴとホームの入口、誤パスワード、範囲外、保存失敗と再試行、再読み込み、実入力の上限と残量表示を検査する。100面は新上限内の歩行だけを使い、敵の反撃を含む全10機の通常弾実戦で11手勝利。旧攻略証拠は当時の移動規則の履歴であり、新上限の成立証拠には流用しない。
