# ARCLINE 0.20.1 — iPhoneのシステム操作を優先

0.20.0公開後、下端からのホーム操作と右上からのシステム操作が使いにくいとの緊急報告を受けた修正。

- iPhone/iPadではネイティブ没入型の全画面を要求せず、既存の全画面状態は解除する。iOSの全画面ボタンも非表示。
- 実際の画面端から最低24 CSS pxまたは安全領域の大きい方をゲーム外へ予約。回転するアプリの外側に、OSジェスチャーを開始できる領域を確保する。
- 外側文書のtouch-actionとoverscrollをautoにし、iOSのタッチ抑制はゲーム操作面だけに限定。画面端とWebKit gestureは一括キャンセルしない。非iOSの既存の発射・マルチタッチ保護は維持する。
- 横向き表示、照準、スクロール、マップカメラ、保存schema8/reset2、進行・解放・物理・公開URLは維持する。

編集：`game/dist/viewport.js`、`fullscreen.js`、`game/styles/gameplay.css`、版数・生成物。iPhone UAで画面端のヒット対象、Webイベントの非キャンセル、全画面APIの不使用・解除、内部のカメラ／発射／保存を検証するブラウザテストを追加。

ネイティブiOSのホーム・コントロールセンター自体はChromiumの自動検証対象外。iPhone実機と公開画面の直接表示は未確認で、CI・Pages配信結果は該当PRへ記録する。
