# 0.24.3 画面と勝利曲の4点修正

難易度選択の表示崩れ、初期画面外の武器・スキル、説明で見えない低い天井、ボス勝利曲の開始遅延を修正する。

難易度画面では、ラベルの内側のカードを各グリッド列の幅に固定し、日英の説明を枠内で折り返す。試撃画面とボタンの配置、難易度別保存、任意の固定条件試撃は維持する。

取得物は `design/pickup_placements.json` の31個の座標と取得証拠を更新。全46個の種類・数量・出現ターン・placementIdを維持する。高い取得物を見せるために機体が極端に縮小されることを避け、既存カメラの画角に近い位置へ移す。表示側でも実際の物理中心とアイコン・名前の余白を確保し、画面外の中心から引いた目印だけに頼らない。5ターン目の出現位置も初期画角に予約する。31個は通常弾の実軌道と±2度／±3威力の9近傍を再計算し、各3件以上の取得を確認。基礎弾道・AI・HP・行動上限・全100面の地形は変更しない。

「低い天井」の説明は、天井ポリゴン全体をフレーミングの対象に加える。準備から通過結果まで天井を含む画角を保持し、結果の拡大で再び天井を画面外へ出さない。

勝利曲はボス戦の開始時に無音で事前読み込みし、撃破判定と同じフレームでそのAudio要素を再利用する。採用②の原本ハッシュを維持。ffmpegのsilencedetect（-40dB）で先頭の無音終端0.211625秒を確認し、再生開始位置を0.21秒とする。以後は原曲の全曲ループを維持。結果画面の再表示・加入・30/60幕間で再スタートしない規則、停止と復帰、100面のエンディング規則は保持する。

追加依頼により、難易度の任意試撃を48度・威力30へ変更。3モードとも同じ通常弾が画面内の標的へ当たり、0.55倍速で全表示・半分・発射方向のみの射線を見比べられる。マスターモードは開始／ロビーのロゴ5回を維持し、合言葉を小文字の `master` へ更新。旧合言葉は受け付けない。保存・進行変更の原子的な保存と失敗時保護は維持する。
