# ARCLINE 0.19.3 — 選択した面から本編を継続

## 依頼と変更

開始ボタンを統一した0.19.1でも、内部ではクリア済みの面が練習扱いになり、勝利後に同じ面を繰り返していました。最新の明示依頼「練習はないので、必ず継続する」に従い、この分岐を廃止します。旧AR-13の練習分離仕様はこの範囲で置き換えます。

どの解放済みステージを選んでも本編のチェックポイントとして保存し、勝利後は次の面へ進みます。30面・60面の幕間と100面のエンディングも、過去にクリアしている面から再生・継続できます。最大クリア数・機体解放・難易度は保持します。

同じ章内で面を選び直した場合は持ち物を引き継ぎ、別の章を選んだ場合はその章の開始規則を適用します。章ボス撃破後の持ち物リセット、同じ面のやり直し時の開始在庫・乱数種、保存失敗時の再試行は維持します。武器一覧は図鑑とし、使う武器は章の持ち物から選びます。通常弾はいつでも使えます。

`campaign-run.js` が選択面のチェックポイントを生成し、`game.js` から練習のHUD・報酬除外・同面ループ・幕間／エンディング除外を削除しました。保存キー・schema8/resetVersion2・戦闘エンジン・100面・素材・音源・公開URLは維持し、版数とキャッシュを0.19.3へ更新しています。
