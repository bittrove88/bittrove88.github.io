# ARCLINE 0.30.0 HPと行動上限の調整

2026-11-09。ユーザーが確定した設定をゲームへ反映。技・敵AI・物理・地形・配置・通常機体のHP・保存schema8/reset2を維持する。ローカル作業ブランチで実装し、マージ・公開は別工程。

## 正本と難易度

`design/combat_balance.json` が表示HP・部位HP・行動上限の正本。通常4面は5面ごとのテーマで共有する。NormalとHardのHP・行動上限は同じ。Easyは基準HPの75%を四捨五入し上限80。部位には本体と同じ減少率を一度だけ適用する。最終戦は各機体の担当量からEasyを計算し、総HPへ展開する。

通常面のNormal/Hard HPは全80面で現行を維持する。行動上限は1〜30面12、31〜40面16、41〜80面18、81〜90面22、91〜99面24。各範囲からボス面を除く。

中ボス5/15/25/35/45/55/65/75/85/95のHPは80/80/100/100/100/120/120/120/160/180、上限は16/18/18/18/20/22/24/24/26/28。5〜45面の部位は表示20、55面以降は30。

大ボス10/20/30/40/50/60/70/80/90のHPは140/160/160/180/180/200/200/240/240、上限は20/22/22/24/26/24/24/28/28。10面の部位20・30、20/30面は各30、それ以降は各40。

100面は自機HP100・各担当150・総HP1500・各20行動・必殺3。Easyは自機HP100・各担当80・総HP800。固定10機、4戦場、出撃時点からの再挑戦を維持する。20行動目の担当達成は交代・勝利を優先し、未達なら敗北。交代ごとにHPと使用行動数をリセットする。

## 実装

`game/tools/balance.py` が共通設定をレベルとエンカウントへ反映する。`build_campaign.py` と `build_encounters.py` が生成元、開始時の有効難易度HPと最終戦の担当量を `engine.js` が戦闘状態だけに適用する。元のレベル配列を変更せず、再開始・再挑戦で二重に縮小しない。最終戦の段階移行で作る部位にも同じHP倍率を適用する。画面の担当量・自機HP・再挑戦の上限説明は有効な状態から表示する。

攻略図の掲載入力は旧バランスの履歴として保持し、現在のHPでの合格表示とは分ける。今回の設定の入力・結果は [新しい検証記録](../../evidence/hp-action-0300/) に保存する。
