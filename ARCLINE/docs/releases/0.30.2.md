# 0.30.2 敵の歩行速度とテレポート演出

ユーザー依頼：41面以降の敵プレイヤーの歩行が速すぎる。71面以降の敵テレポートを、自機と同じ転移技として見えるようにする。

## 修正前の検証計画

- 歩行：`game/dist/game.js` の敵移動時間だけを自機と同じ160px/秒にする。距離の大きい移動を0.45秒へ圧縮しない。140px上限・移動候補・射撃計画は維持。
- 転移：転移先の決定と実際の座標変更を分離する。自機のTELEPORTと同じ弾・光跡・接触輪を表示し、到達時に既存の合法性検査と移動を行う。到着時の既存光輪を見せてから自機へ返す。転移専用の表示軌道は攻撃判定へ渡さない。
- 対象：本編コントローラ、配布キャッシュ、限定ブラウザ検査。敵AI・エンジン・物理・地形・回数・待ち時間・HP・在庫・保存schema8/reset2は変更しない。
- 検査：新しい `enemy-movement-browser` で41面の距離と実時間、71面の出発・飛翔・到着・次の操作、Worker／非Worker、ポーズ、離脱、30/120fps、PC／小画面、隣接する自機転移を確認。変更する生成物だけを正式な生成コマンドで再生成し整合を確認。
- 対象外：仲間画像、全100面の再攻略、全攻撃、音源デコード、エンディング。今回これらは変更しない。
- 完了条件：対象検査成功、地形・AI・物理・保存の差分なし。実装・ローカル検証と、CI・mainマージ・公開・物理端末を区別する。

## 結果

- 41面の140px歩行は旧0.45秒から0.875秒へ。最大速度160px/秒を30/120fpsで確認。序盤9面の15px・0.2秒と、固有敵の旧移動時間は維持。
- 71面の実発射から敵歩行・射撃・次の自機手番、次の転移手番までWorker／非Workerで確認。転移中にHP・射撃数は変わらず、到達時に1回だけ移動・使用回数・既存の到着光輪を確定する。
- 転移弾は自機のTELEPORT描画を共有。AIの合法な転移先へ向かう表示専用の弧で、物理シミュレータや攻撃命中処理は使用しない。既存の候補選択・反撃可能性・回数・2手番の待ち時間を維持。
- PC1280×720、横画面844×390、小画面568×320、30/120fps、ポーズと離脱を検査。通常RAFの約0.784秒の飛翔＋0.55秒の余韻は、実時間約1.33秒で完了。
- 通常速度で発射→飛翔→移動を確認。光跡が転移先を示し、先に座標が飛ばない。既存の到着輪だけを使い、全画面の閃光や不要な停止は追加しない。小画面でも青い転移弾・光跡と到着輪を確認。
- `enemy-movement` と `enemy-movement-browser` が成功。正式ビルド後の初回基準で生成物153件が一致。AI・物理・地形・HP・ダメージ・保存と自機の転移処理／描画はバイト一致を確認。
