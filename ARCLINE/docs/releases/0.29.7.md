# 0.29.7 開始メニュー・武器スキル確認・ストーリー・設定

開始画面とロビーにあったセーブ削除を「設定 → データ」へ移動。従来の確認、キャンセル、失敗時の旧データ保持、保存成功後の初期画面への復帰を維持する。設定を左のカテゴリナビ（プレイ環境・難易度・操作ガイド・セーブデータ）と右の内容ペインへ再設計。環境設定は説明と操作ボタンを一行にまとめ、難易度は射線・敵の狙い・選択状態を示す。見出しとナビを維持し、内容だけをスクロールする。ロビーの難易度ボタンからは該当カテゴリへ直行する。操作ガイドの古い「章ボス後に持ち物リセット」の説明も、現行の章越し持越しへ修正。

ロビーの武器・スキル確認は閲覧専用とする。武器カードの「この武器を装備」と、確認画面からの装備保存処理を削除。戦闘中の武器選択は従来通り。保有タブ横に「武器図鑑」「スキル図鑑」の入口を固定し、それぞれの図鑑へ直行する。スキルカードも選択でき、効果を表示する。ロビーでのスキル使用は行わない。武器・スキル図鑑には通常弾＋現行12武器・15スキルの共有図形・現在の名称・効果・保有数を掲載し、旧アイテムが在庫にあれば併載する。一覧・確認欄を分けてスクロールできるようにし、Escape・閉じるボタンで戻った際のフォーカスと背景入力を復帰する。

ストーリーは「入口 → 一覧 → 詳細」の三階層へ再設計。入口で章再生・旅の記録・仲間の記録を選び、章や仲間を一覧から開く。章一覧はコンパクトな2列で、番号・章名・面範囲・進行バー・クリア／進行数／未解放の状態を分離する。詳細は画面全体を使い、章の概要と再生操作を左右に配置。「一覧へ戻る」と「ロビーへ閉じる」を区別し、Escapeでも階層を一つ戻る。戻った一覧のスクロール位置を維持し、入口から章詳細へ直接進んだ場合は戻り先の選択章を表示する。未解放の章・仲間の条件、物語本文、開いた記録だけを既読にする処理は維持する。

編集元は手書きの `game/dist/index.html`・`menus.js`・`presentation.js`・`game.js`、生成元の `game/ui/onboarding.js`・`battle-ui.js`・`difficulty-ui.js`、新しい `game/styles/menu-ui.css`。版数・キャッシュは `game/runtime.json` から0.29.7へ正式生成。セーブschema8/reset2・保存キー・在庫の数値・取得記録・戦闘・地形・AI・物語本文は変更しない。

[再設計の計画](../../evidence/menu-inventory-0297/redesign/PLAN.txt)。4サイズ×日英に加え、0面と100面の進行で全12条件の設定／ストーリー導線を検査。ローカルでは先行4条件と、一覧の位置復帰を修正後に再開した残り8条件が成功し、最終PRのCIは12条件すべてを通して確認する。言語・左右配置・インストール案内・難易度別保存と再読込、背景の入力遮断、Tab移動、実タッチスクロール、章再生後の同じ詳細への復帰、既読だけの更新を含む。武器スキルと削除の隣接検査も再設計後に成功。前回成功の戦闘UIと保存単体はローカルで重複実行せず、PR全体のCI計画には保持する。
