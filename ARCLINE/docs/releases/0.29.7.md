# 0.29.7 開始メニュー・武器スキル確認・ストーリー・設定

開始画面とロビーにあったセーブ削除を「設定 → データ」へ移動。従来の確認、キャンセル、失敗時の旧データ保持、保存成功後の初期画面への復帰を維持する。設定は基本設定・難易度・操作ガイド・データの4項目に分け、見出しとタブを固定し各項目内だけをスクロールする。操作ガイドの古い「章ボス後に持ち物リセット」の説明も、現行の章越し持越しへ修正。

ロビーの武器カードは確認してから装備を確定する。スキルカードも選択でき、効果を表示する。ロビーでのスキル使用は行わない。武器・スキル図鑑には通常弾＋現行12武器・15スキルの共有図形・現在の名称・効果・保有数を掲載し、旧アイテムが在庫にあれば併載する。一覧・確認欄を分けてスクロールできるようにし、Escape・閉じるボタンで戻った際のフォーカスと背景入力を復帰する。

ストーリーは章番号・面範囲・進行バー・再生ボタン・保存を変えない旨をまとめ、選択中の章が一覧の表示範囲に入るよう調整。未解放の章は無効のまま維持する。

編集元は手書きの `game/dist/index.html`・`menus.js`・`presentation.js`・`game.js`、生成元の `game/ui/onboarding.js`・`battle-ui.js`、新しい `game/styles/menu-ui.css`。版数・キャッシュは `game/runtime.json` から0.29.7へ正式生成。セーブschema8/reset2・保存キー・在庫の数値・取得記録・戦闘・地形・AI・物語本文は変更しない。
