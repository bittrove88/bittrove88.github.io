# 0.31.1 — ボス移動・残像とラスボス固有技の統合

2026-11-09 日本時間。基準はmain `aba82d3`（PR142、0.31.0）。当初の0.30.5候補を本検証してPR143を作成した直後に、ボス移動・残像がmainへ入ったため、PRをDraftへ戻して先行変更を取り込んだ。追加質問へのユーザー回答「終極砲の照射ターンだけ移動せず、予告線を固定する」を最終仕様として反映する。

## 変更後の挙動

- 星環砲：本弾の基礎値20→40、衛星4→8を3発。合計上限32を維持し、部分命中の脅威を上げる。本弾単独も最大32。
- 重界砲：速度係数1.1・重力0.65。高い放物線を優先し、屋根では通る低い軌道を選ぶ。粗い探索で命中候補がない場合だけ周辺を細かく再探索する。予告位置・姿勢・発射方向を固定し、地形衝突と着弾36、双方の次の一射へ作用する領域を維持。
- 終極砲：直前のARC手番から、文字なし・塗りなしの控えめな点線を表示。直前の移動を終えた砲口から、元の予告地点へ射線を揃える。照射する手番は歩行・転移せず、砲口で0.5秒集光し、予告地点まで0.3秒で届く太さ110pxの螺旋レーザーを放つ。
- 判定は予告地点だけでなく、前方の太い射線全体。手前・奥でも重なれば38を一度だけ適用し、線外なら回避する。地形を貫き、転移後の自機へ追尾しない。発射音・反動は出射時、命中音・数字・HPは先端の到達時。保持0.62秒と減衰0.18秒を計画に含める。
- 照射手番の不動は移動判断の例外1件であり、回数を消費しない。攻撃した敵手番として待ち時間は一度だけ進める。それ以外の手番はPR142の歩行・転移・残像を維持する。
- 残像が発砲して固有技を延期する場合、その手番は通常どおり移動・通常攻撃を行い、レーザーの順番を保持する。次のプレイヤー手番で移動後の砲口へ線を揃え、次の実照射を不動にする。
- 再挑戦で、出撃時記録にない古いレーザーチャージが残らないよう消去する。永続セーブ形式は変更しない。

[変更前後と詳細設計](../change-requests/ARCLINE_FINAL_PROJECTILES_DETAIL_20261109.md)。自機HP100、担当150（Easy80）、20行動、必殺3、10機・4戦場、PR141までの在庫・難易度継承を保持。転軌砲、他99面の戦闘、地形・取得物・原画・音源・schema8/reset2を変更しない。
