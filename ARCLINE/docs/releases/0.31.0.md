## 設計矛盾への改善

- 通常敵の反撃評価は本体HPだけなので、部位への有効打と自機の向き直りもボスの評価へ含める。背後への合法な退避を、古い照準方向のせいで除外しない。固定トリガーや追加の発動確率低下は設けない。
- 大型機は実寸で候補を探す。部位・装甲は位置と向きに追従。60面の既存装甲下部と支持斜面の接触は許容し、装甲上部/他の壁・天井への侵入を拒否する。地形を改変して解消しない。
- 30/90面の旧固定横揺れを新しい位置取りに置換。旧座標への復帰や徒歩予算への上乗せを防ぎ、雲・部位・フェーズ変化は保持。
- 残像で本体の攻撃順/再転移CD/ターンを余分に消費しない。固有大技が予定されていれば通常攻撃へ置換して持ち越す。通常の予定は実行して順を進める。
- 自動カメラは旧位置の残像も収める。残像から撃つときに本体の砲口を誤って光らせない。

## 本検証での追加修正

初回の計画CIは [run42606708872](https://github.com/bittrove88/bittrove88.github.io/actions/runs/42606708872) で5スイートと生成物一致が成功。その後の低HP条件の確認で、最終戦の残像威力を残HPで制限した後に25%へ縮小していたため、低HP時に過小ダメージになることを再現した。補助威力を計算してから残HP上限を適用する順に修正し、4戦場それぞれで実命中・表示イベント量・致死時の本体行動抑止を検査する。既存の通常攻撃/大技の威力は変更しない。追加後のボス処理検査は284項目。修正headで計画CIを再実行し、成功したheadだけをマージ対象にする。

代表実戦は50面（推奨モグ・転移1回/残像1回を含む9行動）と75面（推奨モグ・転移1回、残像なしの6行動）でNormal/seed4697の撃破が成立。実際の入力と本番エンジンの敵行動を使用し、自動探索と人の難易度評価を区別する。[実戦入力記録](../../evidence/boss-motion-0310/verification/NATIVE_MATCHES.json)。
