# プロモーションムービーの公開（2026-11-03）

ユーザーの依頼により、制作した2分50秒・全7曲の動画を既存ARCLINE内の `promo/` で視聴できるようにする。

- URL： https://bittrove88.github.io/ARCLINE/promo/
- 720p版を標準にし、1080pへの切り替えと両方の保存リンクを用意。
- 自動再生を行わず、native controls・playsinline・metadata先読み・ポスターを使用。
- 画質変更時は再生位置と再生／一時停止の状態を保持。初回source要素の取得失敗も検知してMP4直接リンクを表示。
- 動画は両方とも170秒・H.264/AAC。1080pはWeb配信用に圧縮。尺と内容を維持し、各ファイルを100MiB未満に収める。サイズ・SHA256は `promo/media.json`。
- アプリ本体・セーブ形式・進行・既存URLは変更しない。ARCLINE内部ページとして既存カタログの1件を維持し、ルートの空白ページも維持する。

検証：必須単体テスト・生成130出力一致。専用ブラウザ検査13項目（4画面サイズ、両動画の170秒／解像度、再生、画質切替時の位置・状態維持、保存リンク、取得失敗案内、攻略保存へのアクセスなし）を通過。`site-tests/promo.test.cjs`を正式ブラウザスイートに登録。結果は `evidence/promo-pages/PROMO_PAGE.json`。

物理端末と人による通しの試聴は未確認。公開URLの直接表示は管理環境の通信制限により未確認とし、GitHub CI・Pagesデプロイ状態はPRで確認・記録する。
