# 0.31.4 — 転移で残った残像を見分ける

0.31.3の公開後、「テレポート時の残像が見にくい」「残像が残ったことも認識できない」という指摘を受領。単色の薄いシルエットと短時間の識別表示では、転移後の状況を伝えきれていなかったため、出現と待機中の表示を改善する。

## 表示の変更

- 原画の砲身・装甲・キャタピラ等を保持して青く着色する。全画素を同じ色で置き換える処理をやめ、内部の形を残す。待機時の不透明度を0.46から0.84へ上げ、出現直後は最大0.96。
- 濃い外縁と明るい内縁、足元の輪を付ける。縁は画面倍率に応じた太さとし、小画面でも背景へ埋もれにくくする。
- 出現時は旧位置へ線を結んだ「残像が残った」／「ECHO LEFT BEHIND」を14pxで表示。強調を1.2秒保持し、その後1秒で弱める。追加強調が終わっても、残像が消えるまで「残像」／「ECHO」の表示、縁取り、足元の輪を残す。
- 残像を作った転移の着地後だけ、表示の間を0.55秒から0.95秒へ延ばす。旧位置の残像と移動先の本体を一緒に収める画角へ0.14秒で移り、0.45秒保持、0.26秒で通常画角へ戻す。自機操作を再開する前に復帰する。
- 動きを減らす設定では出現時のカメラ移動と広がる輪を省き、識別表示と静止した縁・足元の輪を残す。発砲時の既存フォーカスは保持する。

残像の攻撃先・弾数・射程の予告は加えない。移動先の本体とは色と識別表示で区別する。中ボスに残像は追加しない。転移弾の速度、転移の発生条件・回数・クールダウン、残像の照準・威力・寿命・破壊条件、手番、HP、地形、在庫、保存は変更しない。通常敵と中ボスの転移後の間は0.55秒のまま。

## 実装と連動

基準はPR151の公開済みmain `8df8a5a7dc3e8988e22e0c7bede612e0c73cdfd4`。時刻と出現用の画角は `game/ui/charge-camera.js`、着地後の待ちは `game/dist/game.js`、残像の原画・縁・識別表示と画角適用は `game/dist/render.js`。新しい戦闘状態や敵AIは加えない。通常画角を別に保持し、出現用の画角を次手番へ混入させない。

runtime/cacheを0.31.4へ揃え、ゲーム入口・Worker参照・総覧・攻撃確認・キャラ確認・ステージ案内・サイトの実弾道データを正式生成する。

## 事前確認と進行状態

[記録と確認画面](../../evidence/echo-readability-0314/PRECHECK.json)を参照。表示の計算56項目、実ブラウザ8ケースが成功。50面は本来の地形で近接配置を作り、100面は後半の2連射を確認するため平地へ配置する。PC1280×720、小画面568×320、日本語・英語、Worker・協調実行、動きを減らす844×390を含む。

実際の転移、出現時の文言・2地点の画角、操作再開前の復帰、3秒後にも残る識別表示、発砲前の一時停止、残像→本体→次の自機操作を確認した。表示中に手番・HP・クールダウンを消費しない。初回の英語確認では、セーブ読込が既定の日本語を復元していた検査用データを修正し、保存設定を含む日英の経路で確認し直した。

実描画の事前確認後、runtime/cacheのみを0.31.3から0.31.4へ更新。挙動のソースは同一。正式な生成物一致と既存カメラ・通常敵移動への回帰は、[候補計画](../../verification-plan.json)で最終合意後に確認する。事前確認の成功を本検証完了と扱わない。
