# ARCLINE マーケティング・制作資料

作成：2026-11-09。サイト更新・動画編集・配信素材制作に渡すための制作ブリーフ v2。

目的は、収益よりも「遊んで楽しかったと感じる人」を増やすこと。大ヒットを前提にせず、小さく配信し、反応を見ながら改善する。

主訴求は**戦略性と爽快感**。コアターゲットは、敵と地形を読み、自分の作戦で突破し、強い砲撃を決める快感が好きな人。入口のコピー案は「読み切って、撃ち抜け。」。最近の攻撃演出・命中同期・ボス移動・予告固定の更新を根拠に、判断から攻撃の手応えへつなぐ構成にする。

## 状態の読み方

- **ユーザーの方針**：楽しんでくれる人数を重視、手軽な配信を優先、プロローグ全編と100面の結末を保持。冒頭の構成は上記記録に従う。
- **確認した情報**：公開レビューや開発者の報告、参照コミットのコード・資料で確認できる内容。市場全体を代表するとは限らない。
- **制作推奨案**：本資料で選んだターゲット・コピー・構成・配信順。制作を進められる具体案であり、ユーザー調査で確定した成功法則ではない。
- **公開前の確認**：撮影した実プレイ、対応端末、配信先の現行規定など。未確認の宣伝文句を埋めるための項目ではなく、公開原稿を確定する条件。

この一式でサイトのデザイン・動画の絵コンテ・撮影準備に着手できる。v2に合わせた完成動画・追加収録・配信申請一式は未完成。[PR148](https://github.com/bittrove88/bittrove88.github.io/pull/148)ではv1の動画初稿が制作中で、使える実録と編集基盤を活かしながら、必殺技と戦術判断を強める。公開用マスターの確定には、[素材台帳と掲載表現の確認](ASSET_PLAN.md)が必要。

## 実装との関係

参照基準は main `9ebc251943f4ad9ace87f2983cc34c028a3c78d0`。その時点の [runtime.json](../../game/runtime.json) は0.31.2。これは資料作成時の参照点であり、将来の最新版を固定する指定ではない。

本資料の追加は文書のみ。ゲームの導入・戦闘・保存・サイト・既存動画を変更していない。既存素材の再利用と新規制作の順序を定める。実装時は [開発ガイド](../design/ARCLINE_GAME_DEVELOPMENT_GUIDE.md) と対象コミットを確認する。

ユーザーの調査方針は「ARCLINEの特徴に類似作を当てはめず、類似作で受け入れられている軸を先に探す」。調査結果とARCLINEへの適用仮説を混同しない。今回の戦略性・爽快感への改訂は、最近の更新を踏まえたユーザーの指摘に基づく。新しい市場調査で支持率を確認したという意味ではない。
