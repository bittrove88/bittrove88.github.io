# ARCLINE マーケティング・訴求資料

2026-11-09改訂。コンテンツライターへの引き継ぎ資料。主軸は戦略性と爽快感。

## 最初に読む資料

**[コンテンツライター向け訴求ブリーフ](CONTENT_BRIEF.md)** を、サイト・動画・配信ページなどの内容を考える共通資料とする。

中核ターゲット、その人が求める体験とためらい、六つの伝達テーマ、各テーマの具体的な中身・商品上の根拠・分かってほしいこと・感じてほしいこと・伝わった目安を記載している。

本改訂では、これまでの掲載原稿・コピー案・動画の台本・秒数・カット割り・撮影割当を、訴求目的と判断材料へ置き換えた。具体的な言葉と構成は、担当のコンテンツライターが決める。

## 根拠と仮説

ユーザーの方針は、収益より楽しんでくれる人数、手軽な配信、戦略性と爽快感、プロローグ全編と100面の結末の保持。

公開レビューの受容軸、現行ゲームの実装・設計、ターゲットの心理や訴求効果の仮説を分ける。実際のユーザー発言・調査済みの支持率・完成素材を創作しない。

実装参照は main `c56a4aa680dd942e027b9ed218a5ea8cee1eb0a0`、ゲーム0.31.2。資料の改訂でゲーム・サイト・動画を変更していない。制作中のPR148や新しい導入の実装状態は、その対象コミットとPRで確認する。
