# 訴求ムービー初稿 r1

PR145の制作ブリーフを使い、0.31.2の実描画から30秒・15秒のムービーを制作した。本番Pagesには未反映。構成の最終合意前の初稿であり、本検証・CI・実機評価は未実施。

## 誰に、何を残すか

対象は[戦略](STRATEGY.md)の第一候補「一人で自分のペースで、狙いを少し変えて結果を確かめる遊びが好きな人」。物語の説明から始めず、「ここを壊したい→自分の一射で開く→次の射線を試す」という出来事を先に見せる。旅と規模は、その後に興味を広げる役割にする。

| 尺 | 内容 | 意図 |
| --- | --- | --- |
| 0〜5.3秒 | 7面、通常弾のチャージ・発射・遮蔽破壊 | 狙いと結果を同じテイクで読む |
| 5.3〜11秒 | 同じ対戦の次の自分の手番。開いた射線を使う一射が命中 | 敵の手番を省いたカットは「次の自分の手番」と明示 |
| 11〜18秒 | 4面、転移弾→着弾→実移動 | 「冒険で出会う仕組み」と示し、最初から全部使えると誤認させない |
| 18〜22秒 | 61・84面の現行描画、各2秒 | 「20テーマ、100ステージ」を裏付ける。後半の地形の静止画であり勝利録画ではない |
| 22〜26秒 | 既存P03-01の便り | 旅の理由への興味を残す。帰還と結末を出さない |
| 26〜30秒 | 既存ロゴ、ガンの原画、主見出し、ゲームへのCTA | 「自分でも一射を試したい」を行動へつなぐ |

15秒版は同じ一射と次の手番を11秒まで使い、CTAを4秒保持する。6秒版・60秒版は初稿の対象に含めない。新しい回想導入を実装済みとして紹介する映像は使わない。

## 出典と編集条件

- ゲーム基準：main `9ebc251943f4ad9ace87f2983cc34c028a3c78d0`、0.31.2。PR145のマーケティング資料を含む。
- L01/L02：隔離したブラウザの合成進行で解放済みの7面・4面を選択。本編のDOM操作とSpaceキーのチャージ・発射、実エンジンの敵行動・手番・衝突・描画を使う。HP、威力、地形、物理、演出、機体描画の差し替えなし。
- 30fpsで本編の時計を1/30秒ずつ進めて描画を収録。これは編集用の決定的収録であり、物理端末の実測fpsや無編集の実時間プレイの証拠ではない。射撃・飛翔・転移を倍速にしない。
- L01の破壊と次の命中は同じ収録テイク。敵の手番をカットした地点は台本と字幕に明記。L02は移動後の実フレームを0.5秒保持して別場面へ切り替える。
- BGMは既存 `assets/audio/bgm/bgm_battle_a.m4a`。効果音は本編の `ArcSFX.timeline` と収録した発射・着弾の時刻に合わせた編集ミックス。ブラウザ音声の同録ではない。プロローグの音源・本文・本編の導入は変更しない。
- 物語の抜粋は既存 `assets/cinematics/P03-01.jpeg`。ロゴは既存369×54のPNGを原寸配置。ガンは既存894×634の透過原画。第三者の参考作品の映像・音源・画像は使わない。
- [操作・衝突記録](../../promo/edit/capture.json)、[編集台本](../../promo/edit/timeline.json)、[素材ハッシュと仕様](../../promo/edit/manifest.json)を保存。

## サイトへの反映案

既存の`promo/`を新しい30秒版の入口に変更し、15秒・字幕言語・画質の選択と保存リンクを用意。自動再生はしない。画質・字幕言語を変えた際は再生位置と停止状態を保持し、尺の切替は先頭で停止する。紹介サイトのリンクは`0:30`へ揃える。

旧170秒のMP4は削除せず保持するが、旧画面と帰還の映像を新規ユーザー向け主動画として案内しない。[旧素材記録](../../promo/edit/legacy-media.json)と新しい`promo/media.json`を分ける。ゲーム版数・公開URL・セーブ形式は変更しない。

## 制作中の事前確認

- 実エンジンの記録で、L01の遮蔽1単位の破壊と、同じ対戦の次の自分の射撃で敵へ1.5単位の命中を観察。L02で転移弾の着弾後に自機が対岸へ移動したことを観察。
- 動画12ファイルの尺は30.000秒／15.000秒。横1920×1080・1280×720、縦1080×1920、30fps、H.264/AACを出力仕様として確認。
- ローカルのRange対応配信で、1440px・390pxのページ試写。横はみ出しなし、30秒版は自動再生なし。英語字幕への切替は4.5秒を保持し、15秒版の選択は0秒で停止。ページのJavaScript例外なし。
- 字幕つき構成一覧と代表フレームを目視確認。発射・着弾音の位置は本編イベント時計から配置し、出力音声のレベルを観察した。

これらは制作中の限定確認。本検証スイート、全編の人による試聴、初見ユーザーによる無音・スマホ相当の理解評価、物理端末の操作、公開URLでの確認は未実施。初稿を見て、狙いと結果、次の手番へのカット、転移の条件が伝わるかを判断する。
