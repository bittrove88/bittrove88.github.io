## 2 素材は何を裏付けるために使うか

| 素材の役割 | 読み取れる必要があるもの | 確認する条件 |
| --- | --- | --- |
| 地形を使う攻略の根拠 | 何が障害で、どの選択が状況へ働いたか | 現行の地形・弾道・作用と一致する |
| 敵を読んだ判断の根拠 | 何が予告され、どう動き、どんな結果になったか | 実際の手番と回避の関係が正しい |
| 攻撃の手応えの根拠 | 選んだ技の特徴、届いたときの作用と反応 | 別の技や別試行の効果を、同じ攻撃の結果としてつながない |
| 攻略の広がりの根拠 | 地形・敵・仲間が変わることで、考えることが変わる | 進行後の機能を初期状態と混同させない |
| 旅と愛着の根拠 | ガン、便り、風景、仲間の存在と雰囲気 | 重要な答え・結末・感情の頂点を先に明かさない |

素材の数や特定の面を採用条件にしない。素材を使う理由が、訴求ブリーフのM1〜M6のどれにつながるかを判断する。

既存の参照先は[サイト画像の記録](../../site/gameplay-captures.json)、[現行サイト](../../index.html)、[プロモページ](../../promo/index.html)、[PR148の動画初稿](https://github.com/bittrove88/bittrove88.github.io/pull/148)。サイト画像の記録上の実装版は0.30.2で、勝利の録画ではない。最新挙動を示す証拠として使えるかは内容を比較する。PR148は制作中の別変更で、今回の文書改訂で完成・更新したとは扱わない。

原画・ロゴ・音楽・効果音は既存作品素材から確認する。公開リポジトリにあることを広告や再配布の無条件の許諾と扱わず、使用範囲とクレジットを確認する。他作品のキャプチャは[参考リンク](DESIGN_REFERENCES.md)として参照し、ARCLINEの素材へ転用しない。

## 3 掲載前に確定する情報

| 項目 | 確認が必要な内容 |
| --- | --- |
| 無料・課金・広告 | 収益より楽しむ人数を重視する方針と、実際の配信設定が一致するか |
| ブラウザ・インストール不要 | 公開する入口で、追加導入なしに遊べるか |
| スマホ・PC対応 | ブラウザ、入力方法、横向き、音声などの対応条件 |
| 保存・再開 | 公開先で保存・再読込が成立するか。機種間同期のような別機能を約束しない |
| 回想型の導入 | [冒頭の方針](../change-requests/ARCLINE_MARKETING_OPENING_STRATEGY_2026_11_07.md)が実装・確認済みか |
| プレイ時間・難しさ・評価 | 対象条件と根拠があるか。未測定の時間・支持率・誰でも楽しめるという保証を作らない |

## 4 配信先との関係

戦略上の候補は、現行サイトを活かし、itch.ioのブラウザ公開を第一候補、PLiCyを比較候補にすること。配信ページも共通のターゲットとM1/M2・M3の価値を軸に、実際の利用情報を補う。

[itch.ioの公式HTML5ガイド](https://itch.io/docs/creators/html5)と[PLiCyの公式サイト](https://plicy.net/)で、入稿・容量・埋め込み・保存・外部参照などの最新条件を確認する。各社の現行要件を本資料で確定したとは扱わない。媒体固有の原稿や素材仕様は、入稿条件とライターの構成に合わせて決める。

商品情報の確認、素材の完成、配信実装、公開済みの状態は、それぞれ区別して記録する。
