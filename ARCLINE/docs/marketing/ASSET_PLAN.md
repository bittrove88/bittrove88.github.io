## 3 素材ごとの記録形式

制作開始時に素材IDごとの作業記録へ下記を埋める。ゲームの正本や既存画像記録を重複管理するのではなく、実際に使用した素材を追える形にする。

```text
素材ID・ファイル名:
用途・掲載先・言語・縦横:
状態: 未着手 / 制作中 / 確認中 / 掲載可能 / 保留
担当・確認担当:
出典ファイル・原本URL:
ゲームのコミット・版数:
面・機体・難易度・装備・操作条件:
テイクと使用範囲・編集内容:
原寸・fps・尺・形式・SHA-256:
著作者・使用許諾・利用範囲・クレジット:
ネタバレ・未加入キャラ・初期機能の誤認確認:
実プレイと広告表現の一致・対応端末確認:
派生ファイルと確認日:
```

担当者名は未指定のため未割当。必要な役割は、企画判断、ゲーム収録、サイト制作、映像編集、権利と公開の確認。一人が兼任してよい。撮影と編集の工数は、代表テイク1本と30秒ラフ編集の作業量を見て見積もり、根拠なく公開日を固定しない。

他作品のキャプチャは[参考リンク](DESIGN_REFERENCES.md)として参照する。ARCLINEの配布素材へコピーしない。ARCLINEの既存音楽・原画も、公開リポジトリにあるだけで第三者が自由利用できるとは扱わず、今回の配布・広告の利用範囲を確認する。

## 4 宣伝文句と掲載可能になる条件

| 表現 | 根拠・現状 | 掲載条件 |
| --- | --- | --- |
| ターン制砲撃、20テーマ100面、10機 | 現行サイト・README・ゲームの正本に記載 | 撮影対象コミットでも一致することを確認 |
| 反射・破壊・転移 | 現行サイトに実エンジンのデモあり | 紹介する作用の実録を確認。解放前から全部使える印象を避ける |
| 無料で遊べる | 収益より楽しむ人数を重視というユーザー方針。無料配信を推奨 | 実際の配信設定・広告・課金の有無に一致させる |
| ブラウザで遊べる・インストール不要 | 現行Web版あり | 掲載先の埋め込みや実リンクで追加導入なしに動くことを確認 |
| スマホ対応・PC対応 | 実装上の入力と、実際の対応環境は別 | 対応ブラウザ・横向き・音声・タッチ/マウス等を確認し、環境を明記 |
| 続きから遊べる | ローカル保存の実装あり | 各配信先の保存・再読込・別オリジンを確認。機種間同期は約束しない |
| 回想型の導入・最初の一撃から始まる | ユーザー方針を記録済み | 新導入の実装・保存保護・既読分岐の確認後に現行機能として掲載 |
| 30秒で面白い・誰でも簡単・一面○分 | 現時点で実測や根拠なし | 保証表現にしない。調査結果を得ても対象条件とばらつきを示す |
