## 現在のゲーム

ガンから始まり、5面でハナ、10面でコロ、15面でバン、20面でソラ、25面でリコ、30面でヒバリ、40面でモグ、60面でリン、80面でユイが加入する。20テーマ×5面、80通常戦・10中ボス・10大ボス。中ボスは5/15…95面、大ボスは10/20…100面。

通常弾は無制限。通常戦の必殺は自分の第2・4・6ターンに1発ずつ、守り手は最初から3発。機体変更ではHP割合・行動数・必殺残数を維持する。有限の武器・スキルは章ボスまで持ち越す。転移弾は4面から、着弾先へ移動して1行動を使う。

左の2スティックで移動と照準、右の長押し発射。外へずらして離すと取消。左右反転・日英・横向き戦闘・一時停止・難易度別の点線射線に対応する。初回に難易度を確定し、開始画面からも変更できる。

冒険開始後、ストーリーモードでクリア済み各面・9加入画面・プロローグと30/60面の幕間・エピローグを振り返れる。原画10枚と本編23枚は照合済み。再生は進行・編成・加入待ちを変更しない。

## BGM・自動エンディング（0.16.0）

採用済みAAC7曲をストリーミング再生し、通常面・中ボス・大ボス・100面の規則で切り替えます。同じ曲は継続し、ボスから戻った通常曲は保存位置から再開します。音声オフとゲームのポーズを分けます。

エピローグは既存11ショットの台詞・順序・表示尺を維持し、音楽の再生位置で旅の記録・既存ロゴ・静寂・自動復帰まで進みます。回想も手動送り・スキップ・手動ポーズを禁止し、終了後に元の画面と音楽へ戻ります。音源失敗時は検証済みの長さと単調時計へ切り替えます。敵3点とロゴは承認済みシートを再現可能な手順で切り出し、原本を維持します。

新しい必殺技説明は既存の操作デモ後、既存ユーザーには最初の戦闘機会に一度表示します。実際の補充を第2・4・6ターンの境界で検出し、操作を遮らない中央通知を1.5秒表示します。新規既読キーだけ追加し、戦闘バランスは変更しません。

BATTLE_Aは第6章の暫定許容に従う全曲ループです。実際の途中ループ点・聴感品質・実機・公開URLでの再生は別途確認が必要です。

## 保存と前回0.15.5の更新

公開版0.17.1。保存schema8・resetVersion2と保存キーを維持し、追加リセットは行いません。過去のresetVersion2より前の記録に対する既存の一度のリセット契約は変更していません。

新規は端末別案内→プロローグ→ガンの原画紹介→照準・発射と3難易度の射線体験→確定→ステージ1へ進みます。既存の進行・難易度確定済み記録には再体験を強制しません。中断した工程と試射の完了記録を保存します。インストール案内は本編保存と別管理です。

モグの通常弾のみ短距離型へ調整し、固有必殺・他機の性能・100面・解放条件を維持。仲間加入の原画非表示原因を修正し、一覧も原画へ統一。映像はcoverと一方向のカメラ移動を使い、最初の便りの封蝋だけ画像を差し替えました。

補助武器・スキルの残数は章ボス戦まで持ち越し可能です。章ボス撃破後、所持品はリセットされます。練習で使う武器はクリア済み面の再プレイ用で、通常の冒険の在庫を変更しません。

## 起動・生成・検査

```sh
python3 -m http.server 8000
# http://localhost:8000/ARCLINE/game/dist/
cd ARCLINE
npm ci
pip install -r requirements-dev.txt
npm test
npm run check:generated
npm run test:browser
npm run build
python3 game/tools/build_playables.py --output /tmp/arcline-package
```

生成・検査用の依存は配布ゲームへ含めない。配布ZIPはGit外へ出す。物理端末Safari/Android、インストールPWA、YouTube本番認証、人による全100面通しプレイは未確認。
