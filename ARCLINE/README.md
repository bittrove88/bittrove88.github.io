## 新しい旅と保存

ガン一機で、止まった港から出発。5面でハナ、10面でコロ、15面でバン、20面でソラ、25面でヒバリ、30面でリコ、40面でモグ、60面でリン、80面でユイが加入する。加入時に機体を変えるかを選べる。所有した仲間は、戦闘中の自分の照準手番にも変更できる。

**0.13導入時、旧保存の攻略進行を一度だけ0へ戻す。** 選択機体はガン、プロローグと1面から再開する。所有機体・言語・操作の左右・難易度は保持。旧版に所有履歴がなければ、以前の使用権を失わせないよう10機を所有済みとする。新規ユーザーはガンのみ。

章在庫・開始時チェックポイント・武器解放・物語とプレビューの既読は初期化。移行前の原文と最初のバックアップを残し、書込み失敗は再試行できる。schema8/リセット世代1の再読み込みでは進行を再リセットしない。旧クライアントの書戻しも防ぐ。[保存移行仕様](design/expedition_013/SAVE_MIGRATION.md)。

今回の旅での加入と、旧保存から保持された所有権を分ける。旧所有者が先の機体を操作しても、物語はガンから出会いを重ねる順序で進む。

## 戦闘と操作

20テーマ×5面、80通常戦・10中ボス・10大ボス。中ボスは5/15…95面、大ボスは10/20…100面。固有部位を止めると攻撃が弱まり、コアを狙える。通常敵の中心直撃、中ボスのコア倍率1.5、大ボスのコア倍率2は維持し、倍率を二重に重ねない。

通常弾は無制限。通常戦の必殺は**自分の第2・4・6ターンに1発ずつ**解放、開始時0発、合計3発。中ボス・大ボスは最初から3発で、再充填しない。機体を変更しても残数は共通。現在HPの割合を切り捨てて新機体へ換算し、敵HP・地形・行動数・持ち物を保持する。変更だけで回復できない。

最新の通常弾・耐久・チャージ・必殺ダメージ調整を引き継ぐ。チャージは飛距離を変え、威力を増やさない。連射・分裂・連続爆破の合計に1行動の上限を適用する。広範囲は減衰と遮蔽が効く。

|機体|HP|最大チャージ|必殺の個性|合計上限|
|---|---:|---:|---|---:|
|ガン|140|2.6秒|遮蔽破壊・押し出し|35|
|バン|120|2.6秒|着弾点から前方140・半角28°の衝撃|35|
|ヒバリ|120|2.6秒|見通せる相手の近くで空中炸裂|30|
|ハナ|100|2.4秒|時間差の三連射、18/発|48|
|リン|100|3.2秒|精密な中心命中、通常直撃40|50|
|モグ|120|2.4秒|出力で前進間隔を変える3回の爆破、13/回|39|
|コロ|100|2.4秒|床を走り、空隙で落ちて再走行|30|
|ソラ|100|2.8秒|頂点から8発の落下弾、18/子弾|45|
|リコ|80|2.4秒|反射0〜4回で24/28/32/36/40|40|
|ユイ|100|2.8秒|牽引して遅延圧縮、30＋12|42|

移動と照準の2スティックは左、長押し発射は右。発射を押したまま左の操作を切り替えられる。発射の指を外へずらして離すと取消、戻せば発射を再予約。キーボードは矢印とSpace、チャージ中のEscで取消。照準に絵文字は使わない。左右反転、日本語/英語、横向き、一時停止、難易度別の点線射線を維持する。

車体は実際に歩いた方向へ向き、停止中は保持する。照準はその向きからの相対角度。90°より後ろを狙っても、車体は反転せず砲身だけが後ろを向く。坂・左右・後方照準の砲口と実弾の原点を共有する。

転移弾は4面から無限。攻撃の代わりに1行動を使い、最初の接触先へ移動。側壁や天井なら接触側で落下してから敵の手番へ。安全な足場がなければ移動せず行動を使う。敵との安全距離を着地時とターン境界で揃え、不意の開始位置戻りを防ぐ。

## 100面と物語

山・崖・床・破壊できる壁や天井・有限の浮島を個別に組み合わせた100面。1〜30面は環境装置を最大1種類に絞る。11〜14はコロの転がり、21〜24はソラの高弾道、31〜34はリコの1回→2回反射、61〜64はリンの破壊→精密射撃。後半は高低差・準備・環境変化の手順を増やす。

各面の目的、構造の意図、基本／代替の攻略例、利用可能な推奨機体、敵との関係、行動予算と実測結果を[設計データ](design/expedition_013/stage_design.json)へ記録する。[図解](design/expedition_013/)は実データの輪郭、[操作列](design/expedition_013/stage_verification.json)は本番物理の成立例。自動探索による勝利と人の難易度評価は別。

大分断、止まった輸送路、届かなかった返事、守り手が本来の仕事へ戻る物語を維持。ガンだけのプロローグ、仲間との出会い、30/60面の幕間、全100面の復旧メッセージ、四場面のエピローグをつなぎ直した。旅の記録は概要から詳細へ開き、未加入者と終盤の核心を先に語らない。

自機10・通常敵12・中ボス10・大ボス10の全42モデルは専用Canvasパス。機体の形と配色、マットな面塗りを維持する。弾道の下地3px、主線5.5/8/10px、弾体、着弾の半径・寿命・粒子の飛距離を保持する。外観の収集・装備機能は廃止し、機体固有の姿と武器演出は残す。

## 持ち物

武器箱40個（各テーマ2つ）、スキル箱10個、中ボス10戦のスキル報酬を配置。武器箱は3発まで補充。武器3種類・スキル2種類、各3まで。通常弾・転移・固有必殺は章在庫と別枠。拾った武器を勝手に装備しない。

中ボスを越えて持ち越し、10面ごとの大ボス撃破で有限在庫をリセット。報酬は勝利確定時に1回、練習からは持ち帰らない。中断復帰・敗北は面開始時の在庫・乱数・取得台帳へ戻る。防壁、砕路、修理、満杯時の交換／見送り、互換性制限を維持する。

## 起動と再生成

```bash
python3 -m http.server 8000
# http://localhost:8000/ARCLINE/game/dist/
python3 ARCLINE/game/tools/build_crew.py
python3 ARCLINE/game/tools/build_campaign.py
python3 ARCLINE/game/tools/build_levels.py
python3 ARCLINE/game/tools/build_lessons.py
python3 ARCLINE/game/tools/build_story.py
node ARCLINE/game/tools/build_site_scenes.cjs
python3 ARCLINE/game/tools/build_public_assets.py
python3 ARCLINE/game/tools/export_expedition_story.py
python3 ARCLINE/game/tools/build_stage_guide.py
python3 ARCLINE/game/tools/build_playables.py --output /tmp/arcline-package
```

外部SDKを読み込まない37配布ファイル。ZIPはGit外へ生成する。紹介サイトの実演は本番エンジンで生成し、キャラ確認のオフラインHTMLも同じ描画を使う。紹介サイトの実画面は `capture_site_gameplay.cjs` で再撮影できる。テスト用のNode・Playwright・Chromiumは配布物に含めない。

[現行のテスト入口](game/tests/README.md)と[結果](evidence/expedition-013/README.md)を参照。全100面のガン通常弾のみ3条件300戦、推奨機体100戦、加入後の見せ場16戦、1000組の安全な配置、操作・保存・日英・画面回転・実Workerなどを別々の検査で確認する。**人による全100面の通しプレイ、全100面×全10機体の完走、物理端末Safari／Android、YouTube認証は未確認。**

元の引継ぎ書・EXPORT_MANIFEST・初期v1.0/v1.1、[0.12](evidence/story-012/)、[0.11](evidence/visual-b08/)と[18枚のデザイン原本](design/sheets/)は歴史資料として保持。今回の成功数へ過去の検査を加算しない。ルートGitと通常pushを使い、別Gitの初期化・force push・他コンテンツへの無関係な変更はしない。
