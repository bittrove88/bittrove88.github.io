# 新しいCodexセッションへの開始文

このフォルダーのARCLINEを引き継ぎ、最新設計をゲームへ実装してください。

最初にCODEX_HANDOFF.md、design/ARCLINE_Player_Review_v1.1.md、design/ARCLINE_Level_001-100_Design.mdを読み、game/distの現状を確認してください。仕様が重なる場合はv1.1を優先してください。

現在動くゲームは0.3版です。新しい100面・ギミック・スキル・20武器・拾得・ボスは未実装です。設計JSONは配置意図の文章データであり、動作検証済みのランタイムデータではありません。

通常の判断は自律的に進め、単なる計画や最初の10面だけで完了せず、100面の実装と検証を完成させてください。まず現行版を起動し、検証できる状態を作ってから、引き継ぎ書の差分と順序に沿って進めてください。

ゲームUIは英語のみ。スティック移動、押してチャージ・離して発射、直感的な初出プレビューを維持。通常敵3発相当/10射撃、ボス10発相当/18射撃、プレイヤー耐久5。前回弾道は消し、角度は維持。新仕様の実機検証・YouTube審査は未完了なので、実施結果と未確認事項を正確に報告してください。

保存データを無断でリセットせず、既存サイトの公開範囲を変えないでください。必要なアカウントや権限が不足していても、ローカルで可能な実装・テスト・提出準備を終えてください。
