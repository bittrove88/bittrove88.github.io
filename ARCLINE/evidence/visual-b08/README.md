## 実装済み

- B03：自機10の形/配色を維持したマット描画、通常敵12の個別モデル。選択・ロビー・実戦・プレビュー・紹介・確認ページで同じコードを参照。
- B04：100面の有限地形、20テーマの材質、W/B/K/C/U/F/V/M/Tの機構・作用・状態。100面の形と29箱の位置は保持。
- B05：共通FX、通常/補助/10必殺の描画、補給/スキルの意味、実弾道プレビュー。弾道の幅・弾体・着弾演出の寸法は0.10のまま。
- B06：章ボス10体、個別の胴体/部位/砲口/コア、破損と露出。広い胴体に埋まっていた可視コアも狙える照準窓を接続。
- B07：通常敵12の弾種/射角/移動/誤差を接続。5/15…95面の中ボス10戦、部位破壊による攻撃半減とコア1.5倍、1回だけの勝利報酬。中ボスで章在庫をリセットしない。
- B08：100面統合、スマホ横画面の自動確認、共有アセット/紹介/オフラインHTML/PNG/34ファイル配布の同期。物理端末の確認は未実施。
- 追加指示：20守り手の登場名/特徴/短い台詞、撃破後の出来事と仲間の返答、5幕/10章の旅と伏線/背景/関係。物語用のロード待ち・文字送り・追加OKは無し。
- 転移：安全な近隣列を探索し、低い天井・段差付近の失敗を緩和。側壁に当たれば接触側を落下。斜め天井を側壁と誤分類しない。
- 後ろ向き照準：通常−15〜170°、ソラ必殺55〜125°。砲口の実方向で車体を反転。
- 必殺：広い攻撃の合計上限40〜52。狭いリンの精密弾は通常直撃60/中心75。距離減衰・遮蔽・全弾共通上限。通常弾20、HP/チャージ/移動、各面必殺3は維持。
- 保存：schema2〜5を6へ移行。章の開始在庫・所有ID・機体・言語/左右・既読を保持し、最初のバックアップを上書きしない。旧schema5の実装は新しい保存の読み書きを拒否。

## 検証中に直した不整合

- 必殺調整前の威力を要求するプレビュー条件を更新し、調整後の実弾イベントで成立させた。
- ポラリスなどの胴体にコアが埋まる判定を解消。地形と残存外部部位の遮蔽は維持。
- 新しい中ボス報酬を既存のskillId/placementId形式へ揃え、全10体で取得・再取得防止・練習隔離を確認。
- 斜め天井の転移、見本に本編stateがない場合の座標参照、中ボスのコア表示倍率を修正。

## 未確認・実用上の限界

物理端末の**iPhone Safari／ホーム画面起動／Android Chrome**、実機でのタブやズームの挙動、fps/発熱/音、実際の操作感は未確認です。ブラウザの画面模擬を実機確認と表現しません。

全10機×100面×3乱数の実戦完走、人による難易度・楽しさ・物語のテンポ評価、全取得/交換順序は未確認。280勝は自動方策で経路がある根拠であり、全ての人が全機体で簡単に勝てる保証ではありません。

YouTube Playablesの認証・申請・公開は実施していません。外部SDKを読み込まない単独配布です。iOSのホーム画面起動はSafariと保存領域が分かれる場合があります。

B01/B02や0.10以前の合格結果を今回の実行数へ加えていません。B01の同一物理/画素の期待値は歴史資料のまま保持し、今回の変更を通すために再生成していません。
