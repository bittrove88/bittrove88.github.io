# ARCLINE 0.14.3 — 最初の選択・仲間変更・ストーリー再生

## 実装

- **旧記録の全初期化**：保存schema8のまま `campaignResetVersion=2` を採用。以前の攻略・機体／武器所有・持ち物・既読・プレビュー・加入待ち・設定を初期化し、ガンと通常弾から再開する。古い記録の埋め込みバックアップを残さず、保存成功後にブラウザ内の旧ARCLINEキーも削除する。他のアプリの記録は削除しない。更新を読み込んだ各端末で実行し、新しく保存した記録は次回以降リセットしない。SDK保存にも同じ初期化を適用する。読み込み不能なSDKへ初期値を書き込まない。
- **難易度**：初回にイージー／ノーマル／ハードを明示的に確定。開始画面に現在値と変更ボタンを常設する。全表示／半分／方向のみの既存の点線射線を使用する。
- **機体変更**：自分の照準ターンに左上の「機体変更」から解放済み機体をワンタップで選択。選択中は戦闘を止め、チャージを取り消す。HP割合・必殺弾・行動数・位置・敵・地形を維持し、敵ターンや飛翔中は変更できない。
- **ストーリーモード**：冒険開始後に開始画面から使用できる。章ごとに、クリア済み100面のメッセージ、9加入画面、プロローグ／30・60面／エピローグの4映像を開放する。メッセージは既存の文字送り、加入は実際の原画紹介画面を使い、振り返りでは編成・進行・既読・保留演出を変更しない。既存の旅・仲間の資料も別タブに残す。

原画と本編ストーリー本文、戦闘エンジン、地形、ダメージは変更しない。アセットのキャッシュキーは0.14.10、表示版は0.14.3。

## 検証

検査結果は同じディレクトリのJSONと画面に記録する。旧版の結果を今回の合格として流用しない。

- `RESET.json`：旧版と破損記録の初期化、バックアップ除去、新進行の再読込、保存失敗時の再試行。
- `FOUNDATION.json`：100面の実キャンペーン進行と9加入、HP割合を回復しない反復変更、敵ターン制限、武器・砲口・転移の回帰。
- `BROWSER.json`：実Chromiumの568×240・844×390・390×844・1440×900。初回選択とホーム表示・再読込、ワンタップ変更、未来の物語の非表示、100クリア・9加入・4映像の一覧と再生時の保存不変、日英、SDK成功・読込失敗。スマホ戦闘は横向きへ回転して検査する。
- `PUBLIC_UI.json`：公開キャラ紹介とオフラインHTML、公開映像確認ページの回帰。
- `GENERATED.json`：19生成物の再生成一致。
- `BUNDLE_CHECK.json` / `DELIVERY.json`：Git外の配布ZIPと画像の一致、公開配置・展開配置での起動と画像・操作。
- `RELEASE_WEB.json`：公開導線、今回のリセット告知、スマホ・PCのカタログ、空白ルート等。

## 未確認

物理端末のSafari／Android、インストールしたPWA、YouTube本番SDK認証、広域通信速度は未確認。SDKは実画面に接続した模擬APIで保存契約を検証する。公開URLの直接表示は実行環境の通信制限があるため、公開完了はGitHub Pagesのデプロイ結果で別途確認する。過去のユーザーが開いたままの旧タブや端末の保存を、サーバーから即時に消去する仕組みはない。
