# 0.12 物語・場面演出の実装と確認

確認日：2026-11-01。比較元：公開0.11の `431922d98265a390337eb5acff1fbe8ba7782618`。

## 実装済み

- 提供された物語へ更新。通常80面、中ボス10面、大ボス10面、全100面にクリア文を配置。20守り手のクリア文と返答、プロローグ3場面、エピローグ4場面の日本語は添付原稿を採用。
- 通常・中ボス・区間復旧・全線復旧を、半透明枠、見出し、縁、復旧灯で見せ分け。一文字ずつ浮上し、タップで全文表示。
- コードで動く専用シーン：プロローグ3、30/60面の幕間、エピローグ4。全文表示・場面送り・一時停止・スキップ・見直し。
- 70/80/90/95/100面で順に核心を開示。第4/5幕の説明・機体の過去・100面名も先行開示を防ぐ。
- schema6→7の移行、章在庫と進行の保持、未視聴の幕間・エピローグの再開。保存失敗中は次面へ進めない。
- 日英対応。背景化・SDK停止・縦向きでは場面の時計も停止。動きを減らす設定に対応。
