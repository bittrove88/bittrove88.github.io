# 空中庭園の配色・地盤の地表線 改訂1.9

2026-11-07。ユーザーの追加依頼を反映した変更後レビューです。本番公開は未実施です。

[更新版の全100面HTML](../../design/expedition_013/arcline_100_maps_atlas.html)で「空中庭園」を選択すると81〜85面を確認できます。

- 空中庭園の地盤を翡翠を帯びた白石、構造材を象牙白へ変更。淡い青緑の陰と小さな淡金の飾り色を使用し、茶色の土の印象を除きました。背景と地形形状は維持しています。
- 地盤を画面下へ延長したあと、元の衝突ポリゴンの底辺・側辺まで枠線を描いたことが地中の四角い線の原因でした。地盤は地表の輪郭だけを描き、下へ達する色面も地中へ続けます。地表側の材質模様はカメラ移動・拡大で変形させません。
- 有限の浮島・壁には全周の輪郭を残し、破壊材・反射面・橋・機構の共通識別色を保持しました。
