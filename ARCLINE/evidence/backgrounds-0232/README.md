# 全背景の実装検証 — 0.23.2

[BACKGROUNDS_UNIT.json](BACKGROUNDS_UNIT.json) は355項目。実際の1〜99面と10機の最終リレーを通じて全33景の到達を確認し、制作データと配布データの一致、物理・地形・戦闘・保存・前景描画モジュールのバイト一致を検査します。ゲーム処理の基準は実装前mainの `3ebb4c9`、美術の受け渡しは `4c3369f` です。

[BACKGROUNDS_BROWSER.json](BACKGROUNDS_BROWSER.json) はChromiumで2004項目・606描画ケース。1120×604では全103条件×3難易度、844×390・568×240・393×852では全33景×3難易度。DPR1／2を含みます。各背景を描いた直後の実画素を、受け渡しデータの独立Canvas描画と97画素間隔でRGBA比較し、欠落・透過・先に描いた前景の混入がないことを確認。最終画像には既存地形・機体・敵・ギミック・HUDを重ねています。

実描画された射線の頂点を検査し、Easy全軌道・Normal累積距離半分・Hard方向のみを確認。見渡しカメラ、飛翔、着弾揺れで背景画素が動かず、描画前後のゲーム状態・保存内容が変わらないことも確認しています。最終3回の移動は4画面×通常／軽減×6時点（144フレーム）で、55%未満は旧背景、55%以上は新背景。既存の2.2秒／0.7秒を保ち、見渡しとポーズのボタンから戦闘へ復帰できます。

33景すべての実装画像を内部目視確認しました。鏡の岸壁の岩壁と銀紫の海、遺跡の赤土、空港の青空、結晶平原の紫、鉱山の黄土、氷の白青などを区別し、通常→大ボスでは土地の素材を共有して構図を変更。背景装飾を実体ギミックより淡く置き、最終4景では敵本体・点灯済み帰還数・勝利文言を描いていません。背景自体は静止画です。

[GENERATED.json](GENERATED.json) は正式生成145ファイルを隔離環境で2回再生成した一致・安定性の検証です。配布と既存回帰テストの集計は [実装記録](../../docs/releases/0.23.2.md) を参照してください。

検証はヘッドレスChromiumとタッチ・画面サイズ・回転のエミュレーションです。物理端末Safari／Android、インストール済みPWA、公開反映は別工程で、今回の合格に含めません。
