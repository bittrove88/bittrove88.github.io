# 0.24.1 確認記録

対象は承認された17・33・36・39・47面。`MATCHES.json` に15戦の実入力・実移動・敵の反撃・HP・勝敗を保存した。通常弾のみで、GunのNormal／Hardと各推奨機体のNormalを各1戦。新しい大量シナリオや個別テストファイルは追加せず、既存の検査へ現在の5面の承認境界と入力列を登録した。

`ACCEPTANCE.json` は15戦のSHA256と、変更していない95面の設計・実行データのハッシュ。これら95面と100面専用リレーは0.24.0の記録を継承する。全体の現在の入力再生は `game/tests/approved-map-replay.test.cjs`。旧5面の入力を除き、新15戦を加えて158戦を再生する。最終100面のリレーは既存の専用テストで扱う。

`PICKUP_ADJUSTMENTS.json` は39面の承認案に含まれる移動と、47面の到達性のための追加調整を記録する。17面は位置を保持し、39面は承認案の53/20を保持して到達入力を更新した。全46個の到達・在庫・保存は既存テストの対象。

橋の接地・開閉、W/Kの作用の限定確認は [設計時の記録](../../design/stage_reviews/idea_refinement_20261107/minimum_checks.json)を参照。橋の開閉資料は敵ターンを省いた姿勢資料であり、対戦の記録とは分ける。

自動探索・固定seedの再生は人の勝率や操作難易度を保証しない。実機とインストールPWAは未確認。
