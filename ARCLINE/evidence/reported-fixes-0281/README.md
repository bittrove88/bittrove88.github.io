## 検証

[単体検査](REPORTED_FIXES_UNIT.json) ／ [描画と遅延読み込み](REPORTED_FIXES_BROWSER.json) ／ [固定した実入力の指紋](ACCEPTANCE.json)

雲は世界座標で固定し、時刻0と20秒のラスタ差は0、カメラによる切り抜きの重複部分の差も0。見える雲の749接触点と、透明な6839点を比較し、透明画素での物理接触は0だった。雲の減速倍率と一領域につき一度の作用は維持する。

仲間加入では実際の原画を800ms遅らせ、読み込み中の51フレームで代替Canvasが出ないこと、原画の前に飛行演出の時計が進まないことを確認した。一般の原画読み込み失敗時の代替や、映画スキップは維持している。

[通常31ケース](REPLAYS.json)、[最終戦Normal／Hard](FINAL_MATCHES.json)、[8／12面の通常・推奨機体](MAP_GUIDES.json)は新しい実エンジンで記録した入力。旧ファイルは書き換えず、影響する条件だけを置き換えて、全161ケースを敵の実反撃込みで再生する。入力探索は人の難易度・勝率・楽しさの測定ではない。

物理の変更は見える雲の輪郭と非表示の雲の除外だけ。敵AI、基礎弾道、HP・ダメージ、持ち物、保存は保持する。地形は8／12面だけ、全46個の取得物は座標・種類・数量・ID・出現ターンを保持し、4面の検証用入力だけを更新した。

全CIの結果と詳細は修正PRのChecks／成果物を参照。実機Safari／Android・WebKitは未確認。
