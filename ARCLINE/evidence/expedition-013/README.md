# ARCLINE 0.13 — 実装・検証記録

基準はmain `26acaad`（0.12の物語と、直近の必殺ダメージv2・ソラ／モグの照準調整）。キャンペーン5.0、保存schema8／リセット世代1。今回の変更は作業ブランチでレビューする。mainへの自動マージと公開は行っていない。

## 実装済み

一度だけ攻略を戻して所有と設定を引き継ぐ移行、ガン一機から9回の加入、勝利と取得の保存、加入時の選択、戦闘中の所有機体変更、通常戦の自分の第2・4・6ターンの必殺解放、守り手戦の開始時3発、車体方向と砲身の分離、外観機能の撤去、個別設計100面、加入順に沿う物語、概要から開く画面、紹介サイトの3実演と全10機の紹介を実装した。

転移の着地許可とターン境界で敵との距離基準が異なり、開始位置へ戻るケースも修正。別キーのバックアップ保存失敗で移行を再試行できなくなるケースは、保存本体内の原文バックアップを保持して回復できるようにした。

## 検証方法と再現

Nodeの本番エンジンで軌跡・HP・敵手番を解決し、命中や勝利を捏造しない。攻撃の角度と出力、到達可能な歩行、実際の破壊と転移を探索する。ガン300戦は必殺や補給に頼らない代替経路。推奨機体100戦と固有技の見せ場16戦は別に記録し、失敗を省いて成功扱いにしない。

`ARCLINE_EVIDENCE_DIR=/tmp/arcline-013 node ARCLINE/game/tests/<テスト>.test.cjs`。正確な入口と環境は[テストREADME](../../game/tests/README.md)。ブラウザーはPlaywright＋`/usr/bin/chromium`、6横サイズは568×240、667×280、844×390、932×430、1024×768、1440×900。サイトは360×780、390×844、844×390、768×1024、1440×1000。

FX比較は、Git `05a0a72ee640444947b89007243c1b5bac50f673` の `game/dist/render.js` と `combat.js` をGit外のディレクトリへ取り出し、`ARCLINE_BASELINE_DIR` へ指定する。B02のスナップショットに保持された0.10の弾体・着弾関数と比較する。比較元を指定しないSKIPは今回の成功として扱っていない。

## 未確認と公開判断

- 人による全100面の通しプレイ、楽しさ・飽き・操作の難易度曲線、初見の勝率は未確認。入力近傍の成立は実測しているが、人の体験評価ではない。
- 全100面×全10機体の完走は未確認。初期配置1000組と、加入済み推奨機体100戦は確認した。
- 16面以外の全ての複合攻略手順・全ての代替解法や、全乱数の詰みの不在を証明していない。
- 物理端末iPhone Safari／Android、ホーム画面起動、実YouTube SDK・本番認証は未確認。ChromiumとSDKモックの結果で代用して合格としない。

実装と自動検証をレビューできる状態。既知の再現失敗は修正した。進行を戻す大きな更新のため、mainへの自動マージや公開はせず、レビュー可能なPRとして提出する。正式公開の判断には、実端末と人による難易度評価の残りを含めて確認する。
