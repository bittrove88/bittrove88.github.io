# ARCLINE 0.14.4 — UIと検証基盤のリファクタリング

基準版：0.14.3 / `80ca68d8f506015cfef4753084bbabfb7d4adff0`。

## 実装

1. 現行の検査一覧・統一ランナー・固定依存・CIを追加。旧保存fixtureの期待を現行へ更新し、旧世代のリセットと新記録の保持は別の検査として維持した。
2. CSSの同条件・同値の重複宣言39件を削除し、ゲーム・追加UI・映画の読みやすい正本へ分離。読み込み順を保持して生成する。
3. スティック・発射・キーボードをArcBattleInput、難易度と機体変更を専用UIへ分離。ArcScreensでフォーカス・Escape・Tab・inert復帰を共通化し、使われなくなった旧戦闘中変更経路を整理した。
4. 翻訳のMutationObserverを変更された部分に限定し、文書全体の走査を言語変更などへ限定。Canvas描画と文字幅測定の翻訳契約を維持する。
5. runtime.jsonで版数・キャッシュ・依存順序を一元化。UI/CSSの編集元を明示し、再生成検査は一時コピーで2回行い、作業ツリーに書き戻さない。

保存実装は基準版とバイト一致し、schema8・resetVersion2を維持する。この更新で現在の記録を再初期化しない。物理・ダメージ・100面・原画・物語本文も維持する。

## 検証記録

最終集計はCHECKS.jsonへ保存する。実際に実行した結果のみを記録し、以前の成功を合格数へ流用しない。

- 統一unitランナー：保存と再試行、100面進行、在庫、射線、機体・ダメージ、画像と字幕、依存と生成元の一致。
- 統一browserランナー：現行フロー・日英・SDK模擬API、実タッチ取消と2本指、一時停止、公開ページ、オフラインHTML。
- レイアウト比較：直前公開版と6サイズ×10画面の配置・書体・色等のcomputed styleを比較。CSSアニメーションを止めて検査する。
- 翻訳・画面制御：実ChromiumでHUD更新中の全文字走査、追加要素と属性の日英復元、映画を開いた親画面のinert・フォーカス復帰、振り返りの保存不変。
- 生成：一時ツリーの2回の再生成が一致し、元の作業ツリーを変更しないこと。
- 配布：公開配置と展開ZIPの原画パスと停止・スキップ。ZIP・キャッシュ・node_modulesはGit外。
