# ARCLINE 開発エージェント運用ルール

この文書は \`ARCLINE/\` 以下で作業する開発者・AIエージェントの入口です。**本ファイルを読むだけで未実装の変更要求を自動実装してはいけません。** 実装はユーザーの明示的な依頼に従います。

## 最初に読む文書と優先順位

1. **今回のユーザーの明示的な依頼と変更禁止条件。** 「指示書のみ」「アプリには反映しない」等を最優先する。
2. **本ファイル \`ARCLINE/AGENTS.md\` と [更新ルール](docs/UPDATE_RULES.md)。**
3. **現行の変更指示書 [v0.15.5／全21章・AR-01～AR-13](docs/change-requests/ARCLINE_CHANGE_REQUEST_v0.15.5.md)。** 13項目の実装を依頼された場合は、第1章から第21章をすべて読み、共通制約、テスト、完了条件まで遵守する。未実装の指示を現在のアプリの挙動として説明しない。
   **BGMとエンディングの個別実装依頼**は、[BGM・エンディング変更指示書 v2.1.0／全34章](docs/change-requests/ARCLINE_BGM_ENDING_CHANGE_REQUEST_v2.1.0.md)を併読する。これはAR-01～AR-13とは別の未実装要求であり、文書登録だけでゲームへの実装を始めてはいけない。
4. **現在の実装と生成元：** [README](README.md)、[ゲーム編集入口](game/README.md)、\`game/runtime.json\`、現行コード・テスト。
5. **過去の履歴資料：** \`CODEX_HANDOFF.md\`、\`CODEX_START_PROMPT.md\`、\`EXPORT_MANIFEST.json\`、旧 \`updates/\`。当時の実装・URL・バージョン記述は履歴であり、現在の正本に優先しない。

矛盾する場合は、ユーザーからの最新の明示的な指示、現行の実装事実、現行の変更仕様を区別すること。指示書は未来の要求であり、現行動作の証拠ではありません。

## 更新時の必須事項

- 変更前に依存関係・影響箇所・保存互換性を確認する。無関係な機能やリポジトリ内の他サイトを変更しない。
- ARCLINEの既存セーブ、100面の進行、解放状態、画像パス、PWA、公開URLを保護する。セーブリセット・破壊的変更は無断で行わない。
- 生成元データがある場合は生成元を編集し、\`game/runtime.json\` の依存・版数・正式な生成コマンドと整合させる。
- JavaScript・CSS・画像・翻訳の参照先とキャッシュを確認する。原画とCanvas代替の二重表示、Canvasの非表示を理由に親画像領域まで隠すCSSに注意する。
- 難易度の違いは照準ガイドの表示量であり、敵HPやAIの性能変更ではない。通常の章の持ち物とクリア済み面の練習用持ち物を混同しない。
- 変更時は \`npm test\`、\`npm run check:generated\`、必要なブラウザテスト・実機テストを実施し、実行できない検証は未確認として報告する。
- コミット・ビルド・デプロイ・公開URL確認・実機確認は別の工程。確認していない状態を成功と報告しない。
- 大規模なディレクトリ整理は必要性を調査してから独立した作業単位で行う。必要な場合はゲーム側の参照先・ビルド・公開URLまで対応する。
- ドキュメントの保存・マージだけを依頼された場合はゲーム本体を変更しない。
