ARCLINE 0.23.0

新しい地形、選べる補給、学習するライバル。

  • 承認済みの1〜50面を反映。天井下面の反射・大型結晶・下降橋が実際に弾へ作用します。
  • 補助武器12種、通常スキル12種とレア3種。未使用の残数は章を越えて持ち越します。
  • マップのカプセルは武器20・通常スキル20・レア6の計46個。38個は最初から、8個は自分の第5ターンに出現します。
  • 第5ターンより早いクリアでは、未出現品を一度だけ受け取れます。カプセルの取得履歴と消費した残数は再挑戦でも保持します。
  • 後半の敵は近くへ着弾すると次の通常攻撃を学習します。歩行で学習を解除できます。

現在の攻略記録を引き継ぎます。難易度別セーブと旧アイテムの残数、51〜100面の地形、最終戦の4戦場・10機・各HP70・各100ダメージ・必殺3・各28行動を保持します。
