ARCLINE 0.29.0

武器と必殺技の動き・色・演出を、技ごとの特徴に合わせて更新しました。

  • 通常弾は各機体のメインカラー。補助武器は散弾10発、連射弾6発、地面を広がる波、与えた実ダメージ分の回復などを反映しています。
  • 全10機の必殺技に専用の弾道と着弾演出。連華砲の9発、流星砲の12流星、三分岐から一点へ束になる収束砲、吸引と圧縮の重力砲を追加しました。
  • 静止・スロー・加速は必要な瞬間に限定。軽快な連射は本来の間隔を使い、重い接触や軌道が変わる瞬間だけを強調します。
  • 敵弾の色、中ボスの専用演出、大ボス9技と最終4技を追加。予告から移動や地形を使って対処できます。

現在の攻略記録を引き継ぎます。保存データ、全100面の地形、取得物の配置、機体のHP・歩行・チャージと最終リレーの進行規則を維持します。
