ARCLINE 0.28.1

iPhoneで下部の操作・メニューが画面の安全領域まで広がる問題を修正しました。

  • ノッチとホームインジケーターを避けた範囲に、下部の操作を中央寄せします。
  • 武器だけの状態でも、ボタンを横幅いっぱいに引き伸ばさないようにしました。
  • 移動・斜角・発射のボタンサイズと、チャージゲージの表示・操作は維持します。
  • 雲は初期位置で動かず、見える雲の中だけで弾が減速します。
  • 仲間加入のスキップを外し、原画の前に代替画像が一瞬出る問題を修正しました。
  • 8面は水平な天井と低い岩背、12面は少し高い天井へ調整しました。

現在の攻略記録を引き継ぎます。HP割合・必殺技残数の引き継ぎ、チャージ操作、雲の範囲を除く基本の戦闘性能・進行と既存の保存データを維持します。
