ARCLINE 0.28.0

戦闘中の情報と操作、仲間・武器・スキルの選択画面を整えました。

  • マップの隣にキャラチェンジを配置し、一時停止からも同じ画面を開けます。
  • HP・残り行動・操作ボタンを整理。選択状態を青で揃え、武器・スキルは保有している順に詰めて表示します。
  • スマホは左4/5で斜角、右1/5でマップ移動。二本指で戦場を拡大・縮小できます。
  • 序盤の操作案内とキャラチェンジの案内を追加しました。日英の名称・説明も整えています。

現在の攻略記録を引き継ぎます。HP割合・必殺技残数の引き継ぎ、チャージ操作、戦闘の性能・進行と既存の保存データを維持します。
