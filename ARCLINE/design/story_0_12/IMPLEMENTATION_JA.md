# ARCLINE 0.12 物語と演出の反映仕様

## 今回の目的

「何を直し、誰の返事を届けたのか」が、遊んでいる途中とクリア直後に伝わるようにする。原稿の結末を任意の記録だけへ隠さず、100面の結果からエピローグへつなぐ。

ゲームは既存のマットなCanvas 2Dの描画を使い、橋、貨物、灯り、便り、10機、保全中枢を動かす。動画ファイルの読み込みはない。武器の威力、敵AI、100面の地形、箱の位置、弾道の太さ、着弾演出の大きさは変更しない。

## 1. 新しい物語の軸

アークラインは港・橋・昇降機・坑道・炉・空路を結ぶ輸送と供給の仕組み。大分断によって止まり、町へ荷や修理部品が届かなくなった。10機は古い便りを手掛かりに、道と返事をつなぎ直す。

守り手は現在も正常に稼働する中央管制の命令で戦っているのではない。最後に届いた安全規則を保持している。戦闘で止めるのは武装と閉鎖機構。本体の人格は失われず、本来の仕事へ戻る。章の勝利は区間限定の運行再開で、全線復旧は100面。

10機は記憶喪失でも複製でもない。別々の復旧現場で生き延び、自分の仕事を続け、今回の旅に集まった。大分断の日の帰還が中枢へ登録されていなかった。

## 2. クリアごとの表示

| 場所 | 内容 | 見せ方 | 続行 |
|---|---|---|---|
| 通常80面 | その場所で確保した経路・進んだ復旧作業 | 小さな機体画、青緑の縁の半透明枠、短い一文 | 次へ。表示中の初回タップは全文表示 |
| 中ボス10面 | 閉鎖機構を停止して見つかった手掛かり＋章の主役の返答 | 琥珀の太い縁、2段の本文 | 同上。中ボスでは章在庫をリセットしない |
| 大ボス9面 | 区間の復旧＋対象の地域名＋返答 | 大きな見出し、淡い金の縁、10面分の復旧灯 | 次の区間へ。30/60面は短い幕間へ |
| 100面 | 全線復旧、「おかえり」「ただいま」 | 最終結果として強調 | エピローグへ |

文字は書記素単位で1秒32文字、下から0.65em浮上して0.22秒で定着する。日本語の濁点や結合文字を分解しない。英語は単語の途中で不自然に折り返さない。本文タップ、または続行の初回タップで全文を即時表示できる。自動で結果画面を閉じない。

小さい横画面では本文と続行ボタンを左右に分離し、長文は本文枠内でスクロールする。読み上げには完成した一文を一度渡し、文字ごとに繰り返し読み上げない。動きを減らす設定では文字の浮上を省略する。

原稿にある20守り手のクリア文・返答は日本語をそのまま採用。原稿には通常80面の個別クリア文がないため、各章のテーマに沿う接続文を追加した。新しい主要人物や秘密、戦闘上の条件は追加していない。

## 3. 単独の映像演出

| シーン | 映像 | 伝えること |
|---|---|---|
| P01 動いていた世界 | 橋、行き交う貨物、点灯した路線 | 道が支えていた暮らし |
| P02 大分断 | 同じ構図で橋が上がり、灯りが順に消える | 世界が止まった喪失 |
| P03 10機の出発 | 10機の走行と古い便り | 「道が開いたら、また会おう。」 |
| 30面の幕間 | 復旧する路線とヒバリ、返答の灯り | 空白だったのは町ではなく通信 |
| 60面の幕間 | 峡谷の風とリン、迂回路の灯り | 確かさと不確かさを一緒に伝える |
| E01 最後の返事 | ユイと古い端子を結ぶ線、便りと中枢 | 差出人と、長い待機の意味 |
| E02 全機、帰投確認 | 10機の名前と帰還灯が順に点灯 | 最後の一機まで届いた「おかえり」 |
| E03 心臓の休息 | 各地へ伸びる線、静かに薄くなる中枢の灯り | 判断を各地へ返し、世界が再始動する |
| E04 次の旅人へ | 再開した橋と貨物、便り、走り出す機体 | 役目を終えても、道をつくる暮らしは続く |

各場面は導入約0.8〜0.9秒、全文表示に必要な時間、余韻2.5〜3.2秒で自動的に送る。全文表示・次の場面・一時停止・スキップをいつでも使える。長文が枠を越すと文字の進行に合わせてスクロールし、全文表示後は手動でも読み直せる。

これはコードで描く場面演出であり、声優音声やプリレンダリング動画は含まない。既存の短いシンセ音を切替時の合図に使う。

## 4. 開示の順番

- 70面：十の空欄。誰の帰還かは示さない。
- 80面：停止は届いたが、安全を知らせる返事が届かなかった。
- 90面：帰還未確認の名簿は、主人公10機だった。
- 95面：古い便りの宛先は10機。差出人はまだ隠す。
- 100面の登場：初めてアークハートの名前を出す。
- 100面の結果とエピローグ：帰還登録、差出人、権限の返還、次の旅人。

ステージ選択の100面名も未クリア時は「夜明けの核」に置き換える。旅の記録は未クリアの守り手を開かない。ガン・バンの過去と第5幕の説明に含まれる「帰還未登録」の情報も90面まで公開用の短文へ置き換える。

選択中の操作機体にかかわらず、章の主役と返答は共有の旅の仲間として固定する。キャラ変更で物語の主語や伏線を入れ替えない。

## 5. 保存・中断・再生

保存はschema7／contentRevision4.2.1。旧版2〜6の進行・機体・難易度・左右・言語・章在庫・乱数・台帳・最初のバックアップを保持する。古い物語の既読はリセットし、新しい原稿を未読として案内する。新プロローグは最初のプレイ時に一度提示する。

30/60/100面の進行確定と同じ保存へ `pendingMovie` を入れる。進行保存に失敗したまま次へ進めない。中断した映像は次回起動時に最初から再開する。見終わるかスキップすると待機フラグを消す。最終結果からステージ選択へ戻る経路でも未視聴エピローグを提示する。

旅の記録からプロローグ、100面クリア後はエピローグも再生できる。30/60/100面の結果画面からも、その直後の場面を見直せる。見直しで報酬・在庫・ステージ進行を増減しない。

アプリの背景化・SDK一時停止・スマホの縦向きで映像の時計も止める。映像だけを操作可能にし、終了後は元の記録・結果画面へフォーカスを戻す。
