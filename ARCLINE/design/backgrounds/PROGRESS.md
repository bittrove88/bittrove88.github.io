# ARCLINE 背景アート制作台帳

更新：2026-11-05  
運用：**ここでは背景のデザインデータ・コード描画プレビューのみ制作。今後のゲーム実装・公開は別工程。背景データのみこのPRに保存。**

## 共通制作ルール

- **1テーマ＝5面で背景を共有**。画面内の物理地形・敵・ギミックの位置とは独立させる。
- 画像生成ではなく、Canvas 2D / SVGで再現できる幾何学的な色面データを正本とする。
- グラデーション、ぼかし、ノイズテクスチャ、写実的な陰影は使用しない。
- 空気感、色面の分割、主シルエット、余白、機能色との分離を丁寧に設計する。
- プレイ地形・自機・敵・照準・予測弾道・実弾・ギミック・UIより前に描かない。
- テーマ別プレビューと設計データをセットで提供し、**デザイン承認**と**ゲーム内表示検証**を区別する。
- 正式な地形座標・ゲーム仕様を変更しない。既存PR #75のゲーム試作は別途扱う。

## 制作順

先に合意した**代表3テーマ**（21〜25「霧の谷」 → 61〜65「火山の外縁」 → 86〜90「嵐の空母」）を固める。その後、未制作のテーマを1〜100面の番号順に制作し、個別承認を積み上げる。デザインを承認するまで自動的に次テーマへ実装しない。

各テーマの成果物には、テーマ共通の背景データ（JSON）、描画確認用コード、コードから生成したプレビュー（SVG / PNG）、色彩と視認性の設計メモ、静的検査結果を含める。
