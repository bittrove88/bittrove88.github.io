# 背景再制作 v2 — 実装引継ぎ

## 状態

**美術データ・単体プレビューのみ。ゲーム未統合・新作30景はユーザーのデザイン確認待ち。** 旧PR #104は差戻し済み。6〜10面の旧承認も最新依頼で再開され、この版の鏡の岸壁は未承認。

編集元は各 `art_*.py`、継承3景は `sources/*.json`。`recipes.py` は索引、`build.py` は確認済み作品を集める出力処理。実装側の受取先は `data/*.json`、一覧は `manifest.json`。

## 適用順

1. **100面**：現在の `ArcFinalTeam.mapIndex(state)` に対応する `final-100-0`〜`final-100-3`。0始まり。mapIndex未指定で通常背景へ落とさない。
2. **10〜90面の10刻み**：`boss-010`〜`boss-090`。
3. **その他の面**：`normal-00`〜`normal-19`。テーマ番号は `Math.floor((stage-1)/5)`。

`ArcBackgroundCollection.select(scenes, stage, mapIndex)` が参照実装。面番号は1始まりの整数。中ボス5・15…95面は通常テーマを使う。通常データの `stageRange` は分類範囲で、大ボスと最終戦の優先判定を上書きしない。

```js
const background=ArcBackgroundCollection.select(scenes,stageNumber,finalMapIndex);
ArcBackgroundCollection.draw(ctx,widthCssPx,heightCssPx,background,{fit:'cover'});
```

## 描画契約

- 各景の `size` を参照し、中央寄せcoverで画面座標へ描画する。火山の継承データは1000×540、ほかは1120×604。
- カメラの移動・ズーム、照準、機体位置、着弾、ターンに背景を連動させない。
- 背景を最初に描き、実地形・障害物・屋根・ギミック・自機・敵・照準・予測線・実弾・エフェクト・HUDを後から重ねる。
- 描いた橋・水・氷・水晶・磁石・炉・機械・レンズは装飾で、当たり判定・反射・操作・進行表示を与えない。
- 背景のグラデーション、汎用山並み、ランドマークと二重描画しない。既存最終背景の置換は4景を揃えて行う。
- CSSピクセルの寸法を渡し、既存のDPR変換を保全する。描画モジュールはsave/restoreでCanvas状態を戻す。
- ゲームには描画用JSONと必要なモジュールを正式な生成手順で取り込む。PNG・SVG・確認用HTMLを実行時の必須アセットにしない。

## 最終戦の移動

進行度は既存 `travel.age/travel.duration` を使う。旧景は55%未満、新景は55%以上。通常2.2秒／軽減0.7秒を維持し、新しい時計を追加しない。

`transition()` は単体確認用の案で、ゲーム未導入。既存崩壊と切替の視認性を保ち、戦闘中は全背景を静止表示する。詳細は [ARCHEART.md](ARCHEART.md)。

## 本番統合の受入れ

- 全1〜99面と100面の4mapIndex、計103条件で選択を確認する。
- 9→10、19→20…89→90で素材・色の連続性と専用背景の変更を確認する。
- 96〜99面へ最終の正式名・帰還の意味を前倒し表示しない。100面の4景は固定担当順へ合わせる。
- 1120×604／844×390／568×240で実機体・敵・地形・全ガイド・実弾・ギミック・HUDを重ねて確認する。393×852は回転確認として別に扱う。
- 大ボス9体と最終4戦場ではEasy全軌道／Normal半分／Hard方向のみの射線を確認する。
- 雲C、水面、結晶、磁場・極性端子など機能色と背景の混同がないか確認する。問題は背景の明度・彩度・形・位置で修正する。
- 移動、射撃・着弾、転移、見渡し・ズーム、ポーズ復帰、最終の移動と敗北機からの再挑戦で表示を確認する。
- 物理、地形、AI、HP、手数、必殺、進行、保存、公開URLを維持し、`game/runtime.json` の依存・ビルド・キャッシュ手順へ合わせる。
- `npm test`、`npm run check:generated`、対象のブラウザ検証を実施。実機と公開URLは別に確認・記録する。

今回の単体描画と内部美術確認を、実ゲームの視認性合格や実装承認の代用にしない。
