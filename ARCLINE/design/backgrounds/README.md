# ARCLINE 背景アート制作資料（デザイン工程）
更新: 2026-11-05 / PR #75 (draft)

**ここは背景データの制作・レビュー用フォルダです。** 今後のゲーム組み込みは別担当・別工程とし、マップ座標・地形当たり判定・キャラクター・AI・弾道・ギミック・セーブを変更しません。

## 制作ルール
- 1テーマ＝5面共通の背景を作る。物理地形やカメラ座標とは分離
- 大きなシルエット、空気色、隣接する**不透明の単色色面**で表現
- グラデーション、ぼかし、画像生成、ノイズテクスチャ、光彩、前景エフェクトは禁止
- 背景は必ず地形・自機・敵・予測弾道・実弾・機能ギミック・UIより後ろ
- デザイン承認とゲーム画面での視認性検証を別管理
- 自機・敵・弾道・ギミックを見誤らせる細線や偽の足場を描かない
