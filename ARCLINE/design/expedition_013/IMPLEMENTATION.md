# 0.13 統合実装の対応

## 実装した体験

ガン一機の出発、9回の出会い、仲間の切替、100面の地形攻略を一つの進行へまとめた。20テーマ×5面、80通常戦・10中ボス・10大ボスを維持する。元の10機の外見・通常／必殺の性質と、直前の必殺ダメージ調整、弾道の太さ・着弾演出の大きさを引き継ぐ。

## 地形と学習の設計

床・山・崖、残す足場、破壊できる壁・天井を独立した部品として配置する。1〜30面は環境装置を最大1種類とし、11〜14で転がり、21〜24で高弾道、31〜34で1回から2回の反射、61〜64で破壊後の精密弾を見せる。80以降は複数の高さと、先に窓を作る準備、環境の切替を組み合わせる。敵HPの増加だけに変化を任せない。

40の武器箱（各テーマ2つ）と10のスキル箱、中ボス10回のスキル報酬を配置する。旧仕様の「未解放キャラを前提にしたおすすめ」や、別の地形を教えるプレビューを現行の面と照合し直した。物理配置の異なる100面について、目的・構造・基本／代替例・敵との関係・手数・検証結果を持つ。

## 再生成

1. `build_crew.py`：加入表 → 共通ランタイム。
2. `build_campaign.py`：個別地形原稿 → キャンペーンと設計一覧。
3. `build_levels.py`：100面ランタイム。
4. `build_lessons.py`：実際の面の特徴 → プレビュー表とランタイム。
5. `build_story.py`：0.13物語原稿 → 共通物語ランタイム。
6. `build_site_scenes.cjs`：本番弾道 → 紹介サイトの手順と結果。
7. `build_public_assets.py`：同じ描画 → キャラ確認のオフラインHTML。
8. `export_expedition_story.py`：物語全文と加入対応のMarkdown。
9. `record_stage_verification.py --evidence <検証出力>`：実測416戦の操作列を設計資料へ記録。
10. `build_campaign.py`、`build_stage_guide.py`：検証結果入りの100面設計と図解を生成。

スクリーンショットは `capture_site_gameplay.cjs`、配布ZIPは `build_playables.py --output <Git外のパス>`。PNGの既存10機一覧は外見を変更していないため維持する。ZIP・ブラウザーキャッシュ・生の指示文はGitへ含めない。

## 判定の限界

実戦の自動探索とブラウザーの画面検査は、人が全100面を遊んで感じる難易度・飽き・楽しさを保証しない。固有技の見せ場16面は技の発生を検査し、残る面もガンと推奨機体で実際の敵手番を含むクリア例を残す。全10機体で全100面を完走したことや、複合地形の全ての意図した解法を証明したことにはしない。

実端末Safari／Android、ホーム画面起動、YouTube本番SDK・認証、人による全100面の通し評価は未確認。[検証記録](../../evidence/expedition-013/README.md)を参照。
