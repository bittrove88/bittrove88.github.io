## テーマ選択

1. 入力は整数の1〜100面に限定する。
2. **100面を最優先**し、実際の最終リレーの `mapIndex` 0〜3で `final-100-0`〜`final-100-3` を選ぶ。100面にmapIndexがない場合は選択失敗とする。通常テーマ19へ黙って代用しない。
3. 10・20・…・90面は専用大ボス9景。
4. 残りの1〜99面は `Math.floor((stage-1)/5)` の通常20テーマ。

通常テーマの5面区切りは背景分類。末尾の10面は大ボス、100面は最終専用が優先する。通常「夜明けの核」の実際の対象は96〜99面。最終中枢や帰還の意味をそこへ前倒ししない。

## 描画に接続する範囲

地盤 `floor` と自然岩盤 `bedrock` は `materials.terrain`、固定棚・壁などの構造物は `materials.structure` を使う。材質の区分は見え方の選択であり、接地や破壊の条件ではない。造形は `build.py` の `solid` と各JSONの `planes`、ギミックの意匠は同ファイルの共通関数を参照する。

輪郭の正本は `render-style.json`。通常外周0.8px・接地辺1.8pxを基準に、素材色と同じ色相の不透明な線を使う。1.2では暗いinkの混色をやめ、通常材は本体色のRGB各成分97%、機能部品は92%に調整する。`ink` を外周へ戻さず、`build.py` の `outline_color` と `valueScale` を合わせる。反射辺と状態記号は明瞭に保つ。

全ての塗り面は既存の `solid.poly` 内にクリップする。上面の接地辺は現行 `world.surfaces` から取り、水平から70度以下だけ接地用の縁を描く。輪郭線の太さを除く装飾が足場・当たり判定に見える場所へはみ出さないようにする。橋の蝶番は装飾で、衝突形状を増やさない。既存の射線・地形外周への描画継続、画面端の地盤処理も実装側で維持する。

壊れる単位・ポリゴンの頂点数・厚み・開いた橋の姿勢・反射辺を変更しない。破壊材は実際の `destroyed` に従って単位を除去する。共通亀裂を架空のHP段階として扱わない。全ての弾を遮る実体ギミックが現在の足場判定へ接続された状態を維持する。

## 共通部品と状態

改訂1.4の演出は独立プレビューで確認する。枠は1pxの一重線、不透明度はON時25%・OFF時8%にし、補助線を重ねない。`on=false` または `strength<=0` をOFFとして扱い、ラベルは100%に保つ。本体の動きは1.3から維持。`renderer.js` の動きは `kind / on / direction / strength / slow` を読むだけで、物理・状態を更新しない。領域内にクリップし、OFFでは動きを止める。`motion-cases.json` の秒数は比較用で、ゲームの手番周期へ取り込まない。ゲームへ接続する際は実際の `world.regions` と既存の状態変更タイミングを使い、機体・射線より手前で目立ちすぎない描画順に合わせる。`prefers-reduced-motion` と一時停止時は動きを止め、静止した矢印・ラベルを残す。

| 部品 | テーマ間で変えないもの | 読む実データ |
| --- | --- | --- |
| 破壊材 | 紫の面・共通亀裂・外周 | 破壊単位と除去済みID |
| W / K | 青緑の板・明るい反射辺・短い表面記号 | 実際の `poly` と反射辺、姿勢 |
| B | 橋板・接触辺・蝶番 | 現在の橋の `poly` と `hinge` |
| C | 減速記号・状態・速度倍率 | `slow`（通常0.72、薄化0.85） |
| F | 右／左矢印・ON・弱化・停止 | `direction`、`strength`、`on` |
| U / V | 上向き矢印とON/OFF | `on`、現在の領域 |
| M | 正負・回転方向・弱ON/OFF | `direction`、`strength`、`on` |
| T | 操作部の色・＋記号・切替予約の分離 | 現在極性と次の手番の予約 |

Tの基礎や反射板の周りは各テーマの支持材。機能面そのものをテーマ色へ染めない。通常の水晶・氷・磁性鉱物へW/Kの反射記号や磁場の作用領域を付けない。自然の赤い岩を溶岩ダメージの表示に転用しない。

状態ラベルは表示範囲内へ収め、機体・敵・照準・HUD・他のラベルを避ける。縮小時にも画面上の線幅・文字の大きさを保つ。今回のギャラリーは作用領域の上端が画面外にある場合のラベル位置を補正するが、実ゲームの障害物回避とHUD連携は既存の仕組みを使って接続・確認する。

重力×0.5／×2は既存スキルの表示見本。新しい重力領域やマップギミックを追加しない。独立シート下段の全ギミック見本も、そのマップへ配置を追加する指示ではない。

## 組み込み担当の受け入れ確認

実装依頼を受けた段階で、編集JSONと共通描画を正式な生成元・`runtime.json`・配布とキャッシュへ登録する。保存形式やキャンペーン版数を美術変更だけで更新しない。今回の `maps/`・`worlds.json`・独立ギャラリーはゲームへ同梱する必須データではない。

全103選択条件で背景とコンポーネントが一致すること、最終3遷移で旧景／新景が揃うこと、風・噴気・磁場・T・破壊・橋の状態が実戦の変化に追従することを確認する。Easy／Normal／Hardの射線範囲、通常／90%チャージ表示、見渡しカメラ、広い最終戦場、画面端を含める。

既存の機体・敵・弾道・取得物・HUD・文字との実際の重なり、縮小時の読める大きさ、性能、iOS Safari／Android／PWAは統合後に測定する。今回の位置マーカーやブラウザの画面寸法テストを、その代わりにしない。ゲーム地形・戦闘・AI・保存の変更は今回の美術制作に含まない。
