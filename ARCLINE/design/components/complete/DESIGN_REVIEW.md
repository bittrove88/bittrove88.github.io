# デザイナーとしての再評価と動きの方針

## 現行の作用範囲改訂1.7

色の濃さと矢印の明瞭さだけでは、夕景・氷河で発生端と作用範囲の伝達が不足した。風・気流・噴気は実領域と一致した7％の単色の帯、真の発生端の記号、終端までの流線を使い、向きを示す動く線を2.4px・95％へ強めた。[新しい実画面](game-context/flow-range-review.png)。噴出口がHUD下に隠れる時だけ「噴出口↓」で案内し、見えている端へ偽の噴出口を描かない。風の強弱は速度だけ、OFFは帯も流線も非表示。矩形の帯は当たり判定・足場ではなく作用範囲の表示。機体・射線を前へ描く順序と、静かな背景・通常地形を維持する。

T端子の操作面は目立ちすぎる指摘に合わせ、白さと外装の明暗差を少し抑えた。大きさ・記号・切替予約の意味を維持する。以下の1.6は経緯であり、風・気流・噴気には1.7を優先する。

## 現行の視認性改訂1.6

背景へ同化する指摘に対し、[全33景の比較と実画面](VISIBILITY_REVIEW.md)を基準に共通機能色を濃くし、動く線を2px・85％と細い明色へ改訂した。前版の描画差だけの検査は、人が見分けられる評価として不足していた。全33背景・13状態での合成後の明暗差と、破壊材・反射面・橋・端子の共通部品を検査し、実画面と動画で機体・射線との主従を確認する。

地形・背景・常時の粒子数は増やさず、ギミックの機能を示す少数の形だけを強める。磁場以外の領域枠、OFF文字、OFF演出は戻さない。風の弱化は速度だけ、磁場の弱化は速度と弧の数で示し、見失うほど薄くしない。以下は前版までの経緯であり、現行の色・濃さは1.6の正本を優先する。

2026-11-07、輪郭の調整後に、全景のまとまりとギミックの伝わり方を再確認した。通常の比較資料、大ボス9景・最終4景の一覧、水晶の反射路の部品シート、13状態の静止／動画、入江・火山・氷河の背景上の演出を確認した。実際の機体・射線・HUDを重ねた実戦評価はまだ行っていない。

## 現時点の判断

1.4時点では大幅な描き直しを勧めなかったが、実画面で背景と地形の色面が競合する指摘を受け、1.5では地形の内部コントラストと彩度を抑えた。形状・テーマの素材・機能色を維持して静かに整理する。テーマごとの配色・大きな素材面・控えめな輪郭は背景と繋がっており、破壊材の紫、反射面の青緑、状態色の共通化も維持できている。ここから細かな模様・発光・常時の粒子を増やすより、操作対象と機能の読みやすさに絞って仕上げる方がよい。

| 優先度 | 改善・確認すること | 判断 |
| --- | --- | --- |
| 今回 | 作用領域の方向・ON/OFF・弱化を動きで伝える | 枠だけでは「空の領域」に見えるため、少数の矢印・雲・回転する弧を追加した |
| 今回 | 枠を少し透過し、表示の主従を付ける | 磁場以外の枠・定型ラベルは省き、OFFは非表示。風は見た目を変えず速度で強弱を表す |
| 統合後に最優先 | 機体・砲口・射線・HUDが最初に見えるか | 明るい氷河、暗い火山、紫の水晶、広い最終戦場を通常／90%表示と全難易度で確認する |
| 統合後に優先 | 紫の地盤と共通破壊材の区別 | 水晶・プリズム系は色が近い。スマホで亀裂を読み分けられるか確認し、必要なら共通の亀裂の面積・形の明瞭さだけを調整する。直ちにテーマ色や共通識別色を変えない |
| 仕上げ段階 | 破壊・反射・切替の短い反応を揃える | 既存の反応とタイミングを揃えると魅力が増す。常時の装飾を増やすより優先する。今回はゲームへ追加していない |

## バランスを崩しやすい変更

- 地形まで透過させたり外周をさらに消したりすると、背景との境目や足場の端を誤認しやすくなる。今回の透過は作用領域の枠と演出だけに限定した。
- テーマごとに破壊材・反射面・状態色を変えると、章を越えた学習が効かなくなる。周囲の材質だけでテーマを表す方針を維持する。
- 粒子・強い発光・大きな渦を増やすと、砲口、細い射線、敵の弱点が見えにくくなる。演出は少数・低い不透明度・領域内へのクリップに限定する。
- OFFでも流れや残像を動かし続けると、今の状態を誤認する。1.5ではOFFの枠・文字・動きを全て非表示にする。
- 動画の秒数をゲームの切替周期にしたり、粒子の速さを物理値にしたりしない。美術の動きと手番・物理の正本を分ける。

地形・戦闘・物理の数値は変えていないため、今回のデータで数値的なゲームバランスは変更しない。ただし見え方は判断のしやすさ、体感難易度に影響する。実戦なしに「プレイのバランスも問題なし」とは確定しない。

## 動きの見本

[操作できるプレビュー](gimmick-motion.html) ／ [13状態のGIF](gimmick-motion.gif) ／ [背景上での動画](gimmick-motion.mp4)

| 種類 | 動きと切替 |
| --- | --- |
| C 減速雲 | ゆっくり揺れる雲。方向矢印を付けず、風と区別。薄化にも見失わない濃さを残し、画面内の倍率ラベルは省く |
| F 風 | 右／左へ流れる短い矢印。弱化は形・数・濃さを変えず速度だけを抑える。停止は演出ごと非表示 |
| U 上昇気流 | 間隔を取った上向きの流れ |
| V 噴気 | ONの間だけ短い上向きの噴出。OFFでは噴出を止める |
| M 磁場 | 正負で回転方向と共通色を変更。弱化は弧を減らし遅くする。停止は回転を止める |

プレビューは背景上の拡大と13状態の一覧、手動選択、4秒ごとの比較、一時停止、再生位置、動きの抑制に対応。GIFは16秒で固定した13状態を同時比較、動画は26秒で各状態を2秒ずつ表示する。秒数は閲覧用で、ゲームの手番周期ではない。

中央の作用領域は演出比較用に重ねたもの。配置追加や実際の弾道・機体のシミュレーションではなく、ゲームには未統合。実装担当は `motion-cases.json` をゲーム状態の正本にせず、実際の `world.regions` を描画へ渡す。参照実装は `renderer.js` の `fieldMotion`。

## 1.5での実画面確認

[実ゲームの機体・射線・HUDとの比較](game-context/README.md)を追加した。228条件の描画と代表画像で、画面内の演出とOFF非表示を確認。噴気が操作パネルの近くへ偏る点と、暖色背景の気流の弱さを修正した。最小画面の90面の雲はカメラ上端より外にあり、既存の見渡しで確認できる。これは薄さではなくカメラ範囲の課題として残す。
