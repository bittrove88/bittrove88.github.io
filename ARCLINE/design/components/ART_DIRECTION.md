# ARCLINE 地形とオブジェクトの制作ルール

テーマごとに、その場所で使われる素材と配色を設計する。単色の色面で量感を作る描き方を共通にし、背景・地形・装置が同じ世界に見えるように整える。プレイヤーが判断に使う破壊材・反射面・状態記号は、テーマを越えて識別できる共通部品にする。

## テーマの素材から配色を選ぶ

新テーマでは、まず土地・構造物の素材を言葉で定義し、それに適した主色、明面、暗面、接地縁、輪郭、必要な差し色を選ぶ。各テーマに独立したパレットを持たせる。

| 基準見本 | 素材と配色 | 表現する場所の特徴 |
| --- | --- | --- |
| 入江4面 | 砂岩のベージュ、淡い砂色、海を感じる青緑の暗面 | 潮風にさらされた沿岸の岩と港の支持材 |
| 火山61面 | 玄武岩の炭黒、鉄錆の赤褐色、焼けた黄土色 | 黒い岩盤と酸化した鉱物の面 |

これはテーマの素材から選んだ配色。背景のパレットを前景へ複製したり、既存の共通配色の明度・彩度だけを変えたりする方式に置き換えない。ほかの18テーマは、そのテーマの素材を選ぶところから制作する。入江・火山の色の流用を標準にしない。

`component-art.json` の `themeMaterials` に、テーマID、対象5面、素材の説明、`face / shade / light / cap / ink` と任意の `accent` を記録する。火山の赤褐色は鉱物の色面であり、新しい溶岩ダメージや破壊状態を意味しない。

## 共通にする機能部品

| 部品 | 共通化する部分 | テーマに合わせる部分 |
| --- | --- | --- |
| 破壊材 | 紫味の材質、明暗、亀裂、実際の破壊単位の見せ方 | 周囲の固定地盤・支持材 |
| 反射面W・反射板K | ミント系の面、反射する辺、表面記号 | 取り付け先の岩、台座、支持材 |
| 可動橋B | 橋板、支点、接地縁と姿勢の読み方 | 基礎の通常材質 |
| 風・磁場など | 稼働状態、方向・極性の意味、矢印・記号・状態札 | 機能を持たない周囲の支持材 |
| 端子T | 操作部、表示面、記号の意味と読み方 | 台座の通常材質 |

機能部品のパレットは `sharedMaterials` を一元参照する。テーマ固有の定義で破壊材や反射面の色を上書きしない。背景との分離が弱い場合は、輪郭・下地・配置の余白で補助し、機能の識別を保つ。

現在の比較シートは共通部品の色・形を示す見本。既存ゲームの全ギミック、左右の風、磁場の両極性、弱化・停止・切り替え予約を網羅した最終状態シートではない。次の制作で実データの状態を読み取り、状態ごとの姿を揃える。存在しないON/OFFや新しい作用を作り足さない。

JSONの `field.active / inactive` は比較シートの汎用例。実装時は現行の機構別の識別色、正負の極性、方向、稼働・予約の区別を保持し、対応する状態シートを作る。汎用例の1色で既存の状態差を塗りつぶさない。

## 共通の描き方

- 不透明な単色色面を基本とし、上面・正面・暗面など3〜4枚程度の大きな面で量感を作る。
- グラデーション、ブラー、光彩、画像生成、ノイズや写実的なテクスチャを使わない。
- 大きなシルエット、色面の接続、余白を先に整える。細かな割れ目や装飾を全面へ散らさない。
- 前景には背景より明瞭な境界を持たせる。弾、機体、照準、機能部品を読むための空間を確保する。
- 接地縁は実際の支持面へ合わせる。70度以下の歩行・転移できる上面と、70度を超える面の扱いを現行ルールへ合わせる。
- 色面や装飾は元のポリゴン内へ収める。見た目の欠けや張り出しで、実際の足場・谷・通路の境界を変えない。
- 亀裂と継ぎ目は破壊の読み取りに使う。固定岩の装飾が、破壊できる別単位に見えないようにする。

## 新テーマの制作手順

1. 背景担当の最新の承認状態、テーマIDと対象面、素材・構図を確認する。
2. 通常地形と支持材の素材を決め、独立したテーマパレットを作る。
3. 共通の破壊材・反射面・状態記号を組み合わせ、代表マップと部品シートを並べる。
4. 通常表示と90%チャージ縮小、小型横画面で輪郭と機能の識別を確かめる。
5. 編集正本、生成見本、出典、確認結果と未確認の範囲を同じPRへ揃える。

本方針の承認と、未制作テーマの個別アートの完成・承認は区別して記録する。ゲーム実装は[実装引き継ぎ](IMPLEMENTATION_HANDOFF.md)の範囲で別工程にする。
