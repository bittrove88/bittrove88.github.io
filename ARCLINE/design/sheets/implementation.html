01 / SCOPE

美術の完成と、戦闘の完成を分ける。

自機は既に専用コード描画。通常敵は共通車体、大ボスは簡略形状、中ボス戦は未導入です。現在の90通常面・10大ボスから、必要な機能を順に接続します。

A / VISUAL INTEGRATION

現在の遊びを保ち、描画を揃える

自機10・通常敵12外観、地形・背景20テーマ、9ギミック、29箱、10必殺、FX、案内を反映します。弾道、AI、地形の形、在庫、操作を維持します。

B / COMBAT INTEGRATION

判定と戦い方は、別に検証する

大ボスの必要な部位座標調整、通常敵12種の行動差、中ボス10戦。外観だけで能力が追加されたように扱わず、数値・予告・攻略・報酬を確認します。

守る条件

通常弾無限 / 必殺は1面3発 / 章在庫の持越し / 10面ごとのリセット / 左側の移動・照準 / 取消 / 点線3難易度 / 日本語と英語 / 横向きとズーム復帰。

Wは硬い反射地面。新しい水の物理、60面の昇降床、80面の回転足場、90面の可変バリア、100面の無敵・回復ループは今回の採用対象にしません。
