## 1. 結論と今回の範囲

**「マットな精密2D重機」を共通の表現とする案です。** 親しみやすいシルエット、仕事の分かる機構、深い青系の輪郭、少数の面陰影でつなぎます。レトロアーケード感は形・色・動きの明快さでつくり、全面のドット化や荒い省略へ戻しません。

描き方の基軸はS01。ただし、**描き方の統一と、機体の形状をどの案にするかは別の判断**です。自機の形状・配色は従来参照したS02の特徴と現行の識別要素を保ち、艶と密度を揃えます。S01の別形状を、受領順だけで上書き採用しません。地形・背景はS08、装置はS12、効果の手順はS16を接続の基準にします。

今回は内容確認、比較、参照順位、共通ルール、機能の矛盾、工程と受入条件を作成しました。原本画像の描き直し・改名・削除、ゲームコード・100面データ・保存仕様の変更、代表画面の新規描画はしていません。

## 6. 描画ルール案

以下の数値は**実装前の初期設計値**です。原画の厳密な採色値・実機測定結果ではありません。現行から引用した色はその旨を示します。

| 用途 | 色 | 方針 |
|---|---|---|
| 輪郭 | `#142E3B` | 現行機体の輪郭色を継承 |
| 金属の影 | `#40525B` | 現行機体の鋼材色を継承 |
| 塗装の明部 | `#EEE4CA` | 現行機体のクリーム色を継承 |
| 反射面 | `#8DDDD0` | 設計案・非発光のミント |
| 破壊材 | `#9774AF` | 設計案・面の紫 |
| 亀裂 | `#D4B6E5` | 設計案・壊せる手掛かり |
| 予告 | `#F2B45F` | 設計案・攻撃前の注意 |
| 実行/危険 | `#E96A5E` | 設計案・予告と形でも区別 |

- **塗装：** 基本色・明部・影の最大3階調を中心にする。少数の平面と継ぎ目で形を出し、金属全体のグラデーション・光沢筋・連続ブルームは使わない。レンズやコアも小さな色面で示す。
- **機体色：** 現行10機の色を出発点にする。ガン`#EB7928`、バン`#DA3156`、ヒバリ`#24A6AD`、ハナ`#EE617E`、リン`#9570B7`、モグ`#E5A733`、コロ`#A4BD39`、ソラ`#287CC1`、リコ`#D94894`、ユイ`#36B7A4`。環境に合わせるためだけに識別色を変えない。
- **輪郭：** 戦闘表示で外形1.5〜2 CSSpx、内部0.75〜1 CSSpxを初期目安にする。展示サイズは外形2.5〜3.5、内部1〜1.5。カメラ倍率とDPRを考慮して制御し、全てを世界座標の同じ太さで描かない。
- **縮小：** 通常表示、遠距離、展示の3段階で細部を切り替える。遠距離ではボルト・細い傷を省き、砲口・足回り・固有機構を残す。現行の自機本体32px以上、主要操作84pxの確認基準を下回らない。
- **視点：** 横視点に浅い側面の厚み。ゲームで主に見える面を描き込み、俯瞰の車体や3D照明へ切り替えない。履帯/車輪は接地点と斜面へ合う。
- **物体の役割：** 装置は支点・接地・配線、拾得物は独立した浮遊ケース。背景の建物と、当たる壁の輪郭・コントラストを分ける。弱点は色と形・枠の両方で伝える。
- **領域：** C/U/F/V/Mの待機表示は透過0.12〜0.22、短い強調で0.3〜0.4を初期目安にする。領域の矢印が弾や予告線より太く・濃くならない。停止は灰色と線形状を併用する。
- **背景：** BG01空、BG02天体、BG03遠景、BG04ランドマークの4役割。低コントラストの面で奥へ置く。現行の空の緩い色変化は保ち、前景の塗装と同じ光沢処理にはしない。装飾の雲と減速雲を見分けられるようにする。
- **材料：** 固定岩盤は土/石の面、破壊材は紫＋連続する亀裂、Wは硬いミントの表面、Kは厚い縁と台座、橋は支点と板。破壊しない岩を「大きな亀裂」で壊せるように見せない。テーマの紫水晶も破壊材の紫とは縁・亀裂・台座で区別する。
- **反射：** Wのミントは実際の反射コリジョンの表面に一致。横・斜面・段差・洞窟でも架空の水面を描かない。浮島を含め底面と開口を保ち、外周だけの箱に戻さない。

### 情報の重なり順

遠景 → 固定地形 → 装置/領域の淡い面 → 拾得物 → 機体 → 実弾/重要な接触 → 予告の縁 → UI。実際に前を塞ぐ天井・壁の前後関係は保ち、機体や弾を常に最前面へ浮かせて遮蔽を消したように見せません。充填中の着弾点は追加せず、3難易度の点線ルールを維持します。

## 8. エフェクトとアイテムの統一

「控えめ」は小さく分かりにくくする意味ではありません。接触点・作用方向・結果を一つの明快な形で大きく見せ、細粒や常時発光を抑えます。

| 系統 | 共通の見せ方 | 守ること |
|---|---|---|
| FX01 破壊 | 接触の短い星形、消えた部品に合う破片、開いた穴 | 固定岩は砕けない。破片は衝突しない装飾。壊れた後に塗りを残さない |
| FX02 転移 | 実弾、接触リング、車体の移動、接地の短い合図 | 充填中の着弾位置を先に出さない。壁の側面なら下へ落ち、床へ着地してから次へ |
| FX03 武器 | 浮遊ケースに既知の弾形と3目盛り、回収時の一度の短い合図 | ランダム抽選/自動装備/＋3の無限加算へ変えない。取得で3発まで補充 |
| FX04 弾薬 | 箱＋対応する有限補助弾の印、+1の短い合図 | 通常弾へ弾薬制限を作らない。回復箱を勝手に導入しない |
| FX05 予告 | 円/帯/線/扇の実範囲、薄い面と明確な縁、実行時だけ強調 | 敵がまだ選んでいない行動を描かず、発射直前に安全地点へ追尾しない |
| FX06 連動 | 壊れた部位、装置の弱化/停止、露出という順が追える色と形 | 図にある別の床・バリアを、絵だけ先行して存在させない |

個々の必殺は同じ光る爆発へまとめません。ガンは広い破砕、バンは前方の扇、ヒバリは空中の輪、ハナは三拍、リンは細い速射、モグは進む三つの破砕、コロは地面を走る跡、ソラは頂点からの8子弾、リコは反射ごとの形、ユイは引き寄せから圧縮へ。**現在の物理イベントと順序**から描き、演出の都合で弾速・被害・行動数を変えません。

粒子は同時32程度、ピーク64を初期上限案にし、低負荷表示では数と内部線を減らします。揺れは短く小さく、低モーション時は0。全面白フラッシュは使いません。演出の終了待ちで敵ターンを増やさず、プレビューも同じイベントから作ります。粒子数・表示時間・描画負荷の合格は実機で測るまで未確認です。

## 10. 実装の構成案

原本と採用ルールを参照し、画像を切り出してゲームへ貼る方式ではなく、Canvas 2Dで精密なパスとして描き分けます。画像生成をゲーム内描画の代わりにしません。

- **共有スタイル：** 色・画面pxの輪郭・階調・透過・詳細度を一か所で定義。テーマ色と役割色を別にする。
- **形状定義：** 自機/通常敵/中ボス/大ボスのID、輪郭、接地点、砲口、可動軸、表示境界、部位アンカー。物理の当たり判定は別定義とし、デバッグで重ねて確認。
- **地形材質：** 既存ポリゴンの塗りと上面処理へ適用。背景ランドマークは当たり判定を持たせない。反射・破壊・支持の端は実ジオメトリに合わせる。
- **状態：** 稼働/弱化/予約/停止、正常/損傷/破損/露出を共通の表示契約にし、各ボスの機構へ当てる。画像の状態名だけで新しいゲーム状態を作らない。
- **FX：** 物理イベントIDと時刻で再生し、子弾や再描画で二重発生させない。ゲーム本番と案内に同じ描画を使う。
- **負荷：** 静止地形・大きい装飾パスをキャッシュし、画面外/遠距離の微細部を省く。敵の探索は既存Workerを維持。物理結果を省略して軽くしない。

新しい描画部品を共通化しても、全てを同じ履帯車体へ戻しません。既存のセーブID・所有履歴・機体性能・予測線の難易度・武器/スキル在庫を保ちます。後半の補給追加と定着の導入は、該当マップと敵攻撃の設計後に接続します。

## 13. 受入条件

- 同じ機体は、左右・角度・斜面・展示・プレビュー・実戦で同じ形状と特徴を持つ。S01/S02の別案が混ざらない。

- 両端、斜面、洞窟、浮島、暗所、縮小時も塗りが欠けず、Wが水に見えず、領域に弾が埋もれない。
- 全100面×画面サイズ、自機10機、通常敵12種、中ボス10体、大ボス10体/段階を確認。機体本体32px以上と主要操作84px、短い予告と中央クリア表示を維持。
- 3難易度の点線、取消、左右操作、横向き、ズーム復帰、言語、低モーション、保存の回帰を行う。
- 原本/旧在庫/旧クリア/機体IDは失わず、描画変更だけの段階では同じ入力で同じ物理結果になることを確認。
- 実機でフレーム時間・操作遅延・視認性を測る。原画やローカル画像の確認を、実機の遊びやすさ検証と混同しない。
