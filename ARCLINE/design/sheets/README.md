# ARCLINE デザインシート

全18点の原本画像を置くフォルダーです。画像のアップロード後、収録内容・同一対象の別案・表現の差を照合し、全体のデザイン統一方針を整理します。

[ここから画像をアップロード](https://github.com/bittrove88/bittrove88.github.io/upload/main/ARCLINE/design/sheets)

- PNG・JPG・WebP等の元画像を、このフォルダーへアップロードしてください。18点をまとめて追加できます。
- 元のファイル名はそのままで構いません。同名の別画像は、末尾に `-v2` などを付けて上書きを避けてください。
- 同じキャラや地形の別案も残してください。重複対象があっても、異なるデザインを削除・統合しません。
- このフォルダーは参照資料です。画像を追加しても、ゲーム内の描画へ自動適用されません。

このフォルダー作成時点では、チャットで4点を確認しています。原本画像のGitへの追加はこれからです。

| チャット受領順 | 内容 |
|---|---|
| 01 | プレイヤー10機のラインアップ・可動例 |
| 02 | 同10機の詳細リファレンス・配色・三面図・動作・ゲーム内サイズ例 |
| 03 | 大ボス10体・アークハートの段階別形態 |
| 04 | 中ボス10体・動作・弱点 |

18点が揃った後に、実際のファイル名・件数・画像の内容を確認して一覧を更新します。
