# ARCLINE｜初級・中級向けマップ企画ラフ20案

**20案の独立したブレスト企画です。** 企画番号01〜20はステージ番号ではありません。ユーザーが「退屈」と感じている11ステージの代替案を中心に、51〜99面にも応用できる案を含めています。**この企画書でステージへの採用を確定したわけではありません**。既存の地形・承認版・ゲーム実装・正式な指示書を変更しません。

**ラフ画：** この会話で提示した「ARCLINE マップアイデア20案（初級〜中級向け）」の20パネルに対応します。図版の小さな文字や自動生成された右側のステージ対応例は最終判断ではなく、**以下の既存ギミックを調べた割当候補を優先**します。図の形状は自由に改善してよい。ラフ画自体は正式な構築指示書には掲載しません。

**設計基準：** 平坦な床・画面全面の巨大ブロック・同じ高さの島を無意味に量産しない。地形が射角・遮蔽・移動・ギミックの選択を変えるようにする。初級・中級では**1つの主要な発見**を先に設計し、複雑な操作を必須にしない。配置する仕組みは**対象面の既存実装の範囲**にとどめ、新しい物理や勝手なギミック追加をしない。

## 20案の内容と攻略の核

### 01｜反射のくぼみ

**攻略コンセプト：** 山裾に浅い反射ポケットを刻み、高い岩肩は直射・低いくぼみはWの跳ね返りを利用する。正面の壁を全面封鎖せず、洞口の横余白を先に作る。

**地形が攻略に効く理由：** Wがなくなると下部の回り込み射撃の選択が減る。

**実装上の制約：** Wをゲームの既存仕様に従って使用する。図示されたギミックがこの面にない場合、別途合意なしに追加しない。射撃経路は概念上の仮説であり、実命中・敵AI・反撃・手数内攻略は検証済みではない。

**攻略コンセプト：** 短い屋根の下に最初から通れる低い出口を設ける。屋根を必要な一片だけ壊せば近道ができるが、壊さず下を潜って雲Cの外側から撃つ選択も残す。

**地形が攻略に効く理由：** 屋根を全面撤去すると、低路と破壊近道の差が消える。

**実装上の制約：** C・既存の破壊片をゲームの既存仕様に従って使用する。図示されたギミックがこの面にない場合、別途合意なしに追加しない。射撃経路は概念上の仮説であり、実命中・敵AI・反撃・手数内攻略は検証済みではない。

## 合意後に行うこと

ユーザーが採用を選んだ面だけ、**既存ゲーム仕様・PRの個別レビューを読み、採用企画へ改訂**する。いまはどのマップ案も地形座標・ゲーム本体には反映しない。採用時も、最初から意味ある通路・射撃空間・ギミックの働きを作る。動作チェックは軽量な形状確認にとどめ、全体の詳細動作検証は別工程とする。
