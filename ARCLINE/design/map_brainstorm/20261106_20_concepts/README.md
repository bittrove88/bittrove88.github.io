## 現行版の企画とver2の将来機構を分離

**現在の20案では、できる限り既存のゲーム機構だけで攻略の核を実現します。** 対象面の既存ギミックを照合し、新しい物理・新効果を勝手に導入しません。

**[ver2向けギミックの将来アイデアは別ディレクトリに移してあります](https://github.com/bittrove88/bittrove88.github.io/blob/docs/arcline-v2-future-gimmicks-20261106/ARCLINE/docs/v2/gimmick-ideas/README.md)**。重力切替・自動転送・可動遮蔽などは現行版の設計や実装指示ではありません。この企画集では、各案の「現行版での実現方針」を参照してください。

**ステージへの割当・現行ゲームへの組み込み・正式な制作指示書への反映は、今後のユーザー合意後に行います。**

## まず押さえる企画品質

- **地形が攻略の原因であること。** 単に「近づく／遠ざかる」ではなく、遮蔽・射撃方向・移動順・ギミック利用の選択が変わる。
- **大きな固定ブロックで全面を塞がない。** 射点→ギミック→敵方向、入口→内部→出口の有効空間を先に考える。
- **必要な仕組みだけ使用する。** 磁場、反射、気流、可動橋等は対象のステージに既存機構があるか確認する。新しい物理は「既存」と断定しない。
- **案数を制作義務にしない。** 1案の完成度を優先し、後に採用が決まった場合だけ具体設計を進める。

## 空中障害を攻略に組み込む共通方針

全20個別企画書に、浮岩・庇・空中隔壁・破壊片等の配置と、その上・下・脇をどう使うかを追記した。もともと浮島や屋根を含む案も、足場という用途に加えて「どの射線や転移弾を遮るか」を明確にする。

- **空中にも役割のある実体遮蔽を使う。** 効果領域だけで空中障害を表したことにしない。高弾道を遮ること自体は目的にせず、空中障害が射線や射点の選択をどう変えるかを優先する。初級では一つの短い庇等から始め、複雑な多段迂回を必須にしない。
- **通過帯を先に残す。** 空中を全面封鎖せず、上・下・横の開口と着地可能な支持面を設ける。細すぎる穴一つだけを唯一の攻略にしない。
- **案ごとに役割を変える。** 反射順を分ける庇、Uの出口を分ける棚、転移先を限定する隔壁、破壊で開く窓などを使い分ける。
- **有無で比較する。** 障害を外しても射角・射点・移動順・反撃の条件が同じなら再配置する。
- **既存機構の範囲を守る。** 現行版は固定地形等で構成し、移動する浮岩、落下片、自動転送などの新しい物理はv2へ分離する。
- **全景で読み取れること。** 空中障害・開口・効果領域を描き分け、車体・砲口・転移着地の余白を確認する。旧ラフ画像の再制作と座標構築は今回行わない。
