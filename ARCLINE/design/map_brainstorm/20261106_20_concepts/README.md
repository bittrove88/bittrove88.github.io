# ARCLINE マップアイデア・ブレスト20案

**独立した企画案20件の一覧です。01〜20はアイデア番号であり、ARCLINEのステージ番号ではありません。** ユーザーが面白そうだと判断した発想を、後から比較・選別できる企画書として整理しました。

**今回はステージへの割当、実際のマップ座標の構築、正式な制作指示書・面別レビューへの反映を行いません。** どのステージにどの案を当てるかは今後ユーザーと相談して決めます。各企画書はゲームでの動作が実証された仕様書ではありません。

## まず押さえる企画品質

- **地形が攻略の原因であること。** 単に「近づく／遠ざかる」ではなく、遮蔽・射撃方向・移動順・ギミック利用の選択が変わる。
- **大きな固定ブロックで全面を塞がない。** 射点→ギミック→敵方向、入口→内部→出口の有効空間を先に考える。
- **必要な仕組みだけ使用する。** 磁場、反射、気流、可動橋等は対象のステージに既存機構があるか確認する。新しい物理は「既存」と断定しない。
- **案数を制作義務にしない。** 1案の完成度を優先し、後に採用が決まった場合だけ具体設計を進める。

## ラフ画像と初期の文章案の扱い

今回の20個別企画書は、**直前に提示した「ARCLINE マップアイデア ラフ案集」の図版に記載された20案**に対応します。**ラフ画そのものは正式な制作指示書に掲載せず、この会話内のブレスト参考画像として残します。**

同じ会話内で、図版より先に提示した文章版20案は**図版とは名前・内容が一致していません**。それらも失われないように[初期の文章ブレスト20案（別冊）](PROSE_IDEAS_COMPANION.md)へ保存しました。**別冊は今回の図版20案の別名ではなく、追加の発想ストック**です。混同・無断統合はしません。
