# ARCLINE Ver.2 第一案

101〜200面に向けて制作した敵キャラクターの一次ラフ。通常敵24体・中ボス15体・大ボス15体、計54体を18枚のシートに収録しています。2026-11-07（日本時間）に保存・画像再読込レビュー。

**状態：第一案を保存し、見直し済み。最終デザイン・実装用素材・登場順は未確定です。名前はすべて仮称です。**

- [画像・キャラクター台帳（SHA-256・掲載列・候補番号）](manifest.json)
- [保存整合性・実施検証](VALIDATION.json)

## 合意した方向

- Ver.2は同じ世界の別文化圏からARCLINEへ侵攻する敵との戦い。完全な別世界や宇宙文明にはしない。宇宙戦はVer.3の構想。
- 既存の丸み、デフォルメ、機械の質感を土台に、移動方式・車体・装備・振る舞いの幅を広げる。
- 侵攻側を共通機構や共通色で縛らない。所属を示す小さなシンボルは任意。
- 通常敵の複数体同時出現と、単一主人公ARCの12ジョブとの関係を今後設計する。
- 「道具を操る」「地面に仕掛ける」は主軸から外す。9-4「走行と歩行を切り替える機体」は不採用。
- 54体は独立したキャラ枠。色違い・装備違い・ボスの形態数を加算しない。中ボス・大ボスは各15体。

## 保存方法

生成済みPNG18枚を再圧縮・修正・トリミングせずコピーし、保存先と生成元のSHA-256が一致することを確認しました。元ファイル名は台帳に保持し、保存名だけシートID・掲載キャラIDに整理しています。主図に加え、各キャラの小さい動作例を収録していますが、三面図・アニメーション仕様ではありません。

N01・N02・N04がS01、N03・N05・N06がS02です。キャラ番号順と制作順が一部異なります。台帳のcolumnは左から1〜3。N/M/Bはキャラ管理番号で、ステージ番号ではありません。

本編・旧原画・セーブ・ビルドの素材登録は変更していません。第一案は履歴として残し、修正案は別ファイルに保存してください。生成プロンプトは収録していません。
