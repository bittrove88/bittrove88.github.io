# エンドロールの素材準備

今回の依頼は、全体再設計に必要な前作業です。エンドロール本体・本編タイムライン・セーブ・公開ゲームの動作は変更していません。

## 準備済み

- 通常敵12体（6体×2組）、中ボス10体（5体×2組）、大ボス9体（3体×3組）＋アークハート1体、計32体の透過PNG。
- [切り抜き確認一覧](index.html)：暗色・明色・黒背景、原画範囲、個別PNGダウンロード。
- [一括ZIP](../../assets/ending/roll-cutouts/ARCLINE_Ending_Concept_Cutouts.zip)：32PNGと台帳。
- [cutouts.json](cutouts.json)：原画パスとSHA256、切り抜き矩形、マスク、表示グループ、原寸、基準点、目視記録。
- [timeline-draft.json](timeline-draft.json)：ストーリー1.15倍・アークハート4.5秒の最新設計。データ化のみで未実装。
- [player-originals.json](player-originals.json)：承認済み自機10機の原画とハッシュ。背景付きの原画で、集合用の被写体透過化は未実施。

## 画像の扱い

ユーザーの回答「原画の画素を保持する画像処理で進める」に基づきPython/Pillowを使用。S05・S04・S03の大きいコンセプト設定画から取り出し、RGBは元の矩形と完全一致させ、alphaだけを変更します。生成AI・ゲーム内描画・IN-GAME SPRITE欄・縮小例・拡大再生成は使用していません。原画と従来の4切り抜き素材は上書きしません。

紙の除去、色見本の除去、輪郭内の背景穴、別角度の図との重なりを調整しました。白い装甲と鏡面は保持します。ホワイトハウルの足元の雪、ブルーム・テンダーの放水は元絵の一部として残し、隠れた部分を描き足していません。原寸は通常敵約160〜260px、中ボス約250〜275px、大ボス約280〜300pxなので、それ以上の拡大は避けます。

## 再生成

リポジトリルートで `python3 ARCLINE/game/tools/build_roll_cutouts.py`。入力は `cutouts.json` の原画情報と候補矩形、処理は同スクリプトの背景マスク設定です。PNG・確認ボード・一覧・ZIPを再生成します。本編の `build_all.py` には登録していません。組み込み時に登録範囲と配布ZIPを改めて更新します。

## 残る作業

自機10機の被写体マスクと全員集合構図、動き・字幕・音楽同期、本編／確認ページへの組み込み、実機での読みやすさ確認。素材の準備を演出の実装完了とは扱いません。

## 実施した確認

[ASSET_CHECK.json](ASSET_CHECK.json)：32枚の透過・原画RGB一致、原画3枚のハッシュ、ZIP内32画像、再生成ZIPのバイト一致。3枚の確認ボードで全個体を目視照合。ローカルChromiumで一覧32画像のdecode、グループ表示、背景切替を確認。既存単体16スイートと生成45ファイルの一致もPASS。本編のブラウザ全体検査と実機確認は今回は未実施です。
