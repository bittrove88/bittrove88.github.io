# ARCLINE｜1〜100面の個別改善案

2026-11-07／対象：現行0.24.1、main `fee9c40da693ccb6f9dc42f64b846269ae5de4c5`。

ユーザーの「気になったマップ一つずつに対して改善案」「1〜20面も含めて全マップ」という依頼への整理。全100面を一面ずつ扱い、100面は4戦場の方向性も分けた。[共通設計方針](../MAP_DESIGN_PRINCIPLES_001_100.md)の、形状と攻略の違い、序盤の成長のテンポ、地形で生む行動の必然性を適用する。

**制作前の文章案。新しい地形座標・実描画・操作・反撃込み攻略は未作成・未検証。** 「開く」「届く」「遮る」は設計上の狙いであり、実現を確認済みの結果ではない。以下の維持判断も、人による楽しさの保証を意味しない。ゲーム正本・生成物・版数は変更しない。

## 制作へ渡す共通条件

- 各面に「現状の何が妨げか → どこで何をするか → 射線・足場・弾道がどう変わるか」を持たせる。導入面の主題を、開始位置の容易な射撃が同等の手数・危険・狙いやすさで省略する場合は再設計する。
- 別解には異なる位置・準備・入射・危険の選択を残す。一律に高い弧を塞いだり、全装置を直列の必須手順にしたりしない。
- 現行機構の意味を守る。Cは弾の減速、U／F／V／Mは弾への作用。Tの極性変更は手番境界後の射撃へ効く。自機を運ぶ装置や新しい扉連動は作らない。
- 歩行140px、接地・歩行・転移の70度条件、転移の行動消費、射撃後同ターン退避不可を織り込む。砲口・頭上・着地先・破壊開閉後の支持を確保する。
- HP・部位・敵AI・攻撃型・難易度・行動上限・有限在庫の条件は変更しない。専用技や有限装備を説明のない必須条件にしない。取得物がある面は、種類・数量・取得済みIDを保ち、到達性を再確認する。
- 一面ずつ制作 → 実描画 → 内部確認 → 改善 → 再確認。各節の「重点」は必要な限定確認であり、面ごとの専用回帰テスト追加を要求しない。詳細動作検証と最終レビューは最後にまとめる。
- 共通の記録形式は使えても、地形座標や前面の成功形は次面へ流用しない。前後2面・同テーマ・離れた同機構の面も比較する。

### 001｜港の最初の一射〔維持〕

- **残す理由：** 最初の発射を短い距離と読みやすい床で体験できる。最初の成功を返す役割を保持。
- **継続して見る点：** 地形の驚きを足すために初弾を難しくしない。序盤の変化は3面以降で増やす。

<a id="stage-002"></a>

### 002｜丘の肩の道標〔維持〕

- **残す理由：** 緩い上りと敵の高さで、1面から照準の違いを一つ増やせる。
- **継続して見る点：** 3面の歩行の役割と分け、ここでは角度・威力を試す余裕を保つ。

<a id="stage-003"></a>

### 003｜荷車を追い越して〔改修案〕

- **懸念：** 開始位置の照準だけで終われ、歩く理由が弱い。
- **残す核：** 海へ下る連続した坂と、一度の歩行で射点が変わる体験。
- **具体案：** 開始位置を緩い岩肩の内側へ置き、140px以内で出られる広い肩先に水平な射点を作る。肩が浅い射線を遮り、出ると低い敵側を見下ろせる輪郭にする。
- **行動の必然性・手応え：** 一度歩いて肩から出ると、砲口の向きと有効な射線が分かりやすく変わる。開始位置の容易な曲射が同等に成立する場合は肩と敵の位置を描き直す。
- **他面との違い：** 4面の空隙を渡る判断と分け、3面は連続床の短い歩行だけで完結する。
- **制作時の重点：** 一回の歩行量、足元角、射点の広さ、歩行前後の通常弾。屋根・転移・精密着地を要求しない。

<a id="stage-004"></a>

### 004｜弾で渡る船着場〔改修案〕

- **懸念：** 転移を使わず開始位置から2行動で勝つ記録がある。
- **残す核：** 歩行で渡れない空隙と、向こうの広い着地面。
- **具体案：** 対岸の岩肩の裾へ敵を下げ、その内側を狙える広い射点を転移先にする。開始岸からは岩肩が自然な射線を遮り、転移先から側面が開く、岸同士の関係を先に作る。
- **行動の必然性・手応え：** 転移で岩肩の内側の射点を得ることが、読み取りやすい主解になる。着地で一行動を使い、次手から狙えることまで含めて手応えを返す。
- **他面との違い：** 単に距離を縮める面にせず、攻撃する側面が変わる。19面の中継移動、29面の空港デッキと輪郭を共有しない。
- **制作時の重点：** 広い転移着地と頭上、開始岸からの容易な曲射の残り方、着地後の実際の反撃。巨大化や細い窓で解決しない。

<a id="stage-005"></a>

### 005｜巻上げ場の花印〔維持〕

- **残す理由：** 初の中ボスとして、低い丘を越す弧と既存の部位を狙う節目を保持。
- **継続して見る点：** 3・4面を改めた後、ここまでの操作が短くまとまるか比較する。初ボスへ全手段を直列に要求しない。

<a id="stage-006"></a>

### 006｜花のある鏡岸〔維持〕

- **残す理由：** 浅い鏡床への一回反射が実際の攻略で有効。反射の初出として明快。
- **継続して見る点：** 床反射の見える入口・出口と広い許容を保持。通常射撃の別解があることだけで閉鎖的にしない。

<a id="stage-007"></a>

### 007｜岩箱の継ぎ目〔改修案〕

- **懸念：** 岩箱を壊さず、開始位置から高い弧で勝つ例がある。
- **残す核：** 一片を壊すと次に使える射線が開く、最初の破壊。
- **具体案：** 独立した縦箱を、斜めに張り出す自然岩門の根元の一片へ組み替える。敵は岩門奥の側方に置き、壊れる部分と固定の岩体を視覚的にも分ける。
- **行動の必然性・手応え：** 見えているひび割れを一度撃つと、広い攻撃経路が残る。壊す前後で同じ低い射撃の結果が変わる構成を狙う。
- **他面との違い：** 16面の移動先を開く破壊、20面の部位への角度を作る破壊と分け、ここは一片・一つの結果に集中する。
- **制作時の重点：** 一片だけで経路が開くこととその幅、破壊前の容易な山越え。未実装の崩落や連鎖破壊は使わない。

<a id="stage-008"></a>

### 008｜ひさしの下を通る〔改修案〕

- **懸念：** ゲーム内案内は屋根下の低弾道、戦術目標は天井下面反射。床反射だけの勝利例もある。
- **残す核：** 天井を使って下向きへ返す、6面とは異なる一回反射。
- **具体案：** 主題を天井下面反射へ統一する。自機の頭上は開け、前方の斜めの庇の下面に広い反射帯を見せる。敵は小さな岩背の奥へ置き、天井から落とした弾が入る空間を作る。床Wは主経路と役割が重ならない範囲へ整理する。
- **行動の必然性・手応え：** 岩背を正面から撃つと遮られ、見えている天井に当てると奥へ届く。上を使う発見を一回の反射で返す。
- **他面との違い：** 6面は床から上へ、8面は天井から下へ。12面の床を転がす梁下、31面の結晶の向きとも分ける。
- **制作時の重点：** 一回の下面反射と入射の許容、砲口と転移の余地。教材・日英目標も地形と同時に整合させる。

<a id="stage-009"></a>

### 009｜岸壁の踊り場〔改修案〕

- **懸念：** 上段へ移る選択が、開始位置の曲射と比べて弱い。
- **残す核：** 高い敵に対して、自分で射点を選び始める面。
- **具体案：** 低い岸道の先に広い肩を置き、離れた中継棚の上面からも敵側へ撃てる形にする。敵は段丘の裏斜面へ置き、低い岸道からは歩いて肩へ、棚側は一度の転移で角度を得る。
- **行動の必然性・手応え：** 覚えた歩行か転移を選んで射線を得る。移る前の同じ角度調整だけで主題を消せる状態を避ける。
- **他面との違い：** 4面の転移の初体験から、既習得の二つの移動手段の短い比較へ進む。上下の窓を多数足さない。
- **制作時の重点：** 両経路の準備量・狙いやすさ、開始位置の抜け、次の10面へ向けた負荷。

### 011｜次の便は下り坂〔比較維持〕

- **懸念：** 11〜15面を並べると、低い連続床の印象が続く。
- **残す核：** 長い下りへ弾を預ける、転がり弾の明快な入口。
- **具体案：** 基本骨格は保持し、下りの終点に敵と接触するまでの長い連続面を見せる。上空の棚はこの下りを隠さない位置へ整理する程度に留める。
- **行動の必然性・手応え：** 弾を手前に着地させると、床が先へ運んでくれることが見える。特定の有限技を必須にはしない。
- **他面との違い：** 12は梁下、13は段差後の再走行、14は接地位置の判断と分ける。11を他4面のひな形にしない。
- **制作時の重点：** 12〜14改修後の並びを比較。下りが既に読めるなら座標変更を行わない。

<a id="stage-012"></a>

### 012｜低い梁の運搬路〔改修案〕

- **懸念：** 梁が高く、通常の浅い弧で通せるため床を使う理由が薄い。
- **残す核：** 連続床を通る弾と、梁下の横方向の空間。
- **具体案：** 梁の主要部分を中間の通路に沿わせ、上を通る弧は遮るが床沿いの道は広く残す。自機の出撃頭上は開放する。梁の先端近くには歩いて取れる射点も用意する。
- **行動の必然性・手応え：** 転がす弾は手前から梁下を進み、通常弾は前方の射点を取ることで届く。異なる攻撃手段でも梁下の道を使う意味がある。
- **他面との違い：** 8は天井で弾を返す。12は天井に触れず床を使う。連続床を穴で分断して転がり弾を無効化しない。
- **制作時の重点：** 梁下の車体・砲口の余裕、床に着く位置、通常弾の移動後経路。専用技の在庫がなくても成立すること。

<a id="stage-013"></a>

### 013｜段差からの再走行〔比較維持〕

- **懸念：** 11面の下りと見た目が近いが、段差後に床へ戻る挙動には別の学びがある。
- **残す核：** 小段差を落ちて再び走る連続地形。
- **具体案：** 段差前の着地帯と段差後の受け皿を読みやすく分け、必要なら下段の平面を少し広げる。穴や二つ目の落下は増やさない。
- **行動の必然性・手応え：** 手前で着地させた弾が小段差の後も進むことで、11の単純な下りとの違いを返す。
- **他面との違い：** 14の接地位置選択と分け、13は挙動の短い再発見を担う。
- **制作時の重点：** 現行の再走行と読みやすさを比較し、成立していれば現行保持。新しい落下ダメージ等は導入しない。

<a id="stage-014"></a>

### 014｜連続する石畳〔改修案〕

- **懸念：** 連続床と高い梁の構成が12面に近く、異なる判断が見えにくい。

### 098｜逆位相の橋と九つの固定島〔改修案〕

- **懸念：** Normal5行動・Hard6行動の記録で、移動せず橋・V・Wの判断なしに勝っている。
- **残す核：** 逆位相の二本の橋と、姿勢に依存しない9つの固定島。
- **具体案：** 既存の高いスクリーン島を、開始島から敵への山越えに干渉する位置へ寄せる。敵は右の島の逆斜面の低い裾へ置く。既存9島の橋先の受け面を歩行量と転移の接点に合わせ、西橋は接続、東橋は降下帯の射線と支持を担わせる。
- **行動の必然性・手応え：** 今の姿勢を見て渡る先・撃つ位置を選ぶ。西橋は水平の中継と65度の高島への上り、東橋は水平の高路と−58度の低島への降下という違いを活かす。両斜面とも現行70度条件内なので、起きた橋を単に歩行不可とは扱わない。
- **他面との違い：** 37は一本の射線差、39は中腹の足場、87は固定P0前の遮蔽。98だけに複数の位相を読む終盤の役割を持たせる。
- **制作時の重点：** 既存周期を維持し、両姿勢で固定の待機・着地先があること。橋長を一度の140px歩行で渡れると仮定しない。途中の姿勢変更後の支持と、逆斜面への射線・省略経路。

### 100｜アークハート — 最後の帰還〔専用検討〕

- **懸念：** 4戦場とも連続した低い丘・縦壁・薄い長方形棚へ骨格が寄っている。
- **残す核：** 4戦場・固定10機の専用リレーと、段階ごとに射点を選び直す総括。
- **具体案：** 4戦場の個別案を下表に分ける。各3,000pxと担当機体順、既存の機構を維持し、地形の接続・敵への方向・空間の奥行きを変える。
- **行動の必然性・手応え：** 戦場が変わった時、既に知る操作で読み直す地形も変わる。機体や背景の交代だけに違いを依存させない。
- **他面との違い：** 91〜99の形を4つコピーせず、最終戦の担当機体と現在の専用条件から独立に設計する。
- **制作時の重点：** 固定10機・各HP70・各表示100ダメージ・必殺3・各28行動・出現距離800px以上・敗北機から再挑戦を保持。通常面の改訂と混ぜて自動反映しない。

## 着手するときの順序

初出の必然性を確かめる代表として4・31・98を優先する。序盤の3・7・8・9と、11〜20の変化も同じ改善範囲に含める。次に41〜48の比較、63・71・73・91、81〜90の視点の緩急を扱う。各案は一面ずつ描画して仕上げ、その後に区間の比較へ戻る。

条件調整・比較維持の面は、前後の改修後に本当に変更が必要か判断する。100面は担当10機と4戦場の条件を含む専用工程に分ける。1〜100の全案が完成するまで実描画を後回しにする進め方は取らない。
