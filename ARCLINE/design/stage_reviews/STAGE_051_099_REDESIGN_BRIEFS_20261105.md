# ARCLINE ステージ51〜99：面別の改修判定・攻略意図・受入れ条件

**全49面共通の必達品質：** [地形・オブジェクト・攻略・ギミックの品質憲章](MAP_DESIGN_NONNEGOTIABLE_REQUIREMENTS_20261106.md)  
**改修基準：** [1面ずつの制作仕様書](IMPLEMENTER_MAP_REDESIGN_PLAYBOOK_20261105.md)  
**参照：** [PR #74](https://github.com/bittrove88/bittrove88.github.io/pull/74) / head `9a58a777`  
**対象：** ステージ51〜99、計**49面**（うちR＝14、S＝22、K＝11、K/S＝2）。  
**判定の意味：** R＝**PR #74の制作途中案・既存レビューを確認し、継承すべき要素を特定したうえで、新しい攻略が必要な地形骨格を作り直す**、S＝構造と攻略の大幅改修、K＝核を保護した調整、K/S＝設計レビューに応じてKまたはS。現行案のポリゴンをそのままコピーしてRを済ませないが、旧案を見ずに白紙制作もしない。

> **とくに重要：** 65〜89面のうちRは14面、Sは11面。Rに分類した面について、元の `floor` や `parts` を少し曲げたり位置をずらしただけの改修は禁止。敵プロフィール、既存ギミックの仕様、世界観、ゲームルールは守り、**配置する地形と攻略を新しい発想で設計する**。新しい座標・部品数・射点はゲーム表示と実戦を検証できる実装担当が決める。

**面別指示で指定された地形を作るだけでは不十分。** どの面にも品質憲章の「平地・同形島の量産の拒否」「1面1コンセプト」「移動・ギミック・別解に意味を持たせる」を適用する。特殊なステージで平地や人工梁を残す場合も、ゲーム上の機能を説明すること。

**[承認済み5面・72面否決・繰り返しパターンの監査](STAGE_065_072_APPROVAL_AND_DIVERSITY_AUDIT_20261106.md)をこの面別ブリーフとセットで読む。** 65v3・66v4・67v4・69v2・71v5は**設計承認済み（動作未検証）**。72v2はユーザー指摘で**未承認・不採用**。最新指示により次は**72面Rの新設計**とし、承認済み5面を保護する。

**旧版の着手順「65から」は当初の計画であり、今の再開指示ではない。** 続きは **72 → 75 → 76 → 78 → 79 → 81 → 82 → 87 → 89** を優先。72面v2の修正ではなく、新しい骨格からの再設計を先に行う。

**レビューの新基準：** いままで頻出した「高所は攻撃できるが危険、低所は守られるが複合攻撃」という同形ルートや、左右の大屋根／天井アーチの形を、後半の新面で再利用しない。各R面のラフ2案について、既承認面との**地形骨格・移動・射線・ギミック・攻防の5軸**の差を示し、**似た初稿は座標化前に差し戻す**。まず**72面**では巨大屋根／アーチの重複、入口の閉塞、敵への射線不足を根本から解消する別骨格を作ること。75面の設計は72面の承認後。

**1面の検証は引き続き軽量。** 外形・入口／出口の連続性・想定射撃方向の空間、基本データ整合まで。実歩行・射撃・敵AI・戦闘・行動上限は全49面の設計承認後に総合検証。

### R対象の再設計を「見た目だけの刷新」にしないために

- **65/66：火口を同じ高低棚の配列にしない。** 65は噴出による射撃可能な時間帯と部位の選択、66は安全な炉内と危険な稜線の選択。**同じ火山でも別の攻略体験**を作る。
- **67/69：徒歩と位置取りを別の方法で使う。** 67は**ひと続きの地面を歩くことで**敵射線が変わる、69は**たった一つの退避島の肩を歩いて**攻防が変わる。
- **71/72：鉱石の形を攻略課題にする。** 71は3つの異なる地形面とAIの移動に対応、72は**1つの巨大鉱石を上下・横から攻略**。どちらも同じ六角棚の積層を禁止。
- **75/76：人工施設を単なる長方形の橋としない。** 75は部位を守る梁の裏表、76は磁場への入射角が異なる発射室。直線が必要な建造部材は残し、装置の位置に意味を持たせる。
- **78/79：縦坑と可動橋は別の判断を生む。** 78は敵がどの高さに現れるかを読む、79は**B開閉とT操作が射点と弾道を変える**。
- Rの各面では、**2つの異なる骨格案を出し、既存形状から離れたことを説明してから**実装する。隣接面の過去4〜5面とスクリーンショットで差を確認する。
