# ARCLINE マップ改訂の目的と構築担当への入口

**各ステージを、地形そのものが攻略上の判断を生み出す、独創的で自然なマップへ改訂してください。**

地形を先に描いてから攻略の理由を付けるのではなく、**プレイヤーが何に気づき、何を選ぶと攻撃・防御の条件がどう変わるか**を先に設計します。地形やギミックを取り除いても攻略が変わらない案、単なる近距離戦／遠距離戦の違いしかない案は制作に進めません。

**[正式指示書：攻略の因果関係からつくるマップ制作方法](ARCLINE_MAP_DESIGN_SINGLE_SOURCE_OF_TRUTH_20261106.md)**

制作担当はこの正式指示書を正本として読み、旧指示書や試作の説明が矛盾するときは正式指示書を優先してください。正式指示書には、地形・ギミックの必達品質、制作の順序、方向性レビューの条件、承認済み面と今後の対象面、93・98・99面の新企画への参照をまとめています。

**現状：65・66・67・69・71・72・75面は設計承認済み・動作未検証。次の76面は方向性レビュー待ち。** [PR #88のA/Bラフ](https://github.com/bittrove88/bittrove88.github.io/pull/88)は、今回のレビューで攻略の因果が不十分と判断されました。**形状の手直しではなく「ギミックが何の判断を生むか」から再構想してください。**

76面の構想が承認されるまでは、78面以降へ進まないでください。各面の実射撃、転移、敵AI、反撃などの総合動作検証は、全49面の設計承認後に実施します。
