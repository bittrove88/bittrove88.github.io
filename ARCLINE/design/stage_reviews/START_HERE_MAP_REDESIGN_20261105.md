# ARCLINE マップ制作の目的と開始指示

**各ステージの地形とギミックが、プレイヤーに固有の攻略判断を生むマップを作ってください。**

**設計の最初から**、大きなブロックで通路や射撃空間、ギミックを全面的に塞ぐことを避けてください。形を先に描いて攻略理由を後付けするのではなく、「どこからどう攻めると、何が変わるのか」を決めてから地形を作ります。

**提案は1案で構いません。** 2案を必ず作る必要はありません。意味のある攻略が成立する、最も良い案の完成度と制作速度を重視します。

**[正式指示書：マップ制作の基本方針とステージ76の個別レビュー](ARCLINE_MAP_DESIGN_SINGLE_SOURCE_OF_TRUTH_20261106.md)**

現在、**65・66・67・69・71・72・75面は設計承認済み・動作未検証**です。76面の[PR #88](https://github.com/bittrove88/bittrove88.github.io/pull/88) のA案は大きな構造物で磁場の攻略空間が塞がれ、B案は主に距離の選択にとどまっています。新しい制作方針を使い、76面を**攻略の核から見直して完成案を提示**してください。

詳細な制作判断は構築担当に任せます。76面のユーザー設計承認までは78面へ進まず、実戦・AI・全弾道の総合検証は全49面の設計承認後にまとめて行います。
