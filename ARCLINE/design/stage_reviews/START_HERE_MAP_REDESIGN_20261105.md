# ARCLINE マップ改訂の目的

**各ステージの地形を、プレイヤーが読み解き、移動し、工夫して攻略するための舞台へ作り替えてください。**

ステージ51〜99では、地形やオブジェクトの形状が単調になり、平地・同じ高さの足場・似た屋根や浮島が繰り返されています。ギミックを入れ替えても攻略が似た形になっていることが、改訂の根本的な課題です。

求めるのは、**49面それぞれに独立した地形構造と攻略の発見があること**です。坂、断崖、洞窟、浮島、橋、屋根、破壊、反射などを目的に応じて組み合わせ、地形そのものが移動・遮蔽・射撃・ギミック利用の判断を変えるようにしてください。形だけ変えたり、仕掛けを数合わせで追加したりしないでください。

自然地形には自然な造形を、人工物には支持や用途が分かる造形を求めます。**ひと目で地形の意味と攻略の方向性が伝わる、独創的で完成度の高いマップ**にしてください。

**[マップ改訂の目的・品質基準・制作指示を読む](ARCLINE_MAP_DESIGN_SINGLE_SOURCE_OF_TRUTH_20261106.md)**

この指示書に**設計承認済みの6面、再設計が必要な75面、今後レビュー・改修する42面**の一覧と、それぞれの扱いを記載しています。

制作では**ゲームに実装されている機能のみ**を使用し、未実装の重量・動く吊荷などを新しいギミックとして作らないでください。全49面の設計承認後に詳細な動作検証を行うため、各面の制作中は造形と攻略意図、最低限の形状確認を優先します。

まず未承認の**75面**について、既承認面と違う地形骨格と攻略の異なるラフ2案を提示してください。承認を得るまで76面へ進まないでください。

**最も大切なのは、マップの複雑さではなく、その地形だからこそ生まれる攻略の面白さです。**
