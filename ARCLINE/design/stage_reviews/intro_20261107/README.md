## 面ごとの変更

### 31｜見える結晶で一回返す

結晶を入口へ露出し、手前の岩肩と短い反射後の距離を組み合わせた。鏡床だけで済む構成を外した。57°/75の周囲9入力がすべて結晶で一回返して命中。同じ入力で結晶を外すと届かない。高い別の弧は残す。

### 37｜起きた橋から下の受け島へ

初出の橋一本と、下の広い固定島に整理した。橋の水平時は歩いて前へ出られ、実際のターン境界で橋が起きると、x52/h30からx52/h10へ降りる。そこから前進して狙い直せる。上空の別解も残し、待つだけの手順にしない。

### 71｜低所と上棚から磁場へ入れる

磁場を手前へ寄せた。低所では発射直後に弾が曲がり、岩肩を越して鉱壁の下へ通る。棚へ転移して同じ場へ入れると、低い角度にも広い入力がある。低所は準備不要、棚は一手を使う。

### 73｜端子の反転で次の射線を変える

右上から左の洞室へ狙う構図へ変更。端子は通常射線から外し、端子を撃つ一手→敵の実手番→境界の極性反転→次の弾で洞口へ入れる順を実行した。端子と反転後の射撃は各9近傍入力で成立し、射撃の同じ入力は反転前には届かない。
