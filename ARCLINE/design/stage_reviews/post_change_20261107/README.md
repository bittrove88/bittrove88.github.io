## まとめて確認したこと

- 新地形19面のNormalを、Gun・空の開始在庫・通常弾で完走。後半58・64・92面はHardも完走し、16面の別ルートも含め計23戦の実入力と敵の実手番を記録。必要な主要手順には設計時の入力を先頭に使い、その後も実エンジンの射撃・反撃で勝利まで継続した。
- 7・16面は最後の確認で破壊を省く転移直通が見つかり、岩体を地面へ接続して再制作・再描画。16面は隣の安全列を探す転移の挙動も考慮し、上面を水平にした。破壊後の広い射線・下段への着地は保持。
- 8面は日英の教材とデモを庇の下面反射へ統一。10機体の通常弾プロフィールで、実際の下面接触から前・下向きに返る例を確認。
- 0.24.3の取得物可視性・天井全景・試撃・マスター・勝利曲修正とSTG基盤を取り込み。取得物は新配置を優先し、新地形と干渉する12面の座標と14面の高さだけ調整。全46個の種類・数量・取得ID・出現ターン・クリア補償は維持。変更面の取得例を更新した。
- 未変更81面の地形・生成データはmain0.24.3と完全一致。HP・部位・AI・攻撃型・行動上限・歩行／転移／物理・在庫・schema8/reset2・最終100面の専用リレーと、0.24.2の美術素材を保持。
- 面ごとの専用回帰テストは追加していない。既存の地形固定チェックは、この19面だけを新しい正本と元データのハッシュへ差し替えた。未変更面と仕様の保護は継続する。

狙いの近傍入力は許容の限定比較であり、勝率ではない。高い曲射などの別解をすべて禁止したものでもない。通常弾の自動勝利は、任意の転がり装備を含む全別解の完走や、人間の初見理解・楽しさを証明しない。

- 31・37・71・73面など：初出の装置を使う理由。31面の前回候補は反射の許容が足りず不採用であり、課題の解消とは扱わない。
