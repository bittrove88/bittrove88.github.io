## 1. 修正の根本的な目的

従来の三層氷洞には、階ごとに奥行きがあり自然な氷壁や異なる高度がある一方、**通路前面のほぼ全面が連続した屋根で覆われ、上へ進むために氷板の破壊が実質必須**という問題があった。窓幅を大きくするだけでは、破壊→転移→破壊→転移の一本道から抜け出しにくい。16行動上限では、敵に反撃されながら手数を消耗するリスクも大きい。

**今回の設計意図：** 「どの氷板を壊すか」の前に、**「自然に開いた隙間から、どの階へ移るか」**という判断を作る。中層から上段を狙う風洞ルート、高所へ一気に移るルート、必要な場合だけ氷板を壊して広い角度を作るルートを用意する。破壊は近道・角度改善の選択肢であり、通行の絶対条件にしない。

1単位＝10px。全体の幅1560px、下段自機 `(65,8)`、既存3層構造、敵プロフィール・HP・16行動は維持。

## 3. 主攻略・別解・任意破壊

### A. 主攻略：天然立坑→中層→上層東の風洞

- 自機はx65の下層に出現。x58〜80の天然立坑は破壊前から空いている。
- テレポート弾を利用し、中層の大きな棚F03（x82〜106、h43〜45）への移動を狙う。
- 中層を東へ進み、D04（未破壊）の上面x106〜125を足場として、**上層東の大開口x107〜123に向いた射点**に移る。
- この射点からは風Fが上段へ抜ける。D09の屋根に遮られる単純な直線弾ではなく、風を利用した高弾道を検証する。
- D04を先に壊してしまうとその上面を支持面として利用できなくなる。**「壊すか、足場にするか」**という判断が発生する。

**成立条件：** 中段への実転移→D04への実徒歩→風Fを通る実弾道で敵へ命中。**未検証。**

### B. 別解：貫通立坑→上層の開放射点

- x58〜80は下層から最上部まで自然に開いている。上層の固定棚F08はx88〜107にある。
- 中層を経ずに高所へ転移する弾道、または中層へ一旦着地してから上へ移る弾道を選ぶ。
- 上層中央F08（射点x98、h72）から敵側のF10（x147、h72）を狙う。**上下の高度差がほぼ消え、D09を越える射線を作れる**ことが地形上のメリット。

**成立条件：** 実入力でF08上面に着地できること。着地後に通常弾が敵へ命中すること。**未検証。**

### C. 任意の破壊ルート：氷板を開けて攻撃経路を増やす

- 西の中層 `D02`、東の中層 `D04`、西の上層 `D07`、東の上層 `D09` は**すべて任意の破壊可能部品**。
- 西側の穴を拡大したり、東側の障害物を一部だけ取り除いたりできる。
- 屋根の下にいる敵へ通る角度や、自機が使う支持面は破壊前後で変化する。**必要な1片だけを破壊する戦術**を許容する。
- 16行動なので、D02/D04/D07/D09を全部壊すことを攻略条件にしない。

## 5. 静的ジオメトリ検査（実物理ではない）

12個の設計ポリゴンに対し、単純な点・直線の交差を調べた。**結果は視線の候補であり、銃口と弾体の有限サイズ、重力・風・衝突応答、転移弾道、敵行動を含むエンジンの合否ではない。**

| 仮想直線 | 固定・破壊前ポリゴンの交差 | 意味 |
|---|---|---|
| P0(65,12) → 敵近傍(147,76) | F03／D04／D09／F10 と交差 | **開始点からの単純直線射撃では敵を狙えない** |
| P0(65,12) → 上層中央棚左端(88,76) | **交差なし** | 自然の中央立坑を通る上方転移方向が幾何学上開いている |
| 上層中央(98,76) → 敵近傍(147,76) | **交差なし** | 上段へ達すると単純な見通しが明確に改善する |
| 中層中央(96,49) → 敵近傍(147,76) | D09 と交差 | 中層射点は高い弾道／風の価値がある |
| 東風洞射点(115,49) → 敵近傍(147,76) | D09／F10 と交差 | 直線ではなく風を使う上方弾道の試験が必要 |
| 中央立坑(68,12) → (68,93) | **交差なし** | 下層から天窓直下まで連続して空いている |

**この表からわかるのは、初期位置からは射線が塞がれ、上層へ移れば見通しが改善するという地形設計上の差である。** 実際に到達可能な転移弾道があることや、複合ギミックの命中は実戦検証が必要。

**追加の重点監査：** P0から通常弾を高く打ち上げた場合、自然立坑を使って移動せず敵へ容易に当てられないかも試す。成功した場合は、攻防・射角・ギミックの違いを評価し、移動の戦術的価値が薄ければ敵側の庇や射点位置を再設計する。また、中層中央F03の頭上には上層棚F08が近いため、**上層東の開口x107〜123まで歩いて初めて十分な上方射角が得られるか**を確かめる。直接上層テレポートが届かない場合、破壊必須へ戻すのではなく、開口や中継棚の座標を修正する。

## 6. 実装担当に必要な再検証

- [ ] **ステージ全体の静的判定：** 12構造・8独立破壊単位のコリジョンと支持面が設計図と一致。浮島の上下が不当に重なっていない。
- [ ] **天然立坑の移動：** x58〜80の幅220pxの通路を、実際の転移弾と車体で通り、F03中層に着地。可能ならF08上層への直接到達と2段経由の両方を試す。
- [ ] **中層の攻撃：** F03→D04上面へ移動し、風Fが入る角度に余裕があるか。D09越しに実弾が敵へ命中。ダメなら上層東の開口幅や風域位置、D09形状を調整する。
- [ ] **上層の攻撃：** F08から敵側F10への実弾が命中。狙える角度が極細の一点だけにならないこと。
- [ ] **任意破壊：** すべてのD部品を1片ずつ破壊し、隣接片が連動消失しないこと。各破壊前後で射線がどう変わるか記録。
- [ ] **被弾と手数：** 敵の40面以降の徒歩＋反撃込みで複数シードのクリア可能性を確認。**16行動の半分以上を必須の破壊・移動に消費しない**。
- [ ] **ギミックの意味：** 風を通る中層のルートと、風を短く横切る上段のルートが異なる選択として成立する。
- [ ] **開放感：** 下層・中層・上層から視認できる天然の隙間を比較図に明示。単なる全層を覆う長方形天井に戻さない。
- [ ] **再現ログ：** `shotExamples`、`replayViews`、`angleReview` はv4地形の実測でのみ再作成する。v3の成功ログは古い地形用なので流用しない。
