# ステージ99｜個別設計レビュー・新コンセプト反映版

**99面の新しい設計方針は「二峰による直射回避＋複数転移先＋既存ギミックの複合攻略」。ユーザーが99面への採用先を指定した。** マップ形状そのものはまだ未制作・未承認。これは構築担当が99面を設計するときに参照する**最新の改訂レビュー**で、旧PR #74の個別レビューやJSONの上書きではない。

## 参照する設計資料

- **[ユーザーの新マップアイデアを言語化した企画](STAGE_099_MULTI_TELEPORT_TACTICAL_MAP_CONCEPT_20261106.md)**：この面で実現すべき独自の体験。**最優先**。
- [PR #74の99面v2レビュー](stage_099_review_v2.md)・[同v2座標案](stage_099_proposal_v2.json)：以前に検討した地形、複合射撃、ボスではない通常敵・ゲーム仕様の確認材料。
- [構築担当向け正式指示書](ARCLINE_MAP_DESIGN_SINGLE_SOURCE_OF_TRUTH_20261106.md)：全マップ共通の品質、検証区分、担当裁量、進行順。ここまでの承認済み面は無断変更しない。

## 新構想で解決する課題

旧99面には「中央から下る」「低い鏡路」「右上外周」の3経路がある一方、**今回のユーザー案は「二つの山で直射を避けつつ、どの空中足場へ転移するかが主攻略」という異なる構造**を求めている。

旧案の巨大な核空洞を単に小さな浮島へ分割するのではなく、**二峰の高低・左右への射線の遮断・複数島の配置そのものが攻略の選択を変える骨格**にする。橋の状態が主役の98面とは明確に異なる。

| レビュー観点 | 99面の新たな必達条件 |
|---|---|
| 地表 | 左右の二峰とその間の谷が、自然に直射を制限し、転移した位置から射線が変わる。射線封じのためだけの不自然な壁は増やさない |
| 空中 | 少なくとも3系統の**役割が異なる転移候補**を検討。数量合わせや同形・同高さの島は不要。実機での着地成立は後で検証 |
| 射撃 | 島ごとに発射位置、敵を狙う方向、遮蔽と使えるギミックが変わる。主・別解が同一の攻撃にならない |
| ギミック | 元案の**C・M・W**の実装済み機構だけでまず組み立てる。W＋C＋Mの既存の成功要素を継承し、装置の乱用を避ける |
| 攻略 | 初期位置からの単調な直射を避け、転移・位置取り・弾道の選択に意味を持たせる。開始位置の全弾道を数値上禁止すること自体は目的にしない |
| 視認性 | 浮島と二峰のシルエットが読みやすく、狭い射撃余白・島の不自然なめり込みがない |
| 差別化 | **93面は上下反射室／98面は浮島＋可動橋の毎ターン射線変化／99面は二峰を越えて転移先ごとに攻め方が変わる** |
| 実装制約 | 新しい移動・荷重・可動島・敵AI能力・橋B・上昇流U・風F等を無断追加しない。敵の設定と行動上限を維持 |

## 従来の「K」分類の取り扱い

[旧面別ブリーフ](STAGE_051_099_REDESIGN_BRIEFS_20261105.md)では99面を「K：保持・局所改修」としていた。**今回のユーザーの新しい地形構想は骨格変更を伴うため、99面のみ現在の制作判定を「S：大幅構造改修」へ更新する。** ただし、従来のW＋C＋Mによる攻略意図や既存の敵設定は価値があるため、ゼロから無関係な仕組みを発明する指示ではない。

これは**設計の改修区分の更新であり、99面の設計承認ではない**。新しい完成JSONや弾道の実証があるかのように扱わない。

## 制作・受入れの進め方

1. **99面の作業順が来たら**、本レビューと[コンセプト](STAGE_099_MULTI_TELEPORT_TACTICAL_MAP_CONCEPT_20261106.md)、PR #74のv2レビュー・座標案、エンジンの実際の地形・テレポート・W/C/M仕様を確認する。
2. 二峰の輪郭、空中足場の位置・形状と用途が異なる**ラフ2案**を提示する。それぞれ「どの転移先を選ぶと何が得られるか」を具体的に説明する。
3. 採用された1案だけゲーム互換データへ落とし込む。**図で島へ転移できそうに見えることは、実際の着地を証明しない**。制作時は支持面・キャラの余白・表示と明白な閉塞を静的に確認する。
4. 提出は全景、新旧の同縮尺比較、93・98面との固有性の比較、主攻略と別解、軽量な静的品質チェック、最終検証へ持ち越す事項。
5. **99面のユーザー設計承認を受けてから完成扱いにする。** 全49面の設計承認後に、実歩行・転移着地・C/M/W作用・敵反撃・自律転移・行動上限・複数seedを総合検証する。

**この個別レビューは設計制作に必須の参照元。旧v2レビューは歴史・検証の入力であり、新しい二峰＋転移先選択の企画を上書きするものではない。**
