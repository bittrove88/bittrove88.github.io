# ARCLINE 51〜99面｜地形から攻略を生み出すマップ制作指示

## 改訂の目的

**49面のそれぞれを、地形を読み解き、移動・遮蔽・射撃・既存ギミックを使い分ける楽しさがある、独創的で完成度の高いマップにする。**

長い平地、同じ高さの島、似た屋根・洞、意味のない障害物、ギミックを入れ替えただけの同形攻略を量産しない。各面で地形・オブジェクト・敵味方の位置・ギミックが一体となり、**「この面の地形だからこそ、その攻略が生まれる」**と説明できることを求める。

最優先は**面白い攻略の構造**と**自然で読みやすいマップの造形**であり、部品数、ポリゴン頂点数、ギミック数、静的チェックのPASS数ではない。形を先に作り、後から「この地形に意味がある」と説明を付ける制作手順は認めない。

## ステージの作り方：攻略の因果関係から設計する

**制作は「攻略の仕組み → ギミックの役割 → 必要な地形 → 造形と座標」の順に進める。** 2案のラフを描く場合も、見た目を変えた2枚ではなく、プレイヤーの判断が異なる2つのゲームデザイン案にする。

### 1. その面で生みたい発見を、プレイヤーの行動として決める

地形や部品を描く前に、**「プレイヤーは何に気づき、何を選ぶと、どの攻撃・防御上の利益を得られるか」**を1文で定める。

- **合格する説明の例：** 「固定岩の内側へ回ると磁場を通す角度が開く。端子を使う場合はその場所へ移らず別の曲射を選べる」。これは*ゲームで成立するかをこれから検討する設計仮説*であり、特定面の正解指定ではない。
- **不合格の説明：** 「左にブロック、中央に磁場を置く」「高いところか低いところを選べる」「遠距離射撃と近距離射撃の2ルート」。単なる位置・距離の違いは、その面ならではの攻略の発見ではない。

**判断がない装飾的な構造物を追加するのではなく、まず判断を生む条件を作る。** 初期地点からの直射を不自然な壁で塞ぐこと自体は攻略の深さではない。初期地点から撃てても、移動・転移・ギミック利用に異なる利益があるならよい。

### 2. 地形・ギミック・選択・結果の「因果」を結ぶ

構想には少なくとも次の関係が必要。

| 構成 | 設計時に答える問い |
|---|---|
| **地形** | どの空間・開口・遮蔽が、どの行動を有利／不利にするか |
| **ギミック** | いつ・どこから使えるか。使うと実際に何が変わるか |
| **プレイヤーの選択** | 移動・転移・射撃方向・操作・破壊・待機などから何を選ぶか |
| **結果と代償** | 攻撃角、届く対象、遮蔽、移動手数、危険性、次ターンの位置など何が変わるか |

**「ギミックが配置されている」だけでは合格しない。** 発射地点からギミックを通り、狙う相手へ向かう空間が**地形に塞がれていない**ことを最低限確かめる。ギミックが壁や床に遮られ、想定する発射経路に関与できない場合は、配置理由を失っている。端子Tなどの状態変化も、**状態を変えることで有効な射撃条件・移動判断がどう異なるか**を説明できなければ意味がない。

### 3. 反事実テストで、地形とギミックが「必要か」を確かめる

**ラフの時点で、次の3つの問いを必ず行う。**

1. **ギミックをなくした場合：** 同じ攻略がほぼ成立するなら、そのギミックは飾り。使う位置・タイミング・状態によって利益が変わる設計へ戻す。
2. **主要な地形を取り除く・平坦にする場合：** プレイヤーの主な判断が変わらないなら、その地形は攻略装置になっていない。遮蔽・移動・射角を変える構造に見直す。
3. **プレイヤーを前後に動かすだけの場合：** 攻撃距離が変わるだけで、角度・遮蔽・敵への見通し・既存ギミックの作用・危険／行動の選択が実質同じなら、別攻略とは呼ばない。

**この3つに説明できる回答がない案は、どれだけ美しい図や数値チェックがあっても方向性レビューに出さず作り直す。** ただし毎面全ギミックを使わせる必要はない。不要なら削る。

### 4. 一つの仕掛けが、二つ以上の異なる選択を生むようにする

主攻略と別解は、たとえば**遮蔽を残して曲射する／破壊して直射角を得る**、**橋の姿勢を待つ／別の島に転移して橋を迂回する**、**磁場を使う角度に回る／端子操作で偏向方向を変える**など、操作と得失の内容に違いが必要。

**単に「近い・遠い」「高い・低い」だけでは不足。** 実際の地形や既存ギミックによって**攻撃対象、射撃の方向、障害の扱い、反撃される位置、行動の順序**など、意味のある判断が変わることを目指す。複数解を無理に増やすのではなく、まず主題となる選択を明確にする。

2案のラフも、**同じ攻略の外形違い**では認めない。たとえばAが「奥へ進んで磁場から撃つ」、Bが「奥へ転移して磁場を避けて撃つ」でも、結局は敵との距離しか変わらないなら、2つのゲームデザイン案とはいえない。

### 5. 地形・オブジェクトを「攻略目的から」設計する

攻略上必要な**通路、射撃余白、着地候補、遮蔽、島の役割、ギミック領域、敵の配置**が決まってから、地盤の曲線や岩・屋根・梁の形を作る。

- 長大な平地・横並びの同形島・同高さの棚・連続する大屋根や箱型部品を安易に繰り返さない。ただし平地・屋根・橋でも、機能と世界観に必然性があれば使ってよい。
- 岩や洞窟は自然な厚み・断層・崖肩・開口を、人工物は用途に合う支持と接続を持たせる。
- **入口→内部→出口**と**射撃元→ギミック／開口→敵方向**の空間が、描いた形状によって明らかに閉塞されないようにする。
- 「想定の通路を塞いだから小窓を増やす」「射線が邪魔だから地面を盛る」という局所改修を重ねず、主構造を見直す。
- 他の承認済み面と**見た目だけでなく、プレイヤーが最初に考える判断**を変える。

### 6. 詳細作図する前に「攻略の構造」をレビューする

**最初の提出は、完成マップではなく、以下だけでよい。**

| 提出内容 | 要求 |
|---|---|
| **1文の攻略上の発見** | 「何に気づくと、何が有利になるか」が具体的 |
| **異なる2つの構想ラフ** | 地形だけでなく、判断・ギミックとの因果が異なる |
| **主攻略と別解の簡単な流れ** | 出発位置→行動→地形／ギミック→得られる利益と代償 |
| **反事実チェック** | ギミック・地形・前後移動のみの各比較で、何が変わるか |
| **最低限の空間チェック** | 主経路・必要な開口・ギミックへの射線が**明白に**塞がっていない |
| **実装済み仕様の根拠** | 採用する地形部品やギミックが実ゲームで利用可能 |

**これが通るまで詳細なポリゴン座標や複数版の修正図を作らない。** 逆に、企画審査で全射角探索・全キャラ・敵AI・複数seedの実戦試験を要求しない。まず**構想レベルの因果・地形の空間**を検討する。その後の軽量な静的チェックで全景・自己交差・初期位置・通路を確認し、**全49面の設計承認後に総合動作検証**を実施する。

## 今回の76面のA・B案を、この基準で評価する

**[76面の方向性ラフ2案／PR #88](https://github.com/bittrove88/bittrove88.github.io/pull/88)は方向性未承認。**

| 案 | 今回の指摘 | 不足している設計の核心 |
|---|---|---|
| **A：曲面試射路** | 磁場の周辺を大きな曲面ブロックが塞ぎ、磁場が攻略に関わる空間として読み取れない | 「磁場内へ移れば何が可能か」「Tの極性切替で何の射線が変わるか」を、固定地形の**外側を通る有効な発射経路**と結び付けて示せていない |
| **B：背中合わせの制御棟** | 後ろでTを撃つか前進するかの違いだけで、結果は遠距離／近距離の射撃に見える | 背中側のTを操作する必然性、Mを使う／避けることによる攻防の実質的な違い、制御棟だからこそ必要な位置選択が不明確 |

**この2案は静的な形状確認を通過しても、攻略の因果が説明できていないため現状では採用しない。** 実際の弾道が絶対に成立しないと断言するものではなく、**方向性の根拠が不足している**という設計レビューの判断。

76面は**既存M（初期極性−1）とT（既存の極性反転）**を使うステージ。これらが攻略の主役なら、**Tを使う前後／Mを通す前後に、地形によって有効となる射線や安全な位置が実際に異なる見込み**を構想する。**Mを覆う部品を置いて「磁場を使う」とは説明しない**。壁や制御台の形を変えて再提出するのではなく、まず「プレイヤーが何を判断するのか」と、M・Tの使う意味がある別骨格のラフを再作成する。具体座標と地形の発想は構築担当に委ねる。

**75面A v4はユーザー承認済みであり、これまでの7面の承認を保護する。76面の設計承認を得るまで78面へ進まない。**

## 担当範囲と設計承認の条件

**構築担当：** 攻略設計、異なるラフ2案、地形・部品・座標・既存ギミック・敵味方の配置、簡易表示と静的検査を主体的に行う。**レビュー担当：** 地形と攻略の因果、独創性、既存レビューの反映、造形品質を判断する。**ユーザー：** 方向性・1面ごとの設計を承認する。

**方向性段階で差し戻す条件：** ギミックを消しても同じ攻略／地形を消しても同じ攻略／単に近距離と遠距離の違い／明白な固定障害でギミック経路が遮られる／形が違うだけの2ラフ／未実装機構が必要／他面と同じ判断を繰り返す。

**一番大事なのは、地形を先に作ることではなく、プレイヤーの判断を変える攻略の仕組みを先に作ること。**
