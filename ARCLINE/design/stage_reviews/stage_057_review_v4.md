# STAGE 057「氷壁の反射窓」v4｜1面ずつの修正レビュー

**対象：** PR #74 の `stage_057_proposal_v3.json`（コミット `9a58a777`）  
**レビュー用改訂：** `stage_057_proposal_v4.json` / `design/arcline-stage-057-v4-review`  
**位置づけ：** v4は座標まで反映した**ユーザー確認用の設計案**。PR #74の既存ファイル、ゲームランタイム、監査JSONは未変更。最終承認ではない。

## なぜ修正するか

57面の面白さは「巨大な垂直氷壁の上から洞窟内の敵へ、下段反射と洞口への転移という2つの方法で攻撃する」こと。しかし旧形状では、左の高地がx34付近まで水平で、その直後にx40 h70→x41 h28とほぼ垂直に落ちる。上から撃ち下ろす際、崖の肩が視線や弾道を遮り、射点を変える意味が弱い。

**このステージの判断を**「上段で崖肩まで歩いて反射弾を通すか、洞口へ転移して低弾道に切り替えるか」にする。障害物を増やすのではなく、氷壁上端を削って**移動すると攻撃可能な射線が生まれる**ことを優先した。

ゲーム用設計数値は1単位＝10px。

## 移動で射線が変わることの幾何チェック

ここでは実ゲームの銃口ではなく、**説明用の仮想発射点を支持面より5単位上**に置き、窓中央の観測点 `(65,28)` へ直線を引いて地面との交差を数値検証した。

- **初期P0：** 仮想点 `(14,81)` から窓中央を結ぶ線は、斜面との交差があり**遮られる**。
- **崖肩A：** 仮想点 `(26,81)` から同点への線は、**地面に遮られない**。
- **徒歩距離：** `(14,76)→(26,76)` は120pxで、通常移動上限140px／行動の目安に収まる。
- **重要：** これは「床形状による見通しの差」のみを示す。**破壊窓D02は残っているため、弾は無条件に敵へ届かない。** D02を開いた後に反射弾が通るか、銃身・砲弾が現実の当たり判定を回避するか、窓から敵まで弾が届くかは実エンジンの再試射が必要。

これまでのv3に収録されていた `angleReview`、`shotExamples`、`replayViews` は**旧地形固有の証跡であり流用禁止**。v4では空にして再検証待ちとした。
\n**補足の交差確認：** 旧版v3の実射撃ログには、P0(24,76)から角度0°で撃った直後の弾道点(27.5,78.6)が記録されている。この相対差(＋3.5,＋2.6)を新旧P0とAへ仮に適用して再計算しても、仮想線は**P0からは床に遮られ、Aからは床に遮られない**。ただし銃口位置は射角に応じて変化するため、これは参考照合であり実エンジンの命中証明ではない。\n
## 攻略ルート設計

### 主攻略：高所の崖肩→反射床→窓→敵

1. 初期P0の岩陰から右へ約120px歩き、崖肩Aへ立つ。
2. 崖の上部が斜めに削られたため、発射側と下段の窓・反射面を見通す空間が増える。
3. D02の破壊単位を必要な分だけ開き、反射面Wへ弾を送って洞内の敵に当てる。
4. 高所を保てるが、反射角と風の影響を読む必要がある。

**受入れ条件：** P0とAを同じ破壊状態・同じ敵位置で比較し、A側で有効角度幅または弾道の再現性が明確に改善すること。床との幾何関係が改善しただけでは、通常弾道は合格にしない。

### 別解：洞口Bへの転移→低い弾道で洞内へ

1. 初期P0から洞口Bにテレポートする。
2. D02を壊す（必要な独立破壊単位を確認）。
3. 入口Bから洞内へ低い弾道を通す。反射の角度合わせを省く代わりに、敵に近く反撃のリスクが増す。

**受入れ条件：** 新P0からの実際のテレポート入力でBに安全着地でき、窓を開けて敵へ届くこと。初期位置が変わったため、旧テレポート角度・出力のコピーを合格扱いしない。

## 特に守ること

- 上段を単なる広場にせず、**崖肩へ進むと射線が変わる**こと。
- F01の洞窟天井を消して直射が常に容易になる設計にしない。
- D02の2独立破壊単位 `057-LOW-WINDOW@0/@1` の境界と、残存片の当たり判定を図示する。
- W反射ルートと洞口転移ルートが両方実際に成立すること。
- 16行動、敵HP・敵プロフィール、既存アイテムとボスではない性質を保持する。
- 敵の徒歩移動（40面以降）を確認する。**57面は71面未満なので敵の自律テレポート対象ではない**。
- 位置を変えなくても同じ攻撃が容易に成立する場合は、再び崖肩の射角と遮蔽条件を見直す。

## 実装担当へ渡す再検証項目

1. **静的形状：** floorポリラインの単調x、全支持面の整合、斜面からの落下と移動可否、他の部品との重なり。
2. **実移動：** P0からAへ120px歩行し、車体・砲身・地形の衝突がないか。
3. **実転移：** 新P0からBへのテレポート軌道と着地。行動消費と位置補正。
4. **破壊単位：** D02の2部品を個別に壊し、隣接固定部品F01が消えないか。前後の開口を記録。
5. **主・別解試射：** 破壊前後、P0・A・Bそれぞれの射撃許容角度を複数パワーで測り、W反射イベントと実ダメージを記録。
6. **戦闘：** 敵が徒歩移動・反撃する条件で複数シードを確認し、16行動以内の達成可能性を測る。
7. **比較画面：** v3/v4を同縮尺で並べ、崖肩の切削量、破壊単位、移動矢印、射線の変化を確認する。
8. **アイテム：** x47/h29の既存アイテムが削った氷壁に埋まらず、取得可能か。
