**参照：** `stage_059_proposal_v3.json`。

## 変更結果

F04が大きく、中央の高所へ移ったプレイヤーが実際に敵を狙う方向を確保しづらかったため、**F04自身を縮めて右側のF03反射棚との間に隙間を作りました**。中央アーチの下側を移動できるという59面v3の主コンセプトは維持しています。

| 項目 | v3 | v4 | 差 |
|---|---|---|---|
| F04の横幅 | x59〜85＝260px | **x60〜74＝140px** | **約46%縮小** |
| F04の上下幅 | h43〜78＝350px | **h54〜74＝200px** | **約43%縮小** |
| F03との横方向関係 | x82〜85で30px重なり | **x74〜82に80pxの隙間** | 射角を作る空間が増える |
| F04の最上面 | 形が先細りして傾斜 | **x63〜70、h74に70pxの水平な肩** | 着地・照準候補の足場 |
| 下側通路 | 連続して通れる設計 | **維持・上方空間は拡大** | 谷底の回り込みを保護 |
| 味方・敵の開始位置 | P0(44,21.5)、敵(106,65) | 変更なし | 既存の進路選択を保護 |
| F01・F02・F03・F05・F06／風F・鏡W | v3の位置 | **すべて不変** | F04以外を無用に変えない |

### F04の新しいポリゴン

設計数値は1単位＝10px。

```json
{
  "id": "059-CENTRAL-SPIRE",
  "kind": "roof",
  "breakable": false,
  "poly": [
    [60,70],[63,74],[70,74],[72,70],[74,65],
    [74,55],[70,54],[66,58],[62,64],[60,68]
  ]

```

F04は固定の氷アーチ上部で、**破壊可能には変更していません**。小さくして自然の横穴・射撃空間を形成する設計です。

## 攻略上の意味

- **主攻略（谷底の抜け道）**：F04下側の通路を歩いて敵側へ回る。F04縮小後も成立するように、通路の連続性を維持。
- **別解（高所の風見棚A）**：F05（x51,h79）の高所へ登り、風を読む。従来よりF04との位置が離れるため照準空間が広い。
- **新射点D（F04の肩）**：F04の新上面 x63〜70、h74に、候補射点 `(67,74)` を設定。ここに着地できれば、固定の敵に向かう直線の途中にF04自身が入らない。F05より東に近い位置で敵を狙う選択肢になる。
- **鏡ルートC**：F03上の反射Wと右風域Fを使う。F04とF03との間の80pxの自然な空間を利用する。反射が有効な実弾道かは別途検証する。

## F04縮小の静的検査

`stage_059_proposal_v3.json` とv4の全部品ポリゴンに対し、直線交差・横方向の空隙・下側通路の断面を比較。

| 幾何学的な仮想線 | v3 | v4 |
|---|---|---|
| F04新上面の候補射点Dの砲口相当(67,78)→敵近傍(106,69) | F04と交差 | **固定部品と交差しない** |
| F04右側の空中点(79,52)→敵近傍(106,69) | F04と交差 | **固定部品と交差しない** |
| P0(44,25.5)→敵近傍(106,69) | F04と敵棚F01で遮断 | **敵棚F01では引き続き遮断** |
| 高所A(51,83)→敵近傍(106,69) | 固定部品と交差なし | 交差なし、現状維持 |
| 中央から右へ進む下道（x44〜137） | 最小断面約94px | **最小断面約94pxのまま維持** |

**注意：** 仮想線は重力・風・車体・砲身の衝突判定を含まない。F04右側の空中点は着地できる射点ではなく、**空間が開いたかどうかを見るための観測点**。候補射点Dも上面幅70pxが実車体に十分か、テレポートで着地できるかは要検証です。

また、v3のD位置は当時のF04ポリゴン内に含まれるため、射線の交差結果だけで「旧版で実射撃が不可能だった」とは断定しません。今回確定できるのは、F04の縮小で幾何学上の空間が増えたことです。

## 実装担当への再検証指示

1. D(67,74)へテレポートできるか。F04上面の70px幅で車体が接地し、砲身を上下できるか。必要ならF04自体をさらに小さくするのではなく、上面の傾斜と着地幅を調整する。
2. F04頂部DからW01で敵を狙える角度範囲を、複数の出力値で確認。極端な一点命中しかない場合はF04右端の輪郭を再調整。
3. F04とF03の80pxの隙間を含め、弾の初期上昇空間と鏡W経路の反射が実際に成立するか測定。
4. 主攻略の下道について、F04・F03・F01・F02の下を車体が通過できること、敵の右側への転移と反撃込みのクリアが成立することを確認。
5. v3で既に未検証だった反射＋風の複合命中を、v4の地形で再検証する。
6. 同じ敵HP、16行動上限、既存の風F・鏡W・敵徒歩を維持する。承認済み57・58面には変更を加えない。

v3の `shotExamples`、`replayViews`、`angleReview` はv4の合格根拠に転用しない。v4の検証証跡が取れた時点でのみ再作成する。
