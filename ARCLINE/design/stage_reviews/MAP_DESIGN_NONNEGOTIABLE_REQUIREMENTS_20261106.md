# ARCLINE 51〜99面｜マップ改訂の必達事項

**策定：2026-11-06。実装担当が必ず守るマップ設計の品質基準。**
**参照：** [PR #74の最新マップ案・個別レビュー](PR74_IN_PROGRESS_STAGE_SOURCE_INDEX_20261106.md) ／ [各面の改修判定](STAGE_051_099_REDESIGN_BRIEFS_20261105.md) ／ [制作工程](IMPLEMENTER_MAP_REDESIGN_PLAYBOOK_20261105.md)。

**到達目標：外形が少しずつ違う49枚ではなく、地形の読み方と攻略の選択が異なる49面を作ること。** 造形品質とゲームプレイの意図を一体で設計する。

## 進行中の追加必達事項：同じ「屋根＋上下二択」パターンから脱却する

[65〜72面の承認・構造重複監査](STAGE_065_072_APPROVAL_AND_DIVERSITY_AUDIT_20261106.md)で、既承認65・66・67・69・71面の造形・攻略と、**72面v2の否決原因**を確認する。72面は大きな屋根／アーチの形が既存面に似ており、入口と敵への射撃方向も塞がると指摘された。

**設計初稿を描く前に既承認面と5軸（地形骨格・移動判断・遮蔽／射線・ギミックの因果・攻防の得失）で比較する。** **「上は露出するが短く撃てる／下は守られるが反射等が複雑」だけを繰り返してはいけない。** 直近承認面から少なくとも3軸に質的な差を作り、特に地形骨格と移動判断が両方同じなら作り直す。小さい輪郭の変更・屋根の長さ・ギミックの種類変更を独自性とは数えない。

**屋根・庇・岩アーチが主障害になる案は増やし過ぎない。** 屋根を使う場合は上面足場・下を通る・壊して変化する等の新しい使い方を説明し、同じ主攻略の形なら別骨格にする。入口→内部→出口の空間、敵方向へ砲身を向ける余白を見た目と座標で確認。**断面の空隙1か所だけで閉塞の疑義を払拭しない。**

承認済みの65・66・67・69・71面は**設計品質上の保護対象**であり、類似が出たからという理由で無断変更しない。**72面v2は未承認・スキップ保留**。次は75面から進める。

## A. 全面に共通する最重要基準

1. **1マップ1コンセプト。** その面特有の地形、固有の攻略上の問い、主攻略と別解を説明できること。面番号を入れ替えても同じ説明で通用する案は不合格。
2. **長大な平地、地続きの単調な床、同高さの同形島の量産を拒否。** 長い直線地盤に複数の六角形・台形の足場を並べるだけでは独創的なマップにならない。起伏、坂、谷、断崖、庇、屋根、洞窟、縦穴、浮島、橋などで攻略上の空間を構成する。ただし平地や地続き自体を禁止しない。歩行で射線・遮蔽が変わる、滑走路として意味があるなど、**平面である合理的な理由**がある場合は有効。
3. **毎面、異なる立体的な地形の骨格を持つ。** 上から越す、下を潜る、裏へ回る、坂を降りる、吊り橋を渡る、反射面の前へ出るなど、場所の読み方を変える。単に全ての島の高さを上げ下げするだけでは不十分。
4. **ギミックは飾りではなく攻略を変える要因。** 風、反射、橋、磁場、噴出、雲、結晶、端子、上昇気流などは「何の経路、射角、危険度、遮蔽を変えるか」を説明できること。不要な種類を増やさない。
5. **地形、オブジェクト、初期位置、敵位置を同時に設計する。** 通路、砲口の方向、狙える相手、破壊後の地形が連動するように作る。最後にパーツを置いて終わりにしない。
6. **主攻略と別解は本当に違う判断になること。** 上ルートは速く危険、下ルートは安全だが遠い、破壊すると射線が開くが足場を失う、反射は難しいが裏へ届く、など明確な利点と負担が必要。名称だけの二経路は不合格。
7. **開始位置から撃つだけで攻略が完結しない価値を作る。** 初期地点が万能だと移動やギミックが死ぬ。場所を変えることに、遮蔽・射角・対象部位・危険度・戦術切替の理由を持たせる。
8. **ひと目で自然で、合理的に接続していること。** 岩や根には不規則な厚み・崖肩・浸食、人工梁・装甲・クレーンには構造上の必然性を持たせる。意味不明な浮遊部品、めり込み、ぎざぎざの装飾だけの曲線を残さない。

## B. 地形・オブジェクト形状の具体的必達事項

| 番号 | 必達事項 | 不合格例 |
|---|---|---|
| G01 | シルエットで他面と区別できる「地形の骨格」を設計する | 平地に同じ六角島を位置だけ変えて配置 |
| G02 | 傾斜、崖肩、くぼみ、谷の深さ、庇の下面を射撃・遮蔽・移動に関連させる | 凹凸を追加したが攻略は変わらない |
| G03 | 空中の足場ごとに幅、厚み、形、着地条件、射線、遮蔽方向を変える | 同じ高さ・同じ厚みの島が横一列 |
| G04 | 屋根、洞窟、縦穴、横穴、天窓は開口と下を通る空間も設計する | 各階の前面が塞がり、同じ破壊の反復しかない |
| G05 | 上下の多層空間、坂道や地続きの歩行路、浮島の転移経路をテーマに合わせて使い分ける | 高低差があっても全射点から同じ方向に撃つ |
| G06 | 自然岩・氷・根と、人工梁・橋・基地・船体の形状論理を区別する | 岩が箱の集合、人工物が意味のない曲線 |
| G07 | 固定地形と破壊片、移動橋の支持部、オブジェクトIDを見た目とデータの両方で区別する | 破壊後に固定の支持体も消える設計 |
| G08 | 主経路に必要な隙間、砲身を向ける空間、意味のある支持面を描く | 射点と呼ぶ場所が屋根・F04などに囲まれ見通せない |
| G09 | 崖、谷、孤島、洞、庇などの形状を組み合わせるが、闇雲に全種類を積まない | 複雑にしただけで攻略の主題が消える |
| G10 | 完成図は全域を表示でき、地形・部品が切れず不自然な重なりがない | 外部SVGだけ整え、データ上はめり込む |

**特に57〜59面で学んだこと：** 57は上の崖肩が砲口方向を塞がないこと。58は3層洞の各階に自然な開口があり、毎回の破壊を通行の絶対条件にしないこと。59はF04下の移動空間と、F04側から敵を狙う隙間の双方が必要。2026-11-05の試作座標と比較SVGは品質問題のため転用せず、**改善目的だけを継承する**。

## C. 攻略と移動の具体的必達事項

| 番号 | 必達事項 | 不合格例 |
|---|---|---|
| P01 | この面でプレイヤーが発見する「地形の使い方」を1文で定義 | 「島＋風で多彩に遊べる」だけ |
| P02 | 徒歩、落下、段差、テレポートに異なる役割を与える | 使わなくてよい足場を増やしただけ |
| P03 | 高所と低所、表と裏、内側と外側などに、射撃位置と敵からの遮蔽の得失をつくる | どこからでも同じ向き・同じ射角で攻撃 |
| P04 | 初期P0と移動先の違いを説明する | P0から安全に全部位を撃て、移動は不利 |
| P05 | 敵・ボスの支持面、遮蔽、部位配置を地形と一緒に考える | 敵を右端の島頂部に置くだけ |
| P06 | 設計上、移動・反射・射撃を想定した空間が明白な行き止まりにならない | 通路が固定屋根で塞がれている |
| P07 | 一度の失敗で再挑戦不能となる細い穴や片道射点の乱用を避ける | 1度だけ狙える角度が実質唯一の攻略 |
| P08 | 同一の攻略型を近接面で繰り返さず、最近4〜5面と戦術の違いを示す | どの面も「転移して高所から撃つ」 |

## D. ギミック・破壊・重量感の具体的必達事項

1. **浮島＋ギミック：** 高度や島の向きを変える理由をつくる。高所からは風を通し、低所は結晶や反射を使うなど、異なる弾道・安全性を持たせる。
2. **屋根＋洞窟：** 上は足場、下は遮蔽や移動空間、開口は射撃ルートという複数の役割を検討する。「屋根をすべて壊さないと進めない」以外の可能性を残す。
3. **坂＋反射：** 坂や崖肩の向きが入射角を変え、反射する方が有利な状況をつくる。反射面を置いても弾がそこへ届かないのでは意味がない。
4. **破壊＋足場／遮蔽：** 壊すとショートカットや射線が開くが、足場・防御が失われるなど、壊す前後の選択を考える。破壊順序が固有のパズルなら必須破壊も可。
5. **橋＋谷／磁場：** 橋の開閉が移動、敵からの射線、発射位置のいずれかを変えるようにする。橋の有無が攻略に関わらないなら再配置。
6. **噴出・風・雲＋地形：** 噴出周期や風域が安全地帯、撃ち上げのタイミング、回り込みの利点を変える配置にする。
7. **重量・重力・落下の概念：** 重厚な岩盤、クレーン、下方への落下や地形の圧迫感など、**既存エンジンの仕組みで実現できる**形から考える。未実装の重量計算・新物理ギミックを勝手に前提にしない。
8. **反射＋雲＋磁場などの複合：** 本当に組み合わせて攻略する意味がある面のみ採用。「毎面必ず複数のギミックを使う」は禁止。使わないギミックの方が多い案は見直す。

## E. 作品全体の一貫性と新規制作の扱い

- **PR #74の途中案を必ず読む。** [最新JSONと個別レビュー一覧](PR74_IN_PROGRESS_STAGE_SOURCE_INDEX_20261106.md)から、残すべき既存の狙いを特定する。旧レビューを無視して白紙から別ゲームの面を作らない。
- **R（全面再設計）14面は優先着手。** 65 → 66 → 67 → 69 → 71 → 72 → 75 → 76 → 78 → 79 → 81 → 82 → 87 → 89。これらは旧ポリゴンの位置調整だけで済ませず、攻略の問いから地形の骨格を再設計する。ただし旧案の有用な要素は継承してよい。
- **S（大幅改修）22面は良い核を残す。K（保持）11面とK/S2面は独自性を壊さず改修。** 種類による例外なく、形状と攻略意図の品質は同じ基準で判断する。
- **世界観の違いを活用。** 氷山、火口、鉱床、洞、樹根、空母、要塞などは、色・背景だけではなく地形の構造と考えるべき戦術が異なるよう設計する。
- **ゲームルールは勝手に変更しない。** 自機・敵能力、ボスの部位、行動上限、既存物理、1〜50面・100面などは保護。新物理が必要なら別途提案。

## F. 設計段階の軽量受入れゲート（本書の必達をどう判断するか）

次の8項目に**明確な設計上の欠陥がない**ことだけを、各面制作時に確認する。

1. ステージ固有の攻略の問いを1文で説明できる。
2. シルエット・空間構成と攻略の役割が他面と明確に違う。
3. 平地・同形島・同じ高さ・単純な地続きの意味のない連続がない。
4. 主攻略と別解に異なる利点・負担がある。
5. 移動・破壊・ギミックの設置意図が図面で説明できる。
6. 全景と主要部品が正しく描画され、通路と射線が形状上**明白に**塞がっていない。
7. PR #74の最新案と追加レビューの指摘を引き継いでいる。
8. データ読み込み、基本形状、明白なめり込み、部品ID整合に重大な破綻がない。

**設計時の提出は**全景1枚、PR案と同縮尺の比較1枚、主攻略／別解の簡潔な図示、継承／再設計の理由、静的チェック結果のみ。Rは別骨格ラフ2案を比較するが2案とも実装する必要はない。

**制作中は各面の動作検証を最小限にする。** 実際の歩行・転移着地、弾道・命中幅、反射や風の実イベント、AI・反撃、行動上限内のクリア、複数seedは**全49面の設計承認後にまとめて総合検証**。図面で想定した経路を「通れる／命中する」と証明済みのように表記しない。

**担当：** 地形・オブジェクト・座標・描画・簡易検査は実装担当が裁量を持って作る。レビュー担当はゲームデザインの違いと本書の必達条件を判定する。1面の設計承認後に次の面へ進む。

**結論：地形・位置・装置・経路が一体になり、攻略の考え方が異なる49面にする。**
