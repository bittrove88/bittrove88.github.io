# 横断した差別化の確認

制作中の個別全景と、31面をまとめた輪郭一覧・承認済み18面の輪郭を照合した。共通ギミックがあることだけで別の攻略体験とは数えず、地形の通す側、入射方向、開ける物、部位、残す遮蔽を比較した。未測定の類似度点数や「全攻略が完全に異なる」という保証は付けない。

| 比較した系統 | 今回分けた判断・形状 |
|---|---|
| 51・承認済み62/69 | 51は短い徒歩と風域の端。62は逆勾配と庇入口、69は島のくぼみと肩での攻防。51の敵前稜線を他面の共通部品にはしていない |
| 52・61・63・91 | 52は一片の横穴と縦穴、61は門前の中継、63は二枚の破壊順、91は反対側の二門から一方だけを選ぶ。隔壁の数を増やす発展列にはしていない |
| 53・97 | 53は低棚のK入口とF上端、97は中央高所からU低島・逆向きK・Fと窓を選ぶ。97の低島は左地盤に埋まらない位置へ移した |
| 54・99 | 54の既存二峰は風の山越えと谷のW。99は三種類の独立足場から通常弧・W/C/M・逆向き射撃を選ぶ。自然二峰という形状の共通点はあるが、転移先を選ぶ判断が99の主題 |
| 56・承認済み79/87・98 | 56は長い固定氷橋と一本の下橋、79は接続橋とT/Mへの準備、87は荷役板を遮蔽として使う。98は二本の逆位相で別々の空間が閉じる九島群 |
| 57・64 | 57は崖肩から落としてWへ入れる反射洞。64は反射を使わず盆地の右裏へ回る。縦崖だから同じ落射にしない |
| 68・70 | 68は常設横穴と任意の反射蓋。70は既存の二腕とV内外の出口。熱・噴出という題材だけで同じ三段炉にしない |
| 73・77・承認済み76/78・80・96 | 73は同じMへの二方向の入口、77はT/MとWを別経路へ分離、76は磁場の退出側、78は内壁の内外、80は同高さの発生器の左右と極性、96は開けた西門の内周と開放環頂からの外周。77はこの横断確認で再制作・再描画した |
| 74・86・承認済み59/82 | 74は鉱床の下面と上面、86は下甲板の反射湾とU棚、59は同じ氷稜の上と下道、82は固定根を残す床鏡と開いた磁場台。反射を使う低所という共通点はあるが、通す物とギミックの役割を分けた |
| 84・85・承認済み81 | 84は環の中央Mと外側K、85は支持根を壊さず根先から既存給水部位へ、81は割れた根輪の内外。84の島の下面も描画後に描き分けた |
| 55・60/70/80/90/95 | 55は既存一センサー、60は送風機の破壊状態、70は二腕とV、80は二発生器とM、90は浮遊艦の主砲・二推進器と三方向、95は一つのドライブと同座標の露出核。架空の部位や高さは足していない |
| 92・97 | 92は中央下から左Mへ折り返すか右の断崖寄りFへ進む。97は中央高所から三種類の既存機構へ向かう。三つの同形棚を高さ順に巡る構成を避けた |
| 94・承認済み72/89 | 94は湾曲滑走路を挟みC経路とW/M経路で射撃方向を反転。72は露天断層、89は船底から反対向きに撃つ装甲切欠き。94の外板は右一片だけを開く構想 |
| 93・98・99 | 93は狭い上下全面反射室、98は多数島と橋二姿勢、99は屋外二峰と転移先の選択。三面の専用企画を相互流用していない |

地形の役割が分かれていても、実入力後に一つの射点だけが常に支配的になるか、反撃や準備手数に意味のある差が残るかは動作未検証。全49面の設計承認後の総合検証で確かめ、結果に応じて必要な面だけ改善する。
