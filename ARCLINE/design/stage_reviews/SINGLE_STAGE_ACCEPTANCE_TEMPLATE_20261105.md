## 3. 画像と最小限の品質確認

**提出する画像はこれだけでよい：**
- [ ] **新マップの全景1枚**：実エンジンと同じ表示規則、または忠実なマップビューア。全オブジェクト・ギミック・自機・敵が見えること
- [ ] **PR #74の制作途中案との比較1枚**：同縮尺で旧／新。何を継承し、どこを作り替えたかが分かること
- [ ] **必要な箇所の拡大1〜2枚**：複雑な洞口、重なり、特徴的なギミックがある場合だけ
- [ ] **R面の骨格ラフ**：2案を短く示す（メモや簡易図で可）

**制作時に必ず確認する最低限の項目（PASS／要修正）：**

| 検査項目 | 判定／補足 |
|---|---|
| 設計データを読み込める／基本スキーマが破綻していない | |
| マップ全体が表示範囲に収まり、切れ・表示崩れ・めり込みがない | |
| 地盤・島・天井・固定パーツの形状が自然・合理的で、同形の使い回しが目立たない | |
| プレイヤー／敵の開始位置に**明白な**埋没・宙浮きがない | |
| 主・別解の**入口→内部→出口**が図形上つながり、敵を狙う方向に余白がある（代表断面値だけに依存しない） | |
| オブジェクト・独立破壊片のIDや座標定義が大きく矛盾していない | |
| ギミックの配置意図が説明できる | |
| PRの過去レビューで指摘された重大な形状問題を繰り返していない | |
