# ARCLINE — プレイヤー視点の100面レビューと改訂設計 v1.1

2026年10月22日。対象：レベル1〜100詳細設計v1.0。

**結論：地形・テーマ・収集の方向性は維持し、耐久と手数、学習の見せ方、再照準の負担、万能な迂回路、ボス部位ダメージを見直す。** 本書は次の実装に用いる改訂案。元のv1.0を履歴として残し、重なる規則は本書を優先する。ゲーム本体・公開サイトは変更していない。

## 1. シミュレーションの範囲と方法

実際の100面は未実装であり、今回行ったのは「プレイヤーの判断順序を仮定した机上ウォークスルー」「設計データの横断集計」「仮定した命中率とチャージ誤差に対する数理的な感度分析」。実機で100面を遊んだ結果やユーザーテストではない。以下の発言・感想は想定例で、観測済みの発言ではない。

各面を、①画面を見る→②移動先・武器・スキルを選ぶ→③一度外す→④修正する→⑤回収を欲張る→⑥敵が動く/環境が変わる→⑦スキルを失敗しても再挑戦する、の順で点検した。

| 仮想プレイヤー | 主に点検したこと |
|---|---|
| 初見のタッチプレイヤー | 説明なしで押す場所・作用が分かるか。二つの新要素を同時に覚えさせていないか。初回失敗後に修正できるか |
| 操作に慣れた攻略プレイヤー | 最善手が毎回「高台へBLINK」にならないか。ギミックを使うメリットがあるか。ボスが単なる長い削りにならないか |
| 収集を楽しむプレイヤー | 武器を狙う行動が制限ターンの罠にならないか。取得時に弾が消えないか。負けても獲得が残るか |
| 中断後に戻ったプレイヤー | 前回覚えたスキルを短いプレビューで思い出せるか。地形やスキルが変わっても同じUIで使えるか |

100面の個別レビューは後半に掲載。全て同じ点数を付けたり、想像上の満足度を定量化したりはしていない。

## 2. 横断点検で見つかった問題

### 2.1 BLINKと高台への迂回が多い

v1.0のデータを集計すると、BLINK支給は61/100面、最後の20面では15面。別ルートの文章に高台・高角度・高い弧が登場するのは42面、転送/BLINKが登場するのは29面（重複あり）。文章キーワードの件数であり、実際にそのルートが最善だと検証できたわけではない。しかし、似た成功体験へ収束する設計リスクは高い。

**改訂**：BLINKを減らすだけでなく、転送先の役割を変える。屋根を全部無視する高台より、反射板へ入りやすい低地、気流へ浅く入る側面、武器と敵を結べる中間台を使う。基本砲での救済経路は残すが、ギミックを使う経路は「広い成功帯」「回収との両立」「次の射撃姿勢」で明確に有利にする。

### 2.2 高速チャージと狭い許容幅が衝突する

20〜100%を0.72秒で走る場合、1ポイントは9ms。v1.0終盤の目標「±2ポイント」は±18msに相当する。60Hzでは約1フレームのずれで外れ得る。端末遅延や実際の入力処理は別途あるため、これは性能測定ではなく設計上の換算。

仮にリリース時刻の誤差を平均0・標準偏差60msの正規分布と置くと、±2ポイントの範囲内に入る確率は約23.6%、±6ポイントなら約63.2%。この分布は実測ではない。狭い窓と高速ゲージを重ねると、地形を理解してもタイミングだけで失敗する可能性を示している。

**改訂**：ユーザーが望む速い往復感は0.72秒を基準として維持する。通常面の最低一経路は±6ポイント、ボスの大きな本体は±6〜8ポイント程度の有効帯を初期目標にする。狭い任意の回収ショットや弱点は±4程度まで。実機で過度に厳しければ0.9秒との比較で調整する。レベルごとに速度を変えたり、黙って最適値へ吸着させたりはしない。

### 2.3 同じ操作の修正をさせる前に環境が変わる

風向き、反射板、雲、敵位置が一斉に変わると「少し弱くすれば当たったはず」が試せない。前回弾道を消すなら、なおさら学習の足場が必要。

**改訂**：新ギミック導入時は同状態を2プレイヤー行動分保持。習得後の面で1ラウンド周期を使う。大きな状態変化は一境界につき一つ。予告と実際の変化を対応させる。敵の小移動まで常に停止する必要はないが、初導入面では抑える。

### 2.4 ボスの部位を壊す攻略が長期化しやすい

旧案は部位ダメージの50%しか本体へ通らず、一般装甲65%、弱点150%。基本砲30で本体330を削るだけなら、一般装甲は17発、弱点は8発が目安（空振り・爆風・段階の影響を無視した単純計算）。部位を先に攻めるほど長引き、敵の強攻撃を受ける回数も増える。

**改訂**：ボスは全て本体10発相当、通常命中1、弱点2。部位命中も本体へ1を通し、部位破壊は追加で射線・予告の余裕・弱点の広さを改善する。部位と本体へ二重にダメージを加えない。装甲を理由に通常命中を0.65へ落とす仕組みは撤回。

### 2.5 収集と固定手数は衝突し得る

10ターン制で回収専用に2発使うと、敵への試行は8回になる。見た目が報酬でも、取ったために時間切れになると罠に感じやすい。

**改訂**：初武器・ボス補給は原則、敵へ通る弾道上に配置。難しいスキンの寄り道だけは明示的な選択として残す。取得はその時点で保存し、負けても保持。新武器は自動装備しない。討伐時に未回収物があってもクリアを妨げず、後から再挑戦できる。

## 3. 改訂する戦闘の基準

### 3.1 分かりやすい耐久・手数

| 項目 | 通常面 | ボス面 |
|---|---|---|
| 敵の耐久 | 基本砲の直撃3発相当 | 基本砲の通常命中10発相当 |
| プレイヤー耐久 | 5目盛り | 5目盛り |
| 制限 | プレイヤーの射撃10回 | プレイヤーの射撃18回 |
| 通常直撃 | 1目盛り | 1目盛り |
| 爆風のかすめ | 基本0.5目盛り | 基本0.5目盛り |
| 弱点 | 通常敵では原則なし | 2目盛り。部位で入口や幅が変わる |
| 被弾 | 敵の1行動合計で最大1目盛り | ボスの1攻撃シーケンス合計で最大1目盛り |

「3発相当」は武器が何でも必ず3回という意味ではない。Heavyは1.25、複数弾は合計1前後、特殊な押す弾は0.85〜1を目安に正規化する。標準命中3回で倒せる基準を明示し、図鑑の細かいDPS比較を要求しない。通常敵への一射撃上限は1.25、ボス弱点への一射撃上限2。多弾と弱点・部位による重複加算なし。

HPは3/10の太い区分で表示し、かすめは半区分、武器差は区分内の滑らかな減少で示す。プレイヤーは5つの耐久灯、一度の攻撃で複数消さない。敵攻撃の狭い直撃は1、外縁は0.5、回避は0。近くを通っただけで減らさない。

通常面は地形の読解と照準の修正を含めて10回、ボスは部位を試す余地を含めて18回。最終ボスも18回で統一し、3/3/4の段階へ分ける。段階を跨ぐ超過ダメージは保持、移行で残り手数を戻さない。特別に強い敵だけ隠れて耐久を増やさない。

旧案のE0〜E5のHP60〜110、ボスHP140〜330、各敵攻撃の最大12〜26といった旧HPスケールは本節で置き換える。敵行動・移動幅・部位構成は残す。部位は通常1〜2命中で破壊できるよう2目盛りを標準とし、初ボスの脚のみ1目盛りを初期案とする。

### 3.2 「ちょうど10ターン目にHP0」は採用しない

敵の命中を裏で操作して結末を合わせると、回避が成功しても意味がなくなる。逆に早く被弾した人を救うため途中の敵を不自然に外すと、敵の性質が読めなくなる。

耐久による敗北と手数切れを分離する。HPが0ならその時点で敗北。HPが残っていても10回/18回を使い切り、敵が残れば手数切れ。HUDには最初から残り射撃を見せ、残り3で外枠が暖色、最後の1回で短い英語「LAST SHOT」。敵の能力や命中補正は残りHPや残り手数に合わせて密かに変えない。

最後のプレイヤー射撃は、全弾・回収・弱点命中を解決してから勝敗を判定する。倒せたら勝利、残っていたら手数切れ。最後に見えないダメージを与えてHP0へ偽装しない。敵の追加攻撃を挟んで敗因を曖昧にしない。

Lv1〜3も手数表示は統一する。失敗したら同じ面で即再挑戦、取得済み外観/武器は保持。序盤の敵精度は低くし、3発の基準を隠れて変える救済は使わない。

### 3.3 スキル、移動と手数の関係

移動・照準・装備切替・プレビュー・キャンセルは手数を消費しない。BLINKはスキル回数だけ消費し、そのターンの射撃は残る。攻撃スキルは発射に付随する。回収専用の射撃も1回使う。飛翔中に追加射撃やスキル操作はできない。

敵の攻撃を待つだけのスキップは基本UIに置かない。どのギミック状態でも現在の通常弾か支給スキルに有効な射撃経路を残し、閉じた橋が開くまで空振りする面にしない。

## 4. 手数モデルの感度分析

これは命中確率が毎射撃独立・一定という仮定での二項計算。学習・移動・弱点・プレイヤー被弾・子弾・かすめを含まず、実際のクリア率ではない。

| 仮定 | 1射撃の命中確率35% | 55% | 65% | 75% |
|---|---:|---:|---:|---:|
| 通常3命中を10回で達成 | 73.8% | 97.3% | 99.5% | 約100% |
| 回収に2回使い、通常3命中を8回で達成 | 57.2% | 91.2% | 97.5% | 99.6% |
| ボス通常10命中を18回で達成 | 6.0% | 57.8% | 86.1% | 98.1% |
| 回収に2回使い、ボス通常10命中を16回で達成 | 2.3% | 36.6% | 68.8% | 92.0% |

通常3/10は試行錯誤の余裕を持ちやすい。一方、ボス10/18を通常命中だけで要求すると初見に厳しい。そのため、弱点2相当・大きいボス判定・部位ダメージの全量反映・敵と同時に回収できる補給をセットにする。単に18回に伸ばしただけでは解決しない。

初ボスは5〜7回の有効命中、後半ボスも6〜10回の有効命中で攻略できる構造を目標にする。これは弱点への命中を含む目標で、実測値ではない。手数内クリア率は実機で測り、悪ければHPを増減する前に成功帯と弱点の視認性を直す。

## 5. 説明文に頼らない初出プレビュー

### 共通の見せ方

最初の出現時だけ、現地に重ねた半透明の見本を0.9〜1.5秒程度見せる。ボタンを押して説明を閉じるモーダルにはしない。タッチで即中断でき、再挑戦時は自動再生しない。実弾ではなく見本であることを、白い輪郭と半透明の機体で統一する。

プレビュー中は手数・敵行動・環境周期を進めず、スキルも消費しない。実際の配置と同じ物理条件で作用を示すが、敵までの正解射線は全部描かない。スキル/ギミックのアイコン長押しで短い見本を再表示できる。新ギミック・新スキル・新武器の自動プレビューは一度に最大一つ。

| 対象 | 初出で見せる動作 |
|---|---|
| 浮遊アイテム | 弾がカプセルを通過→カプセルだけ装備枠へ飛ぶ→弾はそのまま進む |
| BLINK | スキル枠が光る→候補に車体の仮姿→元の位置から移る。敵や手数は動かさない |
| PUSH/PULL | 弾の着弾点→敵の半透明像が押される/引かれる。矢印で方向を示す |
| PHASE | 一枚の薄い壁を通る弾→元の色へ戻る。厚すぎる壁では遮断輪郭 |
| BOUNCE/SPLIT/BURST | 一度跳ねる/頂点で分かれる/着弾輪が広がる、の一作用だけ |
| SWAP | 二つの車体像が同時に交換。大型ボスでは露出面が回る専用の見本 |
| 水/雲/反射 | 水切りの跳ね、雲で尾が縮む、板で向きが変わる。作用前後が一画面で見える |
| 風/噴流/磁場 | 流線に入った短い弾の軌跡が変わる。噴流は休→発生も見せる |
| 開閉橋 | 現在姿勢→次の仮姿→短い二つの射撃入口。キャラ退避先も仮表示 |

数字や文章をゼロにするのではなく、残り回数、短い英語名、無効状態の形は残す。映像だけを一度見逃したら理解不能、という設計にはしない。音が消えていても動作を読めるようにする。

## 6. 前回の弾道・角度の扱い

**前回弾道は消す。角度はリセットしない。** この組合せを採用する。

- 現在飛んでいる弾の軌跡は大きく見せ、着弾後約0.8秒で振り返れるよう残す。その後約0.6秒で尾からほどけて消す。遅くとも次の自分の操作開始前に消えている。
- 前回チャージのマーカー・数値も次の操作開始前に消す。旧案の常時残る「LAST」数値や薄い前回線は撤回。
- 角度は前回の車体相対角を維持。地形を移動すれば世界射角は変わる。完全リセットやランダムなずらしはしない。発射直後に反動を見せても、砲身は狙っていた角度へ戻る。
- 短い現在の照準線は残す。直近のギミック接触方向までで、着地点の正解予測にはしない。
- 初見面では敵・環境を少し固定して修正できる余地を作る。習得後は小移動や周期変化で照準を考え直させる。
- 同じ良いショットを再現して倒せること自体は否定しない。学んだ成果として残す。全ターン必ず違う角度を強制すると、成功から学ぶ意味が消える。

## 7. 代表的なプレイヤー視点ウォークスルー

以下は想定プレイの分岐。弾道が実際に通ることやプレイヤーが必ず気づくことを確認した記録ではない。

### Lv6：水切りの最初の成功

1. 初見：浅い弾が水面で跳ねる短い見本を見る。押す位置は既知、試す対象は水面一つ。
2. 1発目が短い。水面で跳ねた地点と減速した尾を見て、作用自体は成功したと分かる。
3. 軌跡が消えても砲身角は残る。敵は静止なので次は強さだけを増やす。
4. 命中で耐久3区分の一つが消える。あと2命中と分かる。
5. 失敗側：スキルを無駄に使っても基本砲で続行でき、手数が残る。必要なのは角度の初期化でなく、成功帯の広さ。

### Lv20：橋ボスの部位破壊

1. 慣れた人：上からコアを狙うか、橋下から砲台を壊すかを選ぶ。
2. 砲台へ1命中すると本体も1減る。安全を作る選択が遅延行動にならない。
3. 2命中で砲台破壊、危険範囲が減る。橋は予告通りの周期を続ける。
4. チャージ回収とコア攻撃を同じ弧へ乗せる。最後の攻撃で弱点なら2減り、一気に進む。
5. 旧案の「壊したら橋が不利に固定」は撤回。良い行動が不意の罰にならない。

### Lv42：気流が天井に当ててしまう

1. 初見：前面では上へ持ち上げて成功した。今回は同じ操作で天井にぶつかる可能性がある。
2. 開始見本で上昇と天井の関係を見せる。実射で外れても気流で上がった原因が見える。
3. 砲角を少し下げる、低い入口へ移る、の二つに選択を絞れる。
4. BLINKの行き先は全ギミックを消す万能高台ではなく、浅く気流へ入れる側面。
5. 攻略者は同じ気流の別用途を楽しめる。初見は狭いタイミングだけで詰まらない。

### Lv73：SWAPの初登場

1. 初見：BLINKを同時支給せず、二機が交換されるプレビューを見る。
2. 1発目を直撃できれば通常ダメージを与え、位置が入れ替わる。
3. 次は高台から撃ち下ろす。画面上の左右関係に合わせて機体が向き直す。
4. 外した場合も通常の斜路から攻撃できる。交換を成功させないとクリア不能にはしない。
5. 後の大型ボスで効果が変わる時は、新しい専用プレビューが必要。既知アイコンだから説明なしで意味が変わってよいわけではない。

### Lv100：最終戦

1. 18回の射撃と5耐久、敵10耐久を見る。段階は3/3/4で、何が残っているか分かる。
2. 門を壊す射撃も本体へ通る。途中で武器を試しても丸ごと無駄な削りにならない。
3. 弱点を狙うと2区分減り、難しい経路を使った報酬を感じる。
4. 部位破壊・雲変化・橋切替を順に見せ、同時に全部を追わせない。段階移行は手数消費なし。
5. 最終射撃で倒したら全弾と回収を処理して勝利。倒せなければ手数切れを明示し、見えないHP操作をしない。
6. 18回で厳しい場合は、まず大きな当たり判定と弱点に入る許容幅を直す。弱点への到達を狭くしたまま敵HPを削って帳尻を合わせない。

## 8. 全100面の個別修正メモ

この表は、v1.0の各面を点検して得たリスクと修正案。体験上のリスクは仮説であり、実測済みの不具合ではない。耐久・手数・弾道表示については全て前述の共通改訂が優先する。
