## 仕様管理の読み方

- **FIX**: ユーザーが最終承認または明示指示した内容。
- **現行設計**: 対話での採用ベースとなった内容。実装数値や例外の承認まで含まない。
- **提案**: 設計の手がかり。未承認として扱う。
- **未決定**: 補完で勝手に確定させない。

既存実装と異なる箇所は「ver.2の未来設計」であり、既存ゲームの現在の動作とは区別する。ファイルの存在は自動実装の命令ではない。
