# ARCLINE ver.2｜実装への引き継ぎ

## 現在地
ここに格納した内容は**次期設計**であり、公開済み1〜100面の実装ではない。旧ARCLINE現行版とビルド・データ・セーブを保護し、実装指示が出るまではゲームコードを変更しない。

## 実装前に行うこと
1. `ARCLINE/AGENTS.md`、現行ゲーム `ARCLINE/game/`、`game/runtime.json`、保存・テストを読む。
2. **ARCひとつ＋12ジョブ衣装**と旧10機を別のデータ概念に分ける。
3. `02_jobs/jobs.json` の名前、外観、技・必殺技の動きと由来を読み込む。数字や資源は入っていないので勝手に追加しない。
4. 旧キャラに由来するU02/U05/U06/U09の挙動を現行コードで検証してそのまま引き継ぐ。
5. 元のユーザーARC原画とFIXラインナップをゲームアセット化する場合、四輪・単眼・車体構造を同じキャラとして保持し、画像内の日本語は別途校正する。
6. 101面以降のステージデータは旧1〜100面と独立管理し、セーブや進行の移行は明示設計する。

## 将来のデータモデル例（**提案でありFIXではない**）
- `arcBase`: 4輪・シアン単眼・砲塔基部・共通通常技。
- `jobDefinition`: ID・名前・技能ID・必殺ID・ステータスパッケージID・ウェアID。
- `learnedJobs`: 習得中の最大3ジョブ。
- `availableActions`: 共通通常技1＋各ジョブ技3＋各必殺技3。
- `wearDefinition`: カラー・ウィング・砲身外装・装甲・アクセサリー。
- `stageDefinition`: 101面以降の地形・敵・目的・攻略代替経路。
- `progressSave`: 既存進行と新ARC進行を安全に識別する互換保存。移行方法未決定。
