# キャラクター企画図鑑

[HTML図鑑を開く](../index.html) ／ [全案記録](CHARACTER_PLANNING_ARCHIVE.md)

通番C0001〜C0231の全231記録を、自キャラ・敵キャラ・検討案の分類、名称、発想、形状、当時の評価、関連する版とともに表示します。画像がある227記録は、既存の81原画ファイル（敵の生成原画74枚、既存世界の参照5枚、ARC基本形態と12ジョブの原画2枚）へ対応します。画像をクリックすると、原画全体・掲載位置の拡大・前後の記録を確認できます。

カードの画像は原画を切り出して保存せず、HTML上の表示範囲を指定しています。原画のバイトは変更しません。名前や通番を変更せず、同じ名前の別原画も維持します。

## バージョンタブ

初期表示はVer.2です。大きな「Ver.2」「Ver.1」タブで切り替え、各タブの一覧・件数・分類・詳細の前後移動を分けます。Ver.2はARCと新しい敵・検討案の179記録、Ver.1は1〜100面の既存キャラ参照52記録です。全案記録の「1〜100面の参考企画」をVer.1として区分し、改訂番号r01/r02をゲームのバージョンと混同しません。

タブを切り替えると検索条件とページ送りをリセットします。「すべて表示」や絞り込み解除は選択中のバージョン内で行います。記録への直接リンクは該当するバージョンのタブを開きます。タブはキーボードの左右キー・Home・Endでも切り替えられます。

## 表示エリアと初期の並び順

プレイヤーと敵キャラは別エリアに表示します。Ver.2のプレイヤーはARC基本形態・12ジョブ、Ver.1のプレイヤーは旧自機の参照記録です。敵は個性敵キャラ、大ボス、中ボス、通常敵の順に並べ、未生成の発想は末尾に残します。「個性敵キャラ」は全案記録の「強敵の比較案」に対応する表示名です。通番・分類の原記録は保持します。

ページ送りはプレイヤーと敵キャラで独立し、敵の次ページへ進んでもプレイヤーの表示を維持します。各エリアは最大36記録ずつ表示し、同じ分類では通番順です。詳細の前後移動もプレイヤーと敵のエリア内で行います。ページ上部のリンクから各エリアへ移動できます。

## 主人公とジョブの原画

`assets/ARC_BASE_ORIGINAL_REFERENCE.png` と `assets/ARC_12_JOBS_FIXED_LINEUP.png` に保存された原画を、基本形態と12ジョブの13記録に紐付けています。各ジョブの説明には `02_jobs/jobs.json` の現行仕様も表示します。原画の誤植や旧説明が現行仕様を上書きすることはありません。

画像未生成の発想4記録は文章とともに明示します。既存案と無断で統合せず、原画を生成して補いません。

## 再生成

リポジトリルートで次を実行します。PythonとPillowを使います。

```sh
python3 ARCLINEver2/04_art/build_character_gallery.py
```

入力は全案記録と `02_jobs/jobs.json`、テンプレート `character-gallery.html.template`、参照する原画です。出力は `ARCLINEver2/index.html` 一つ。データ・CSS・JavaScriptをHTMLへ含め、表示にCDNやデータ取得APIを必要としません。画像はリポジトリ内の原画を相対参照します。

図鑑の検索・分類・状態フィルターはこのページ内の機能です。リポジトリ共通のカタログには同じ構成の入口カードを1件だけ追加しています。別コンテンツへの移動はカタログを経由します。
