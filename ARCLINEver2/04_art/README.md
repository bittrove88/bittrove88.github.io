## 仕様との関係

主人公の基本車体とジョブ技の仕様は、既存の主人公・ジョブ文書を参照します。敵キャラの機体をARCと同じ車体へ揃える設計にはしません。敵54枠と独立した比較案は制作した候補であり、登場面・性能・実装数は未確定です。

旧 `ARCLINE/design/` にあったVer.2専用資料93ファイルを、このディレクトリへ移動しました。原画はバイト単位で保持し、全案記録の通し番号も維持しています。1〜100面の共通参照原画は元の `ARCLINE/design/sheets/` に残し、相対リンクで参照します。旧入口のMarkdownには移転案内を置いています。

ここは設計・制作資料です。資料の存在や移動を、ゲームの実装・本番マージ・公開の完了として扱いません。
