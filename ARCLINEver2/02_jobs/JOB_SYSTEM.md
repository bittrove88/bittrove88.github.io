# 101面以降のジョブシステム

- 主人公アーク1機が12ジョブから3ジョブを習得する。
- 1ジョブは機体性能パッケージ＋ジョブ技1＋必殺技1を含む。弱点も含めたバランス設計とし、長所だけの切り出しはしない。
- **共通通常技1＋ジョブ技3＋必殺技3＝7技**。習得済み技の切替は自由な方向。具体UI、使用回数、必要資源、クールダウン等は未決定。
- テレポートを標準能力として全ジョブへ恒久付与しない。専用技なしでもステージに攻略経路を設ける。

## 12ジョブ技
| 分類 | 技 | 操作／効果 |
|---|---|---|
| 位置 | 着弾テレポート | 砲撃の着弾位置へ自機を転移 |
| 位置 | 近距離テレポート | 近距離の指定地点へ転移 |
| 位置 | 位置交換 | 指定敵と自機の位置を交換 |
| 位置 | 浮遊 | 上下にのみ浮上／下降。水平移動を足さない |
| 防御 | バリア | 被ダメージを一定量吸収 |
| 防御 | 反撃 | 敵攻撃に備え、条件成立時に反撃弾を自動発射 |
| 回復 | HP再生 | 自機HPを**一部**回復。全回復しない |
| 付加弾 | 毒弾 | 通常射撃に継続毒ダメージを追加 |
| 付加弾 | HP吸収弾 | 通常射撃の与ダメージの一部をHPへ還元 |
| 付加弾 | 弱体化弾 | 通常射撃命中時に敵能力低下 |
| 付加弾 | 強化弾 | 通常射撃の**敵命中時**に自機の次回攻撃を強化 |
| 付加弾 | 必殺技奪取弾 | 通常射撃の敵命中時に敵必殺技を直接奪う。印・クリティカル・蓄積は不要 |

5種の追加効果弾はすべて**標準弾道／通常ダメージ**を維持する。分身・召喚・ナパームは必殺技でありジョブ技へ戻さない。

## 必殺技
射撃や動きが各ジョブで固有のスペクタクル攻撃（連続爆破・集中砲撃・分身・重力落下・衝撃波・貫通・追尾・焼夷・亡霊包囲・散開収束・旋回掃射・増幅反射）。単に数字の異なるダメージ球にしない。既存4技U02/U05/U06/U09は元挙動維持。

## 不採用／未決定
凍結ジョブ技・マーキング・エネルギー蓄積は不採用。凍結を加える必殺技は未決定。属性システム、7技UI、技・状態異常の数値、奪取技の保持期間・使用回数、各ジョブの能力補正、ジョブ取得条件、切替タイミングは未決定。
